Instala el [plugin de Mintlify](https://cursor.com/marketplace/mintlify) desde Cursor Marketplace. El plugin agrega el Admin MCP, el [MCP de búsqueda](/es/ai/model-context-protocol) para la documentación de Mintlify, y el skill y las reglas de redacción de Mintlify. Completa el inicio de sesión OAuth cuando Cursor se conecte por primera vez al Admin MCP.

Para agregar solo el Admin MCP:

1. Abre la paleta de comandos con <kbd>Cmd</kbd> \+ <kbd>Shift</kbd> \+ <kbd>P</kbd> (<kbd>Ctrl</kbd> \+ <kbd>Shift</kbd> \+ <kbd>P</kbd> en Windows).
2. Busca **Open MCP settings** y haz clic en **Add custom MCP**.
3. En `mcp.json`, agrega el Admin MCP:

```json
{
  "mcpServers": {
    "mintlify-admin": {
      "url": "https://mcp.mintlify.com"
    }
  }
}
```

4. Recarga Cursor y completa el inicio de sesión OAuth cuando se te solicite.
