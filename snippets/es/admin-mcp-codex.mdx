Agrega el servidor Admin MCP con la CLI de Codex:

```bash
codex mcp add mintlify --url https://mcp.mintlify.com
```

Codex abre una ventana del navegador para completar el inicio de sesión OAuth. Tras autenticarte, Codex reutiliza la sesión en las llamadas posteriores. Si el inicio de sesión no comienza, ejecuta `codex mcp login mintlify`.

El comando agrega el servidor a tu configuración de Codex en `~/.codex/config.toml`. Para editar el archivo de configuración directamente, agrega:

```toml
[mcp_servers.mintlify]
url = "https://mcp.mintlify.com"
```

Consulta la [documentación de Codex MCP](https://developers.openai.com/codex/mcp) para más detalles.
