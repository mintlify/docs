Agrega el servidor Admin MCP a la configuración de tu CLI de Codex en `~/.codex/config.toml`:

```toml
[mcp_servers.mintlify]
url = "https://mcp.mintlify.com"
```

En el primer uso, Codex abre una ventana del navegador para completar el inicio de sesión OAuth. Tras autenticarte, Codex reutiliza la sesión en las llamadas posteriores.

Consulta la [documentación de Codex MCP](https://developers.openai.com/codex/mcp) para más detalles.
