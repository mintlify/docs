Install the [Mintlify plugin](https://cursor.com/marketplace/mintlify) from the Cursor Marketplace. The plugin adds the admin MCP, the [search MCP](/ai/model-context-protocol) for the Mintlify documentation, and the Mintlify skill and writing rules. Complete the OAuth login when Cursor first connects to the admin MCP.

To add only the admin MCP instead:

1. Open the command palette with <kbd>Cmd</kbd> \+ <kbd>Shift</kbd> \+ <kbd>P</kbd> (<kbd>Ctrl</kbd> \+ <kbd>Shift</kbd> \+ <kbd>P</kbd> on Windows).
2. Search for **Open MCP settings** and click **Add custom MCP**.
3. In `mcp.json`, add the admin MCP:

```json
{
  "mcpServers": {
    "mintlify-admin": {
      "url": "https://mcp.mintlify.com"
    }
  }
}
```

4. Reload Cursor and complete the OAuth login when prompted.
