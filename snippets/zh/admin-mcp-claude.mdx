<Steps>
  <Step title="添加 Mintlify 连接器">
    1. 在 Claude 连接器目录中打开 [Mintlify 连接器](https://claude.com/marketplace/connectors/mintlify)。
    2. 点击 **Connect** 并完成 OAuth 登录。

    如需改为将其添加为自定义连接器，请前往 Claude 设置中的 [Connectors](https://claude.ai/settings/connectors) 页面，点击 **Add custom connector**，然后输入 URL `https://mcp.mintlify.com`。
  </Step>
  <Step title="在聊天中使用 MCP">
    点击附件按钮 (加号图标)，然后选择 Mintlify 连接器。Claude 现在可以在回答你的提示时调用 Mintlify 管理员 MCP 工具。
  </Step>
</Steps>
