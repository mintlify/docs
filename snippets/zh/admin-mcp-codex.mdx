使用 Codex CLI 添加管理员 MCP 服务器：

```bash
codex mcp add mintlify --url https://mcp.mintlify.com
```

Codex 会打开一个浏览器窗口以完成 OAuth 登录。完成认证后，Codex 会在后续调用中复用该会话。如果登录流程没有启动，请运行 `codex mcp login mintlify`。

该命令会将服务器添加到 `~/.codex/config.toml` 中的 Codex 配置里。如果你想直接编辑配置文件，请添加：

```toml
[mcp_servers.mintlify]
url = "https://mcp.mintlify.com"
```

详情请参见 [Codex MCP 文档](https://developers.openai.com/codex/mcp)。
