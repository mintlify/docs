从 Cursor Marketplace 安装 [Mintlify 插件](https://cursor.com/marketplace/mintlify)。该插件会添加管理员 MCP、用于 Mintlify 文档的[搜索 MCP](/zh/ai/model-context-protocol)，以及 Mintlify skill 和写作规则。当 Cursor 首次连接到管理员 MCP 时，请完成 OAuth 登录。

如果只想添加管理员 MCP：

1. 使用 <kbd>Cmd</kbd> \+ <kbd>Shift</kbd> \+ <kbd>P</kbd> (Windows 上为 <kbd>Ctrl</kbd> \+ <kbd>Shift</kbd> \+ <kbd>P</kbd>) 打开命令面板。
2. 搜索 **Open MCP settings** 并点击 **Add custom MCP**。
3. 在 `mcp.json` 中添加管理员 MCP：

```json
{
  "mcpServers": {
    "mintlify-admin": {
      "url": "https://mcp.mintlify.com"
    }
  }
}
```

4. 重新加载 Cursor，并在出现提示时完成 OAuth 登录。
