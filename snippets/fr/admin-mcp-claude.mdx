<Steps>
  <Step title="Ajouter le connecteur Mintlify">
    1. Ouvrez le [connecteur Mintlify](https://claude.com/marketplace/connectors/mintlify) dans l'annuaire des connecteurs de Claude.
    2. Cliquez sur **Connect** et terminez la connexion OAuth.

    Pour l'ajouter plutôt comme connecteur personnalisé, accédez à la page [Connectors](https://claude.ai/settings/connectors) dans les paramètres de Claude, cliquez sur **Add custom connector** et saisissez l'URL `https://mcp.mintlify.com`.
  </Step>
  <Step title="Utiliser le MCP dans une conversation">
    Cliquez sur le bouton des pièces jointes (l'icône plus), puis sélectionnez le connecteur Mintlify. Claude peut maintenant appeler les outils Mintlify Admin MCP tout en répondant à votre prompt.
  </Step>
</Steps>
