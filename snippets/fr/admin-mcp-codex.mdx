Ajoutez le serveur Admin MCP avec la CLI Codex :

```bash
codex mcp add mintlify-admin --url https://mcp.mintlify.com
```

Codex ouvre une fenêtre de navigateur pour finaliser la connexion OAuth. Après authentification, Codex réutilise la session pour les appels suivants. Si la connexion ne démarre pas, exécutez `codex mcp login mintlify-admin`.

La commande ajoute le serveur à votre configuration Codex dans `~/.codex/config.toml`. Pour modifier directement le fichier de configuration, ajoutez :

```toml
[mcp_servers.mintlify-admin]
url = "https://mcp.mintlify.com"
```

Consultez la [documentation Codex MCP](https://developers.openai.com/codex/mcp) pour plus de détails.
