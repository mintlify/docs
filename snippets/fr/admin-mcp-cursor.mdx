Installez le [plugin Mintlify](https://cursor.com/marketplace/mintlify) depuis le Cursor Marketplace. Le plugin ajoute l'Admin MCP, le [MCP de recherche](/fr/ai/model-context-protocol) pour la documentation Mintlify, ainsi que le skill et les règles de rédaction Mintlify. Terminez la connexion OAuth lorsque Cursor se connecte pour la première fois à l'Admin MCP.

Pour ajouter uniquement l'Admin MCP :

1. Ouvrez la palette de commandes avec <kbd>Cmd</kbd> \+ <kbd>Shift</kbd> \+ <kbd>P</kbd> (<kbd>Ctrl</kbd> \+ <kbd>Shift</kbd> \+ <kbd>P</kbd> sous Windows).
2. Recherchez **Open MCP settings** et cliquez sur **Add custom MCP**.
3. Dans `mcp.json`, ajoutez l'Admin MCP :

```json
{
  "mcpServers": {
    "mintlify-admin": {
      "url": "https://mcp.mintlify.com"
    }
  }
}
```

4. Rechargez Cursor et terminez la connexion OAuth lorsque vous y êtes invité.
