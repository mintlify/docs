## Create your knowledge base

<Tabs>
  <Tab title="New to Mintlify">
    <Steps>
      <Step title="Sign up for Mintlify">
        Go to [app.mintlify.com/signup?product=base](https://app.mintlify.com/signup?product=base) and create your account. Then click **Get started**.
      </Step>
      <Step title="Choose how you'll make updates">
        Select how you plan to make updates: **Code editor**, **Web editor**, or **MCP**. This selection is only for the initial setup. You can use every method in your knowledge base later.
      </Step>
      <Step title="Create the project">
        Click **Create project**. Your knowledge base opens in the editor with a starter page.
      </Step>
    </Steps>
  </Tab>
  <Tab title="Existing organization">
    <Steps>
      <Step title="Create a knowledge base from the project switcher in your dashboard">
        1. In your [dashboard](https://app.mintlify.com/), click the project switcher at the top of the left sidebar.
        2. Click <Icon icon="plus" /> **New project**.
        3. Select **Knowledge base**, then click **Continue**.

        Your knowledge base is part of the same organization as your other projects.
      </Step>
      <Step title="Choose how you'll make updates">
        Select how you plan to make updates: **Code editor**, **Web editor**, or **MCP**. This selection is only for the initial setup. You can use every method in your knowledge base later.
      </Step>
      <Step title="Create the project">
        Click **Create project**. Your knowledge base opens in the editor with a starter page.
      </Step>
    </Steps>
  </Tab>
</Tabs>

<Check>
  Your knowledge base appears in the project switcher in your dashboard. The editor sidebar shows a setup checklist with your next steps.
</Check>

## Add pages

Create pages for your team in the **Navigation** section of the sidebar.

Click the <Icon icon="plus" /> plus button beside the **Navigation** header and select **New page**. To bring in existing Markdown files, drag them from your computer onto the sidebar.

When you make changes to pages in **Navigation**, Mintlify commits them to your knowledge base's repository automatically. To draft privately first, create a page in the **Personal** section and move it to **Navigation** when you want it to be available to your team.

For more information on editing pages, see [Create and edit pages](/editor/pages).

## Invite your team

Members of your organization can access your knowledge base. To add teammates, invite them from your [Members](https://app.mintlify.com/settings/organization/members) settings.

## Connect your AI tools

Connect Claude, ChatGPT, Cursor, or another AI tool to your knowledge base so it can search, read, and update your pages.

1. In your dashboard, open your knowledge base and go to the [MCP](https://app.mintlify.com/products/mcp) settings.
2. Under **Connect**, select your AI tool and follow the prompts to sign in.

When an AI tool edits your knowledge base, it commits changes the same way the editor does. For the tools available and example prompts, see [Admin MCP](/ai/mintlify-mcp).

## (Optional) Create from a local folder

If you have an existing folder of Markdown files, you can publish it to a new knowledge base from the command line using the Mint CLI.

<Steps>
  <Step title="Provision the knowledge base">
    Run the following command from any directory, replacing `<name>` with your chosen subdomain:

    ```bash
    mint deploy --knowledge-base --subdomain <name>
    ```

    The output includes a clone command with a short-lived write token, and the editor link for your new knowledge base.
  </Step>

  <Step title="Clone the hosted repository">
    Copy and run the clone command from the previous step's output. It looks like this:

    ```bash
    git -c http.<REPOSITORY_URL>.extraHeader="Authorization: Bearer <WRITE_TOKEN>" clone <REPOSITORY_URL> <name>
    ```

    This creates a `<name>` directory containing the hosted repository. The write token in the clone command expires; run `mint deploy --knowledge-base` again from the same directory to get a fresh one if needed.
  </Step>

  <Step title="Copy your content and commit">
    Copy your Markdown and MDX files into the cloned directory. Place `docs.json` and your pages at the repository root.

    Then commit your changes:

    ```bash
    cd <name>
    git add .
    git commit -m "Initial content"
    ```
  </Step>

  <Step title="Push to the knowledge base">
    Run the following command from the directory where you ran `mint deploy` (not from inside the clone):

    ```bash
    mint deploy --knowledge-base --push <name>
    ```

    This rebases your commits onto the latest main branch of the hosted repository and pushes them. Do not run `git push` directly.

    If a rebase conflict occurs, resolve it, run `git rebase --continue` inside the clone, then rerun this command.
  </Step>

  <Step title="Claim the knowledge base">
    The knowledge base you provisioned isn't in your Mintlify account yet. The `mint deploy` output shows when it expires. If nobody claims it by then, Mintlify deletes it.

    After your content is pushed, run [`mint claim`](/cli/commands#mint-claim) from the directory where you ran `mint deploy`:

    ```bash
    mint claim
    ```

    Open the claim link it prints, sign in, and click **Confirm**. The knowledge base moves into your account.
  </Step>
</Steps>

After the claim, open your knowledge base at the editor link from the first step. The CLI can no longer push to it, so edit it in the editor or [connect your own repository](#optional-connect-your-own-repository).

## (Optional) Connect your own repository

Your knowledge base starts with a repository that Mintlify hosts. To edit your knowledge base locally or to use [Autopilot](/autopilot), connect a repository from your [Git settings](https://app.mintlify.com/settings/project/git-settings). Commits pushed to the connected repository update your knowledge base.

## (Optional) Add a project icon

Add an icon to tell your knowledge base apart from your other projects in the project switcher. To add an icon, you need a [role](/dashboard/roles) that can manage site and workspace settings.

1. In your dashboard, open your knowledge base and go to the [Project](https://app.mintlify.com/settings/project/site) settings.
2. In the **Icon** row, click **Upload** and select a PNG, JPEG, WebP, or SVG file up to 4 MB.

To change the icon later, click **Replace**. To remove it, click the <Icon icon="trash" /> delete button next to **Replace**.
