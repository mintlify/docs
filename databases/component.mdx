Use `<Database />` to render a database on a page. The component reads the columns for headers and types, and the records for content, so a page stays current without a redeploy.

```mdx
<Database name="app_versions" />
```

## Props

<ParamField path="name" type="string" required>
  The database slug.
</ParamField>
<ParamField path="columns" type="string[]">
  Column names to show, in order. Defaults to every column in display order.
</ParamField>
<ParamField path="where" type="object">
  Equality filters keyed by column name, for example `{{ Channel: "stable" }}`.
</ParamField>
<ParamField path="sort" type="string">
  A column name, optionally followed by `:asc` or `:desc`. Defaults to creation order.
</ParamField>
<ParamField path="limit" type="number" default="50">
  Records per page, up to 100. Pagination controls appear when there are more.
</ParamField>
<ParamField path="search" type="boolean" default="false">
  Show a search box that filters the visible records.
</ParamField>

```mdx releases/studio.mdx
<Database
  name="app_versions"
  columns={["App", "Version", "Release date", "Download URL"]}
  where={{ App: "Studio", Channel: "stable" }}
  sort="Release date:desc"
  search
/>
```

Columns render by type: dates in the reader's locale, URLs as links, booleans as checks, and `select` values as badges.

## A page for every record

Put a template in the database's folder using the record page convention and every record gets its own URL.

```mdx releases/[Version].mdx
---
title: "{{ row.App }} {{ row.Version }}"
---

<Badge>{{ row.Channel }}</Badge>

Downloads: {{ row.Downloads }}
```

Values are available as `row.<columnName>`. The bracketed segment in the file name chooses the column that becomes the URL slug, so this template produces `/releases/4.2.0`, `/releases/4.3.0-beta.1`, and so on.

## Reading records in snippets

For layouts the component does not cover, read records directly in a [snippet](/create/reusable-snippets) with the `mint.db` helper.

```mdx snippets/latest-releases.mdx
export const LatestReleases = async () => {
  const { rows } = await mint.db("app_versions").find({
    where: { Channel: "stable" },
    sort: "Release date:desc",
    limit: 5,
  });
  return (
    <ul>
      {rows.map((row) => <li key={row.id}>{row.App} {row.Version}</li>)}
    </ul>
  );
};
```

`find`, `get`, and `count` are read-only. Writes go through the [REST API](/databases/api) or the dashboard.
