<Info>
  Databases are in early access and must be enabled for your project. Contact your Mintlify account team to turn it on.
</Info>

This quickstart builds an `App versions` database that a release pipeline keeps current: one record per app, version, and channel.

## Prerequisites

- A project with Databases enabled.
- An [admin API key](https://app.mintlify.com/settings/organization/api-keys) with the `write` scope. Admin API keys begin with `mint_` and are server-side secrets.
- Your project ID, from the same page.

Set them in your shell:

```bash
export MINT_API_KEY="mint_..."
export BASE="https://api.mintlify.com/api/external/v1/databases/$PROJECT_ID"
```

<Steps>
  <Step title="Create a database">
    <CodeGroup>
    ```bash curl
    curl -X POST "$BASE" \
      -H "Authorization: Bearer $MINT_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{ "name": "App versions" }'
    ```
    ```json Response
    {
      "id": "8f14e45f-ceea-467f-a0e6-4b7ab2a5f2a1",
      "slug": "app_versions",
      "name": "App versions",
      "columns": [],
      "rowCount": 0,
      "cursor": "6e306bde-6324-4853-9188-ad08415d8a2f:1",
      "createdAt": "2026-10-03T12:00:00.000Z",
      "updatedAt": "2026-10-03T12:00:00.000Z"
    }
    ```
    </CodeGroup>

    The slug `app_versions` is derived from the name. Use it in every request from here on. Renaming the database later does not change it.
  </Step>

  <Step title="Add columns">
    Mark the columns you filter or sort on as `indexed`, and the ones every record must have as `required`.

    ```bash curl
    curl -X POST "$BASE/app_versions/columns" \
      -H "Authorization: Bearer $MINT_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{
        "columns": [
          { "name": "App", "type": "text", "required": true, "indexed": true },
          { "name": "Version", "type": "text", "required": true },
          { "name": "Channel", "type": "select", "options": ["stable", "beta"], "strict": true, "indexed": true },
          { "name": "Platforms", "type": "multi_select", "options": ["macOS", "Windows", "Linux"] },
          { "name": "Release date", "type": "date", "indexed": true },
          { "name": "Download URL", "type": "url" },
          { "name": "Downloads", "type": "number" }
        ]
      }'
    ```

    The response is the database with its new columns. `Channel` is strict, so a typo such as `stabel` is rejected. `Platforms` is not, so writing a new platform such as `iOS` adds it as an option.
  </Step>

  <Step title="Write records">
    Upsert sends up to 500 records in one atomic request. Key `fields` by column name, and send an `Idempotency-Key` so a retried request is not applied twice.

    <CodeGroup>
    ```bash curl
    curl -X PUT "$BASE/app_versions/records" \
      -H "Authorization: Bearer $MINT_API_KEY" \
      -H "Content-Type: application/json" \
      -H "Idempotency-Key: release-2026-10-03" \
      -d '{
        "records": [
          {
            "fields": {
              "App": "Studio",
              "Version": "4.2.0",
              "Channel": "stable",
              "Platforms": ["macOS", "Windows"],
              "Release date": "2026-10-01",
              "Download URL": "https://downloads.example.com/studio/4.2.0",
              "Downloads": 1840
            }
          },
          {
            "fields": {
              "App": "Studio",
              "Version": "4.3.0-beta.1",
              "Channel": "beta",
              "Platforms": ["macOS"],
              "Release date": "2026-10-03"
            }
          }
        ]
      }'
    ```
    ```json Response
    {
      "records": [
        {
          "id": "1b9d6bcd-bbfd-4b2d-9b5d-ab8dfbbd4bed",
          "version": 1,
          "fields": {
            "App": "Studio",
            "Version": "4.2.0",
            "Channel": "stable",
            "Platforms": ["macOS", "Windows"],
            "Release date": "2026-10-01",
            "Download URL": "https://downloads.example.com/studio/4.2.0",
            "Downloads": 1840
          },
          "createdAt": "2026-10-03T12:01:00.000Z",
          "updatedAt": "2026-10-03T12:01:00.000Z",
          "createdBy": "key:key_3ZbQ9mXk",
          "updatedBy": "key:key_3ZbQ9mXk"
        },
        {
          "id": "6fa459ea-ee8a-4ca4-894e-db77e160355e",
          "version": 1,
          "fields": {
            "App": "Studio",
            "Version": "4.3.0-beta.1",
            "Channel": "beta",
            "Platforms": ["macOS"],
            "Release date": "2026-10-03"
          },
          "createdAt": "2026-10-03T12:01:00.000Z",
          "updatedAt": "2026-10-03T12:01:00.000Z",
          "createdBy": "key:key_3ZbQ9mXk",
          "updatedBy": "key:key_3ZbQ9mXk"
        }

      "updated": 0
    }
    ```
    </CodeGroup>

    <Check>
      Every write is validated against the columns. A wrong type, an unknown column name, or a missing required value returns `422` with one message per field, and nothing is written.
    </Check>
  </Step>

  <Step title="Query records">
    Find stable releases for macOS, newest first, and count them.

    ```bash curl
    curl -X POST "$BASE/app_versions/records/query" \
      -H "Authorization: Bearer $MINT_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{
        "where": [
          { "column": "Channel", "op": "eq", "value": "stable" },
          { "column": "Platforms", "op": "contains", "value": "macOS" }
        ],
        "sort": { "column": "Release date", "direction": "desc" },
        "count": true
      }'
    ```

    The response has `records`, `nextCursor` for the next page, and `total`.
  </Step>

  <Step title="Ask a question with SQL">
    For aggregates, use a read-only SQL query.

    <CodeGroup>
    ```bash curl
    curl -X POST "$BASE/app_versions/sql" \
      -H "Authorization: Bearer $MINT_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{
        "query": "SELECT \"Channel\", count(*) AS releases, sum(\"Downloads\") AS downloads FROM records WHERE \"Release date\" >= ? GROUP BY \"Channel\"",
        "params": ["2026-01-01"]
      }'
    ```
    ```json Response
    {
      "columns": ["Channel", "releases", "downloads"],
      "rows": [
        ["beta", 1, null],
        ["stable", 1, 1840]
      ],
      "truncated": false
    }
    ```
    </CodeGroup>
  </Step>
</Steps>
