Mintlify does not have a direct "import ZIP" feature. Mintlify builds your site from files in a Git repository, so migrating from a ZIP export means converting the exported files into Markdown or MDX pages in your docs repo. The right path depends on which platform produced the ZIP.

## Convert the export with `mint migrate`

Unzip the export into a folder, then run `mint migrate` from a new, empty directory and point your coding agent at the unzipped files. Pass `--from` if the ZIP came from a supported platform, such as `document360` or `readme`:

```bash
mint migrate --agent claude --from document360
```

ReadMe ZIP exports link to hosted images instead of including them, so the agent downloads those separately. See [Migrate to Mintlify](/migration) for every supported platform.

## Exporting your Mintlify docs as a ZIP

<Info>
  Offline exports require an [Enterprise plan](https://mintlify.com/pricing?ref=offline-export).
</Info>

If you want the opposite direction, a ZIP archive of your published Mintlify docs for offline viewing or private distribution, use `mint export`. See [Offline export](/deploy/export).
