If you paste the authorization code from `mint login` and the CLI exits with:

> keytar is required for credential storage but is not installed. Install it with: npm install keytar

your installed Mintlify CLI is trying to use `keytar`, a native Node module for OS keychain access. Current versions of the CLI do not depend on `keytar`. They save credentials to `~/.config/mintlify/config.json` instead. See [`mint login`](/cli/commands#mint-login).

## Fix the error

Update the CLI to the latest version:

<CodeGroup>
  ```bash npm
  npm i -g mint@latest
  ```

  ```bash pnpm
  pnpm add -g mint@latest
  ```
</CodeGroup>

Then run `mint login` again.

If the error persists, you likely have both the legacy `mintlify` package and the current `mint` package installed. Remove `mintlify` and reinstall `mint`:

```bash
npm uninstall -g mintlify
npm cache clean --force
npm i -g mint
```

See [Install the CLI](/cli/install) for the full install and troubleshooting reference.
