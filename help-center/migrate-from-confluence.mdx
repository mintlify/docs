---
title: "Migrate from Confluence to Mintlify"
description: "Use mint migrate and a coding agent to convert Confluence content into a Mintlify project."
---

Run `mint migrate --from confluence` from a new, empty directory. It prints instructions your coding agent follows to convert your Confluence spaces into MDX pages and `docs.json` navigation:

```bash
mint migrate --agent claude --from confluence
```

The agent works from a Confluence export or the published site. See [Export content from Confluence Cloud](https://support.atlassian.com/confluence-cloud/docs/export-content-to-word-pdf-html-and-xml/) for export formats, and [Migrate to Mintlify](/migration) for the full workflow.

## Use Confluence as context for the Mintlify agent

Separately from migration, the Mintlify agent can connect to Confluence as a context source. This lets the agent read pages in your Confluence spaces when drafting or updating docs. Automations can also trigger when someone creates a Confluence page or adds content to a space. See [Integrations for the agent and automations](/automations/integrations).
