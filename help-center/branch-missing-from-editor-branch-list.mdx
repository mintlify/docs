If a branch that exists in your repository doesn't appear in the web editor's branch dropdown, the branch is not deleted. The dropdown intentionally lists only:

- Branches created in the web editor.
- Branches with an open pull request or merge request targeting your deployment branch.

Branches pushed directly to GitHub, GitLab, or Bitbucket without an open pull request don't appear in the list. Your work on those branches is safe in your repository. You can confirm this by viewing the branch in your Git provider.

## Open a branch that isn't listed

Use either approach:

- **Open a pull request or merge request** for the branch against your deployment branch in your Git provider. The branch then appears in the editor's branch dropdown.
- **Edit the editor URL.** Open any branch in the editor, then replace the branch name in your browser's URL with the name of the branch you want. The editor loads that branch directly.

For more on creating and switching branches, see [Work with branches](/guides/branches).
