The `title` prop of the [Accordion](/components/accordions), [Card](/components/cards), [Step](/components/steps), [Tab](/components/tabs), [Tile](/components/tiles), and [Color.Row](/components/color) components supports a bounded set of inline Markdown. Write the Markdown syntax directly in the `title` string and Mintlify renders it as formatted text.

## Supported formatting

- Bold: `**text**`
- Italic: `*text*` or `_text_`
- Strikethrough: `~~text~~`
- Inline code: `` `text` ``
- Links: `[text](https://example.com)`

```mdx Example
<AccordionGroup>
  <Accordion title="Edit the `docs.json` file">
    Inline code renders in the accordion title.
  </Accordion>
  <Accordion title="**Required:** set your API key">
    Bold text renders in the accordion title.
  </Accordion>
</AccordionGroup>
```

## Limitations

- Links in titles render as styled label text, not clickable links. This avoids nesting a link inside an already interactive title.
- Block-level Markdown, images, raw HTML, and MDX components in titles render as literal text.
- Underline is not supported.

## How formatted titles affect IDs and navigation

Anchor IDs, table of contents entries, and tab synchronization use the plain text of the title with formatting characters removed. For example, a tab titled `**npm**` synchronizes with a tab titled `npm` because both resolve to the same plain text.
