The Mintlify dashboard opens to **Home**, which is the web editor, by default. You can choose a different starting page so the dashboard opens where you work most often, such as **Analytics** or **Activity**.

Your starting page is a personal preference. It applies to every project you open and does not change what other members of your organization see.

## Set your starting page

1. In the dashboard, go to [**Settings** > **Profile**](https://app.mintlify.com/settings/account).
2. In the **Preferences** section, select a page from the **Starting page** menu:
   - **Home**
   - **Activity**
   - **Analytics**
   - **Automations**

Mintlify saves your choice immediately. If the save fails, the dashboard shows an error and keeps your previous choice.

## When your starting page applies

Mintlify uses your starting page when you open the dashboard or open a project root, such as `https://app.mintlify.com/{organization}/{project}`. Opening a project root takes you to the starting page of that project.

Links to a specific page, document, or branch still open that destination. Selecting **Home** in the sidebar always opens the editor.

If your starting page isn't available for a project, the dashboard opens **Home** instead. If the editor isn't available either, the dashboard opens **Activity**.
