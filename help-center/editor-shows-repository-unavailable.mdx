The web editor shows a **Repository unavailable** notice when Mintlify can't reach the repository or deployment branch that your documentation builds from. Refreshing the page doesn't fix it. You need to restore access or update your Git settings.

## Common causes

- The repository was deleted, renamed, or moved to another owner.
- The repository was removed from the Mintlify GitHub App's selected repositories.
- The deployment branch, such as `main`, was deleted or renamed.

## Restore access

1. Select **Open Git settings** in the notice to open the [Git settings](https://app.mintlify.com/settings/project/git-settings) page of your dashboard.
2. Confirm that the organization, repository, and branch match where your docs live now. Update them if the repository or branch changed.
3. If you use GitHub, confirm the Mintlify GitHub App still has access to the repository. See [Manage repository access](/deploy/github#manage-repository-access).
4. Return to the editor and select **Reload editor**.

For more on connecting your repository, see [GitHub](/deploy/github) or [GitLab](/deploy/gitlab).
