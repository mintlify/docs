The agent is an AI tool that writes and updates your documentation. It reads your docs, connected repositories, and the web, checks that your site still builds, then opens a pull request for your team to review or commits directly to your deployment branch, depending on your [review process setting](/agent/configure#choose-how-the-agent-publishes-changes).

## What you can do with the agent

- Write new content from prompts, pull requests, Slack threads, or file attachments.
- Update existing documentation for new features or API changes.
- Add images, diagrams, and other files from Slack attachments to your docs.
- Describe images in your docs, connected repositories, and attachments, write alt text, or check that screenshots match your content.
- Revise code examples and API references across your docs.
- Reference source code from any repository that has the Mintlify GitHub App installed.
- Address code review feedback on documentation pull requests.
- Answer questions about your docs and technical writing topics.
- Capture knowledge from Slack conversations and pull requests before it gets lost.

## Use AI tools alongside the agent

The agent works asynchronously through pull requests, but you can also use AI coding tools like Cursor or Claude Code locally for fast, iterative edits. Install the Mintlify [skill](/ai/skillmd) and connect the [Model Context Protocol (MCP) server](/ai/model-context-protocol) so your editor has the same context the agent uses.

To let an external agent edit your content directly through MCP tool calls, connect it to the [Mintlify MCP server](/ai/mintlify-mcp).
