当你将更改推送到已连接的存储库时，你的文档站点会自动部署。如果你的存储库位于 GitHub 上，你必须安装并连接 Mintlify GitHub 应用。如果你的存储库位于 GitLab 或 Bitbucket 上，请参阅 [GitLab](/zh/deploy/gitlab) 或 [Bitbucket](/zh/deploy/bitbucket) 了解连接设置。

如果你的最新更改没有显示在在线站点上，且你的存储库位于 GitHub 上，首先检查拥有你文档存储库的 GitHub 账户或组织是否已安装该 GitHub 应用。参见 [GitHub 故障排查](/zh/deploy/github#troubleshooting) 以获取更多信息。

如果你的存储库已连接，但更改仍未部署，请在控制台手动触发一次部署。

<div id="manually-trigger-a-deployment">
  ## 手动触发部署
</div>

<Steps>
  <Step title="确认你的最新提交已成功。">
    检查你的最新提交是否已出现在文档存储库中，并确认未出现任何错误。你可以在[部署历史](#view-deployment-history)中确认该提交是否已成功构建。
  </Step>

  <Step title="手动触发部署。">
    前往你的[控制台](https://dashboard.mintlify.com)，点击“部署”按钮。

    <Frame>
      <img src="/images/deployments/manual-update-light.png" alt="用橙色矩形标注的“手动更新”按钮。" className="block dark:hidden" />

      <img src="/images/deployments/manual-update-dark.png" alt="用橙色矩形标注的“手动更新”按钮。" className="hidden dark:block" />
    </Frame>
  </Step>
</Steps>

<div id="view-deployment-history">
  ## 查看部署历史
</div>

前往控制台中的[活动](https://app.mintlify.com/activity)页面，查看你的部署历史并确认每次构建是否成功。在 **Live** 标签页中，点击某次构建即可展开并查看详细信息，包括提交消息和作者。

<div id="roll-back-a-deployment">
  ## 回滚部署
</div>

如果有变更进入在线站点、需要立即移除，请直接服务之前的一次成功构建，而不是回退提交并等待新的构建。参见[回滚](/zh/deploy/rollbacks)。

<div id="delete-a-deployment">
  ## 删除部署
</div>

你可以在控制台设置中的 [Danger zone](https://dashboard.mintlify.com/settings/organization/danger-zone) 永久删除某个部署。该操作不可撤销，将移除所有部署数据，包括任何关联的预览部署。

<Steps>
  <Step title="导航到 Danger zone。">
    前往控制台设置页面中的 [Danger zone](https://dashboard.mintlify.com/settings/organization/danger-zone)。
  </Step>
  <Step title="删除部署。">
    1. 在 **Delete my deployment** 区域中填写删除原因。
    2. 点击删除按钮，并确认你要删除该部署。
  </Step>
</Steps>

<Warning>
  删除部署是永久性的且无法撤销。如果你有有效订阅，你将在当前计费周期内对剩余未使用时间获得按比例折算的抵扣额度。
</Warning>

如果你有多个部署，删除后你会被重定向到另一个部署。如果你删除了唯一的部署，你会被重定向到 Mintlify 首页。当你删除某个部署时，组织管理员会收到一封确认删除的电子邮件通知。
