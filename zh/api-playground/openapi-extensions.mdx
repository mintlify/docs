Mintlify 会读取 OpenAPI 规范中的以下扩展和字段。它不读取 `x-tagGroups`。要将规范中的其他字段显示为参数上的标签，请使用[参数标记](/zh/api-playground/customize-endpoint-pages#add-parameter-pills)。

要为你不直接编辑的规范添加扩展，请使用 [Overlay](/zh/api-playground/overlays)。

<div id="operation-extensions">
  ## 操作扩展
</div>

将这些扩展添加到操作上，例如 `paths./users.get`。

| 扩展 | 作用 |
| --- | --- |
| `x-mint.metadata` | 覆盖页面的 frontmatter，例如 `title`、`sidebarTitle`、`description`、`playground` 或 `tag`。请参阅[覆盖页面元数据](/zh/api-playground/customize-endpoint-pages#override-page-metadata)。 |
| `x-mint.content` | 向页面添加 MDX 内容。请参阅[向页面添加内容](/zh/api-playground/customize-endpoint-pages#add-content-to-a-page)。 |
| `x-mint.href` | 设置页面的 URL。请参阅[为单个端点设置 URL](/zh/api-playground/endpoint-urls#set-a-url-for-one-endpoint)。 |
| `x-mint.playground.expand` | 设置为 `false` 可让嵌套对象字段默认折叠。请参阅[折叠试验台字段](/zh/api-playground/customize-endpoint-pages#collapse-playground-fields)。 |
| `x-mint.groups` | 仅向所列用户组中的读者显示该端点。也适用于路径。请参阅[过滤端点](/zh/create/personalization#filter-endpoints)。 |
| `x-hidden` | 创建页面，但不在导航中显示。请参阅[隐藏或排除端点](/zh/api-playground/organize-endpoints#hide-or-exclude-endpoints)。 |
| `x-excluded` | 不创建页面。请参阅[隐藏或排除端点](/zh/api-playground/organize-endpoints#hide-or-exclude-endpoints)。 |
| `x-codeSamples` | 添加你自己的请求示例。`x-code-samples` 也可以使用。请参阅[编写你自己的示例](/zh/api-playground/code-examples#write-your-own-examples)。 |

`x-hidden` 和 `x-excluded` 也适用于 webhook。

<div id="schema-extensions">
  ## Schema 扩展
</div>

将这些扩展添加到 schema 或属性上。

| 扩展 | 作用 |
| --- | --- |
| `x-mint.pre`、`x-mint.post` | 在参数名称之前或之后添加标记。请参阅[添加参数标记](/zh/api-playground/customize-endpoint-pages#add-parameter-pills)。 |
| `x-mint.groups` | 仅向所列用户组中的读者显示某个属性或 `oneOf` 变体。请参阅[过滤 schema 属性](/zh/create/personalization#filter-schema-properties)。 |
| `x-mint-enum` | 仅向所列用户组中的读者显示单个枚举值。请参阅[过滤枚举值](/zh/create/personalization#filter-enum-values)。 |
| `x-default` | 使用某个值预填试验台，而不更改文档中的示例或 `default`。在参数上，无论是否开启 `api.examples.prefill`，它都优先于示例。在请求体字段上，仅在关闭 `api.examples.prefill` 时生效。请参阅[预填示例值](/zh/api-playground/configure-playground#prefill-example-values)。 |

<div id="security-scheme-extensions">
  ## 安全方案扩展
</div>

| 扩展 | 作用 |
| --- | --- |
| `x-default` | 在试验台中预填凭据输入框。适用于 `apiKey` 和 `http` bearer 方案。请参阅[预填凭据](/zh/api-playground/configure-playground#prefill-credentials)。 |

<div id="tag-extensions-and-fields">
  ## Tag 扩展和字段
</div>

| 字段 | 作用 |
| --- | --- |
| `x-group` | 设置该 tag 的导航分组标签。请参阅[重命名 tag 分组](/zh/api-playground/organize-endpoints#rename-tag-groups)。 |
| `x-displayName` | 当 tag 没有 `x-group` 时设置分组标签。 |
| `parent`、`kind`、`summary` | 仅限 OpenAPI 3.2。用于嵌套分组、显示 badge 标记和设置标签。请参阅[使用 tag 层级嵌套分组](/zh/api-playground/organize-endpoints#nest-groups-with-tag-hierarchies)。 |

这些字段都不会改变页面 URL。URL 使用 tag 的 `name`。

<div id="frontmatter-fields">
  ## Frontmatter 字段
</div>

在引用你的规范的 MDX 页面中使用这些字段。

| 字段 | 作用 |
| --- | --- |
| `openapi` | 根据一个操作或 webhook 生成页面，例如 `openapi: "openapi.json GET /users"`。请参阅[为端点创建 MDX 页面](/zh/api-playground/customize-endpoint-pages#create-mdx-pages-for-endpoints)。 |
| `openapi-schema` | 根据 `components.schemas` 中的 schema 生成页面。请参阅[为数据模型创建页面](/zh/api-playground/customize-endpoint-pages#create-pages-for-data-models)。 |
| `playground` | 设置该页面的试验台显示模式。请参阅[选择显示模式](/zh/api-playground/configure-playground#choose-a-display-mode)。 |
