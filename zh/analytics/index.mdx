<Info>
  分析功能需要 [Pro 或 Enterprise 套餐](https://mintlify.com/pricing?ref=analytics)。
</Info>

dashboard 中的[分析](https://app.mintlify.com/analytics)页面展示了访客如何发现和使用您的文档。利用这些信号识别高价值页面、发现内容缺口,并跟踪随时间的变化。

分析数据通常会在交互发生后几分钟内出现。最近发生的事件可能不会立即显示。

<div id="choose-an-analytics-view">
  ## 选择分析视图
</div>

<Card title="流量" horizontal icon="chart-line" href="/zh/analytics/traffic">
  跟踪访客、页面浏览量、引荐来源以及来自人类和 agent 的流量。
</Card>
<Card title="助手" horizontal icon="message-square" href="/zh/analytics/assistant">
  查看助手使用情况、对话主题、满意度和记录。
</Card>
<Card title="搜索" horizontal icon="search" href="/zh/analytics/search">
  分析搜索量、常见查询和点击率。
</Card>
<Card title="用户参与" horizontal icon="route" href="/zh/analytics/user-engagements">
  了解内容操作、导航路径,以及搜索和助手漏斗。
</Card>
<Card title="反馈" horizontal icon="square-dashed-text" href="/zh/optimize/feedback">
  查看随时间变化的反馈、审阅特定评分和书面反馈,并跟踪后续工作。
</Card>
<Card title="导出分析" horizontal icon="file-chart-column" href="/zh/analytics/export">
  将 dashboard 数据导出为 CSV,用于分析、报告或归档。
</Card>
<Card title="流式传输分析事件" horizontal icon="database" href="/zh/analytics/streaming">
  将分析事件发送到 Amazon S3 以进行下游处理。
</Card>
