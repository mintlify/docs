</Info>

[分析](https://app.mintlify.com/analytics)页面中的 **节省** 视图用于估算 Mintlify 为你的团队节省了多少工作量。它会显示 Agent 和自动化节省的工时，以及助手回答用户问题时避免的支持成本。

使用“节省”视图可以：

- **汇报投资回报**：与相关方分享预估节省的工时和金额。
- **比较自动化的价值**：查看哪些类型的自动化工作贡献了最多的时间节省。

<div id="time-saved">
  ## 节省的时间
</div>

**节省的时间（小时）** 图表将预估节省的工时分为四类。

- **Slack Agent**：[Agent 从 Slack 发起](/zh/agent/slack)的 pull request。
- **自更新内容自动化**：来自[自更新内容自动化](/zh/automations/reference#self-updating-content-automations)的 pull request，例如“从代码变更中更新”和“起草更新日志”。
- **维护自动化**：来自[维护自动化](/zh/automations/reference#maintenance-automations)的 pull request，例如“翻译内容”和“修复失效链接”。
- **自定义自动化**：来自[自定义自动化](/zh/automations/create)的 pull request。

Mintlify 只统计在所选时间范围内首次创建并已合并的 pull request。每个 pull request 会根据变更行数累加工时。

| 变更行数       | 节省工时 |
| :------------- | :------- |
| 少于 20        | 0.5      |
| 20 到 99       | 2        |
| 100 或以上     | 5        |

当某个 pull request 的行数不可用时，Mintlify 会使用默认估算值。

<div id="money-saved">
  ## 节省的成本
</div>

**节省的成本** 卡片显示两项指标。

- **节省的成本**：预估避免的支持成本，按助手每回答一个问题节省 12 美元计算，依据是各行业支持工单的平均成本。
- **助手回答的问题**：在所选时间范围内，由[助手](/zh/analytics/assistant)回答且未将用户转至销售或支持团队的对话数量。
