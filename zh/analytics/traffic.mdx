[分析](https://app.mintlify.com/analytics)页面的 **Traffic** 视图展示总访客数、页面浏览量、助手对话数、搜索次数和用户反馈消息。

查看流量分析可以:

- **监控流量趋势**:观察更新或新内容发布后人类和 agent 流量的变化,了解变更带来的影响。
- **识别热门页面**:通过排名靠前的页面了解哪些内容对用户最重要,保持这些页面的更新和完整。
- **跟踪引荐来源**:了解用户从哪里来,以便针对合适的受众优化内容。

<div id="how-mintlify-counts-traffic">
  ## Mintlify 如何统计流量
</div>

Mintlify 根据 user agent 对每个请求进行分类,只有人类流量和 agent 流量会计入访客数和页面浏览量总数。搜索索引爬虫、AI 训练爬虫和其他 bot 的流量不计入这两项指标。有关各流量类别的详细说明,请参阅[解读流量导出](/zh/analytics/export#interpret-traffic-exports)。

<Note>
  2026 年 9 月,Mintlify 更新了访客统计方式,使其采用与页面浏览量相同的爬虫过滤规则。大多数站点的访客总数因此下降,且该变更适用于所有日期范围。请参阅[为什么爬虫过滤后访客数下降了](/zh/help-center/visitor-count-dropped-after-crawler-filtering)。
</Note>

<div id="interpret-agent-views">
  ## 解读 agent 浏览量
</div>

Mintlify 通过 IP 地址和 user agent 识别 agent 访客。agent 访客数近似表示 AI 流量的不同来源,而非单个 agent 会话或对话。来自同一 IP 地址的多次请求计为一个访客。

<Note>
  agent 流量的度量方式在 2026 年 6 月进行了扩展。此前,分析仪表板仅捕获一部分 agent 流量。从 2026 年 6 月 8 日起,Mintlify 识别更广泛的 agent user agent,除了 Markdown 请求外还统计 agent 的 HTML 页面浏览量,并向更多 agent 提供 Markdown。因此,大多数站点在该日期前后的 agent 浏览量都有所增加。这反映的是度量方式的改进和 agent 访问范围的扩大,并非流量本身的突然变化。在比较不同时间段的 agent 浏览量时,请将此变化考虑在内。

  增长幅度因站点而异,取决于每个站点接收的 agent 流量。被 AI 工具频繁引用的站点,其增长幅度会大于 agent 流量较少的站点。
</Note>

使用 agent 浏览量了解:

- **AI agent 分布**:查看哪些 AI 平台访问您的 docs,了解用户偏好哪些工具。
- **集成机会**:识别哪些 AI 平台应优先进行优化和测试。
- **AI 流量模式**:监控哪些 agent 最活跃,以及它们的使用情况如何随时间变化。

agent 明细按提供商对流量进行分组,例如 ChatGPT、Claude 和 Cursor。其余的 agent 流量归入三个类别:

- **HTTP clients**:来自 curl、wget 和 Python HTTP 客户端等工具和库的请求。
- **Browser**:从 Web 浏览器发出的 Markdown 请求。
- **Other**:与已知提供商或客户端不匹配的 agent 流量。

Mintlify 会从 agent 明细中排除自身的内部流量,例如链接检查和页面重新验证。
