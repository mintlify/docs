<Info>
  朗读功能需要 [Pro 或 Enterprise 套餐](https://mintlify.com/pricing)。
</Info>

朗读功能会在每个页面顶部添加一个 **Listen to this page** 播放器。当读者按下播放时，Mintlify 会生成页面的语音版本，并将音频流式传输到浏览器。

Mintlify 根据你已发布的内容按需生成朗读音频，因此音频始终与页面内容一致。页面更新后，下一位收听者会触发重新生成。

**Listen to this page** 播放器只会出现在包含可朗读内容的页面上。过短的页面以及主要由非文字内容组成的页面无法朗读。需要身份验证才能访问的部署不支持朗读功能。

朗读功能使用你组织共享余额中的积分。每次生成消耗 50 积分。重复播放同一版本的页面免费。详情请参阅[积分定价](/zh/credits)。你可以在控制台的 [Usage](https://app.mintlify.com/settings/organization/usage) 页面跟踪用量。

<div id="how-narration-works">
  ## 朗读的工作方式
</div>

朗读会依次读出页面标题、描述和正文。Mintlify 会用简短的语音提示播报步骤、选项卡、提示框和折叠面板。朗读会跳过代码块、表格、媒体和 API 字段。

播放音频时，Mintlify 会高亮当前朗读的句子，并滚动页面使其保持在可见范围内。如果读者滚动到其他位置，自动滚动会停止，音频继续播放。读者可以暂停播放、查看进度，并在 0.8x 到 2x 之间调整播放速度。打开其他页面会停止当前朗读。

<div id="enable-narration">
  ## 启用朗读
</div>

1. 在控制台中前往 [General](https://app.mintlify.com/settings/deployment/general) 设置的 **Narration** 部分。
2. 启用 **Page narration**。
