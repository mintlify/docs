<Info>
  AI 助手需要 [Pro 或 Enterprise 套餐](https://mintlify.com/pricing?ref=assistant)。
</Info>

当 AI 助手无法根据你的文档回答问题时，它可以把用户转给你的团队。用户因此有办法联系到真人，而不会走进死胡同。

在仪表盘 [Assistant](https://app.mintlify.com/products/assistant) 页面“响应处理”部分的 **Support** 菜单中，选择支持类问题的去向：

| 选项 | 用户看到的内容 | 请求的去向 |
| :--- | :--- | :--- |
| [Email](#send-questions-by-email) | 聊天中的联系表单 | 你的支持或销售邮箱地址 |
| [Link](#link-to-your-help-center) | 一张链接到你支持 URL 的卡片 | 你的帮助中心、工单门户或社区论坛 |
| [Direct support ticketing](#create-tickets-in-plain-or-zendesk) | 聊天中的联系表单 | Plain 或 Zendesk 中的新工单 |

如果你使用 Plain 或 Zendesk 以外的 help desk，请使用 **Link** 将用户引导到其联系页面或帮助中心。

<div id="send-questions-by-email">
  ## 通过邮件发送问题
</div>

在 **Support** 菜单中选择 **Email**，然后填写以下任一或两个地址：

- **Support email**：AI 助手无法根据文档解答的问题。
- **销售**：与定价、套餐或购买相关的问题。

当 AI 助手检测到匹配的问题时，聊天面板中会出现一个联系表单。该表单会向用户询问名字、姓氏、公司、公司邮箱和一条消息。Mintlify 会通过电子邮件将提交内容发送给对应的团队，该团队可以直接回复用户的邮箱。

<Tip>
如果你希望将支持类问题引导至现有的支持渠道，请在“响应处理”部分关闭 **Contact form**。

当联系表单关闭时，AI 助手会以纯文本形式将用户引导至你的支持邮箱地址，而不再显示聊天面板中的表单。当已配置销售邮箱时，销售类问题仍会使用聊天面板中的表单。
</Tip>

<div id="link-to-your-help-center">
  ## 链接到你的帮助中心
</div>

在 **Support** 菜单中选择 **Link**，将用户引导到你现有的支持平台，例如帮助中心、工单门户或社区论坛，而不是通过聊天面板中的表单收集邮箱。

输入你的支持目标的完整 URL。URL 必须使用 `http` 或 `https`，且不能包含凭据。

当 AI 助手检测到支持类问题时，会向用户显示一张带有你支持 URL 链接的卡片。Mintlify 会将 AI 助手会话线程 ID 作为 `threadId` 查询参数追加到该 URL，方便你的支持工具将会话转录附加到生成的工单。使用 [获取 AI 助手会话线程](/zh/api/analytics/assistant-thread) 端点获取转录。

选择 **Link** 后，AI 助手不会显示联系表单，也不会转接销售类问题。

<div id="create-tickets-in-plain-or-zendesk">
  ## 在 Plain 或 Zendesk 中创建工单
</div>

AI 助手可以将支持请求作为工单提交到 Plain 或 Zendesk，而不是通过邮件发送。

在连接 Plain 之前，请创建一个具有以下权限的 Plain API 密钥：

- `customer:create`
- `customer:edit`
- `customer:read`
- `thread:create`
- `thread:read`

1. 在 **Support** 菜单的 **Response handling** 部分，选择 **Direct support ticketing**。
2. 选择一个 **Ticketing platform**：**Plain** 或 **Zendesk**。
3. 在平台卡片上，点击 **Connect**，并在打开的窗口中完成连接。对于 Plain，请使用你创建的 API 密钥。

只有在平台连接成功后，Mintlify 才会保存直接支持工单设置。在此之前，你当前的支持选项仍保持生效。该连接是你组织共享的集成。

当 AI 助手检测到支持类问题时，会显示聊天内联系表单。Mintlify 会根据提交内容在你已连接的平台中创建工单。工单包含用户的联系方式和消息，以及 AI 助手对话中最多前三条消息。如果对话更长，工单会链接到你 dashboard 中的完整对话。

如果你已在 **Email** 下保存了 **销售** 地址，销售类问题仍会通过邮件发送到该地址。

如果 Plain API 密钥缺少任一所需权限，平台卡片会显示 **Scopes misconfigured**。点击 **Configure** 查看缺少哪些权限，然后在 Plain 中将其添加到该 API 密钥。
