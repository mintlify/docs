<Info>
  AI 助手需要 [Pro 或 Enterprise 套餐](https://mintlify.com/pricing?ref=assistant)。
</Info>

把 AI 助手带到用户已经在使用的地方，例如你的应用、仪表盘、营销网站或支持门户。它与你文档站点上的 AI 助手基于同一份文档作答。

使用 AI 助手 API 构建你自己的界面，完全掌控它的外观和行为。使用 [AI 助手 API 密钥](https://app.mintlify.com/settings/organization/api-keys)进行身份验证。

- 按照[构建应用内 AI 助手](/zh/guides/assistant-embed)查看完整的 Next.js 示例。
- 有关端点，请参阅[创建 AI 助手消息](/zh/api/assistant/create-assistant-message)和[搜索文档](/zh/api/assistant/search)。
