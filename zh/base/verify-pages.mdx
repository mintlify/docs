</Note>

验证 Base 中的页面，让团队了解哪些页面是最新的。添加属性（例如负责人），记录谁对页面负责以及页面的其他详细信息。

每个页面的 frontmatter 都会存储其验证状态和属性。通过 [MCP 服务器](/zh/ai/mintlify-mcp)或你的 Git 仓库读取 Base 的 AI 工具，会在读取页面内容的同时看到验证状态和其他属性。

验证和属性仅适用于 Base 项目中的页面，在文档项目中不可用。

<div id="verification-statuses">

## 验证状态

</div>

{/* vale off */}

| 状态 | 含义 |
| --- | --- |
| **Verified** | 有人确认该页面是最新的，且内容正确。 |
| **Outdated** | 有人将该页面标记为已过时。 |
| **Expired** | 该页面曾经过验证，但其验证期已结束。 |
| **Not verified** | 没有人验证过该页面，或有人移除了其验证。 |

{/* vale on */}

<div id="verify-a-page">

## 验证页面

</div>

要验证 Teamspace 页面或更改其状态，你必须拥有编辑者或管理员[角色](/zh/dashboard/roles)。要验证私有页面，你必须在该页面上拥有 **Editor** 或 **Full Access** 角色。任何可以打开页面的人都能看到其状态。

1. 在编辑器中打开页面。
2. 将鼠标悬停在页面标题上方，以显示 <Icon icon="badge-check" /> **Add verification** 按钮。
3. 点击 **Add verification**。
4. 选择验证的有效期：**For 90 days**、**For 30 days**、**For 7 days**、**Indefinitely** 或 **Pick a date**。

页面的验证状态会显示在顶部栏中。点击该状态可查看最后验证该页面或将其标记为已过时的人。

<div id="change-a-pages-status">

## 更改页面状态

</div>

点击顶部栏中的验证状态即可更改其状态。

- 要更改验证的结束时间，请使用 **Expiration** 菜单选择新的日期。
- 要将已验证的页面标记为已过时，请点击 **Mark Outdated**。
- 要重新验证已过时或已过期的页面，请选择新验证的有效期。
- 要将页面恢复为 **Not verified**，请点击 **Remove verification**。

<div id="verification-in-your-inbox">

## 收件箱中的验证通知

</div>

当同事验证页面、将其标记为已过时或移除其验证，或者页面的验证过期时，Mintlify 会向页面[负责人](#add-properties)的[收件箱](/zh/dashboard/inbox#sections-and-filters)发送通知；如果页面被标记为已过时、被移除验证或已过期，还会通知最后验证该页面的人。

你不会收到有关自己所做更改的通知。

<div id="add-properties">

## 添加属性

</div>

一个页面可以有一个负责人和任意数量的自定义属性。

- **Owner**：负责该页面的同事。当页面的验证状态发生变化时，负责人会收到收件箱通知。
- **自定义属性**：由你自行命名的字段，例如发布日期或团队。可从以下类型中选择：Text、Number、Date、Person、Select、Multi-select、URL 和 Checkbox。

要添加属性，你必须拥有编辑者或管理员[角色](/zh/dashboard/roles)。要为私有页面添加属性，你必须在该页面上拥有 **Editor** 或 **Full Access** 角色。任何可以打开页面的人都能看到其属性。

1. 在编辑器中打开页面。
2. 将鼠标悬停在页面标题上方，以显示 <Icon icon="ellipsis" /> **Page properties** 菜单。
3. 要添加负责人，请选择 **Owner** 并选择一位同事。
4. 要添加自定义属性，请选择 **New property** 并选择一种类型。

有值的属性会显示在页面标题下方。你也可以在 **Page settings** 面板的 **Properties** 部分查看和添加属性。

<div id="verification-and-properties-in-git">

## Git 中的验证和属性

</div>

编辑器会将页面的验证状态写入 `verification` frontmatter 键，并将其负责人和属性写入 `metadata` 键。

```yaml Example verification frontmatter
---
title: "Deploy runbook"
verification:
  status: "verified"
  expiresAt: "2027-02-01T00:00:00Z"
---
```

要通过编辑文件更改页面状态，请将 `verification.status` 设置为 `verified`、`outdated` 或 `not_verified`。对于已验证的页面，请将 `expiresAt` 设置为验证结束的时间，格式为 ISO 8601 日期和时间。如果省略 `expiresAt`，页面将无限期保持已验证状态。

如果你通过编辑文件更改页面状态，编辑器不会显示是谁验证了该页面，也不会有人收到收件箱通知。

`metadata` 键通过 Mintlify 用户 ID 引用同事。请在编辑器中编辑负责人和属性。
