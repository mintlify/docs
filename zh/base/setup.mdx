<div id="create-your-base">

## 创建你的 Base

</div>

<Tabs>
  <Tab title="首次使用 Mintlify">
    <Steps>
      <Step title="注册 Mintlify">
        前往 [app.mintlify.com/signup?product=base](https://app.mintlify.com/signup?product=base) 并创建你的账户。然后点击 **Get started**。
      </Step>
      <Step title="选择更新方式">
        选择你计划的更新方式：**Web editor**、**Local development** 或 **MCP**。此选择仅用于初始设置。之后你可以在 Base 中使用所有方式。
      </Step>
      <Step title="创建项目">
        点击 **Create project**。你的 Base 会在编辑器中打开，并包含一个初始页面。
      </Step>
    </Steps>
  </Tab>
  <Tab title="已有组织">
    <Steps>
      <Step title="从控制台中的项目切换器创建 Base">
        1. 在你的[控制台](https://app.mintlify.com/)中，点击左侧边栏顶部的项目切换器。
        2. 点击 <Icon icon="plus" /> **New project**。
        3. 选择 **Base**，然后点击 **Continue**。

        你的 Base 与其他项目属于同一个组织。
      </Step>
      <Step title="选择更新方式">
        选择你计划的更新方式：**Web editor**、**Local development** 或 **MCP**。此选择仅用于初始设置。之后你可以在 Base 中使用所有方式。
      </Step>
      <Step title="创建项目">
        点击 **Create project**。你的 Base 会在编辑器中打开，并包含一个初始页面。
      </Step>
    </Steps>
  </Tab>
</Tabs>

<Check>
  你的 Base 会显示在控制台项目切换器的 **Base** 下。编辑器侧边栏会显示一个设置清单，列出你的后续步骤。
</Check>

<div id="add-pages">

## 添加页面

</div>

在侧边栏的 **Teamspace** 分区中为你的团队创建页面。

点击 **Teamspace** 标题旁的 <Icon icon="plus" /> 加号按钮，然后选择 **New page**。若要导入现有的 Markdown 文件，请将它们从电脑拖到侧边栏上。

当你更改 Teamspace 中的页面时，Mintlify 会自动将更改提交到 Base 的仓库。若要先以私有方式起草，请在 **Personal** 分区中创建页面，并在希望团队可以使用时将其移动到 **Teamspace**。

有关编辑页面的更多信息，请参阅[创建和编辑页面](/zh/editor/pages)。

<div id="invite-your-team">

## 邀请你的团队

</div>

你组织的成员可以访问你的 Base。若要添加同事，请在 [Members](https://app.mintlify.com/settings/organization/members) 设置中邀请他们。

<div id="connect-your-ai-tools">

## 连接你的 AI 工具

</div>

将 Claude、ChatGPT、Cursor 或其他 AI 工具连接到你的 Base，使其能够搜索、阅读和更新你的页面。

1. 在控制台中，打开你的 Base 并前往 [MCP](https://app.mintlify.com/products/mcp) 设置。
2. 在 **Connect** 下，选择你的 AI 工具并按照提示登录。

当 AI 工具编辑你的 Base 时，它提交更改的方式与编辑器相同。有关可用工具和示例提示词，请参阅 [Admin MCP](/zh/ai/mintlify-mcp)。

<div id="optional-connect-your-own-repository">

## （可选）连接你自己的仓库

</div>

你的 Base 起初使用由 Mintlify 托管的仓库。若要在本地编辑 Base，请在 [Git 设置](https://app.mintlify.com/settings/project/git-settings)中连接一个仓库。推送到已连接仓库的提交会更新你的 Base。
