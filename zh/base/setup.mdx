<div id="create-your-knowledge-base">

## 创建你的知识库

</div>

<Tabs>
  <Tab title="首次使用 Mintlify">
    <Steps>
      <Step title="注册 Mintlify">
        前往 [app.mintlify.com/signup?product=base](https://app.mintlify.com/signup?product=base) 并创建你的账户。然后点击 **Get started**。
      </Step>
      <Step title="选择更新方式">
        选择你计划的更新方式：**Code editor**、**Web editor** 或 **MCP**。此选择仅用于初始设置。之后你可以在知识库中使用所有方式。
      </Step>
      <Step title="创建项目">
        点击 **Create project**。你的知识库会在编辑器中打开，并包含一个初始页面。
      </Step>
    </Steps>
  </Tab>
  <Tab title="已有组织">
    <Steps>
      <Step title="从控制台中的项目切换器创建知识库">
        1. 在你的[控制台](https://app.mintlify.com/)中，点击左侧边栏顶部的项目切换器。
        2. 点击 <Icon icon="plus" /> **New project**。
        3. 选择 **Knowledge base**，然后点击 **Continue**。

        你的知识库与其他项目属于同一个组织。
      </Step>
      <Step title="选择更新方式">
        选择你计划的更新方式：**Code editor**、**Web editor** 或 **MCP**。此选择仅用于初始设置。之后你可以在知识库中使用所有方式。
      </Step>
      <Step title="创建项目">
        点击 **Create project**。你的知识库会在编辑器中打开，并包含一个初始页面。
      </Step>
    </Steps>
  </Tab>
</Tabs>

<Check>
  你的知识库会显示在控制台的项目切换器中。编辑器侧边栏会显示一个设置清单，列出你的后续步骤。
</Check>

<div id="add-pages">

## 添加页面

</div>

在侧边栏的 **Navigation** 分区中为你的团队创建页面。

点击 **Navigation** 标题旁的 <Icon icon="plus" /> 加号按钮，然后选择 **New page**。若要导入现有的 Markdown 文件，请将它们从电脑拖到侧边栏上。

当你更改 **Navigation** 中的页面时，Mintlify 会自动将更改提交到知识库的仓库。若要先以私有方式起草，请在 **Personal** 分区中创建页面，并在希望团队可以使用时将其移动到 **Navigation**。

有关编辑页面的更多信息，请参阅[创建和编辑页面](/zh/editor/pages)。

<div id="invite-your-team">

## 邀请你的团队

</div>

你组织的成员可以访问你的知识库。若要添加同事，请在 [Members](https://app.mintlify.com/settings/organization/members) 设置中邀请他们。

<div id="connect-your-ai-tools">

## 连接你的 AI 工具

</div>

将 Claude、ChatGPT、Cursor 或其他 AI 工具连接到你的知识库，使其能够搜索、阅读和更新你的页面。

1. 在控制台中，打开你的知识库并前往 [MCP](https://app.mintlify.com/products/mcp) 设置。
2. 在 **Connect** 下，选择你的 AI 工具并按照提示登录。

当 AI 工具编辑你的知识库时，它提交更改的方式与编辑器相同。有关可用工具和示例提示词，请参阅 [Admin MCP](/zh/ai/mintlify-mcp)。

<div id="optional-create-from-a-local-folder">

## （可选）从本地文件夹创建

</div>

如果你已有一个包含 Markdown 文件的文件夹，可以使用 Mint CLI 从命令行将其发布到新的知识库。

<Steps>
  <Step title="预配知识库">
    在任意目录中运行以下命令，并将 `<name>` 替换为你选择的子域名：

    ```bash
    mint deploy --knowledge-base --subdomain <name>
    ```

    输出中包含一条带有短期写入令牌的克隆命令，以及新知识库的编辑器链接。
  </Step>

  <Step title="克隆托管仓库">
    复制并运行上一步输出中的克隆命令。它类似于：

    ```bash
    git -c http.<REPOSITORY_URL>.extraHeader="Authorization: Bearer <WRITE_TOKEN>" clone <REPOSITORY_URL> <name>
    ```

    这会创建一个包含托管仓库的 `<name>` 目录。克隆命令中的写入令牌会过期；如有需要，在同一目录中再次运行 `mint deploy --knowledge-base` 以获取新令牌。
  </Step>

  <Step title="复制内容并提交">
    将你的 Markdown 和 MDX 文件复制到克隆的目录中。将 `docs.json` 和页面放在仓库根目录。

    然后提交你的更改：

    ```bash
    cd <name>
    git add .
    git commit -m "Initial content"
    ```
  </Step>

  <Step title="推送到知识库">
    在你运行 `mint deploy` 的目录中（而不是在克隆目录内）运行以下命令：

    ```bash
    mint deploy --knowledge-base --push <name>
    ```

    这会将你的提交变基到托管仓库最新的 main 分支上并推送。不要直接运行 `git push`。

    如果出现变基冲突，请解决冲突，在克隆目录中运行 `git rebase --continue`，然后重新运行此命令。
  </Step>

  <Step title="认领知识库">
    你预配的知识库尚未加入你的 Mintlify 账户。`mint deploy` 的输出会显示它的过期时间。如果到那时仍无人认领，Mintlify 会将其删除。

    推送内容后，在你运行 `mint deploy` 的目录中运行 [`mint claim`](/zh/cli/commands#mint-claim)：

    ```bash
    mint claim
    ```

    打开它输出的认领链接，登录并点击 **Confirm**。知识库随即转入你的账户。
  </Step>
</Steps>

认领完成后，通过第一步中的编辑器链接打开你的知识库。CLI 无法再向其推送内容，因此请在编辑器中编辑，或[连接你自己的仓库](#optional-connect-your-own-repository)。

<div id="optional-connect-your-own-repository">

## （可选）连接你自己的仓库

</div>

你的知识库起初使用由 Mintlify 托管的仓库。若要在本地编辑知识库或使用 [Autopilot](/zh/autopilot)，请在 [Git 设置](https://app.mintlify.com/settings/project/git-settings)中连接一个仓库。推送到已连接仓库的提交会更新你的知识库。

<div id="optional-add-a-project-icon">

## （可选）添加项目图标

</div>

添加一个图标，以便在项目切换器中将你的知识库与其他项目区分开来。要添加图标，你需要一个可以管理站点和工作区设置的[角色](/zh/dashboard/roles)。

1. 在你的 dashboard 中，打开你的知识库并前往 [Project](https://app.mintlify.com/settings/project/site) 设置。
2. 在 **Icon** 行中，点击 **Upload** 并选择一个不超过 4 MB 的 PNG、JPEG、WebP 或 SVG 文件。

如需稍后更改图标，请点击 **Replace**。如需移除图标，请点击 **Replace** 旁边的 <Icon icon="trash" /> 删除按钮。
