连接 Hightouch 之前，你需要一个来自 Hightouch 事件源的 write key。在你的 Hightouch 工作区中创建事件源并复制其 write key。设置步骤请参阅 [Hightouch 的事件源文档](https://hightouch.com/docs/events/sources/overview)。

将 write key 添加到你的 `docs.json` 文件中，即可将 Analytics 发送到 Hightouch。

<Info>

  `apiHost` 中不要包含 `https://`。

</Info>

<CodeGroup>

```json docs.json 中的 Analytics 选项
"integrations": {
    "hightouch": {
        "writeKey": "required",
        "apiHost": "optional"
    }
}
```

```json 示例
"integrations": {
    "hightouch": {
        "writeKey": "9132c81do371p76sr11da0075469b54f77649c9a067dp0303p56q0q64n072336",
        "apiHost": "us-east-1.hightouch-events.com"
    }
}
```

</CodeGroup>

<div id="configuration-options">
  ## 配置选项
</div>

<ParamField path="writeKey" type="string" required>
  来自你的 Hightouch 事件源的 write key。
</ParamField>

<ParamField path="apiHost" type="string">
  Hightouch 事件 API 主机，不包含 `https://`。默认为 `us-east-1.hightouch-events.com`。
</ParamField>

<div id="verify-the-integration">
  ## 验证集成
</div>

部署更改后，Mintlify 会将页面浏览、搜索查询等互动事件发送到 Hightouch。要确认事件已送达，请在 [Hightouch 的事件调试器](https://hightouch.com/docs/events/sources/overview#debugger)中查看实时事件。

要了解 Mintlify 跟踪的事件概览，请参阅[Analytics 集成](/zh/integrations/analytics/overview)。
