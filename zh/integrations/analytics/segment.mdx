将你的 Segment write key 添加到 `docs.json` 文件，以将分析数据发送到 Segment。

<CodeGroup>

```json docs.json 中的 Analytics 选项
"integrations": {
    "segment": {
        "key": "required",
        "cdnUrl": "optional"
    }
}
```

```json 示例
"integrations": {
    "segment": {
        "key": "nqJxiRG15Y6M594P8Sb8ESEciU3VC2",
        "cdnUrl": "https://cdn.mydomain.com"
    }
}
```

</CodeGroup>

## 自定义 CDN URL

如果你使用 [Segment 的自定义域名功能](https://segment.com/docs/connections/sources/custom-domains/)，可以设置 `cdnUrl`，从你的自定义域名而不是默认的 `cdn.segment.com` 加载 Segment 脚本。从自己的域名加载有助于防止广告拦截器拦截你的分析数据。

`cdnUrl` 必须是 HTTPS URL，且不能包含查询参数或片段。
