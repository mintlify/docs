在你的 `docs.json` 文件中添加以下配置，将 Analytics 发送到 Pirsch。

你可以在 Settings &gt; Developer &gt; Identification Code 中获取你的网站 ID。

<CodeGroup>
  ```json docs.json 中的 Analytics 选项
  "integrations": {
      "pirsch": {
          "id": "required"
      }
  }
  ```

  ```json 示例
  "integrations": {
      "pirsch": {
          "id": "8Kw7OKxBfswOjnKGZa7P9Day8JmVYwTp"
      }
  }
  ```
</CodeGroup>
