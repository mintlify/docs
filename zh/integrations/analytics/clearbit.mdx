在你的 `docs.json` 文件中添加以下内容，将 Analytics 数据发送到 Clearbit。

<CodeGroup>
  ```json docs.json 中的 Analytics 选项
  "integrations": {
      "clearbit": {
          "publicApiKey": "required"
      }
  }
  ```

  ```json 示例
  "integrations": {
      "clearbit": {
          "publicApiKey": "pk_1a1882"
      }
  }
  ```
</CodeGroup>
