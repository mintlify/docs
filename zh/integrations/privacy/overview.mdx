## Cookie 同意横幅

Mintlify 内置了 Cookie 同意横幅，会在站点跟踪分析或营销 Cookie 之前请求访客同意。如果你希望在不接入第三方平台的情况下满足 GDPR 等法规要求，可以启用该横幅。

启用或关闭横幅的步骤：

1. 在控制台中，前往 **Settings** > **Privacy**。
2. 打开 **Consent banner** 以向访客展示横幅，或关闭以隐藏横幅。

启用横幅后，分析类集成仅会为已同意的访客发送事件。撤销同意会重新加载页面，以卸载已加载的分析脚本。

<div id="cookie-consent-and-disabling-telemetry">
  ## Cookie 同意与禁用遥测/使用数据
</div>

如需检查用户是否已为符合 GDPR 要求而同意使用 Cookie，你可以在 `cookies` 下指定一个本地存储中的 key 和值：

```json
  "integrations": {
    "cookies": {
      "key": "LOCAL STORAGE KEY",
      "value": "LOCAL STORAGE VALUE"
    }
  }
```

如果你设置了这些值，你的站点会检查本地存储中指定的 key 和值，以确定用户是否已同意使用 Cookie。若用户未同意，你的站点将为该用户禁用遥测/使用数据。

如果你希望为所有用户禁用遥测/使用数据，请在你的 `docs.json` 文件中添加以下内容：

```json
  "integrations": {
    "telemetry": {
      "enabled": false
    }
  }
```

<Note>
  如果禁用遥测/使用数据，即使在控制台中开启了反馈，也无法在文档页面收集反馈。
</Note>
