使用 CSS 为 HTML 元素设置样式，或添加自定义 CSS 和 JavaScript，全面定制文档的外观与使用体验。

<div id="style-with-tailwind-css">
  ## 使用 Tailwind CSS 进行样式设计
</div>

使用 Tailwind CSS v3 为 HTML 元素和组件设置样式。你可以控制布局、间距、颜色及其他视觉属性。常见的类包括：

* `w-full` - 宽度占满
* `aspect-video` - 16:9 比例
* `rounded-xl` - 大圆角
* `block`, `hidden` - 显示控制
* `dark:hidden`, `dark:block` - 深色模式下的可见性

<div id="style-components-with-classname">
  ### 使用 `className` 为组件设置样式
</div>

组件接受 `className` prop。Mintlify 会将你的类与组件自身的样式合并，因此你无需额外的包裹标记或编写 CSS 覆盖，即可为单个实例重新设置样式。

```mdx className example
<Note className="mt-0">This callout has no top margin.</Note>

<Card title="Quickstart" href="/quickstart" className="border-2 border-blue-500">
  Deploy your first documentation site.
</Card>
```

有三个组件不接受 `className`：[Banner](/zh/components/banner)、[MDX](/zh/components/mdx) 和 [Visibility](/zh/components/visibility)。

<div id="arbitrary-values-and-variants">
  ### 任意值与变体
</div>

当没有工具类能满足所需的值时，请使用任意值（arbitrary value）。

```mdx Arbitrary value examples
<img src="/images/diagram.png" alt="System architecture diagram" className="w-[450px]" />

<Frame className="lg:w-[calc(100%-2rem)] bg-[#0f172a]">
  <img src="/images/hero.png" alt="Product hero image" />
</Frame>
```

变体（variant）的用法与任何 Tailwind 项目相同，包括响应式前缀（`sm:`、`md:`、`lg:`）、状态变体（`hover:`、`focus:`）、`dark:`、数据属性变体（`data-[state=open]:`）、不透明度修饰符（`bg-black/50`）以及 `!` important 修饰符。

Mintlify 会为在页面源码中找到的 Tailwind 类生成 CSS，因此请完整写出类名。

```mdx Write class names in full
{/* Generates CSS: the full class name appears in the page source. */}
<div className="bg-blue-500" />

{/* Generates no CSS: the class name is assembled at runtime. */}
<div className={`bg-${color}-500`} />
```

<Note>
  Web 编辑器的实时预览不会为页面特有的 Tailwind 类生成 CSS，因此已设置样式的页面在编辑时可能看起来没有样式。请参阅 [Tailwind 类在编辑器实时预览中不生效](/zh/help-center/tailwind-classes-not-applying-in-editor-preview)。
</Note>

<Warning>
  请避免使用 `style` prop。它可能会在页面加载时导致布局位移，尤其是在自定义模式的页面中。请改用 Tailwind CSS 类或自定义 CSS 文件。
</Warning>

<div id="add-custom-css">
  ## 添加自定义 CSS
</div>

Mintlify 会自动在你的文档站点的每个页面中包含内容目录下的任何 `.css` 文件，方式与包含自定义 `.js` 文件相同。内容目录是仓库中包含 `docs.json` 文件和 MDX 页面的文件夹。你无需在 `docs.json` 或 MDX 文件中导入或引用该文件。

要添加自定义样式，请在内容目录的任意层级创建一个 `.css` 文件（例如 `style.css`）。你在其中定义的任何类名、ID 选择器或元素选择器都可以在所有 MDX 文件中使用。

例如，在 `style.css` 中定义一个类：

```css
.my-callout {
  border-radius: 1rem;
  background: #f0f9ff;
  padding: 1rem;
}
```

然后在任意 MDX 文件中通过 `className` 属性使用它：

```mdx
<div className="my-callout">
  内容在这里。
</div>
```

你可以在同一个元素上将自定义类名与 [Tailwind CSS](/zh/customize/custom-scripts#style-with-tailwind-css) 类组合使用。

自定义 CSS 会应用于站点的每个页面，包括自定义模式页面和落地页。若要将样式限定到特定页面或部分，请使用 [数据属性](#data-attributes)中介绍的 `html[data-current-path="..."]` 属性选择器。

引用和常用元素的样式可能会发生变化。请谨慎使用自定义样式，因为未来更新中可能出现不兼容的变更。

例如，你可以添加以下 `style.css` 文件以自定义导航栏和页脚的样式。

```css
#navbar {
  background: #fffff2;
  padding: 1rem;
}

footer {
  margin-top: 2rem;
}
```

CSS 定位钩子使用不同的语法：

- **ID 选择器**：页面级唯一元素，在 CSS 中使用 `#value { }` 定位
- **类选择器**：组件和布局的类，在 CSS 中使用 `.value { }` 定位，例如 `.card`。
- **元素选择器**：HTML 标签，在 CSS 中使用 `value { }` 定位，例如 `footer`。
- **属性选择器**：组件部件或状态，使用方括号定位，例如 `[data-component-part="card-icon"]`。

这些选择器不能互换使用。例如，`.card` 定位的是一个类，而 `card` 定位的是名为 `<card>` 的标签。钩子取决于渲染时的主题、组件、配置和状态。有关确切的语法、可用性、生命周期和兼容性参考，请参阅[自定义 skill](/zh/customize/agent-skill)。

<Tip>
  使用"检查元素"来定位你要自定义的元素引用。
</Tip>

<div id="change-the-sidebar-width">
  ### 更改侧边栏宽度
</div>

设置 CSS 变量 `--sidebar-width` 可更改桌面端侧边栏的宽度。内容区域、页眉和页脚会随新宽度自动调整，因此你无需覆盖 `#sidebar` 或自行偏移其他元素。

```css style.css
:root {
  --sidebar-width: 20rem;
}
```

如果你未设置该变量，每个主题会使用其默认侧边栏宽度：

| 主题 | 默认宽度 |
| :--- | :--- |
| Mint, Linden, Willow, Aspen, Sequoia | `18rem` |
| Maple, Palm | `19rem` |
| Almond | `16.5rem` |
| Luma | `14rem` |

在 Palm 主题中，该变量设置的是展开状态下侧边栏的宽度。折叠状态下的侧边栏保持固定宽度。

<div id="change-the-content-width">
  ### 更改内容宽度
</div>

设置 CSS 变量 `--content-width` 可更改使用默认[页面模式](/zh/organize/pages#page-mode)的页面中文本列的最大宽度。该值设置的是文本本身的宽度。每个主题都会在文本周围添加各自的内边距，因此相同的值在所有主题中都会产生相同的文本宽度。

```css style.css
:root {
  --content-width: 768px;
}
```

文本列的宽度永远不会超过侧边栏与目录之间的空间。如果你设置了较大的值，文本列会填满可用空间，而不会与其他元素重叠。

如果你未设置该变量，每个主题会使用其默认内容宽度：

| 主题 | 默认宽度 |
| :--- | :--- |
| Mint, Palm, Aspen | 无最大值。文本填满可用空间。 |
| Linden | 在较小屏幕上无最大值。在超大屏幕上为 `35.75rem`。 |
| Maple | `36rem`。在最大的屏幕上为 `42rem`。 |
| Willow | `600px` |
| Almond | `36rem` |
| Sequoia, Luma | `40.5rem` |

`--content-width` 不会影响 `wide`、`center`、`custom` 或 `frame` 模式的页面。

<div id="add-styles-to-a-single-page">
  ### 为单个页面添加样式
</div>

如需为某个页面设置样式而不添加全局 `.css` 文件，请在该页面中添加一个 `<style>` 代码块。将 CSS 写在模板字面量中。

```mdx Example page style
<style>{`
  .pricing-callout {
    border-left: 4px solid #0D9373;
    padding-left: 1rem;
  }

  @keyframes page-pulse {
    from { opacity: 1; }
    to { opacity: 0.3; }
  }
`}</style>

<div className="pricing-callout">Prices shown in USD.</div>

<span className="animate-[page-pulse_1s_ease-in-out_infinite_alternate]">Live</span>
```

Mintlify 会将代码块中的每个选择器限定在该页面的内容区域内，因此这些规则不会影响导航、侧边栏或其他页面。页面样式会在你已发布的站点和 Web 编辑器中渲染。

你可以在页面样式中使用以下 at 规则：

- `@media`、`@supports` 和 `@container`。
- `@keyframes`，前提是名称以 `page-` 开头。可通过 `animation` 属性或 Tailwind 类（例如 `animate-[page-pulse_1s_infinite]`）引用该动画。该前缀可防止页面替换 Mintlify 使用的动画。

Mintlify 会从代码块中移除其他所有内容：

- 其他 at 规则，例如 `@import` 和 `@font-face`。
- 选择器以组合符（`>`、`+`、`~`）开头或使用 `&` 嵌套选择器的规则。
- 加载资源的声明，例如 `url()` 和 `image-set()`。
- `position: fixed`。
- keyframes 中的 `!important`。

Mintlify 会忽略 `<style>` 标签上的属性。如果 CSS 不是纯模板字面量，例如包含 `${}` 表达式或变量，Mintlify 会移除整个代码块。

<div id="custom-javascript">
  ## 自定义 JavaScript
</div>

自定义 JS 允许你在全局添加自定义可执行代码，相当于在每个页面都插入一个包含 JS 代码的 `<script>` 标签。

Mintlify 会将文档站点的 content 目录中的任何 `.js` 文件注入到每个文档页面，包括自定义模式页面和落地页。自定义 JavaScript 文件会在页面变为可交互后运行，无法将其作用范围限定到特定页面；当存在多个 `.js` 文件时，它们都会执行，但执行顺序无法保证。

若要加载第三方脚本，请从你的自定义 JavaScript 文件中注入 `<script>` 元素，而不是在 MDX 中直接添加原始的 `<script src="...">` 标签：

```js
const script = document.createElement('script');
script.src = 'https://example.com/widget.js';
script.async = true;
document.head.appendChild(script);
```

比如，你可以添加下面的 `ga.js` 文件，在整个文档站点启用 [Google Analytics](https://marketingplatform.google.com/about/analytics)。

```js
window.dataLayer = window.dataLayer || [];
function gtag() {
  dataLayer.push(arguments);
}
gtag('js', new Date());

gtag('config', 'TAG_ID');
```

<Warning>
  请谨慎使用，避免造成安全漏洞。
</Warning>

<div id="run-code-on-every-page">
  ### 在每个页面上运行代码
</div>

自定义 JavaScript 每次访问只运行一次。当读者在页面之间切换时，Mintlify 会在不重新加载的情况下替换页面内容，因此修改页面内容的代码只会在第一个页面上运行。监听 `mintlify:navigate` 事件，以便在每次导航后再次运行它。新页面渲染完成后，该事件会在 `window` 上触发，并附带 `event.detail.path`、`event.detail.search` 和 `event.detail.hash`。`path` 使用与 `data-current-path` 相同的格式。该事件不会在首次加载时触发，因此请自行调用一次你的函数。

```js Add a button to every heading
function addCopyButtons() {
  document.querySelectorAll('#content h2[id]').forEach((heading) => {
    if (heading.querySelector('.copy-link')) return;

    const button = document.createElement('button');
    button.className = 'copy-link';
    button.textContent = 'Copy link';
    button.addEventListener('click', () => {
      navigator.clipboard.writeText(`${location.origin}${location.pathname}#${heading.id}`);
    });
    heading.append(button);
  });
}

addCopyButtons();
window.addEventListener('mintlify:navigate', addCopyButtons);
```

请使用该事件，而不是在 `document.body` 上使用 `MutationObserver`，后者会在每次 DOM 变更时运行，并拖慢大型页面。若要跟踪点击，请改为在 `document` 上使用单个监听器；无需该事件，它也能在导航之间持续生效。

<div id="navigate-to-another-page">
  ### 导航到其他页面
</div>

使用 `window.mintlify.navigate` 从自定义 JavaScript 中将读者引导到其他页面。它使用客户端导航，因此页面切换时无需完整重新加载，并且会触发 `mintlify:navigate` 事件。而设置 `location.href` 则会重新加载整个页面。

```js Navigate to a page
window.mintlify.navigate('/quickstart');
```

如需替换浏览器历史记录中的当前条目而不是添加新条目，请传入 `replace: true`。读者无法使用后退按钮返回到被你替换的页面。

```js Replace the current page
window.mintlify.navigate('/quickstart', { replace: true });
```

如果你的网站托管在[子路径](/zh/deploy/docs-subpath)下，Mintlify 会为尚未包含该子路径的根相对路径自动添加子路径。例如，在托管于 `/docs` 的网站上，`/quickstart` 和 `/docs/quickstart` 都会跳转到 `/docs/quickstart`。

指向其他域名的 URL、位于子路径之外的路径，以及在页面加载完成之前发起的调用，都会使用完整页面加载。

<div id="set-api-playground-server-variables">
  ### 设置 API Playground 服务器变量
</div>

使用 `window.mintlify.api.playground.setServerVariables`，通过自定义 JavaScript 预填充 [OpenAPI 服务器变量](/zh/api-playground/openapi-setup)。当页面加载后才能获得这些值时使用此方法，例如身份验证 SDK 初始化完成或租户发生变化时。该方法会立即更新已打开的 API Playground，也会应用到之后打开的 Playground。

传入一个值为字符串的对象。每次调用都会替换完整的运行时覆盖值。省略的键会被移除，无效值会被忽略。运行时值优先于 OpenAPI 默认值和已保存的服务器变量。

```js Set API Playground server variables
window.mintlify.api.playground.setServerVariables({
  tenantDomain: 'example.us.auth0.com',
});
```

当这些值不再适用时调用 `window.mintlify.api.playground.clearServerVariables()`，例如注销后。清除后，API Playground 会回退到其他已配置的值。

```js Clear API Playground server variables
window.mintlify.api.playground.clearServerVariables();
```

在客户端初始化之前发出的调用会进入队列，并在客户端初始化时应用。覆盖值仅在当前页面会话的内存中保留。不会写入 `localStorage` 或凭据存储。完整刷新页面会移除覆盖值。

<Warning>
  只能从客户端代码设置非机密值。不要在服务器变量中包含 API 密钥、令牌或其他凭据。
</Warning>

<div id="access-personalized-user-data">
  ### 访问个性化用户数据
</div>

如果你的站点启用了[认证](/zh/deploy/authentication-setup)或[个性化](/zh/create/personalization)，自定义脚本可以通过 `window.mintlify.user` 读取已识别的访客。它与 MDX 页面中暴露的 [`user` 变量](/zh/create/personalization#dynamic-mdx-content)是同一个对象，因此对应你用户数据中的 `content` 字段。

由于自定义脚本会在用户信息解析之前运行，请监听 `mintlify:user` 事件，以便在用户对象可用时做出响应。该事件会在用户信息解析时触发，之后每次发生变化也会再次触发。事件的 `detail` 是用户对象；当访客处于未登录或未识别状态时，则为 `null`。

```js Read the user after it resolves
window.addEventListener('mintlify:user', (event) => {
  const user = event.detail;
  if (!user) return; // Signed out or unidentified.

  renderAppLauncher(user);
});
```

如果你的脚本运行时用户已经解析完成，可直接读取 `window.mintlify.user`。

```js Read the current user
const user = window.mintlify?.user;
if (user) {
  renderAppLauncher(user);
}
```

在用户信息解析完成之前，以及访客处于未登录或未识别状态时，`window.mintlify.user` 都为 `undefined`。读取嵌套字段时请使用可选链操作符。

<Warning>
  你放入用户 `content` 字段的所有内容都会暴露给客户端脚本。不要在其中包含不应在浏览器中被读取的机密或凭据。
</Warning>
