`mintlify` 技能可帮助你的编码代理编写文档、配置站点，并自定义站点的外观和浏览器行为。它包含有关选择器、组件部件、CSS 变量、浏览器 API、脚本生命周期、主题和 React 代码片段的参考资料。你的代理只会加载任务所需的参考资料。

<div id="install-the-skill">
  ## 安装技能
</div>

你需要 Node.js 和一个支持技能的编码代理。

```bash
npx skills@latest add \
  https://github.com/mintlify/docs/tree/main/agent-context/context/skills/mintlify \
  --skill mintlify
```

根据提示选择你的代理和作用范围。添加 `--global` 可在你的所有项目中安装。

如需更新，请使用相同选项重新运行同一命令，然后启动新的代理会话。如果你通过插件获取该技能，请改为更新插件。

<div id="ask-your-agent-to-customize-your-site">
  ## 让你的代理自定义站点
</div>

描述你想要的结果、你的主题以及受影响的页面或组件。例如：

```text
Use mintlify to make the left sidebar 320px wide on desktop in the mint theme.
Keep the content and footer aligned, and check at 1024px and 1440px.
```

```text
Use mintlify to set body text to 17px with a 1.6 line height and widen
the content column to 768px on large screens.
```

```text
Use mintlify to review my styles.css and replace selectors that depend on
generated class names with stable IDs or data attributes.
```

```text
Use mintlify to hide breadcrumbs in search results.
```

相比全局 CSS 或 JavaScript，该技能会优先使用[配置](/zh/organize/settings)、[组件 props](/zh/components/index) 和 [React 组件](/zh/customize/react-components)。
