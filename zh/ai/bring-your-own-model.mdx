<Info>
  使用自己的模型需要 [Enterprise 方案](https://mintlify.com/pricing?ref=bring-your-own-model)。只有当你的合同包含该功能时，**AI model** 部分才会显示在你的 dashboard 中。
</Info>

默认情况下，Mintlify 会选择为 assistant、agent 和 Autopilot 提供支持的模型。要使用你自己的提供商账户运行特定模型，请提供 API 密钥并选择模型。随后，Mintlify 会通过你的提供商执行推理。如果你使用 Anthropic，可以[关联你的 Claude 组织](#link-your-claude-organization)，而无需提供 API 密钥。

一份配置即可覆盖一个项目上的所有 AI 产品：[assistant](/zh/assistant)、[agent](/zh/agent)、[自动化](/zh/automations/index)和 [Autopilot](/zh/autopilot)。

你需要为每个项目单独选择模型，而不是为整个组织统一选择。如果你的组织有多个项目，请分别配置每一个。未配置的项目会使用 Mintlify 的默认模型。

<div id="supported-providers">
  ## 支持的提供商
</div>

- OpenRouter
- Anthropic，可使用 API 密钥或关联计费
- OpenAI
- Amazon Bedrock

无论使用哪个受支持的提供商，assistant、agent、自动化和 Autopilot 都会使用你的提供商账户和你的模型。

辅助性 AI 任务同样使用你的提供商账户运行，而不是 Mintlify 的账户。这些任务包括特定页面的[入门问题](/zh/assistant/configure#add-sample-questions)，以及你从[编辑器](/zh/editor/index)发布时 Mintlify 撰写的提交信息和拉取请求详情。对于这些任务，Mintlify 会使用你的提供商中适合该任务的模型，而不是你选择的模型。如果你的账户无法访问该模型，Mintlify 会改用你选择的模型重试。

每个提供商都支持一组固定的模型。模型菜单只会列出你所选提供商可用的模型。对于 Amazon Bedrock，可用模型取决于你选择的区域。

<div id="configure-your-model">
  ## 配置你的模型
</div>

[编辑者和管理员](/zh/dashboard/roles)可以配置模型。

1. 选择要配置的项目。
2. 前往 dashboard 中的 [API 密钥](https://app.mintlify.com/settings/organization/api-keys)页面。
3. 在 **AI model** 部分，启用 **Bring your own model**。
4. 选择一个提供商。如果选择 Amazon Bedrock，还需选择一个 **Region**。
5. 选择一个 **Assistant model**。
6. 可选：选择一个 **Agent model**，让 agent、自动化和 Autopilot 使用不同的模型。如果留空，它们会使用 assistant 的模型。
7. 输入你的提供商 API 密钥。对于 Amazon Bedrock，请使用 Amazon Bedrock API 密钥。Mintlify 不支持 AWS 访问密钥或 IAM 角色凭证。对于 Anthropic，你也可以改为[关联你的 Claude 组织](#link-your-claude-organization)。
8. 点击 **Save**。

Mintlify 会加密存储你的密钥，保存后不会再显示。

<div id="link-your-claude-organization">
  ## 关联你的 Claude 组织
</div>

<Note>
  通过 Claude Platform 进行关联计费目前处于公开预览阶段。
</Note>

如果你使用 Anthropic，可以关联你的 Claude Platform 组织，而无需输入 API 密钥。Anthropic 会将 assistant、agent、自动化和 Autopilot 产生的 Claude API 用量直接计费到你的 Claude 组织。对于使用关联计费的项目，Mintlify 不会存储 Anthropic API 密钥。Mintlify 会单独对你的订阅计费。

只需为你的 Mintlify 组织关联一次 Claude 组织。然后，为需要使用关联计费的项目选择关联计费。一个 Claude 组织只能关联到一个 Mintlify 组织。

<Warning>
  关联计费只会改变你的计费方式。请求仍在 Mintlify 的 Claude 组织中运行，因此适用的是 Mintlify 与 Anthropic 之间的设置和数据协议，而不是你的。如果你的 Claude 组织启用了零数据保留（ZDR），它不涵盖关联用量。你的商业伙伴协议（BAA）、客户管理的密钥和 IP 允许列表同样不适用。如果你需要 HIPAA、FERPA 或 CMEK，请勿在公开预览期间关联你的 Claude 组织。
</Warning>

要关联你的组织，你需要：

- 一个由 Anthropic 直接计费的 Claude Platform 组织。如果你通过 Amazon Bedrock、Google Cloud Vertex AI、Microsoft Foundry 或云市场购买 Claude，请改用 API 密钥。
- 在你的 Claude 组织中拥有 Owner、Admin 或 Billing 角色。
- 在你的 Mintlify 组织中拥有[管理员或所有者角色](/zh/dashboard/roles)。组织关联后，编辑者可以在项目上选择关联计费。

<Steps>
  <Step title="选择关联计费">
    1. 选择要配置的项目。
    2. 前往 dashboard 中的 [API 密钥](https://app.mintlify.com/settings/organization/api-keys)页面。
    3. 在 **AI model** 部分，启用 **Bring your own model**。
    4. 选择 **Anthropic** 作为提供商。
    5. 选择 **Linked billing** 作为 **Billing method**。

    如果你的 Mintlify 组织已经关联，**Linked billing** 行会显示 **Linked**。请直接跳到第四步。
  </Step>
  <Step title="关联你的 Claude 组织">
    点击 **Link your Claude organization**。
  </Step>
  <Step title="批准关联">
    登录 Claude，然后查看并批准关联。Claude 会将你带回 **API 密钥**页面。
  </Step>
  <Step title="选择模型并保存">
    1. 选择一个 **Assistant model**。
    2. 可选：选择一个 **Agent model**。
    3. 点击 **Save**。
  </Step>
</Steps>

如果你在 Claude 组织中没有 Owner、Admin 或 Billing 角色，或者你拒绝了请求，Claude 会将你带回 dashboard，且不会完成关联。请让 Claude 组织中拥有上述角色之一的人员进行关联。该人员还需要在你的 Mintlify 组织中拥有管理员或所有者角色。

组织关联后，Anthropic 会向你的 Claude 组织的所有者、管理员和计费成员发送电子邮件。Anthropic 不会向某些组织（例如受 HIPAA 约束的组织）发送这些邮件。

<div id="linked-usage-billing">
  ### 关联用量计费
</div>

Anthropic 会将关联用量计入你的 Claude 组织的预付余额；如果你的组织按月计费，则计入其账单。部分额度不能用于支付关联用量，包括 Max、Ultra 和 Team 方案附带的每月 API 额度，以及来自 Anthropic 合作伙伴、风投和初创企业计划的额度。

如果你的 Claude 账户没有余额或无法开具账单，Anthropic 会拒绝请求，并停止使用关联计费的项目上的 Mintlify AI 功能。

<div id="set-a-spend-limit">
  ### 设置支出限额
</div>

你可以在批准关联时，或之后在 Claude Console 的 [Linked platforms](https://platform.claude.com/linked-platforms) 页面上，为 Mintlify 设置可选的每月支出限额，该页面中称为 spend cap。你也可以为所有关联平台设置默认限额。你为 Mintlify 设置的限额会替代默认限额。

- 当用量达到限额时，Anthropic 会拒绝请求，直到你提高限额或限额在下个月初重置。超过限额的那个请求仍会完成，因此用量可能会略微超出限额。
- 限额按目录价格计算用量，不计入你与 Anthropic 协商的任何折扣。如果你享有折扣，可能会在账单达到该金额之前就达到限额。
- 你的 Claude 组织自身的每月支出限额仍然适用。先达到的限额会停止请求。
- 当用量达到限额的 80% 时，你的 Claude 组织管理员会收到一封电子邮件，达到 100% 时还会再收到一封。

如果 Anthropic 因支出限额、额度不足或其他计费问题拒绝请求，使用关联计费的项目上的 AI 功能将停止工作。请在 Claude Console 中检查你的支出限额、余额和账户。

<div id="unlink-your-claude-organization">
  ### 取消关联你的 Claude 组织
</div>

你可以随时在 Claude Console 的 [Linked platforms](https://platform.claude.com/linked-platforms) 页面上取消与 Mintlify 的关联。你的 Mintlify 组织中的管理员或所有者也可以在 dashboard 中 [API 密钥](https://app.mintlify.com/settings/organization/api-keys)页面的 **AI model** 部分点击 **Unlink**。

取消关联通常会在 10 秒内停止新请求。已在运行的请求会完成，并计费到你的 Claude 组织。当 Mintlify 取消关联时，Anthropic 会向你的 Claude 组织的所有者、管理员和计费成员发送电子邮件。

取消关联会影响你的 Mintlify 组织中所有使用关联计费的项目。在你重新关联或将项目切换为 API 密钥之前，这些项目上的 AI 功能将停止工作。

要将项目切换为 API 密钥：
1. 选择要配置的项目。
2. 前往 dashboard 中的 [API 密钥](https://app.mintlify.com/settings/organization/api-keys)页面。
4. 选择 **API key** 作为 **Billing method**。
5. 输入你的密钥。
6. 点击 **Save**。

如有关于 Mintlify 的问题，请联系[支持团队](mailto:support@mintlify.com)。如有关于你的 Claude 组织或其计费的问题，请联系 Anthropic。

<div id="end-user-identifiers">
  ## 终端用户标识符
</div>

Mintlify 在每次向 OpenAI、Anthropic 和 OpenRouter 发送请求时，都会附带终端用户的哈希标识符。如果你的提供商的安全系统检测到滥用流量，提供商可以只封禁该用户，而不是封禁你的整个 API 密钥。

该标识符是根据你的项目以及用户的 IP 地址、会话或 Mintlify 账户生成的 HMAC 哈希。它不包含原始 IP 地址、电子邮件或其他个人信息。同一用户在不同请求中获得相同的标识符，因此你可以在提供商的控制台中关联被标记的活动。

| 提供商 | 请求字段 |
| --- | --- |
| OpenAI | `safety_identifier`（Responses API）或 `user`（Chat Completions API） |
| Anthropic | `metadata.user_id` |
| OpenRouter | `user` |

<div id="rotate-or-remove-your-key">
  ## 轮换或删除密钥
</div>

在同一项目上，Mintlify 会为同一提供商的不同模型复用你已保存的密钥。只有在轮换密钥、切换提供商或配置其他项目时，才需要重新输入密钥。

要轮换密钥，请在 **API key** 字段中输入新密钥，然后点击 **Save**。

要停止使用自己的模型，请禁用 **Bring your own model**。Mintlify 会删除为该项目存储的配置和密钥，其 AI 产品将恢复使用 Mintlify 的默认模型。其他项目会保留各自的配置。在项目上禁用使用自己的模型不会取消关联你的 Claude 组织。
