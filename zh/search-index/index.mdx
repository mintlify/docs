Mintlify Index 为编码代理提供了一个统一的技术知识搜索层。它会将有关已索引产品的问题路由到托管在 Mintlify 上、由发布者维护的文档；对于超出该语料库的问题，则使用网络搜索。

你可以通过公共 MCP 服务器或受访问控制的 REST API 使用 Index。

- **MCP 服务器**：连接 AI 工具，让它在你工作时检索带来源引用的上下文。公开可用，无需 API 密钥。
- **REST API**：搜索按相关性排序的来源、在令牌预算内组装上下文，或检索所选结果的内容。受访问控制，需要 Index API 密钥。

<div id="how-index-retrieves-context">
  ## Index 如何检索上下文
</div>

<Steps>
  <Step title="路由问题">
    Index 会判断问题涉及其文档语料库中的产品，还是需要更广泛的网络结果。
  </Step>
  <Step title="检索相关来源">
    针对特定产品的问题会搜索发布者的最新文档。其他问题会搜索网络。
  </Step>
  <Step title="返回可供代理使用的上下文">
    Index 会对结果排序，并返回包含相关内容的来源 URL。MCP `context` 工具和 REST `context` 端点会在令牌预算内组装这些内容。
  </Step>
</Steps>

<div id="choose-a-retrieval-operation">
  ## 选择检索操作
</div>

- **[`context`](/zh/api/search-index/context)**：大多数代理任务都应使用它。它会在一次请求中返回一组紧凑、带来源引用的材料。
- **[`search`](/zh/api/search-index/search)**：当应用需要排序后的结果并自行控制要读取的来源时使用。可通过 REST API 使用。
- **[`contents`](/zh/api/search-index/contents)**：在 `search` 之后使用它，检索所选 Mintlify 结果 ID 或结果 URL 的内容。可通过 REST API 使用。
