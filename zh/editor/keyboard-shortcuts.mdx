使用键盘快捷键可以在网页编辑器中更快地浏览和编辑。除下列快捷键外，编辑器还支持复制、粘贴、撤销和全选等常用快捷键。

<div id="editor-wide">

## 全局快捷键

</div>

无论处于哪种模式，这些快捷键都可用。

| 命令 | macOS | Windows |
| :--- | :--- | :--- |
| **搜索文件和内容** | <kbd>Cmd</kbd> + <kbd>K</kbd> | <kbd>Ctrl</kbd> + <kbd>K</kbd> |
| **显示或隐藏 AI 助手**（未在编辑文本时） | <kbd>Cmd</kbd> + <kbd>I</kbd> | <kbd>Ctrl</kbd> + <kbd>I</kbd> |
| **在可视化模式与 source 模式之间切换** | <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>S</kbd> | <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>S</kbd> |
| **显示全部文件**（包括 dotfile 和非内容文件） | <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>.</kbd> | <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>.</kbd> |

<div id="smart-substitutions">

### 智能替换

</div>

在你输入时，编辑器会自动把某些字符序列转换为排版符号。编辑器会跳过代码块和行内代码中的替换。

| 输入 | 结果 |
| :--- | :--- |
| `->` | → |
| `<-` | ← |
| `=>` | ⇒ |
| `<=` | ≤ |
| `>=` | ≥ |
| `!=` | ≠ |
