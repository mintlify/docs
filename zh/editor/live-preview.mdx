在编辑时预览你的站点。实时预览会准确呈现页面发布后的效果，并在你对内容、导航和配置进行修改时实时更新。

<div id="open-live-preview">
  ## 打开实时预览
</div>

点击工具栏中的 <Icon icon="play" /> 实时预览按钮。实时预览是在新浏览器标签页中打开，还是在编辑器中打开，取决于[编辑器设置](/zh/editor/settings)中的 **Open live preview in new tab** 偏好设置。

当实时预览在编辑器中打开时，点击预览工具栏中的 **Site settings**，即可在不离开预览的情况下编辑站点配置。

<div id="edit-site-settings-in-live-preview">
  ## 在实时预览中编辑站点设置
</div>

当你需要在查看渲染结果的同时调整站点配置时，请使用 **Site settings** 检查器。它包含与[站点配置](/zh/editor/configurations)面板相同的配置分区。

1. 在编辑器中打开实时预览。
2. 点击预览工具栏中的 **Site settings**。
3. 选择配置分区并编辑设置。
4. 点击 **Close site settings** 关闭检查器并返回预览。

预览会在编辑时更新。如果你的偏好设置会在新标签页中打开实时预览，请在[编辑器设置](/zh/editor/settings)中关闭 **Open live preview in new tab**，然后使用检查器。

<div id="ask-the-agent-in-live-preview">
  ## 在实时预览中向代理提问
</div>

点击预览工具栏中的 **Ask agent**，在实时预览旁打开[编辑器代理](/zh/editor/agent)。打开代理会关闭 Site settings 面板。打开 Site settings 会关闭代理。Viewer 角色看不到 **Ask agent** 按钮。

<div id="live-preview-versus-preview-deployments">
  ## 实时预览与预览部署
</div>

|  | 实时预览 | 预览部署 |
|---|---|---|
| **速度** | 即时 | 需要构建 |
| **访问方式** | 本地 URL | 可分享的 URL |
| **使用时机** | 在编辑时查看更改 | 与团队共享以供审阅 |
| **可用性** | 当编辑器打开时 | 只要该 branch 存在 |

在编辑过程中使用实时预览以获得即时反馈。当你需要与团队共享更改，或在不同设备上测试时，请使用 [预览部署](/zh/editor/branching-and-publishing#preview-your-changes)。
