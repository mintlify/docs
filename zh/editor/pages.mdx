<div id="workspace-and-site">

## Workspace 与 Site

</div>

编辑器侧边栏分为两个标签页：**Workspace** 和 **Site**。

**Workspace** 显示不属于已发布站点的内容。它包含你的 **Personal** 草稿，以及他人 **Shared with me** 的页面。

**Site** 显示访问者看到的页面。**Navigation** 是由 `docs.json` 定义的有序结构。**Hidden files** 列出仓库中未包含在导航里的文件。

切换标签页会重新打开你在该标签页上次查看的页面。**Share** 仅在 **Workspace** 的顶部栏中显示。**Preview**、分支下拉菜单和 **Publish** 仅在 **Site** 中显示。

Hidden files 默认会隐藏部分文件，包括 `docs.json`、名称以点开头的文件和文件夹、没有扩展名的文件、像 `README.md` 这样的全大写 Markdown 文件，以及 `.css`、`.js`、`.jsx`、`.mjs`、`.cjs` 和 `.pdf` 文件。若要查看全部文件，请启用 [Show all files](/zh/editor/settings#appearance)，或按 <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>.</kbd>（macOS）或 <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>.</kbd>（Windows）。

<div id="create-a-page">

## 创建页面

</div>

若要把页面添加到导航中，请在你想放置该页面的导航元素上点击 <Icon icon="plus" /> 加号按钮，然后输入页面名称。编辑器会自动添加 `.mdx` 扩展名。

<div id="add-media">

## 添加媒体

</div>

输入 <kbd>/image</kbd> 或 <kbd>/video</kbd> 上传文件，或选择仓库中已有的文件。你也可以把文件从电脑拖放到页面上。若要复用媒体，请把图片或视频从导航树拖到页面上。

- 上传的文件会保存到 `images/` 和 `videos/` 文件夹，并随下次发布一起提交。
- 支持的格式为 PNG、JPG、JPEG、GIF、WebP、SVG、MP4 和 WebM。
- 若要在浅色和深色模式下显示不同的图片，请将鼠标悬停在已插入的图片上并使用 **Light/dark variants**。
- 输入 <kbd>/embed</kbd> 并粘贴 YouTube、Loom 或 Vimeo 的 URL 即可生成 iframe。其他情况请切换到 **Manual embed** 以编写自定义 HTML。

有关图片格式和 Frame 组件的用法，请参阅[图片与嵌入内容](/zh/create/image-embeds)。

<div id="organize-navigation">

## 组织导航

</div>

在 Navigation 视图中拖动元素即可重新排序或嵌套。发布时，编辑器会把你的更改写入 `docs.json`。有关每个导航元素的作用，包括 group、tab、anchor、dropdown、menu、product、version 和 language，请参阅[导航](/zh/organize/navigation)。

<Note>
  有些元素无法嵌套在其他元素中。例如，tabs 不能嵌套在 groups 中。编辑器会阻止无效的组合。
</Note>

若要修改页面的标题、slug、描述或 layout，请从导航树中打开该页面的设置。有关各项设置的更多信息，请参阅[页面](/zh/organize/pages)。

<div id="add-and-remove-pages-from-your-navigation">

## 在导航中添加和移除页面

</div>

把 **Hidden files** 中的页面拖到 **Navigation** 中，即可在拖放位置添加它。拖动文件夹会把它作为一个 group 添加。你可以拖动多行选择，所有被选中的项会按文档顺序一起移动。

把 **Navigation** 中的页面或 group 拖到 **Hidden files** 中，即可在不删除文件的情况下将其从导航中移除。你也可以在导航树中打开页面的选项菜单，然后选择 **Move to hidden files**。移动后会显示一个撤销提示。

若要把私有页面提升到你的站点，请打开其选项菜单并选择 **Move to site**，或者把它从 **Personal** 拖到 **Navigation**。侧边栏会切换到 **Site** 并高亮显示新添加的行。将私有页面提升为公开是不可逆的操作。

<div id="move-a-page">

## 移动页面

</div>

若要将页面移动到其他文件夹，请打开其选项菜单并选择 **Move to**。菜单旁会打开一个文件夹选择器，按导航树相同的顺序显示你的 workspace 文件夹。

你可以从以下位置打开选项菜单：

- 已打开页面右上角的 <Icon icon="ellipsis" /> **More options**。
- 导航树中页面旁的 <Icon icon="ellipsis" /> 菜单。
- 在导航树中右键点击页面。
- 在页面打开时按 <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>P</kbd>（macOS）或 <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>P</kbd>（Windows）。

在选择器中，通过搜索筛选文件夹、展开文件夹以查看嵌套目标，然后选择一个文件夹来移动页面。当前文件夹会以浅色显示，无法被选中。

移动站点页面会更新其文件路径及其在导航中的位置。移动私有页面会在你的 **Personal** 区中重新归位。Editors 和 admins 可以移动站点页面。你可以移动你所拥有的私有页面。

<div id="delete-a-page">

## 删除页面

</div>

若要删除页面，请点击页面右上角的 <Icon icon="ellipsis" /> **More options**，然后点击 **Move to trash**。你也可以在导航树中通过页面的选项菜单删除页面。

删除页面会同时移除文件及其导航条目。尽管菜单项名为 **Move to trash**，但并没有可用于恢复页面的回收站视图。如果误删了页面，请使用删除后出现的撤销提示。删除操作会在你发布时提交到你的仓库，因此发布之后只能从仓库的历史记录中恢复该页面。

若要在不删除文件的情况下把页面从已发布的导航中移除，请在页面的选项菜单里选择 **Move to hidden files**。

Viewers 无法删除页面。对于私有页面，菜单会显示 **Delete page**，并且删除会立即生效，因为私有页面不会提交到你的仓库。

<div id="version-history">

## 版本历史

</div>

版本历史让你查看并恢复页面此前保存的版本。`docs.json` 不支持版本历史。

Viewers 可以查看和比较私有页面的已保存版本。Editors 和 admins 可以恢复这些版本。

只要内容与最近一次记录的版本不同，编辑器就会记录一条新条目。版本历史按分支划分，只能查看当前分支的版本历史。

若要查看版本历史，请点击页面右上角的 <Icon icon="ellipsis" /> **More options**，然后点击 **Version history**。

如果你恢复某个版本，页面上未保存的更改会被覆盖。恢复公开页面时，只会在当前分支上恢复。恢复私有页面时，会在所有分支上恢复。

<div id="private-pages">

## 私有页面

</div>

私有页面是位于 **Workspace** 标签页 **Personal** 分区中的草稿。它们仅你自己可见，不会提交到你的仓库，也永远不会出现在已发布的站点上。

若要创建私有页面或文件夹，请点击 **Personal** 分区标题上的 <Icon icon="plus" /> 加号按钮，然后选择 **New page** 或 **New folder**。**Workspace** 标签页底部的 **New page** 按钮同样会创建一个私有页面。

若要把私有页面提升到你的站点，请打开其选项菜单并选择 **Move to site**，或者把它拖到 **Site** 标签页的 **Navigation** 中。

<Warning>
  在你把页面提升为公开之后，就无法再把它移回 **Personal** 分区。把私有页面变为公开是不可逆的操作。
</Warning>
