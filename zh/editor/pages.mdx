<div id="home-and-publishing">

## Home 与 Publishing

</div>

编辑器工作区分为两个标签页：**Home** 和 **Publishing**。

**Home** 是你的工作区，显示仓库中的内容文件，包括你的私有页面，无论它们是否出现在已发布的站点上。

**Publishing** 是你已发布的站点，显示访问者看到的导航以及站点设置。

Home 默认会隐藏部分文件，包括 `docs.json`、名称以点开头的文件和文件夹、没有扩展名的文件、像 `README.md` 这样的全大写 Markdown 文件，以及 `.css`、`.js`、`.jsx`、`.mjs`、`.cjs` 和 `.pdf` 文件。若要查看全部文件，请启用 [Show all files](/zh/editor/settings#appearance)，或按 <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>.</kbd>（macOS）或 <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>.</kbd>（Windows）。

<div id="create-a-page">

## 创建页面

</div>

若要把页面添加到导航中，请在你想放置该页面的导航元素上点击 <Icon icon="plus" /> 加号按钮，然后输入页面名称。编辑器会自动添加 `.mdx` 扩展名。

<div id="add-media">

## 添加媒体

</div>

输入 <kbd>/image</kbd> 或 <kbd>/video</kbd> 上传文件，或选择仓库中已有的文件。你也可以把文件从电脑拖放到页面上。若要复用媒体，请把图片或视频从导航树拖到页面上。

- 上传的文件会保存到 `images/` 和 `videos/` 文件夹，并随下次发布一起提交。
- 支持的格式为 PNG、JPG、JPEG、GIF、WebP、SVG、MP4 和 WebM。
- 若要在浅色和深色模式下显示不同的图片，请将鼠标悬停在已插入的图片上并使用 **Light/dark variants**。
- 输入 <kbd>/embed</kbd> 并粘贴 YouTube、Loom 或 Vimeo 的 URL 即可生成 iframe。其他情况请切换到 **Manual embed** 以编写自定义 HTML。

有关图片格式和 Frame 组件的用法，请参阅[图片与嵌入内容](/zh/create/image-embeds)。

<div id="organize-navigation">

## 组织导航

</div>

在 Navigation 视图中拖动元素即可重新排序或嵌套。发布时，编辑器会把你的更改写入 `docs.json`。

- **Groups**：可折叠的分区，用于聚合相关页面。可以嵌套在其他 group 中。
- **Tabs**：带水平导航的顶级分区。适用于 API 参考、指南等相互独立的区域。
- **Anchors**：位于侧边栏顶部的常驻条目。适合外部资源。可以设为全局，从而出现在每个页面上。
- **Dropdowns**：位于侧边栏顶部的可展开菜单。相比 tabs 更轻量的替代方案。
- **Menus**：tab 内部的下拉条目，直接链接到特定页面。
- **Products**：用于切换多套产品文档，每套都有各自的导航。
- **Versions**：用于切换同时存在的多个文档版本。
- **Languages**：用于切换多语言文档。

<Note>
  有些元素无法嵌套在其他元素中。例如，tabs 不能嵌套在 groups 中。编辑器会阻止无效的组合。
</Note>

若要修改页面的标题、slug、描述或 layout，请从导航树中打开该页面的设置。有关各项设置的更多信息，请参阅[页面](/zh/organize/pages)。

<div id="version-history">

## 版本历史

</div>

版本历史让你查看并恢复页面此前保存的版本。`docs.json` 不支持版本历史。

Viewers 可以查看和比较私有页面的已保存版本。Editors 和 admins 可以恢复这些版本。

只要内容与最近一次记录的版本不同，编辑器就会记录一条新条目。版本历史按分支划分，只能查看当前分支的版本历史。

若要查看版本历史，请点击页面右上角的 <Icon icon="ellipsis" /> **More options**，然后点击 **Version history**。

如果你恢复某个版本，页面上未保存的更改会被覆盖。恢复公开页面时，只会在当前分支上恢复。恢复私有页面时，会在所有分支上恢复。

<div id="private-pages">

## 私有页面

</div>

私有页面是位于 **Home** 标签页 **Personal** 分区中的草稿。它们仅你自己可见，不会提交到你的仓库，也永远不会出现在已发布的站点上。

若要创建私有页面或文件夹，请点击 **Personal** 分区标题上的 <Icon icon="plus" /> 加号按钮，然后选择 **New page** 或 **New folder**。

把私有页面或文件夹拖入 workspace 后，协作者会立即可以访问它，但它不会被添加到站点导航中。

<Warning>
  你无法把 workspace 中的内容移回 **Personal** 分区。把私有页面变为公开是不可逆的操作。
</Warning>
