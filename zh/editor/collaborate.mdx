你可以通过评论页面、对页面提出建议，或与同事同时协同编辑，来与团队一起处理页面。

<div id="comments">

## 评论

</div>

评论让你可以针对特定文本留下反馈，而无需修改内容。

**评论永远不会进入你的仓库。** 它们只存在于编辑器中，不会包含在已发布的站点里，也不会提交到 Git。

若要添加评论，请选中文本并点击工具栏中的 <Icon icon="message-square-text" /> **Comment** 图标。若要回复，请点击高亮显示的文本，或点击评论侧边栏中的线程。

<Frame>
  <img src="/images/editor/comment-light.png" alt="编辑器中所选文本上方浮动工具栏里的评论按钮。" className="dark:hidden" />
  <img src="/images/editor/comment-dark.png" alt="编辑器中所选文本上方浮动工具栏里的评论按钮。" className="hidden dark:block" />
</Frame>

所有[角色](/zh/dashboard/roles)都可以发表评论和回复，包括 viewers。只有 editors 和 admins 可以解决线程。解决线程会把它从侧边栏中移除，并清除页面上的高亮。

你可以删除自己的评论，admins 可以删除任何评论。删除线程中的第一条评论会删除整个线程。

输入 `@` 提及同事。对方必须是你所在组织的成员，并会收到电子邮件通知。

如果你的分支存在打开的 pull request，Mintlify 会在其描述中添加未解决线程的摘要，并附上指向每条评论的链接。该摘要会随线程的变化而更新。

<div id="suggestions">

## 建议

</div>

建议会在保留当前内容的前提下提出修改，便于同事接受或拒绝。

Editors 和 admins 可以接受或拒绝任何建议，viewers 不能。

若要提出建议，请选中文本并点击工具栏中的 <Icon icon="pen" /> **Switch to Suggesting** 按钮。在建议模式下，你的删除和插入会以高亮文本的形式显示，而不会直接修改内容。待处理的建议会与评论一起显示在侧边栏中。

<Note>
  [Viewers](/zh/dashboard/roles) 始终处于建议模式。viewer 打开编辑器时会自动进入建议模式，这样他们就可以在不直接修改内容的情况下提出修改。
</Note>

点击高亮显示的建议即可接受或拒绝。无论选择哪一项，该建议线程都会被解决并删除。被接受的修改会成为当前分支的一部分，并在你下次[发布](/zh/editor/publish)时上线。

<div id="ask-the-mintlify-agent">

## 询问 Mintlify 智能体

</div>

在评论、建议或回复中提及 `@mintlify`，即可就当前页面向[编辑器智能体](/zh/editor/agent)提问。智能体会在后台运行，并以该页面、线程和分支作为上下文，然后把回答作为回复发布到同一线程中。

```text
@mintlify does this endpoint support pagination?
@mintlify are there any pages that contradict this?
```

智能体在回复评论时以只读模式运行。它可以搜索你的文档、阅读页面、获取网页内容并加载 skills，但无法编辑内容、创建建议或发布。若要进行修改，请直接打开[编辑器智能体](/zh/editor/agent)。

对于已有访问权限的成员，提及功能在私有页面上同样有效。每条回复都会计入你的编辑器智能体用量。

<div id="real-time-editing">

## 实时编辑

</div>

当多人在同一分支上打开同一页面时，他们会协同编辑。每个人的光标和编辑对所有人可见，工具栏中会显示头像。

- 所有协作者的更改会自动合并。两人编辑同一部分不会产生冲突。
- 撤销只影响你自己的编辑。
- 如果你断开连接，编辑会保存在本地，并在重新连接时同步。

当 [Mintlify 智能体](/zh/agent)通过 API 或 MCP 编辑页面时，它会像其他协作者一样出现，带有头像和位于其最近编辑位置的实时光标。智能体完成后，光标会自动消失。
