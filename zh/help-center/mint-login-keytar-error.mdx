description: "通过将 Mintlify CLI 更新为将凭据保存到配置文件的版本，解决 mint login 报告缺少 keytar 的错误。"
keywords: ["keytar", "mint login", "凭据存储", "npm install keytar", "CLI 认证错误", "mint login 失败"]
---

如果你粘贴了 `mint login` 的授权码，而 CLI 退出并显示：

> keytar is required for credential storage but is not installed. Install it with: npm install keytar

说明你安装的 Mintlify CLI 正在尝试使用 `keytar`，这是一个用于访问操作系统钥匙串的 Node 原生模块。当前版本的 CLI 不依赖 `keytar`，而是将凭据保存到 `~/.config/mintlify/config.json`。请参阅 [`mint login`](/zh/cli/commands#mint-login)。

<div id="fix-the-error">
  ## 修复此错误
</div>

将 CLI 更新到最新版本：

<CodeGroup>
  ```bash npm
  npm i -g mint@latest
  ```

  ```bash pnpm
  pnpm add -g mint@latest
  ```
</CodeGroup>

然后重新运行 `mint login`。

如果错误仍然存在，你可能同时安装了旧版 `mintlify` 包和当前的 `mint` 包。请移除 `mintlify` 并重新安装 `mint`：

```bash
npm uninstall -g mintlify
npm cache clean --force
npm i -g mint
```

完整的安装和故障排查参考，请参阅[安装 CLI](/zh/cli/install)。
