当 Mintlify 无法访问用于构建你文档的仓库或部署分支时，Web 编辑器会显示 **Repository unavailable** 提示。刷新页面无法解决此问题。你需要恢复访问权限或更新 Git 设置。

<div id="common-causes">
  ## 常见原因
</div>

- 仓库已被删除。
- GitHub 仓库已被重命名或转移给其他所有者。
- 部署分支（例如 `main`）已被删除或重命名。

<div id="restore-access">
  ## 恢复访问
</div>

1. 在提示中选择 **Open Git settings**，打开控制台中的 [Git 设置](https://app.mintlify.com/settings/project/git-settings)页面。
2. 确认组织、仓库和分支与你文档当前所在的位置一致。如果仓库或分支已更改，请进行更新。
3. 返回编辑器并选择 **Reload editor**。

<div id="restore-github-app-access">
  ## 恢复 GitHub App 访问权限
</div>

如果 Mintlify GitHub App 失去了对你的 GitHub 仓库的访问权限，编辑器会显示 **Repository Access Required**，而不是 **Repository unavailable** 提示。

1. 选择 **Grant Repository Access**。GitHub 会在新标签页中打开 Mintlify GitHub App 的安装设置。
2. 选择包含你文档的仓库并保存。参见[管理仓库访问权限](/zh/deploy/github#manage-repository-access)。
3. 返回编辑器标签页。编辑器会重新检查访问权限并加载你的内容。

有关连接仓库的更多信息，请参见 [GitHub](/zh/deploy/github) 或 [GitLab](/zh/deploy/gitlab)。
