[Accordion](/zh/components/accordions)、[Card](/zh/components/cards)、[Step](/zh/components/steps)、[Tab](/zh/components/tabs)、[Tile](/zh/components/tiles) 和 [Color.Row](/zh/components/color) 组件的 `title` 属性支持一组有限的内联 Markdown。直接在 `title` 字符串中书写 Markdown 语法，Mintlify 会将其渲染为带格式的文本。

<div id="supported-formatting">
  ## 支持的格式
</div>

- 加粗：`**text**`
- 斜体：`*text*` 或 `_text_`
- 删除线：`~~text~~`
- 内联代码：`` `text` ``
- 链接：`[text](https://example.com)`

```mdx Example
<AccordionGroup>
  <Accordion title="Edit the `docs.json` file">
    Inline code renders in the accordion title.
  </Accordion>
  <Accordion title="**Required:** set your API key">
    Bold text renders in the accordion title.
  </Accordion>
</AccordionGroup>
```

<div id="limitations">
  ## 限制
</div>

- 标题中的链接会渲染为带样式的标签文本，而不是可点击的链接。这样可以避免在本身已可交互的标题内嵌套链接。
- 块级 Markdown、图片、原始 HTML 和 MDX 组件在标题中会渲染为纯文字。
- 不支持下划线。

<div id="how-formatted-titles-affect-ids-and-navigation">
  ## 带格式的标题如何影响 ID 和导航
</div>

锚点 ID、目录条目和标签页同步都使用去除格式字符后的标题纯文本。例如，标题为 `**npm**` 的标签页会与标题为 `npm` 的标签页同步选中状态，因为两者解析出的纯文本相同。
