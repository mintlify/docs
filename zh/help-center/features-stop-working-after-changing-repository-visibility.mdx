如果你将文档仓库从私有改为公开，或从公开改为私有，一些依赖 Git 的功能可能会停止工作：

- **Edit suggestions** 或 **Raise issues** 没有出现在你已发布的网站上。
- 新的拉取请求没有生成预览部署。
- 控制台或编辑器中的分支选项看起来已过时。

Mintlify 会缓存你仓库的可见性和权限。更改可见性后，该缓存状态会一直过时，直到你重新验证 Git 连接。

<div id="check-which-direction-the-visibility-changed">
  ## 确认可见性的变更方向
</div>

- **从私有改为公开**：重新验证会恢复受影响的功能，包括编辑建议和提交 issue。
- **从公开改为私有**：编辑建议和提交 issue 仅适用于公开仓库，因此它们消失属于预期行为。重新验证不会恢复这些功能，但仍会修复其他连接过时的问题，例如缺少预览部署或分支选项过时。

有关反馈功能及其仓库要求的更多信息，请参阅[反馈](/zh/optimize/feedback#enable-feedback)。

<div id="revalidate-your-git-connection">
  ## 重新验证你的 Git 连接
</div>

1. 前往控制台中的 [Git 设置](https://app.mintlify.com/settings/project/git-settings)页面。
2. 按 <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>Enter</kbd>（macOS）或 <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>Enter</kbd>（Windows）。

Mintlify 会重新检查你仓库的可见性和权限。等待大约一分钟，然后刷新你的文档网站。

如果你的部署使用 GitLab，也可以点击 GitLab 设置框中的绿色 **Active** 徽章。请参阅[重新验证 Git 设置](/zh/deploy/gitlab#revalidate-git-settings)。

如果重新验证后功能仍无法正常工作，请联系 [Mintlify 支持](/zh/contact-support)。
