如果 Web 编辑器中的 **Publish** 按钮被禁用，并且将鼠标悬停在按钮上时显示 **Fix invalid MDX before publishing**，说明你分支上至少有一个页面的 MDX 无法解析。在分支上的每个页面都能成功解析之前，编辑器会阻止发布。这可以防止损坏的语法进入你的线上站点。

提示信息会告诉你有多少页面存在错误。常见原因包括：

- 未闭合的组件标签，例如缺少对应 `</Note>` 的 `<Note>`。
- 页面正文中格式错误的 JSX，例如表达式中未闭合的大括号。
- 不是有效 YAML 的 frontmatter，例如缩进不一致或引号未闭合。

<div id="fix-the-error">
  ## 修复错误
</div>

1. 在编辑器中打开受影响的页面。
2. 使用 <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>S</kbd>（macOS）或 <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>S</kbd>（Windows）切换到 source 模式。source 模式会高亮显示无效的 MDX 并展示解析错误。
3. 修复语法。页面能够成功解析后，错误就会消除，**Publish** 按钮会重新可用。

当页面存在无效的 MDX 或无效的 frontmatter YAML 时，这些编辑只会保留在你本地。编辑同一页面的同事只会收到有效内容，因此你引入的语法错误不会覆盖他们的工作。有关实时编辑如何处理无效内容，请参阅[在编辑器中协作](/zh/editor/collaborate)。

有关发布时会发生什么，请参阅[发布更改](/zh/editor/publish)。
