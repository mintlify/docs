如果你无法点击编辑器中的 **Publish** 按钮，并且将鼠标悬停在上面时出现 **Fix invalid MDX before publishing** 错误提示，说明你分支上至少有一个页面的 MDX 无法解析。在分支上的每个页面都能成功解析之前，编辑器都会阻止发布。这可以避免损坏的语法进入你的线上站点。

提示会告知你有多少页面存在错误。同一错误也会在 feature branch 上阻止 **Request review**。常见原因包括：

- 未关闭的组件标签，例如没有对应 `</Note>` 的 `<Note>`。
- 页面正文中格式错误的 JSX，例如表达式中未闭合的大括号。
- frontmatter 不是有效的 YAML，例如缩进不一致或引号未闭合。

当某个页面存在无效的 MDX 或无效的 frontmatter YAML 时，那些编辑仅保留在你本地。协作编辑同一页面的同事只会收到有效内容，因此你引入的语法错误不会覆盖他们的工作。有关实时编辑如何处理无效内容的说明，请参阅[在编辑器中协作](/zh/editor/collaborate)。

<div id="fix-the-error-manually">

## 手动修复错误

</div>

1. 在编辑器中打开受影响的页面。
2. 使用 <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>S</kbd>（macOS）或 <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>S</kbd>（Windows）切换到 source 模式。source 模式会高亮显示无效的 MDX 并展示解析错误。
3. 修复语法。页面能够解析后，错误即会消失，**Publish** 按钮也会重新可用。

<div id="fix-the-error-with-the-agent">

### 使用智能体修复错误

</div>

1. 打开编辑器面板。
2. 提示智能体修复所有无效的 MDX 或 frontmatter YAML。
