如果从 fork 打开的拉取请求没有显示预览部署链接，或者使用 fork 分支调用 [Trigger preview deployment](/zh/api/preview/trigger) 端点失败，这是预期行为。Mintlify 不会从 fork 分支构建预览部署。

Mintlify GitHub 应用必须安装在仓库上才能构建预览。该应用安装在你的主仓库上，而不是贡献者的 fork 上，因此无法读取 fork，也无法基于 fork 构建预览。这同时适用于自动的拉取请求预览和通过 API 触发的预览。API 请求中的 `branch` 值必须存在于与你的 Mintlify 项目连接的仓库中。

<div id="preview-changes-from-a-fork">
  ## 预览来自 fork 的更改
</div>

拥有主仓库写入权限的维护者可以将 fork 的分支推送到主仓库，然后从该分支打开拉取请求，或将该分支名称传递给 API。有关详细信息，请参阅 [Fork 拉取请求](/zh/deploy/preview-deployments#fork-pull-requests)。
