---
title: "修复 logo.href 或 navbar.primary.href 的 \"Must be a valid url\" 错误"
description: "解决在 logo.href、navbar.links 或 navbar.primary.href 中使用 /contact 等相对路径时出现的 docs.json 验证错误。"
keywords: ["Must be a valid url", "Invalid docs.json", "logo.href", "navbar.primary.href", "navbar.links", "relative path", "mint dev error"]
---

当你在 `docs.json` 的 `logo.href`、`navbar.links[].href` 或 `navbar.primary.href` 字段中使用 `/contact` 等相对路径并运行 `mint dev` 或 `mint validate` 时，过时的 CLI 会报告如下错误：

```text
🚨 Invalid docs.json:
#.logo.href: Must be a valid url
#.navbar.primary.href: Must be a valid url
```

当前版本的 Mintlify CLI 在这些字段中既接受绝对 URL，也接受以 `/` 开头的相对路径。使用相对路径可以让链接在预览部署、自定义域名和本地预览中正常工作，而无需硬编码你的生产域名。

<div id="update-the-cli">
  ## 更新 CLI
</div>

更新到最新版本的 CLI：

```bash
mint update
```

如果你的版本不支持 `mint update`，请重新安装 CLI。有关重新安装命令，请参见[安装 CLI](/zh/cli/install#update)。

然后检查你的版本并再次运行验证：

```bash
mint version
mint validate
```

<div id="example-configuration">
  ## 示例配置
</div>

```json docs.json
"logo": {
  "light": "/logo/light.svg",
  "dark": "/logo/dark.svg",
  "href": "/quickstart"
},
"navbar": {
  "links": [
    { "label": "Changelog", "href": "/changelog" }
  ],
  "primary": {
    "type": "button",
    "label": "Contact us",
    "href": "/contact"
  }
}
```

相对路径必须以 `/` 开头。像 `contact` 这样没有前导斜杠的值仍然无法通过验证。`github` 和 `discord` 按钮类型仍然需要 GitHub 仓库 URL 或 Discord 邀请 URL。

有关完整的字段参考，请参见 [`logo`](/zh/organize/settings-appearance#logo) 和 [`navbar`](/zh/organize/settings-structure#navbar)。
