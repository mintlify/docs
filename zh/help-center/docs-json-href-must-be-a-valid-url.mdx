---
title: "修复 logo.href 或 navbar.primary.href 的 \"Must be a valid url\" 错误"
description: "在 logo.href、navbar.links 或 navbar.primary.href 中使用 /contact 等相对路径时，解决 docs.json 验证错误。"
keywords: ["Must be a valid url", "Invalid docs.json", "logo.href", "navbar.primary.href", "navbar.links", "relative path", "mint dev error"]
---

你可以在 `docs.json` 的 `logo.href`、`navbar.links[].href` 或 `navbar.primary.href` 字段中使用 `/contact` 等相对路径。如果你使用旧版本的 CLI 运行 `mint dev` 或 `mint validate`，它会报告类似以下的错误：

```text
🚨 Invalid docs.json:
#.logo.href: Must be a valid url
#.navbar.primary.href: Must be a valid url
```

当前版本的 Mintlify CLI 在这些字段中同时接受绝对 URL 和以 `/` 开头的相对路径。使用相对路径后，链接可以在预览部署、自定义域名和本地预览中正常工作，无需硬编码你的生产域名。

<div id="update-the-cli">
  ## 更新 CLI
</div>

将 CLI 更新到最新版本：

```bash
mint update
```

如果你的版本不支持 `mint update`，请重新安装 CLI。重新安装命令请参阅[安装 CLI](/zh/cli/install#update)。

然后检查你的版本并重新运行验证：

```bash
mint version
mint validate
```

<div id="example-configuration">
  ## 配置示例
</div>

```json docs.json
"logo": {
  "light": "/logo/light.svg",
  "dark": "/logo/dark.svg",
  "href": "/quickstart"
},
"navbar": {
  "links": [
    { "label": "Changelog", "href": "/changelog" }
  ],
  "primary": {
    "type": "button",
    "label": "Contact us",
    "href": "/contact"
  }
}
```

相对路径必须以 `/` 开头。没有前导斜杠的值（例如 `contact`）仍然无法通过验证。`github` 和 `discord` 按钮类型仍然需要 GitHub 仓库 URL 或 Discord 邀请 URL。

完整的字段参考请参阅 [`logo`](/zh/organize/settings-appearance#logo) 和 [`navbar`](/zh/organize/settings-structure#navbar)。
