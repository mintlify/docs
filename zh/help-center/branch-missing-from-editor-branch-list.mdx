如果你在编辑器工具栏中完全看不到分支下拉菜单，它可能被个人偏好设置隐藏了。请参阅[显示分支选择器](/zh/editor/publish#show-the-branch-selector)。

如果仓库中存在的某个分支没有出现在 Web 编辑器的分支下拉菜单中，该分支并没有被删除。下拉菜单有意只列出：

- 在 Web 编辑器中创建、且没有已合并或已关闭拉取请求的分支。
- 有指向部署用分支的开放拉取请求或合并请求的分支。

以下分支不会出现在下拉菜单中：

- 直接推送到 GitHub、GitLab 或 Bitbucket、且没有开放拉取请求的分支。
- 拉取请求已被合并或关闭的分支，包括在 Web 编辑器中创建的分支。分支的拉取请求被合并后，即使该分支仍存在于你的仓库中，它也会从下拉菜单中移除。
- 拉取请求指向部署用分支以外分支的分支。
- 拉取请求是从 fork 打开的分支。有关 fork 的相关限制，请参阅[未为 fork 分支创建预览部署](/zh/help-center/preview-deployment-not-created-for-fork-branch)。

你在这些分支上的工作都安全地保存在你的仓库中。你可以在 Git 提供商中查看该分支来确认这一点。

<div id="open-a-branch-that-isnt-listed">
  ## 打开未列出的分支
</div>

为该分支打开一个指向部署用分支的拉取请求或合并请求，且分支需位于同一仓库中，而不是 fork。之后该分支就会出现在编辑器的分支下拉菜单中，并获得完整的编辑器支持。

如果你需要在打开拉取请求之前查看或编辑该分支，请先在编辑器中打开任意分支，然后将浏览器 URL 中的分支名称替换为你想要的分支名称。编辑器会加载该分支，但在拉取请求存在之前，分支专属功能不可用：自动提交会被跳过，审阅视图无法加载差异（diff），并且你无法在编辑器中重命名或删除该分支。

有关创建和切换分支的更多信息，请参阅[使用 branch](/zh/guides/branches)。
