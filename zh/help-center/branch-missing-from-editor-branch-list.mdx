如果存储库中存在的某个 branch 没有出现在 Web 编辑器的 branch 下拉菜单中，该 branch 并没有被删除。下拉菜单有意只列出：

- 在 Web 编辑器中创建的 branch。
- 有指向部署用分支的开放拉取请求（PR）或合并请求（MR）的 branch。

未开启拉取请求、直接推送到 GitHub、GitLab 或 Bitbucket 的 branch 不会出现在列表中。你在这些 branch 上的工作仍安全地保存在存储库中。你可以在 Git 提供商中查看该 branch 加以确认。

<div id="open-a-branch-that-isnt-listed">
  ## 打开未列出的 branch
</div>

可使用以下任一方法：

- **开启拉取请求或合并请求**：在你的 Git 提供商中为该 branch 开启一个指向部署用分支的拉取请求或合并请求。该 branch 随后就会出现在编辑器的 branch 下拉菜单中。
- **编辑编辑器 URL**：在编辑器中打开任意 branch，然后将浏览器 URL 中的 branch 名称替换为你想要的 branch 名称。编辑器会直接加载该 branch。

要详细了解如何创建和切换 branch，请参阅[使用 branch](/zh/guides/branches)。
