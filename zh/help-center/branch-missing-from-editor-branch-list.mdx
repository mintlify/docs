如果你在编辑器工具栏中完全看不到分支下拉菜单，它可能被个人偏好设置隐藏了。请参阅[显示分支选择器](/zh/editor/publish#show-the-branch-selector)。

如果仓库中存在的某个分支没有出现在 Web 编辑器的分支下拉菜单中，该分支并没有被删除。在输入搜索内容之前，下拉菜单有意只列出：

- 在 Web 编辑器中创建、且没有已合并或已关闭拉取请求的分支。
- 有指向部署用分支的开放拉取请求或合并请求的分支。

<div id="find-a-branch-with-search">
  ## 通过搜索查找分支
</div>

在下拉菜单的搜索框中输入内容，即可找到不在默认列表中的分支：

- 直接推送到 GitHub、GitLab 或 Bitbucket 且没有拉取请求的分支，会在你的搜索内容匹配分支名称的一部分时出现。这些条目只显示分支名称，不显示拉取请求状态或贡献者。
- 拉取请求已合并或已关闭的分支，会在你的搜索内容匹配分支名称或拉取请求标题时出现。

从 fork 发起拉取请求的分支仍然不会出现，因为该分支位于 fork 中，而不在你的仓库里。相关的 fork 限制请参阅[未为 fork 分支创建预览部署](/zh/help-center/preview-deployment-not-created-for-fork-branch)。

<div id="work-with-a-branch-that-has-no-pull-request">
  ## 使用没有拉取请求的分支
</div>

你可以在下拉菜单中搜索并选择没有拉取请求的分支来打开它。在针对部署用分支的拉取请求存在之前，特定于分支的编辑器功能不可用：自动提交会被跳过，审阅视图无法加载 diff，你也无法在编辑器中重命名或删除该分支。

从同一仓库（而非 fork）中的分支，针对你的部署用分支为该分支打开拉取请求或合并请求。之后该分支就会出现在编辑器的分支下拉菜单中，并获得完整的编辑器支持。

关于创建和切换分支的更多信息，请参阅[使用分支](/zh/guides/branches)。
