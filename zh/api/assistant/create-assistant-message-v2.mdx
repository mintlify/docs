<Info>
  assistant 消息 v2 端点兼容 **AI SDK v5+**。如果你正在使用 AI SDK v4，请改用 [assistant 消息 v1 端点](/zh/api/assistant/create-assistant-message)。
</Info>

<div id="integration-with-usechat">
  ## 与 `useChat` 集成
</div>

Vercel 的 AI SDK 提供的 `useChat` hook 是在你的应用程序中集成 assistant API 的推荐方式。

<Steps>
  <Step title="安装 AI SDK">
    ```bash
    npm i ai@^6 @ai-sdk/react
    ```
  </Step>

  <Step title="使用 hook">
    ```tsx
    import { useState } from "react";
    import { useChat } from "@ai-sdk/react";
    import { DefaultChatTransport } from "ai";

    function MyComponent({ domain }) {
      const [input, setInput] = useState("");

      const { messages, sendMessage } = useChat({
        transport: new DefaultChatTransport({
          api: `https://api.mintlify.com/discovery/v2/assistant/${domain}/message`,
          headers: {
            Authorization: `Bearer ${process.env.PUBLIC_MINTLIFY_ASSISTANT_KEY}`,
          },
          body: {
            fp: "anonymous",
            retrievalPageSize: 5,
            context: [
              {
                type: "code",
                value: 'const example = "code snippet";',
                elementId: "code-block-1",
              },
            ],
          },
        }),
      });

      return (
        <div>
          {messages.map((message) => (
            <div key={message.id}>
              {message.role === "user" ? "User: " : "Assistant: "}
              {message.parts
                .filter((part) => part.type === "text")
                .map((part) => part.text)
                .join("")}
            </div>
          ))}
          <form
            onSubmit={(e) => {
              e.preventDefault();
              if (input.trim()) {
                sendMessage({ text: input });
                setInput("");
              }
            }}
          >
            <input value={input} onChange={(e) => setInput(e.target.value)} />
            <button type="submit">Send</button>
          </form>
        </div>
      );
    }
    ```

    **必填配置：**

    * `transport` - 使用 `DefaultChatTransport` 来配置 API 连接。
    * `body.fp` - 指纹标识符 (使用 `'anonymous'` 或唯一的用户标识符) 。
    * `body.retrievalPageSize` - 要使用的搜索结果数量 (推荐：5) 。

    **可选配置：**

    * `body.context` - 提供给 AI 助手的上下文信息数组。每个 context 对象包含：
      * `type` - `'code'` 或 `'textSelection'` 之一。
      * `value` - 代码片段或选中的文本内容。
      * `path` (可选) - 源文件或页面的路径。
      * `elementId` (可选) - 包含该 context 的 UI 元素标识符。
    * `body.currentPath` - 用户当前正在查看页面的路径。提供该字段时，AI 助手会利用此 context 提供更相关的回答。最大长度：200 个字符。
  </Step>
</Steps>

更多详情参见 AI SDK 文档中的 [useChat](https://ai-sdk.dev/docs/reference/ai-sdk-ui/use-chat) 和 [Transport](https://ai-sdk.dev/docs/ai-sdk-ui/transport)。

<div id="migrate-from-v1">
  ## 从 v1 迁移
</div>

v1 端点已停用，并返回 `410 Gone`。要进行迁移，请将 URL 从 `/discovery/v1/assistant/{domain}/message` 更改为 `/discovery/v2/assistant/{domain}/message`，并更新你的消息和流处理逻辑。

你的 API 密钥以及以下请求体字段保持不变：`fp`、`threadId`、`threadKey`、`regenerate`、`retrievalPageSize`、`filter`、`context` 和 `currentPath`。

<div id="if-you-use-usechat">
  ### 如果你使用 `useChat`
</div>

升级到 AI SDK v5 或更高版本，并按照[与 `useChat` 集成](#integration-with-usechat)中的示例使用 `DefaultChatTransport`。移除 `streamProtocol` 和 `sendExtraMessageFields`，v2 中不再需要它们。从 `message.parts` 而不是 `message.content` 渲染消息。

<div id="if-you-call-the-api-directly">
  ### 如果你直接调用 API
</div>

**消息使用 `parts` 而不是 `content`。** 移除 `content` 字符串，并将文本作为 text part 发送。不再接受 `data` 角色。

<CodeGroup>

```json v1
{
  "id": "msg_1",
  "role": "user",
  "content": "How do I get started?",
  "parts": [{ "type": "text", "text": "How do I get started?" }]
}
```

```json v2
{
  "id": "msg_1",
  "role": "user",
  "parts": [{ "type": "text", "text": "How do I get started?" }]
}
```

</CodeGroup>

**附件是 `file` part。** 将 `experimental_attachments` 替换为 `parts` 中的条目。

<CodeGroup>

```json v1
{
  "experimental_attachments": [
    { "name": "screenshot.png", "contentType": "image/png", "url": "data:image/png;base64,..." }
  ]
}
```

```json v2
{
  "parts": [
    { "type": "file", "filename": "screenshot.png", "mediaType": "image/png", "url": "data:image/png;base64,..." }
  ]
}
```

</CodeGroup>

**响应以 server-sent events 形式流式返回。** v1 返回 AI SDK v4 的 data stream，由 `0:"..."` 行组成。v2 返回 AI SDK 的 [UI message stream](https://ai-sdk.dev/docs/ai-sdk-ui/stream-protocol#ui-message-stream)。每个事件都是一行 `data: {...}` JSON，文本通过 `text-delta` 事件传递，流以 `data: [DONE]` 结束。`X-Thread-Id`、`X-Thread-Key` 和 `X-Message-Id` 响应头保持不变。
