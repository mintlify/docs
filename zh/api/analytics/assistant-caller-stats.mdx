<div id="usage">
  ## 使用方法
</div>

使用此端点查看来自每种调用方类型的助手会话数量。无论会话包含多少个问题，每个会话只计数一次。响应将会话总数细分为：

- `web`：来自文档站点的会话
- `api`：来自直接 API 调用的会话
- `other`：来自其他来源的会话（例如集成、SDK）
- **total**：所有调用方类型的总和

<div id="filtering">
  ## 筛选
</div>

使用 `dateFrom` 和 `dateTo` 参数按日期范围筛选。每个会话计入其开始时所在的日期范围。

<div id="rate-limits">
  ## 速率限制
</div>

此端点允许每个组织每小时最多 100 次请求。所有分析端点共享此限制。
