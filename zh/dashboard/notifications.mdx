在控制台的[通知](https://app.mintlify.com/settings/organization/notifications)页面选择 Mintlify 向你发送哪些邮件。通知偏好设置仅适用于你自己的账户。组织中的每位成员各自管理自己的偏好设置。

<div id="email-notification-types">
  ## 电子邮件通知类型
</div>

你可以针对单个事件或整个类别开启或关闭邮件。

| 类别 | 事件 |
| -------- | ------ |
| 评论 | 页面上的新评论、你关注的线程收到的回复、`@` 提及、线程被解决，以及你的评论收到的回应。请参见[在编辑器中协作](/zh/editor/collaborate)。 |
| 建议 | 新建、被接受和被拒绝的建议。 |
| 自动化运行 | 成功和失败的[自动化](/zh/automations/index)运行。 |
| 通用产品反馈 | 正面和负面的[页面反馈](/zh/optimize/feedback)。 |

评论和建议邮件默认开启。回应、自动化运行和反馈邮件默认关闭。

<div id="organization-notification-settings">
  ## 组织通知设置
</div>

Admins 还可以在通知页面管理组织范围的通知邮件：

- **管理员联系邮箱（Admin contact emails）**：用于接收账单提醒、部署通知以及其他与你的组织相关的通信的邮箱地址。
- **安全联系人（Security contact）**：用于接收安全相关通信的邮箱地址。请参见[安全联系人](/zh/dashboard/security-contact)。
