在 [Members](https://app.mintlify.com/settings/organization/members) 页面管理谁可以访问你组织的 dashboard。每位成员都有一个[角色](/zh/dashboard/roles)，用于控制其可以执行的操作。

<div id="add-members-to-your-organization">
  ## 向组织添加成员
</div>

默认情况下，创建 Mintlify 组织的人拥有管理员权限。如果你的组织使用[扩展角色](/zh/dashboard/roles#expanded-roles)，此人即为所有者。你可以在 dashboard 的 [Members](https://app.mintlify.com/settings/organization/members) 页面添加其他成员。

<Info>
  Starter 方案最多可有 5 名成员。文档项目的 Pro 和 Enterprise 方案可以邀请任意数量的成员。Base 有其自身的[席位限制](/zh/base/index#features-and-plans)。
</Info>

editor 和 admin 可以邀请 editor 和 viewer。只有 admin 可以邀请其他 admin。

1. 前往 dashboard 的 [Members](https://app.mintlify.com/settings/organization/members) 页面。
2. 在 **New member** 中输入电子邮件地址，或粘贴一份以逗号、分号、空格或换行符分隔的列表。你一次最多可以邀请 250 个地址。
3. 选择一个角色。在 Enterprise 套餐中，默认角色为 **Viewer**。
4. 点击 **Invite**。

如果所有地址都是新的，邀请会立即发送。如果有任何地址无效、重复，或已是成员或已被邀请，则会打开一个查看抽屉。移除相应行或更改角色，然后点击 **Send invites**。

<Info>
  **Bulk invite** 需要 [Pro 或 Enterprise 方案](https://mintlify.com/pricing)。
</Info>

使用 **Bulk invite** 上传包含电子邮件地址的 CSV 文件。选择一个角色，点击 **Invite**，并在发送邀请前查看列表。

<div id="change-a-members-role">
  ## 更改成员的角色
</div>

管理员可以更改分配给任意成员的角色。

1. 前往 dashboard 的 [Members](https://app.mintlify.com/settings/organization/members) 页面。
2. 在该成员所在行，从 **Role** 下拉菜单中选择新的角色。更改会立即保存。

新角色将在该成员下次加载 dashboard 时生效。你无法更改自己的角色。如果某成员的角色来自 [SCIM 目录同步](/zh/dashboard/scim#roles-for-provisioned-members)，其所在行会显示 **Managed by SSO**，你需要在身份提供商中更改其角色。

如果你的组织使用[扩展角色](/zh/dashboard/roles#expanded-roles)，只有在所有者将所有权转移给其他成员后，所有者的角色才能更改。

<div id="transfer-ownership">
  ### 转移所有权
</div>

如果你的组织使用[扩展角色](/zh/dashboard/roles#expanded-roles)，所有者可以将其他成员设为所有者。只有所有者才能在 **Role** 下拉菜单中看到 **Owner** 角色。原所有者会成为管理员，并且只有新所有者可以再次转移所有权。

1. 前往 dashboard 的 [Members](https://app.mintlify.com/settings/organization/members) 页面。
2. 在该成员所在行，从 **Role** 下拉菜单中选择 **Owner**。
3. 在 **Transfer ownership?** 对话框中，输入 `TRANSFER` 进行确认。
4. 点击 **Transfer ownership**。

你只能将所有权转移给活跃成员。你无法将其转移给待处理的邀请，也无法转移给角色来自身份提供商的成员。

<div id="assign-a-custom-role">
  ### 分配自定义角色
</div>

如果你的组织有[自定义角色](/zh/dashboard/roles#custom-roles)，在你邀请成员、更改成员角色或更改待处理邀请的角色时，它们会显示在 **Role** 下拉菜单中的内置角色下方。下拉菜单只列出你拥有其权限的角色。

<div id="delete-a-custom-role">
  ## 删除自定义角色
</div>

1. 前往 dashboard 的 [Members](https://app.mintlify.com/settings/organization/members) 页面。
2. 在 **Custom roles** 部分，打开该角色的操作菜单并选择 **Delete role**。
3. 如果有成员拥有该角色，请为每位成员选择新角色。未更改的成员将成为查看者。
4. 点击 **Delete permanently**。

如果某位成员的该角色来自你的身份提供商，则无法删除该角色。请先在身份提供商中移除该角色分配。

<div id="remove-a-member">
  ## 移除成员
</div>

管理员可以将成员从组织中完全移除，这会删除其访问权限以及其创建的任何密钥。

1. 前往 dashboard 的 [Members](https://app.mintlify.com/settings/organization/members) 页面。
2. 在该成员所在行，打开操作菜单并选择 **Remove member**。
3. 点击 **Remove** 进行确认。

你无法移除使用[扩展角色](/zh/dashboard/roles#expanded-roles)的组织的所有者。要移除所有者，请先将[所有权转移](#transfer-ownership)给其他成员。

移除成员与撤销凭证不同：移除会将该成员从组织中删除，而撤销会将其登出并清除其密钥，但保留其成员身份。

<div id="revoke-a-members-credentials">
  ## 撤销成员的凭证
</div>

管理员可以将成员从 dashboard 中登出，并撤销其密钥和令牌，而无需将其从组织中移除。在 offboarding 某人或响应账户被盗用时，可以使用撤销凭证功能。

1. 前往 dashboard 的 [Members](https://app.mintlify.com/settings/organization/members) 页面。
2. 在该成员所在行，打开操作菜单并选择 **Revoke credentials**。
3. 选择要撤销的凭证。
4. 点击 **Revoke**。

你可以撤销以下凭证的任意组合：

| 凭证 | 撤销后的效果 |
| ---------- | --------------------- |
| Sessions | 将该成员从 dashboard 登出。 |
| CLI tokens | 将该成员从 [CLI](/zh/cli/install) 登出。 |
| API keys | 删除该成员创建的 API 密钥。 |
| Discovery API keys | 删除该成员创建的 discovery API 密钥。 |
| M2M clients | 撤销该成员的机器对机器（M2M）客户端凭证。 |
| Connected apps | 断开该成员通过 OAuth 授权的应用。 |

撤销凭证无法撤消。除非你同时将该成员从组织中移除或阻止其登录方式，否则该成员仍可以重新登录并创建新的密钥和令牌。你无法撤销自己的凭证。
