在你的[个人资料](https://app.mintlify.com/settings/account)设置中管理你的个人信息和控制台偏好。个人资料设置仅适用于你的账户，不会改变组织中其他成员看到的内容。

<div id="personal-information">
  ## 个人信息
</div>

更新你的名字和姓氏，或上传头像。头像可以是 PNG、JPEG、WebP 或 SVG 文件。

<div id="starting-page">
  ## 起始页
</div>

默认情况下，当你访问 [app.mintlify.com](https://app.mintlify.com) 时会加载编辑器。要在打开 Mintlify 时使用其他起始页，请在 **Preferences** 部分的 **Starting page** 菜单中进行选择。

当你打开控制台、切换组织或打开项目的根 URL（例如 `https://app.mintlify.com/{organization}/{project}`）时，控制台会使用你的起始页。指向特定页面、文档或分支的链接仍会打开相应的目标位置。

<div id="theme">
  ## 主题
</div>

在 **Appearance** 部分选择 **Light** 或 **Dark**。

<div id="desktop-app">
  ## 桌面应用
</div>

如果你通过此浏览器登录了[桌面应用](/zh/desktop)，**Desktop app** 部分会显示 **Always open in desktop app** 开关。开启后，来自 Slack、电子邮件和其他应用的 Mintlify 链接会在桌面应用而不是浏览器中打开。此设置仅适用于当前浏览器。参见[从浏览器打开控制台页面](/zh/desktop#open-dashboard-pages-from-your-browser)。

<div id="workspace">
  ## 工作区
</div>

**Workspace** 部分显示你加入组织的时间。如果你的组织使用[角色](/zh/dashboard/roles)，该部分还会显示你的角色。

<div id="connect-github">
  ## 连接 GitHub
</div>

在 **Integrations** 部分点击 **Authorize** 以连接你的 GitHub 账户。连接后：

- Mintlify 会使用你的 GitHub 账户（而不是 Mintlify GitHub App）签署[你在网页编辑器中所做的 commit](/zh/editor/publish#commit-signing)。
- 代理会将[它创建的拉取请求](/zh/agent/index#connect-your-github-account)归属于你，而不是 Mintlify 机器人。

要移除连接，请点击 **Disconnect**。
