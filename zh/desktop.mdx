<Note>
  桌面应用目前处于 beta 阶段，可能会发生变化。
</Note>

Mintlify 桌面应用在你的电脑上运行你的[控制台](https://app.mintlify.com)和[编辑器](/zh/editor/index)。你可以在标签页或多个窗口中工作，访问与浏览器中相同的内容和设置。

桌面应用更新内容的方式与在编辑器中工作相同。它不会打开或编辑你电脑上的文件。如需处理本地文件，请使用 [CLI](/zh/cli/index)。

<div id="install">
  ## 安装
</div>

<Tabs>
  <Tab title="macOS">
    需要搭载 Apple 芯片的 macOS 14 或更高版本。

    1. 从 [mintlify.com/desktop](https://mintlify.com/desktop) 下载桌面应用。
    2. 打开该文件。
    3. 将 **Mintlify** 拖到你的 **Applications** 文件夹中。

    你也可以通过终端安装。

    ```bash Install the desktop app
    curl -fsSL https://desktop.mintlify.com/install.sh | bash
    ```

    该脚本会安装到 `/Applications`；如果你无法写入 `/Applications`，则会安装到 `~/Applications`。
  </Tab>
  <Tab title="Windows">
    需要 64 位 Windows 10 或更高版本。

    1. 从 [mintlify.com/desktop](https://mintlify.com/desktop) 下载桌面应用。
    2. 运行安装程序。

  </Tab>
  <Tab title="Linux">
    需要 x86_64 设备。桌面应用提供 AppImage 和 `.deb` 软件包两种格式。

    从 [mintlify.com/desktop](https://mintlify.com/desktop) 下载任一文件，或通过终端安装 AppImage。

    ```bash Install the desktop app
    curl -fsSL https://desktop.mintlify.com/install.sh | bash
    ```

    该脚本会将应用安装到 `~/.local/share/mintlify-desktop`，在 `~/.local/bin` 中添加 `mintlify-desktop` 命令，并将 Mintlify 添加到你的应用程序菜单中。

    AppImage 需要 FUSE 2。如果桌面应用无法启动，请安装 FUSE 2。在 Ubuntu 上：

    ```bash Install FUSE 2
    sudo apt install libfuse2
    ```
  </Tab>
</Tabs>

<div id="sign-in">
  ## 登录
</div>

1. 打开桌面应用。桌面应用会显示 **Log in to Mintlify** 界面。
2. 点击 **Log in here instead**。
3. 按照你在浏览器中登录控制台的相同方式登录。

<Note>
  beta 访问期间不支持基于浏览器的登录。你无法使用 **Continue in browser** 按钮登录。
</Note>

<div id="tabs-and-windows">
  ## 标签页和窗口
</div>

在单独的标签页或窗口中打开你正在处理的每个页面。重启应用后，标签页和窗口会恢复到你离开时的位置。

右键点击标签页可以复制该标签页、复制其链接或关闭其他标签页。用鼠标中键点击标签页可以将其关闭。

如需在侧边栏而不是窗口顶部显示标签页，请在[设置](#settings)中更改标签页布局。

<div id="each-tab-has-its-own-session">
  ### 每个标签页都有独立的会话
</div>

新标签页打开时，会登录到与打开它的标签页相同的账户和组织。之后，每个标签页都会保持各自独立的会话：

- 在一个标签页中切换组织不会影响其他标签页，因此你可以同时在不同的组织中工作。
- 退出登录或登录其他账户只会影响当前标签页。

如需在所有位置退出登录，请使用[设置](#settings)中的 **Clear all data**。

<div id="links-to-other-sites">
  ### 指向其他网站的链接
</div>

标签页只会加载 Mintlify 控制台以及它用于登录、获取 AI 功能额度和连接 Git 提供商的服务。指向任何其他网站的链接都会在你的默认浏览器中打开。

<div id="keyboard-shortcuts">
  ## 键盘快捷键
</div>

在 Windows 和 Linux 上，请使用 <kbd>Ctrl</kbd> 代替 <kbd>Cmd</kbd>。

| 操作 | 快捷键 |
| :--- | :--- |
| 新建标签页 | <kbd>Cmd</kbd> + <kbd>T</kbd> |
| 新建窗口 | <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>N</kbd> |
| 关闭标签页 | <kbd>Cmd</kbd> + <kbd>W</kbd> |
| 关闭窗口 | <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>W</kbd> |
| 转到标签页 1-9 | <kbd>Cmd</kbd> + <kbd>1</kbd>-<kbd>9</kbd> |
| 下一个标签页 | <kbd>Ctrl</kbd> + <kbd>Tab</kbd> |
| 上一个标签页 | <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>Tab</kbd> |
| 后退 | <kbd>Cmd</kbd> + <kbd>[</kbd> |
| 前进 | <kbd>Cmd</kbd> + <kbd>]</kbd> |
| 重新加载 | <kbd>Cmd</kbd> + <kbd>R</kbd> |
| 复制页面 URL | <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>C</kbd> |
| 打开设置 | <kbd>Cmd</kbd> + <kbd>,</kbd> |

有关编辑器内的快捷键，请参阅[键盘快捷键](/zh/editor/keyboard-shortcuts)。

<div id="settings">
  ## 设置
</div>

在 macOS 上按 <kbd>Cmd</kbd> + <kbd>,</kbd>，或在 Windows 和 Linux 上按 <kbd>Ctrl</kbd> + <kbd>,</kbd> 打开设置。

- **Tab layout**：在窗口顶部（**Horizontal**）或侧边栏中（**Vertical**）显示标签页。
- **Clear all data**：退出所有标签页的登录，关闭所有标签页并重置设置。应用会重新启动。

设置窗口还会显示应用版本。

<div id="updates">
  ## 更新
</div>

应用会在启动时以及运行期间每四小时检查一次更新。有可用更新时，标签栏中会出现 **Update** 按钮。

如需立即检查，请在[设置](#settings)中点击版本号旁边的 **Check for updates**。如果有可用更新，该按钮会变为 **Update to** 加新版本号。点击该按钮即可安装更新，效果与标签栏按钮相同。

- **macOS**：点击 **Update**，在应用内下载并安装更新。
- **Windows 和 Linux**：点击 **Update**，从浏览器下载新版本，然后进行安装。

<div id="uninstall">
  ## 卸载
</div>

<Tabs>
  <Tab title="macOS">
    1. 退出桌面应用。
    2. 将 **Mintlify** 从你的 **Applications** 文件夹移到废纸篓。
    3. 如需删除你的登录信息和设置，请删除 `~/Library/Application Support/Mintlify Electron`。
  </Tab>
  <Tab title="Windows">
    1. 打开 **Settings** > **Apps** > **Installed apps**。
    2. 找到 **Mintlify** 并选择 **Uninstall**。
    3. 如需删除你的登录信息和设置，请删除 `%APPDATA%\Mintlify Electron`。
  </Tab>
  <Tab title="Linux">
    如果你是通过脚本安装的桌面应用，请删除脚本创建的文件：

    ```bash Remove the desktop app
    rm -rf ~/.local/share/mintlify-desktop \
      ~/.local/bin/mintlify-desktop \
      ~/.local/share/applications/mintlify-desktop.desktop \
      ~/.local/share/icons/hicolor/512x512/apps/mintlify-desktop.png
    ```

    如果你安装的是 `.deb` 软件包，请使用你的软件包管理器将其删除。

    如需删除你的登录信息和设置，请删除 `~/.config/Mintlify Electron`。
  </Tab>
</Tabs>
