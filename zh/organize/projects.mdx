你的 Mintlify 组织包含一个或多个项目。每个项目要么是文档，要么是 Base。组织成员可以在每个项目中工作，因此同一个团队既可以维护你的公开文档，也可以维护你的内部知识库。

<div id="project-types">

## 项目类型

</div>

|  | Docs | Base |
| --- | --- | --- |
| 面向对象 | 你的用户及其智能体 | 你的团队及其智能体 |
| 内容示例 | API 参考、指南和帮助中心 | 规范、运维手册和入职指南 |
| 阅读位置 | 拥有独立 URL 的文档站点，可公开访问或需要[身份验证](/zh/deploy/authentication-setup) | 你的控制台和已连接的 AI 工具，仅限你组织的成员 |
| 保存更改 | 在分支上编辑，然后发布 | 对共享页面的编辑会自动提交到你的仓库 |
| 开始使用 | [快速开始](/zh/quickstart) | [设置 Base](/zh/base/setup) |

两种项目类型使用相同的[编辑器](/zh/editor/index)、[智能体](/zh/editor/agent)和 [admin MCP](/zh/ai/mintlify-mcp)，因此在任一类型中编辑内容的体验都相同。并且两种项目类型都将页面存储在 Git 仓库中。

<div id="create-a-project">

## 创建项目

</div>

注册 Mintlify 时，你会创建第一个项目。你可以从[控制台](https://app.mintlify.com/)向组织添加其他项目。

<Steps>
  <Step title="创建新项目">
    1. 点击左侧边栏顶部的项目切换器。
    2. 点击 <Icon icon="plus" /> **New project**。
  </Step>
  <Step title="选择项目类型">
    1. 选择 **Docs** 或 **Base**。
    2. 对于文档项目，输入 **Site address**。
    3. 点击 **Continue**。
  </Step>
  <Step title="设置项目">
    1. 选择你计划的更新方式：**Web editor**、**Local development** 或 **MCP**。此选择仅用于初始设置。之后你可以在项目中使用所有方式。
    2. 点击 **Create project**。
  </Step>
</Steps>

<div id="switch-projects">

## 切换项目

</div>

1. 点击左侧边栏顶部的项目切换器。
2. 选择一个项目。

<div id="copy-pages-between-projects">

## 在项目之间复制页面

</div>

若要在另一个项目中复用某个页面，例如你想在文档中发布的 Base 页面，请打开其选项菜单并选择 **Copy to a project**。副本独立于原始页面。有关详细信息，请参阅[将页面复制到其他项目](/zh/editor/pages#copy-a-page-to-another-project)。
