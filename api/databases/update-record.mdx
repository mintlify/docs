## Conditional writes

Send `If-Match` with the quoted `version` you last read, such as `If-Match: "3"`. If the record changed in the meantime, nothing is written and the response is `412` with `code: "version_mismatch"` and the current `version`. See [versions](/databases/records#versions-and-conditional-writes).
