Use this endpoint to start an [Autopilot](/autopilot) run from your own tools. Each request queues a run that follows the `prompt` in the request body, using the same context, skills, and review settings as Autopilot's other runs.

Autopilot must be enabled for the project.

## Use cases

Autopilot already watches your connected repositories. Use the webhook for changes that happen outside them:

- **Feature launches**: Update the docs when a feature flag rolls out to everyone or a beta becomes generally available.
- **Support tools**: Send a docs request when your support team tags a ticket as a docs gap.
- **Internal tooling**: Send docs requests from internal dashboards or scheduled jobs you already run.

## Get the webhook URL and auth header

Open the [Autopilot](https://app.mintlify.com/products/autopilot) page in your dashboard. The **Webhook** section shows the full webhook URL and a **Copy auth header** action for the `Authorization: Bearer <api-key>` header template.

Replace `<api-key>` with an unexpired organization API key with write access. Create or manage keys on the [API keys](https://app.mintlify.com/settings/organization/api-keys) page.

## Example

Ask Autopilot to update the docs when a beta feature becomes generally available:

```bash
curl -X POST "https://api.mintlify.com/v2/autopilot/$PROJECT_ID/webhook" \
  -H "Authorization: Bearer $MINTLIFY_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"prompt": "Scheduled exports are now generally available to all plans. Remove the beta callout from the scheduled exports pages and add the feature to the changelog."}'
```

## What happens after a request

Autopilot works on the prompt like any other run. When it opens or updates a pull request, it assigns reviewers and notifies your team the same way it does for code changes. Each run appears as its own thread on the Autopilot page.

If Autopilot is paused, the run waits until you resume Autopilot.

## Rate limits and credits

This endpoint shares a rate limit with [Trigger update](/api/update/trigger), [Trigger automation](/api/automations/trigger), and [Trigger automation webhook](/api/automations/webhook): up to 10 requests per 10 seconds per organization.

A run costs 250 credits when it opens or updates a pull request. See [Autopilot credits](/autopilot#credits).
