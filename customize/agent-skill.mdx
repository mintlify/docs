The `mintlify` skill helps your coding agent write documentation, configure your site, and customize its appearance and browser behavior. It includes references for selectors, component parts, CSS variables, browser APIs, script lifecycle, themes, and React snippets. Your agent loads only the references a task needs.

## Install the skill

You need Node.js and a coding agent that supports skills.

```bash
npx skills@latest add \
  https://github.com/mintlify/docs/tree/main/agent-context/context/skills/mintlify \
  --skill mintlify
```

Select your agent and scope when prompted. Add `--global` to install it across all your projects.

To update, rerun the same command with the same options, then start a new agent session. If you get the skill through a plugin, update the plugin instead.

## Ask your agent to customize your site

Describe the result you want, your theme, and the affected pages or components. For example:

```text
Use mintlify to style the quickstart Card with an authored class.
Check light and dark mode, and make sure the styling persists after internal navigation.
```

```text
Use mintlify to add a copy button in a reusable React snippet
with accessible success and failure messages.
```

The skill prefers [configuration](/organize/settings), [component props](/components/index), and [React components](/customize/react-components) over global CSS or JavaScript.
