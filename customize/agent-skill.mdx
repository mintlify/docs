The `mintlify` skill helps your coding agent write documentation, configure your site, and customize its appearance and browser behavior. Its focused customization references cover selectors and component parts, CSS variables, browser APIs, script lifecycle, themes, navigation, React components, and reusable snippets.

The same skill explains which mechanism fits a change and what to check so it survives navigation and works in light and dark mode. Your agent loads the references needed for each task.

## Install the skill

You need Node.js and a coding agent that supports skills. Install the complete folder from the Mintlify docs repository to include the entrypoint, references, and reviewed inventory:

```bash
npx skills@latest add \
  https://github.com/mintlify/docs/tree/main/agent-context/context/skills/mintlify \
  --skill mintlify
```

Select your agent and project scope when prompted. Add `--global` to install it for your personal use across projects. Run `npx skills@latest list` and inspect the installed folder to confirm that `SKILL.md`, the `reference` directory, and `reference/customization/inventory.json` are present.

The [canonical skill folder](https://github.com/mintlify/docs/tree/main/agent-context/context/skills/mintlify) contains the entrypoint and all references. If you already use a Mintlify plugin, check its bundled skill before installing another copy.

## Ask your agent to customize your site

Give the agent the intended result, your theme, and the pages or components affected. For example:

```text
Use mintlify to style the quickstart Card with an authored class.
Keep the linked Card usable with a keyboard, check light and dark mode, and
verify that the styling persists after internal navigation.
```

```text
Use mintlify to add a copy button in a reusable React snippet.
Show accessible success and failure messages, and verify navigation cleanup.
```

The skill favors supported [configuration](/organize/settings), [component props](/components/index), and [React components](/customize/react-components) before adding global CSS or JavaScript. Its inventory labels documented hooks and observed behavior separately. Your agent should inspect the current DOM and verify the environments your change must support.

## Update an installed skill

Rerun the installation command above to refresh the skill from the same folder. Keep the same agent, project or global scope, and copy or symlink choices you used during installation. Add the same `--agent`, `--global`, and `--copy` arguments if you used them.

`@latest` selects the installer version. Rerunning the command refreshes the installed skill content. Publishing new documentation does not update your local copy automatically. Reload skills or start a new agent session after updating, following your agent's current instructions.

If your skill comes from a plugin, update that plugin through its supported mechanism.

See the [installation and update reference](https://github.com/mintlify/docs/blob/main/agent-context/context/skills/mintlify/reference/customization/installation-and-updates.md) for command details and the [compatibility reference](https://github.com/mintlify/docs/blob/main/agent-context/context/skills/mintlify/reference/customization/compatibility-and-verification.md) for compatibility guidance and verification coverage.
