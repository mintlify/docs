The `mintlify-customization` skill gives your coding agent a short workflow and focused references for customizing your documentation site. It covers selectors and component parts, CSS variables, browser APIs, script lifecycle, themes, navigation, React components, and reusable snippets.

Use it alongside the general Mintlify documentation skill. The customization skill explains which mechanism fits a change and what to check so it survives navigation and works in light and dark mode.

## Install the skill

You need Node.js and a coding agent that supports skills. Install from the GitHub folder to include the entrypoint, references, and source-backed inventory:

```bash
npx skills@latest add https://github.com/mintlify/docs/tree/main/agent-context/context/skills/mintlify-customization --skill mintlify-customization
```

Select your agent and project scope when prompted. Add `--global` to install it for your personal use across projects. Run `npx skills@latest list` and inspect the installed folder to confirm that `SKILL.md`, the `reference` directory, and `reference/inventory.json` are present.

The [canonical skill source](https://github.com/mintlify/docs/tree/main/agent-context/context/skills/mintlify-customization) contains the complete bundle. The named skill entrypoint served by the docs site links to its references; the GitHub-folder installation includes those files locally.

## Ask your agent to customize your site

Give the agent the intended result, your theme, and the pages or components affected. For example:

```text
Use mintlify-customization to style the quickstart Card with an authored class.
Keep the linked Card usable with a keyboard, check light and dark mode, and
verify that the styling persists after internal navigation.
```

```text
Use mintlify-customization to add a copy button in a reusable React snippet.
Show accessible success and failure messages, and verify navigation cleanup.
```

The skill favors supported [configuration](/organize/settings), [component props](/components/index), and [React components](/customize/react-components) before adding global CSS or JavaScript. Its inventory labels documented hooks and source-observed behavior separately. Your agent should inspect the current DOM and verify the environments your change must support.

## Update an installed skill

Update a project installation:

```bash
npx skills@latest update mintlify-customization --project
```

Update a global installation:

```bash
npx skills@latest update mintlify-customization --global
```

`@latest` updates the installer used by the command. The `update` command refreshes the installed skill content. Publishing new documentation does not update your local copy automatically. Reload skills or start a new agent session after updating, following your agent's current instructions.

If a Mintlify plugin or Kiro power provides the skill, update it through that package's manager. Avoid installing a second copy over a plugin-owned skill. Generated packages include `.mintlify-agent-context.json` so you can inspect the source revision and included skills.

See the [installation and update reference](https://github.com/mintlify/docs/blob/main/agent-context/context/skills/mintlify-customization/reference/installation-and-updates.md) for packaging differences and the [compatibility reference](https://github.com/mintlify/docs/blob/main/agent-context/context/skills/mintlify-customization/reference/compatibility-and-verification.md) for source revisions and verification coverage.
