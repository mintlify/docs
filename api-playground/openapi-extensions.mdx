Mintlify reads these extensions and fields in your OpenAPI specification. It doesn't read `x-tagGroups`. To show any other field from your specification as a label on parameters, use [parameter pills](/api-playground/customize-endpoint-pages#add-parameter-pills).

To add extensions to a specification you don't edit directly, use an [overlay](/api-playground/overlays).

## Operation extensions

Add these to an operation, such as `paths./users.get`.

| Extension | What it does |
| --- | --- |
| `x-mint.metadata` | Overrides the page's frontmatter, such as `title`, `sidebarTitle`, `description`, `playground`, or `tag`. See [Override page metadata](/api-playground/customize-endpoint-pages#override-page-metadata). |
| `x-mint.content` | Adds MDX content to the page. See [Add content to a page](/api-playground/customize-endpoint-pages#add-content-to-a-page). |
| `x-mint.href` | Sets the page's URL. See [Set a URL for one endpoint](/api-playground/endpoint-urls#set-a-url-for-one-endpoint). |
| `x-mint.playground.expand` | Set to `false` to start nested object fields collapsed. See [Collapse playground fields](/api-playground/customize-endpoint-pages#collapse-playground-fields). |
| `x-mint.groups` | Shows the endpoint only to readers in the listed user groups. Also works on a path. See [Filter endpoints](/create/personalization#filter-endpoints). |
| `x-hidden` | Creates the page but leaves it out of the navigation. See [Hide or exclude endpoints](/api-playground/organize-endpoints#hide-or-exclude-endpoints). |
| `x-excluded` | Doesn't create a page. See [Hide or exclude endpoints](/api-playground/organize-endpoints#hide-or-exclude-endpoints). |
| `x-codeSamples` | Adds your own request examples. `x-code-samples` also works. See [Write your own examples](/api-playground/code-examples#write-your-own-examples). |

`x-hidden` and `x-excluded` also work on webhooks.

## Schema extensions

Add these to a schema or property.

| Extension | What it does |
| --- | --- |
| `x-mint.pre`, `x-mint.post` | Adds pills before or after a parameter name. See [Add parameter pills](/api-playground/customize-endpoint-pages#add-parameter-pills). |
| `x-mint.groups` | Shows a property or `oneOf` variant only to readers in the listed user groups. See [Filter schema properties](/create/personalization#filter-schema-properties). |
| `x-mint-enum` | Shows individual enum values only to readers in the listed user groups. See [Filter enum values](/create/personalization#filter-enum-values). |
| `x-default` | Prefills the playground with a value without changing the documented `default`. Requires `api.examples.prefill`. See [Prefill example values](/api-playground/configure-playground#prefill-example-values). |

## Security scheme extensions

| Extension | What it does |
| --- | --- |
| `x-default` | Prefills the credential input in the playground. Works on `apiKey` and `http` bearer schemes. See [Prefill credentials](/api-playground/configure-playground#prefill-credentials). |

## Tag extensions and fields

| Field | What it does |
| --- | --- |
| `x-group` | Sets the navigation group label for the tag. See [Rename tag groups](/api-playground/organize-endpoints#rename-tag-groups). |
| `x-displayName` | Sets the group label if the tag has no `x-group`. |
| `parent`, `kind`, `summary` | OpenAPI 3.2 only. Nest groups, show badge pills, and set labels. See [Nest groups with tag hierarchies](/api-playground/organize-endpoints#nest-groups-with-tag-hierarchies). |

None of these change page URLs. URLs use the tag `name`.

## Frontmatter fields

Use these in MDX pages that reference your specification.

| Field | What it does |
| --- | --- |
| `openapi` | Generates the page from one operation or webhook, such as `openapi: "openapi.json GET /users"`. See [Create MDX pages for endpoints](/api-playground/customize-endpoint-pages#create-mdx-pages-for-endpoints). |
| `openapi-schema` | Generates the page from a schema in `components.schemas`. See [Create pages for data models](/api-playground/customize-endpoint-pages#create-pages-for-data-models). |
| `playground` | Sets the playground display mode for the page. See [Choose a display mode](/api-playground/configure-playground#choose-a-display-mode). |
