A codebase knowledge graph is a Mintlify project that describes your code: what each repository does, the services and APIs it exposes, how repositories depend on each other, and how to work in each one. Agents query it through MCP before they write or change code, so they work from an accurate picture of your systems instead of guessing.

You don't need existing documentation or a migration to build one. A coding agent generates the first version from your source code, automations update it when code changes, and the [search MCP server](/ai/model-context-protocol) serves it to any agent your team uses.

The setup has three steps:

1. [Generate the initial knowledge graph](#step-1-generate-the-initial-knowledge-graph) with your coding agent.
2. [Set up automations](#step-2-keep-the-knowledge-graph-current) to keep it current.
3. [Use the knowledge graph through MCP](#step-3-use-the-knowledge-graph-through-mcp).

Step through the pipeline to see what each part does.

## Prerequisites

- A Mintlify project connected to a Git repository. This is the central hub repository that holds the knowledge graph. It can start empty. If you don't have a project yet, see the [Quickstart](/quickstart).
- The [Mintlify GitHub App](/deploy/github) installed on the hub repository and on every source repository you want to document.
- An [Enterprise plan](https://mintlify.com/pricing?ref=knowledge-graph) for [custom automations](/automations/create).
- A coding agent such as [Claude Code](/guides/claude-code), [Codex](/guides/codex), or [Cursor](/guides/cursor).

<Tip>
  If the knowledge graph should only be visible to your team, set up [authentication](/deploy/authentication-setup) on the project. The search MCP server then requires each user to log in and only returns content they have access to.
</Tip>

## Plan the structure

Keep every repository's documentation in one hub project rather than a separate site per repository. A single project gives agents one MCP server to query and lets pages link across repositories.

Give each repository its own group, and add an overview section that explains how the repositories fit together.

```json docs.json
{
  "navigation": {
    "groups": [
      {
        "group": "Overview",
        "pages": ["index", "architecture", "glossary"]
      },
      {
        "group": "Web app",
        "pages": ["repos/web-app/index", "repos/web-app/local-development", "repos/web-app/routing"]
      },
      {
        "group": "API service",
        "pages": ["repos/api-service/index", "repos/api-service/endpoints", "repos/api-service/data-model"]
      },
      {
        "group": "API gateway",
        "pages": ["repos/api-gateway/index", "repos/api-gateway/auth"]
      }
    ]
  }
}
```

Each repository section should answer the questions an agent asks before it changes code:

- **Purpose**: What the repository does and who owns it.
- **Interfaces**: Endpoints, events, packages, or other services it exposes.
- **Dependencies**: Which repositories and services it calls, and which call it.
- **Data**: Key models, schemas, and where the data lives.
- **Working in the repository**: How to run, test, and deploy it, plus conventions a contributor needs to follow.

## Step 1: Generate the initial knowledge graph

Use a coding agent with local access to your source code to write the first version of each repository's documentation.

<Steps>
  <Step title="Set up your coding agent">
    Clone the hub repository and your source repositories into the same parent directory so the agent can read all of them.

    ```bash
    mkdir knowledge-graph && cd knowledge-graph
    git clone https://github.com/your-org/docs-hub.git
    git clone https://github.com/your-org/web-app.git
    git clone https://github.com/your-org/api-service.git
    git clone https://github.com/your-org/api-gateway.git
    ```

    From the hub repository, run [`mint agent setup`](/cli/commands#mint-agent-setup) to install the Mintlify skill and connect the [admin MCP server](/ai/mintlify-mcp) to Claude Code, Codex, or Cursor. The skill gives the agent context on Mintlify components, `docs.json`, and writing standards.

    ```bash
    cd docs-hub
    mint agent setup
    ```
  </Step>
  <Step title="Generate documentation for one repository">
    Start your agent in the parent directory and give it a prompt that names the source repository, the target folder, and the questions each page must answer.

    ```text Example prompt
    Read the source code in ../api-service and write documentation for it in
    docs-hub/repos/api-service/.

    Create these pages:
    - index.mdx: what the service does, who owns it, and how it fits into the
      rest of the system
    - endpoints.mdx: every HTTP endpoint with method, path, parameters, and
      response shape, based on the route definitions
    - data-model.mdx: the main models and database tables
    - local-development.mdx: how to install, run, and test the service

    For each page, list the other repositories this service calls or is called
    by, and link to their pages under docs-hub/repos/.

    Only document what you can confirm from the code. If something is unclear,
    leave a TODO comment instead of guessing.

    Add the new pages to docs-hub/docs.json in a group named "API service".
    ```

    Review the output, fix anything the agent got wrong, and run `mint dev` from the hub repository to preview the pages.
  </Step>
  <Step title="Repeat for each repository">
    Run the same prompt for your other representative repositories, changing the repository name and page list. Then ask the agent to write the overview pages from the repository pages it created.

    ```text Example prompt
    Read every page under docs-hub/repos/ and write docs-hub/architecture.mdx.
    Describe how the repositories depend on each other, which services call
    which, and how a request moves through the system. Link to the repository
    pages for details.
    ```
  </Step>
  <Step title="Publish the hub">
    Commit the pages to the hub repository and open a pull request. When it merges, Mintlify deploys the knowledge graph and indexes it for search and MCP.
  </Step>
</Steps>

<Tip>
  Save the prompts that worked as a [custom skill](/ai/skillmd#custom-skill-files) or an `AGENTS.md` file in the hub repository. Anyone adding a new repository later gets the same page structure.
</Tip>

## Step 2: Keep the knowledge graph current

A knowledge graph is only useful while it matches the code. Create a [custom automation](/automations/create) with a code change trigger so the agent updates the documentation whenever a pull request merges in a source repository.

<Steps>
  <Step title="Create the automation">
    1. Open your [Automations](https://app.mintlify.com/settings/project/automations) settings.
    2. Click **New automation**.
    3. Select the **Code change** trigger.
    4. Click **Add repo** for each source repository you documented in step 1. One automation can listen to up to 50 repositories.
  </Step>
  <Step title="Filter the trigger">
    Under **Show advanced options** on each repository card, narrow when the automation runs:

    - **Listening to changes in**: Only run for pull requests that touch source paths, such as `src/**`, so changes to tests or CI configuration don't trigger an update.
    - **Excluding PRs from**: Skip pull requests from bots, such as dependency update accounts.

    See [Filter code change triggers](/automations/manage#filter-code-change-triggers) for details.
  </Step>
  <Step title="Write the instructions">
    Tell the agent how source repositories map to pages in the hub and what to change.

    ```text Example instructions
    1. Read the merged pull request diff from the trigger repository.
    2. Find the matching folder under /repos/ in this project. The folder name
       matches the repository name.
    3. Identify changes to endpoints, events, data models, dependencies on
       other repositories, or setup steps.
    4. Update the affected pages in that folder. If the change affects how
       repositories depend on each other, also update /architecture.mdx.
    5. If the pull request doesn't change anything the documentation covers,
       make no changes.
    6. Open a pull request that lists the pages you changed and links to the
       source pull request.
    ```

    See [Use automations](/guides/use-automations#write-effective-instructions) for more guidance on writing instructions.
  </Step>
  <Step title="Choose an update mode">
    - **Modify and wait for review**: The agent opens a pull request in the hub repository and assigns the authors of the source change as reviewers. Start here while you tune the instructions.
    - **Update and merge changes**: Changes merge without review. Switch to this once the results are consistent. If your hub repository has branch protection, see [Configure automerge](/guides/configure-automerge).
  </Step>
  <Step title="Test the automation">
    Save the automation and [run it manually](/automations/manage#run-an-automation-manually) against a recent pull request. Check the [run history](/automations/manage#view-run-history) to confirm the agent changed the right pages, then refine the instructions if needed.
  </Step>
</Steps>

## Step 3: Use the knowledge graph through MCP

Mintlify hosts a [search MCP server](/ai/model-context-protocol) for every project. Connect it to the agents your team uses so they can search the knowledge graph and read full pages while they work.

Your MCP server URL is the `/mcp` path of your site URL, for example `https://docs.your-company.com/mcp`. If your project requires authentication, use the `/authed/mcp` path and [enable authenticated MCP](/ai/model-context-protocol#enable-authenticated-mcp) first.

<Tabs>
  <Tab title="Claude Code">
    ```bash
    claude mcp add --transport http knowledge-graph https://docs.your-company.com/mcp
    ```
  </Tab>
  <Tab title="Codex">
    ```bash
    codex mcp add knowledge-graph --url https://docs.your-company.com/mcp
    ```
  </Tab>
  <Tab title="Cursor">
    Add the server to `.cursor/mcp.json` in your project, or `~/.cursor/mcp.json` for all projects.

    ```json .cursor/mcp.json
    {
      "mcpServers": {
        "knowledge-graph": {
          "url": "https://docs.your-company.com/mcp"
        }
      }
    }
    ```
  </Tab>
</Tabs>

See [Use your MCP server](/ai/model-context-protocol#use-your-mcp-server) for other clients.

To make agents check the knowledge graph without being asked, add an instruction to the `CLAUDE.md`, `AGENTS.md`, or Cursor rules file in each source repository.

```markdown AGENTS.md
Before changing code that calls another service or repository, search the
knowledge-graph MCP server for that service. Use its documented endpoints,
data models, and conventions instead of guessing.
```

Agents can then answer questions such as:

- Which services call the API gateway, and what headers do they send?
- What do I need to change in other repositories if I rename this field?
- How do I run the API service locally?

export const KgPipeline = () => {
  const stages = [
    { name: "Source repositories", tag: "Your code", detail: "Your application, service, and library repositories. Nothing in them moves or changes. The coding agent and automations only read them." },
    { name: "Coding agent", tag: "Step 1", detail: "Claude Code, Codex, or Cursor reads each source repository and writes the first version of its pages into the hub repository. You review the output before you merge it." },
    { name: "Hub project", tag: "Mintlify", detail: "One Mintlify project holds the pages for every repository, with a group per repository and an overview section. Each merge deploys the site and indexes it for search and MCP." },
    { name: "Automation", tag: "Step 2", detail: "When a pull request merges in a source repository, a code change automation runs the agent. It updates the affected pages and opens a pull request in the hub, or merges directly." },
    { name: "Search MCP server", tag: "Step 3", detail: "Mintlify hosts an MCP server at /mcp, or /authed/mcp for sites with authentication. It exposes tools to search the knowledge graph, read pages, and submit feedback." },
    { name: "Your agents", tag: "Consumers", detail: "Coding agents connected to the MCP server look up services, endpoints, and conventions before they change code, and report pages that are wrong." },
  ];
  const [active, setActive] = useState(0);
  const [playing, setPlaying] = useState(false);
  useEffect(() => {
    if (!playing) return;
    const id = setInterval(() => {
      setActive((current) => {
        if (current >= stages.length - 1) { setPlaying(false); return current; }
        return current + 1;
      });
    }, 1800);
    return () => clearInterval(id);
  }, [playing]);
  const loopActive = active === 3;
  return (
    <KgFrame title="How a codebase knowledge graph works" caption={`Stage ${active + 1} of ${stages.length}`}>
      <div style={{ display: "grid", gridTemplateColumns: "repeat(auto-fit, minmax(130px, 1fr))", gap: 8 }}>
        {stages.map((stage, i) => {
          const isActive = i === active;
          return (
            <button
              key={stage.name}
              type="button"
              onClick={() => { setPlaying(false); setActive(i); }}
              aria-current={isActive ? "step" : undefined}
              style={{
                textAlign: "left", padding: 10, borderRadius: 10, font: "inherit", color: "inherit", cursor: "pointer", minWidth: 0,
                border: isActive ? `2px solid ${KgTheme.accent}` : `1px solid ${KgTheme.border}`,
                background: isActive ? KgTheme.accentSoft : i < active ? KgTheme.surface : "transparent",
                opacity: i > active ? 0.6 : 1, transition: "background .25s, opacity .25s",
              }}
            >
              <div style={{ fontSize: 11, textTransform: "uppercase", letterSpacing: ".04em", opacity: 0.7 }}>{stage.tag}</div>
              <div style={{ fontWeight: 600, fontSize: 13 }}>{stage.name}</div>
            </button>
          );
        })}
      </div>
      <div style={{ display: "flex", alignItems: "center", gap: 8, fontSize: 12, opacity: loopActive ? 1 : 0.55, transition: "opacity .25s" }}>
        <svg width="18" height="18" viewBox="0 0 18 18" aria-hidden="true" style={{ flexShrink: 0 }}>
          <path d="M3 9a6 6 0 0 1 10.5-4M15 9a6 6 0 0 1-10.5 4" fill="none" stroke={loopActive ? KgTheme.accent : "currentColor"} strokeWidth="1.6" strokeLinecap="round" />
          <path d="M13.8 1.8v3.4h-3.4M4.2 16.2v-3.4h3.4" fill="none" stroke={loopActive ? KgTheme.accent : "currentColor"} strokeWidth="1.6" strokeLinecap="round" />
        </svg>
        <span>The automation loops back on every merged pull request, so the hub stays in step with the source repositories.</span>
      </div>
      <p style={{ margin: 0, lineHeight: 1.55, minHeight: 66 }}>{stages[active].detail}</p>
      <div style={{ display: "flex", flexWrap: "wrap", gap: 8 }}>
        <KgButton onClick={() => { setPlaying(false); setActive(active - 1); }} disabled={active === 0}>Back</KgButton>
        <KgButton onClick={() => { setPlaying(false); setActive(active + 1); }} disabled={active === stages.length - 1}>Next</KgButton>
        <KgButton primary onClick={() => { if (!playing && active === stages.length - 1) setActive(0); setPlaying(!playing); }}>{playing ? "Pause" : "Play"}</KgButton>
      </div>
    </KgFrame>
  );
};

    { label: "Author not excluded", pass: !authorExcluded, note: authorExcluded ? "Pull requests from dependabot[bot] are excluded." : `${pr.author} isn't on the exclusion list.` },
  ];
  const firstFail = checks.findIndex((c) => !c.pass);
  const runs = firstFail === -1;
  const updates = runs && pr.documented;
  let outcome;
  if (!runs) outcome = { tone: "skip", head: "No run", body: "The automation never starts, so it costs nothing." };
  else if (!updates) outcome = { tone: "skip", head: "Run finds nothing to update", body: "The agent reads the diff, finds no documented behavior changed, and makes no changes. Runs with no updates cost nothing." };
  else outcome = { tone: "ok", head: mode === "review" ? "Pull request opened in the hub" : "Changes merged into the hub", body: mode === "review" ? `The agent updates ${pr.pages.length} ${pr.pages.length === 1 ? "page" : "pages"} and opens a pull request. ${pr.author} is assigned as reviewer because they wrote the source change.` : `The agent updates ${pr.pages.length} ${pr.pages.length === 1 ? "page" : "pages"} and merges them into the deploy branch without review.` };
  const tone = outcome.tone === "ok" ? { color: KgTheme.accent, bg: KgTheme.accentSoft } : { color: KgTheme.warn, bg: KgTheme.warnSoft };
  return (
    <KgFrame title="Code change trigger simulator" caption="Sample pull requests">
      <div style={{ display: "grid", gap: 6 }}>
        <div style={{ fontSize: 12, opacity: 0.65 }}>Merged pull request</div>
        <div style={{ display: "grid", gridTemplateColumns: "repeat(auto-fit, minmax(210px, 1fr))", gap: 6 }}>
          {prs.map((p) => (
            <button key={p.id} type="button" onClick={() => setPrId(p.id)} aria-pressed={p.id === prId} style={{ textAlign: "left", padding: "8px 10px", borderRadius: 9, font: "inherit", color: "inherit", cursor: "pointer", minWidth: 0, border: p.id === prId ? `2px solid ${KgTheme.accent}` : `1px solid ${KgTheme.border}`, background: p.id === prId ? KgTheme.accentSoft : "transparent" }}>
              <div style={{ fontSize: 12, opacity: 0.7, fontFamily: "ui-monospace, monospace" }}>{p.repo} · {p.author}</div>
              <div style={{ fontSize: 13, fontWeight: 600 }}>{p.title}</div>
            </button>
          ))}
        </div>
      </div>
      <div style={{ display: "grid", gap: 6 }}>
        {checks.map((c, i) => {
          const reached = firstFail === -1 || i <= firstFail;
          const color = !reached ? "currentColor" : c.pass ? KgTheme.accent : KgTheme.warn;
          return (
            <div key={c.label} style={{ display: "flex", gap: 10, alignItems: "flex-start", opacity: reached ? 1 : 0.4, transition: "opacity .25s" }}>
              <span aria-hidden="true" style={{ width: 20, height: 20, borderRadius: 10, flexShrink: 0, display: "grid", placeItems: "center", fontSize: 12, fontWeight: 700, color: "#fff", background: reached ? color : "rgba(127,127,127,.35)" }}>{!reached ? "·" : c.pass ? "✓" : "✕"}</span>
              <div style={{ minWidth: 0 }}>
                <div style={{ fontWeight: 600, fontSize: 13 }}>{c.label}<span style={{ position: "absolute", left: -9999 }}>{!reached ? " (not checked)" : c.pass ? " (passes)" : " (stops here)"}</span></div>
                {reached ? <div style={{ fontSize: 12, opacity: 0.75, overflowWrap: "anywhere" }}>{c.note}</div> : null}
              </div>
            </div>
          );
        })}
      </div>
      <div style={{ display: "flex", flexWrap: "wrap", alignItems: "center", gap: 8 }}>
        <span style={{ fontSize: 12, opacity: 0.65 }}>Update mode</span>
        <KgButton pressed={mode === "review"} onClick={() => setMode("review")}>Modify and wait for review</KgButton>
        <KgButton pressed={mode === "merge"} onClick={() => setMode("merge")}>Update and merge changes</KgButton>
      </div>
      <div aria-live="polite" style={{ borderRadius: 10, padding: 12, background: tone.bg, borderLeft: `3px solid ${tone.color}`, display: "grid", gap: 6 }}>
        <div style={{ display: "flex", flexWrap: "wrap", justifyContent: "space-between", gap: 8 }}>
          <span style={{ fontWeight: 600 }}>{outcome.head}</span>
          <span style={{ fontWeight: 600, fontVariantNumeric: "tabular-nums" }}>{updates ? "250 credits" : "0 credits"}</span>
        </div>
        <div style={{ fontSize: 13, lineHeight: 1.5 }}>{outcome.body}</div>
        {updates ? (
          <div style={{ display: "flex", flexWrap: "wrap", gap: 4 }}>
            {pr.pages.map((page) => <code key={page} style={{ fontSize: 12, padding: "2px 7px", borderRadius: 6, border: `1px solid ${KgTheme.border}` }}>{page}</code>)}
          </div>
        ) : null}
      </div>
    </KgFrame>
  );
};

export const KgCreditEstimator = () => {
  const schedules = [
    { id: "daily", label: "Daily", runs: 7 },
    { id: "twice", label: "Twice weekly", runs: 2 },
    { id: "weekly", label: "Weekly", runs: 1 },
  ];
  const [merges, setMerges] = useState(40);
  const [scheduleId, setScheduleId] = useState("daily");
  const schedule = schedules.find((s) => s.id === scheduleId);
  const perRun = 250;
  const pushRuns = merges;
  const scheduledRuns = Math.min(merges, schedule.runs);
  const push = pushRuns * perRun;
  const scheduled = scheduledRuns * perRun;
  const max = Math.max(push, scheduled, perRun);
  const fmt = (n) => n.toLocaleString("en-US");
  const bars = [
    { label: "Code change trigger", runs: pushRuns, credits: push, note: "One run per merged pull request" },
    { label: `${schedule.label} schedule`, runs: scheduledRuns, credits: scheduled, note: `Up to ${schedule.runs} ${schedule.runs === 1 ? "run" : "runs"} a week, each batching every merge since the last run` },
  ];
  return (
    <KgFrame title="Weekly credit estimate" caption="250 credits per run that updates docs">
      <label style={{ display: "grid", gap: 6 }}>
        <span style={{ display: "flex", justifyContent: "space-between", gap: 8, fontSize: 13 }}>
          <span style={{ fontWeight: 600 }}>Merged pull requests per week that change documented code</span>
          <span style={{ fontVariantNumeric: "tabular-nums" }}>{merges}</span>
        </span>
        <input type="range" min={0} max={150} step={1} value={merges} onChange={(e) => setMerges(Number(e.target.value))} style={{ width: "100%", accentColor: KgTheme.accent }} />
      </label>
      <div style={{ display: "flex", flexWrap: "wrap", alignItems: "center", gap: 8 }}>
        <span style={{ fontSize: 12, opacity: 0.65 }}>Schedule to compare</span>
        {schedules.map((s) => <KgButton key={s.id} pressed={s.id === scheduleId} onClick={() => setScheduleId(s.id)}>{s.label}</KgButton>)}
      </div>
      <div style={{ display: "grid", gap: 12 }}>
        {bars.map((b) => (
          <div key={b.label} style={{ display: "grid", gap: 4 }}>
            <div style={{ display: "flex", flexWrap: "wrap", justifyContent: "space-between", gap: 8, fontSize: 13 }}>
              <span style={{ fontWeight: 600 }}>{b.label}</span>
              <span style={{ fontVariantNumeric: "tabular-nums" }}>{fmt(b.credits)} credits · {b.runs} {b.runs === 1 ? "run" : "runs"}</span>
            </div>
            <div style={{ height: 12, borderRadius: 6, background: KgTheme.surface, overflow: "hidden" }}>
              <div style={{ height: "100%", width: `${(b.credits / max) * 100}%`, minWidth: b.credits ? 4 : 0, borderRadius: 6, background: KgTheme.accent, transition: "width .3s ease" }} />
            </div>
            <div style={{ fontSize: 12, opacity: 0.65 }}>{b.note}</div>
          </div>
        ))}
      </div>
      <div style={{ fontSize: 13, padding: 10, borderRadius: 8, background: KgTheme.surface }}>
        {merges === 0 ? "With no merges, neither option runs, so both cost nothing." : push === scheduled ? "Both options cost the same at this volume. The code change trigger updates docs sooner." : `The ${schedule.label.toLowerCase()} schedule uses ${fmt(push - scheduled)} fewer credits a week. The tradeoff is that docs can lag code by up to ${schedule.runs === 7 ? "a day" : schedule.runs === 2 ? "half a week" : "a week"}.`}
      </div>
    </KgFrame>
  );
};

export const KgMcpReplay = () => {
  const scenarios = [
    {
      id: "rename",
      question: "What do I need to change in other repositories if I rename customer_id?",
      steps: [
        { tool: "search", input: "customer_id", output: "repos/api-service/data-model · repos/api-gateway/auth · architecture" },
        { tool: "query docs filesystem", input: "cat repos/api-service/data-model.mdx", output: "orders.customer_id is a foreign key to accounts.id. It is returned by GET /orders and GET /orders/{id}." },
        { tool: "query docs filesystem", input: "grep -r customer_id repos/api-gateway", output: "repos/api-gateway/auth.mdx: the gateway copies customer_id from the token into the X-Customer-Id header." },
        { tool: "answer", input: "", output: "Update the gateway's header mapping in api-gateway and the GET /orders response in api-service. web-app reads the field through the gateway, so check its order views too." },
      ],
    },
    {
      id: "local",
      question: "How do I run the API service locally?",
      steps: [
        { tool: "search", input: "run api-service locally", output: "repos/api-service/local-development" },
        { tool: "query docs filesystem", input: "cat repos/api-service/local-development.mdx", output: "Copy .env.example to .env, start Postgres with docker compose up db, then run npm run dev on port 4000." },
        { tool: "answer", input: "", output: "Copy .env.example to .env, run docker compose up db, then npm run dev. The service listens on port 4000." },
      ],
    },
    {
      id: "stale",
      question: "Which headers does the gateway send to backend services?",
      steps: [
        { tool: "search", input: "gateway headers backend", output: "repos/api-gateway/auth" },
        { tool: "query docs filesystem", input: "cat repos/api-gateway/auth.mdx", output: "The gateway sends X-Customer-Id and X-Request-Id." },
        { tool: "submit feedback", input: "repos/api-gateway/auth: page doesn't mention X-Trace-Id, which the gateway code sets on every request", output: "Recorded. It appears in the project's feedback dashboard." },
        { tool: "answer", input: "", output: "It sends X-Customer-Id, X-Request-Id, and X-Trace-Id. I reported that the auth page is missing X-Trace-Id." },
      ],
    },
  ];
  const toolColor = { search: "#3B82F6", "query docs filesystem": "#8B5CF6", "submit feedback": KgTheme.warn, answer: KgTheme.accent };
  const [scenarioId, setScenarioId] = useState("rename");
  const [shown, setShown] = useState(1);
  const [playing, setPlaying] = useState(false);
  const scenario = scenarios.find((s) => s.id === scenarioId);
  useEffect(() => {
    if (!playing) return;
    const id = setInterval(() => {
      setShown((n) => {
        if (n >= scenario.steps.length) { setPlaying(false); return n; }
        return n + 1;
      });
    }, 1400);
    return () => clearInterval(id);
  }, [playing, scenarioId]);
  const pick = (id) => { setScenarioId(id); setShown(1); setPlaying(false); };
  const done = shown >= scenario.steps.length;
  return (
    <KgFrame title="MCP tool call replay" caption={`Step ${shown} of ${scenario.steps.length}`}>
      <div style={{ display: "flex", flexWrap: "wrap", gap: 6 }}>
        {scenarios.map((s) => <KgButton key={s.id} pressed={s.id === scenarioId} onClick={() => pick(s.id)}>{s.question}</KgButton>)}
      </div>
      <div style={{ display: "grid", gap: 8, padding: 12, borderRadius: 10, background: KgTheme.surface }}>
        <div style={{ justifySelf: "end", maxWidth: "85%", padding: "8px 12px", borderRadius: 12, background: "rgba(127,127,127,.14)", fontSize: 13 }}>{scenario.question}</div>
        {scenario.steps.slice(0, shown).map((step, i) => {
          const color = toolColor[step.tool];
          if (step.tool === "answer") {
            return <div key={i} style={{ maxWidth: "90%", padding: "8px 12px", borderRadius: 12, border: `1px solid ${KgTheme.accent}`, background: KgTheme.accentSoft, fontSize: 13, lineHeight: 1.5 }}>{step.output}</div>;
          }
          return (
            <div key={i} style={{ display: "grid", gap: 4, padding: "8px 10px", borderRadius: 9, border: `1px solid ${KgTheme.border}`, borderLeft: `3px solid ${color}`, minWidth: 0 }}>
              <div style={{ display: "flex", flexWrap: "wrap", gap: 8, alignItems: "baseline", minWidth: 0 }}>
                <span style={{ fontSize: 11, fontWeight: 700, textTransform: "uppercase", letterSpacing: ".04em", color }}>{step.tool}</span>
                <code style={{ fontSize: 12, opacity: 0.85, overflowWrap: "anywhere" }}>{step.input}</code>
              </div>
              <div style={{ fontSize: 12, opacity: 0.75, overflowWrap: "anywhere" }}>{step.output}</div>
            </div>
          );
        })}
      </div>
      <div style={{ display: "flex", flexWrap: "wrap", gap: 8 }}>
        <KgButton onClick={() => { setPlaying(false); setShown(Math.max(1, shown - 1)); }} disabled={shown <= 1}>Back</KgButton>
        <KgButton onClick={() => { setPlaying(false); setShown(shown + 1); }} disabled={done}>Next</KgButton>
        <KgButton primary onClick={() => { if (!playing && done) setShown(1); setPlaying(!playing); }}>{playing ? "Pause" : done ? "Replay" : "Play"}</KgButton>
      </div>
    </KgFrame>
  );
};
