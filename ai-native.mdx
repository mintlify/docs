Mintlify's built-in AI features use your content to help users find answers and help your team keep docs current.

## Reading

Users can chat with the [assistant](/assistant) for instant answers with links to relevant pages. Embed it in your own apps with the [API](/api/assistant/create-assistant-message-v2).

## Writing

The [agent](/agent) opens pull requests based on your prompts, pull requests, and Slack threads. Add it to Slack so anyone on your team can update docs, or trigger it from your tools with [webhook automations](/api/automations/webhook). [Automations](/automations/index) run the agent on a schedule or on repository pushes.

Configure [Cursor](/guides/cursor), [Claude Code](/guides/claude-code), or [Devin Desktop](/guides/devin-desktop) to reference the Mintlify schema, your style guide, and best practices.

## Discovering

Mintlify optimizes your site for AI tools and search engines automatically:

- **Markdown for agents:** Pages serve Markdown instead of HTML to AI agents, so they process content faster with fewer tokens. Append `.md` to any URL to view it. Use the [visibility](/components/visibility) component to tailor content per audience.
- **`llms.txt` and `skill.md`:** Hosted for you, so LLMs answer with relevant information and agents know your product's capabilities.
- **MCP server:** Users connect your docs to their AI tools for up-to-date answers. On Pro and Enterprise plans, WebMCP-capable browsers can search and read your content with no setup.
- **Search:** Full-text and semantic search understands intent, and 404 pages suggest related content. No configuration required.

For questions spanning multiple products or the web, [Mintlify Index](/search-index) gives coding agents one MCP server and REST API for publisher-maintained docs and web context.

<Tip>
  Help users install your `skill.md` with the [`Prompt` component](/components/prompt):

  ```mdx
  <Prompt description="Install the skill for your product." actions={["copy", "cursor"]}>
  npx skills add https://your-docs-domain.com
  </Prompt>
  ```
</Tip>
