Mintlify's built-in AI features use your content to help users find answers, help your team keep docs current, and make your docs readable by AI tools.

## Reading

The [assistant](/assistant) answers user questions with links to relevant pages. Embed it in your own apps with the [API](/api/assistant/create-assistant-message-v2).

## Writing

The [agent](/agent) opens pull requests from prompts, pull requests, and Slack threads. Trigger it from your tools with [webhook automations](/api/automations/webhook), or run it on a schedule or on repository pushes with [automations](/automations/index).

Point [Cursor](/guides/cursor), [Claude Code](/guides/claude-code), or [Devin Desktop](/guides/devin-desktop) at the Mintlify schema, your style guide, and best practices.

## Discovering

Every site is optimized for AI tools and search engines with no configuration:

- **Markdown for agents:** AI agents get Markdown instead of HTML, so they use fewer tokens. Append `.md` to any URL to view it, and use the [visibility](/components/visibility) component to tailor content per audience.
- **`llms.txt` and `skill.md`:** Hosted for you so LLMs and agents know what your product does. Help users install your skill with the [`Prompt` component](/components/prompt).
- **MCP server:** Users connect your docs to their AI tools. On Pro and Enterprise plans, WebMCP-capable browsers can search and read your content with no setup.
- **Search:** Full-text and semantic search understands intent, and 404 pages suggest related content.
- **Mintlify Index:** For questions spanning multiple products or the web, [Mintlify Index](/search-index) gives coding agents one MCP server and REST API for publisher-maintained docs and web context.
