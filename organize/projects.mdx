Your Mintlify organization contains one or more projects. Each project is either docs or a base. Organization members can work in every project, so the same team can maintain your public documentation and your internal knowledge base.

## Project types

|  | Docs | Base |
| --- | --- | --- |
| Built for | Your users and their agents | Your team and its agents |
| Example content | API references, guides, and help centers | Specs, runbooks, and onboarding guides |
| Where people read it | A documentation site at its own URL, publicly available or behind [authentication](/deploy/authentication-setup) | Your dashboard and connected AI tools, for members of your organization only |
| Saving changes | Edit on a branch, then publish | Edits to shared pages automatically commit to your repository |
| Get started | [Quickstart](/quickstart) | [Set up a base](/base/setup) |

To pick a project type, choose who reads the content.

<ProjectTypePicker />

Both project types use the same [editor](/editor/index), [agent](/editor/agent), and [admin MCP](/ai/mintlify-mcp), so editing content on either is the same experience. And both project types store their pages in a Git repository.

## Create a project

When you sign up for Mintlify, you create your first project. You can add another project to your organization from your [dashboard](https://app.mintlify.com/). You need the editor role or higher to create a project. See [Roles](/dashboard/roles).

<Note>
  On Enterprise plans, **New project** opens the Mintlify contact sales page in a new tab. Contact sales to add a project.
</Note>

<Steps>
  <Step title="Create a new project">
    1. Click the project switcher at the top of the left sidebar.
    2. Click <Icon icon="plus" /> **New project**.
  </Step>
  <Step title="Choose a project type">
    1. Select **Docs** or **Base**.
    2. For docs, enter a **Site address**.
    3. Click **Continue**.
  </Step>
  <Step title="Set up the project">
    1. Select how you plan to make updates: **Web editor**, **Local development**, or **MCP**. This selection is only for the initial setup. You can use every method in the project later.
    2. Click **Create project**.
  </Step>
</Steps>

## Switch projects

1. Click the project switcher at the top of the left sidebar.
2. Select a project.

The project switcher groups your projects under **Docs** and **Base**. If your organization has more than eight projects, hover over a project type to open its list, then search by project name or subdomain.

## Copy pages between projects

To reuse a page in another project, such as a base page you want to publish in your docs, open its options menu and select **Copy to a project**. The copy is independent of the original. For details, see [Copy a page to another project](/editor/pages#copy-a-page-to-another-project).

  const types = [
    {
      key: "docs",
      audience: "Your users and their agents",
      name: "Docs",
      rows: [
        ["Example content", "API references, guides, and help centers"],
        ["Where people read it", "A documentation site at its own URL, publicly available or behind authentication"],
        ["Saving changes", "Edit on a branch, then publish"],
        ["Get started", "Quickstart"],
      ],
    },
    {
      key: "base",
      audience: "Your team and its agents",
      name: "Base",
      rows: [
        ["Example content", "Specs, runbooks, and onboarding guides"],
        ["Where people read it", "Your dashboard and connected AI tools, for members of your organization only"],
        ["Saving changes", "Edits to shared pages automatically commit to your repository"],
        ["Get started", "Set up a base"],
      ],
    },
  ];
  const [active, setActive] = useState(0);
  const accent = "#3b82f6";
  const current = types[active];
  return (
    <div className="not-prose" style={{ border: "1px solid rgba(127,127,127,.25)", borderRadius: 12, padding: 16, display: "grid", gap: 14 }}>
      <div role="radiogroup" aria-label="Who reads the content" style={{ display: "grid", gridTemplateColumns: "repeat(auto-fit, minmax(180px, 1fr))", gap: 8 }}>
        {types.map((t, i) => (
          <button
            key={t.key}
            type="button"
            role="radio"
            aria-checked={i === active}
            onClick={() => setActive(i)}
            style={{
              textAlign: "left", padding: 10, borderRadius: 8, font: "inherit", color: "inherit", cursor: "pointer", minWidth: 0,
              border: i === active ? `2px solid ${accent}` : "1px solid rgba(127,127,127,.3)",
              background: i === active ? "rgba(59,130,246,.12)" : "transparent",
            }}
          >
            <div style={{ fontSize: 12, opacity: 0.7 }}>Readers</div>
            <div style={{ fontWeight: 600 }}>{t.audience}</div>
          </button>
        ))}
      </div>
      <div style={{ fontSize: 15 }}>
        Create a <strong>{current.name}</strong> project.
      </div>
      <div style={{ display: "grid", gap: 8 }}>
        {current.rows.map(([label, value]) => (
          <div key={label} style={{ display: "grid", gridTemplateColumns: "minmax(120px, 160px) 1fr", gap: 12, fontSize: 14, paddingTop: 8, borderTop: "1px solid rgba(127,127,127,.2)" }}>
            <span style={{ opacity: 0.7, minWidth: 0 }}>{label}</span>
            <span style={{ minWidth: 0 }}>{value}</span>
          </div>
        ))}
      </div>
    </div>
  );
};
