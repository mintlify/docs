<Note>
  The desktop app is in beta and subject to change.
</Note>

The Mintlify desktop app runs your [dashboard](https://app.mintlify.com) and [web editor](/editor/index) in a native window. It adds tabs, multiple windows, and keyboard shortcuts, and keeps Mintlify in your dock or taskbar instead of a browser tab.

The desktop app works with the same content as the dashboard. It does not open or edit files on your computer. To work on local files, use the [CLI](/cli/index).

## Install

<Tabs>
  <Tab title="macOS">
    Requires macOS 14 or later on Apple silicon.

    1. Download the `.dmg` file from [mintlify.com/desktop](https://mintlify.com/desktop).
    2. Open the file and drag **Mintlify** to your **Applications** folder.

    You can also install from the terminal. The script checks the download's SHA-256 checksum before installing.

    ```bash
    curl -fsSL https://desktop.mintlify.com/install.sh | bash
    ```

    The script installs to `/Applications`, or to `~/Applications` if you can't write to `/Applications`.
  </Tab>
  <Tab title="Windows">
    Requires Windows 10 or later, 64-bit.

    1. Download the installer from [mintlify.com/desktop](https://mintlify.com/desktop).
    2. Run the installer.

    The installer is not code signed yet, so Windows SmartScreen warns you the first time you run it. Click **More info**, then **Run anyway**.
  </Tab>
  <Tab title="Linux">
    Requires an x86_64 machine. The app is available as an AppImage and a `.deb` package.

    Download either file from [mintlify.com/desktop](https://mintlify.com/desktop), or install the AppImage from the terminal. The script checks the download's SHA-256 checksum before installing.

    ```bash
    curl -fsSL https://desktop.mintlify.com/install.sh | bash
    ```

    The script installs the app to `~/.local/share/mintlify-desktop`, adds a `mintlify-desktop` command to `~/.local/bin`, and adds Mintlify to your application menu.

    AppImages need FUSE 2. If the app doesn't start, install it. On Ubuntu:

    ```bash
    sudo apt install libfuse2
    ```
  </Tab>
</Tabs>

## Sign in

Open the app and sign in the same way you sign in to the dashboard in your browser. The app keeps you signed in when you restart it.

## Tabs and windows

Open each page you're working on in its own tab or window. Tabs and windows reopen where you left them when you restart the app.

Right-click a link in the dashboard to open it in a new tab, a new window, or your browser. Right-click a tab to duplicate it, copy its link, or close other tabs.

To show tabs in a sidebar instead of across the top of the window, change the tab layout in [Settings](#settings).

{/* TODO: screenshot of the vertical tab layout */}

### Each tab has its own session

A new tab opens signed in to the same account and organization as the tab you opened it from. After that, each tab keeps its own session:

- Switching organizations in one tab doesn't change your other tabs, so you can work in different organizations side by side.
- Signing out or signing in to a different account only affects that tab.

To sign out everywhere, use **Clear all data** in [Settings](#settings).

### Links to other sites

Tabs only load the Mintlify dashboard and the services it uses for signing in, billing, and connecting Git providers. While a tab is on one of those services, the tab shows its address. Links to any other site open in your default browser.

## Keyboard shortcuts

On Windows and Linux, use <kbd>Ctrl</kbd> instead of <kbd>Cmd</kbd>.

| Action | Shortcut |
| :--- | :--- |
| New tab | <kbd>Cmd</kbd> + <kbd>T</kbd> |
| New window | <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>N</kbd> |
| Close tab | <kbd>Cmd</kbd> + <kbd>W</kbd> |
| Close window | <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>W</kbd> |
| Go to tab 1–9 | <kbd>Cmd</kbd> + <kbd>1</kbd>–<kbd>9</kbd> |
| Next tab | <kbd>Ctrl</kbd> + <kbd>Tab</kbd> |
| Previous tab | <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>Tab</kbd> |
| Back | <kbd>Cmd</kbd> + <kbd>[</kbd> |
| Forward | <kbd>Cmd</kbd> + <kbd>]</kbd> |
| Reload | <kbd>Cmd</kbd> + <kbd>R</kbd> |
| Copy page URL | <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>C</kbd> |
| Open settings | <kbd>Cmd</kbd> + <kbd>,</kbd> |

Middle-click a tab to close it. For shortcuts inside the editor, see [Keyboard shortcuts](/editor/keyboard-shortcuts).

## Settings

Open settings with <kbd>Cmd</kbd> + <kbd>,</kbd> on macOS or <kbd>Ctrl</kbd> + <kbd>,</kbd> on Windows and Linux.

- **Tab layout**: Show tabs across the top of the window (**Horizontal**) or in a sidebar (**Vertical**).
- **Clear all data**: Sign out of every tab, close all tabs, and reset settings. The app restarts.

The settings window also shows the app version.

## Updates

The app checks for updates when it starts and every four hours while it runs. When an update is available, an **Update** button appears in the tab strip.

- **macOS**: Click **Update** to download and install the update in place.
- **Windows and Linux**: Click **Update** to download the new version from your browser, then install it.

## Uninstall

<Tabs>
  <Tab title="macOS">
    1. Quit Mintlify.
    2. Move **Mintlify** from your **Applications** folder to the Trash.
    3. To remove your sign-in and settings, delete `~/Library/Application Support/Mintlify Electron`.
  </Tab>
  <Tab title="Windows">
    1. Open **Settings** > **Apps** > **Installed apps**.
    2. Find **Mintlify** and select **Uninstall**.
    3. To remove your sign-in and settings, delete `%APPDATA%\Mintlify Electron`.
  </Tab>
  <Tab title="Linux">
    If you installed with the script, delete the files it created:

    ```bash
    rm -rf ~/.local/share/mintlify-desktop \
      ~/.local/bin/mintlify-desktop \
      ~/.local/share/applications/mintlify-desktop.desktop \
      ~/.local/share/icons/hicolor/512x512/apps/mintlify-desktop.png
    ```

    {/* TODO: verify the deb package name by installing Mintlify-amd64.deb and running `dpkg -l | grep -i mintlify` */}
    If you installed the `.deb` package, remove it with your package manager.

    To remove your sign-in and settings, delete `~/.config/Mintlify Electron`.
  </Tab>
</Tabs>

## Troubleshooting

<AccordionGroup>
  <Accordion title="A tab is signed in to the wrong account or organization">
    Each tab keeps its own session after you open it. Switch organizations or sign in again in that tab, or close it and open a new tab from a tab that's signed in the way you want.
  </Accordion>
  <Accordion title="A link opened in my browser instead of the app">
    Tabs only load the Mintlify dashboard and the services it uses for sign-in, billing, and Git providers. The app opens every other site in your default browser.
  </Accordion>
  <Accordion title="The app won't start on Linux">
    AppImages need FUSE 2. On Ubuntu, run `sudo apt install libfuse2`, then start the app again.
  </Accordion>
</AccordionGroup>
