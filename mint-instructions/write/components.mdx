Use this catalog to pick a built-in component and write it correctly. Components need no import.

## Workflow
1. Check which components the project's existing pages already use and prefer those.
2. Copy the minimal syntax below, then add only the props you need.
3. Run the Verify commands.

## Rules
- Component names are case-sensitive and capitalized (`<Card>`, not `<card>`).
- Every component except Banner, MDX, and Visibility accepts `className` (Tailwind classes or your own CSS).
- `icon` props accept a Font Awesome, Lucide, or Tabler name (per `icons.library` in `docs.json`), an emoji, a URL, a file path, or `{<svg>...</svg>}`. `iconType` applies to Font Awesome only: `regular`, `solid`, `light`, `thin`, `sharp-solid`, `duotone`, `brands`.
- `title` props on Card, Step, Tab, Accordion accept inline Markdown.
- Avoid the `style` prop for sizing (layout shift); use Tailwind classes.

## Catalog

Structure:
- **Tabs / Tab**: switchable panels. `<Tabs><Tab title="A">...</Tab></Tabs>`. Tabs: `defaultTabIndex` (0-based), `sync` (default true, syncs matching titles across tabs and code groups), `borderBottom`. Tab: `title` (required), `icon`, `id`.
- **CodeGroup**: titled code blocks as tabs. Each block needs a title (` ```bash npm `). `dropdown` swaps tabs for a menu.
- **Steps / Step**: numbered procedure. `<Steps><Step title="Install">...</Step></Steps>`. Steps: `titleSize` (`p`, `h2`, `h3`, `h4`). Step: `title` (required), `icon`, `stepNumber`, `id`, `noAnchor`.
- **Columns / Column**: grid. `<Columns cols={2}>...</Columns>`, `cols` 1 to 4 (default 2). Wrap arbitrary content in `<Column>`.
- **Panel**: replaces the right-side table of contents. `<Panel><Info>...</Info></Panel>`. If present, RequestExample and ResponseExample must be inside it. Suppressed by `mode` `wide`, `center`, `custom`.

Draw attention:
- **Callouts**: `<Note>`, `<Info>`, `<Tip>`, `<Warning>`, `<Check>`, `<Danger>` (children only). Custom: `<Callout icon="key" color="#FFC107">...</Callout>`.
- **Banner**: site-wide, configured in `docs.json`, not MDX: `"banner": { "content": "Markdown text", "dismissible": true, "type": "info" }`. `type`: `info`, `warning`, `critical`. `color: { "light": "#hex", "dark": "#hex" }`. Per language via `navigation.languages[].banner`. No custom components in `content`.
- **Badge**: inline label. `<Badge color="green" size="sm">Beta</Badge>`. `color`: `gray`, `blue`, `green`, `yellow`, `orange`, `red`, `purple`, `white`, `surface`, `white-destructive`, `surface-destructive`. `size`: `xs`, `sm`, `md`, `lg`. `shape`: `rounded`, `pill`. `icon`, `stroke`, `disabled`.
- **Update**: changelog entry. `<Update label="2026-10-01" description="v2.1.0" tags={["API"]}>...</Update>`. `label` required and unique (anchor). Generates RSS from plain Markdown; add `rss={{ title, description, date }}` when the body has components or HTML.
- **Frame**: border around images or video. `<Frame caption="Text" hint="Text"><img src="/images/x.png" alt="..." /></Frame>`. Caption supports Markdown.
- **Tooltip**: hover definition. `<Tooltip tip="Definition" headline="API" cta="Read more" href="/api">API</Tooltip>`. `tip` required; `href` required with `cta`.

AI prompts:
- **Prompt**: copyable prompt card. `<Prompt description="What it does" actions={["copy", "cursor"]}>Prompt text</Prompt>`. `description` and children required.

Show and hide:
- **Accordion / AccordionGroup**: collapsible section. `<AccordionGroup><Accordion title="Q">A</Accordion></AccordionGroup>`. Props: `title` (required), `description`, `defaultOpen`, `icon`, `id`.
- **Expandable**: nested properties inside a field. `<ResponseField name="user" type="object"><Expandable title="properties">...</Expandable></ResponseField>`. `title`, `defaultOpen`.
- **View**: per-language content selected from a page dropdown. `<View title="Python" icon="python">...</View>`. One View per language per page; TOC follows the selected view.
- **MDX**: compile Markdown inside JSX expressions or conditionals. `{platform === "ios" ? (<MDX>...</MDX>) : (<MDX>...</MDX>)}` (only the active branch renders). Leave a blank line after the opening tag in block form. Max 8 nesting levels, 500 fragments per page.
- **Visibility**: audience-specific content. `<Visibility for="humans">...</Visibility>`. `for`: `humans` (web only), `agents` (Markdown and `llms-full.txt` only), `signed-in`, `signed-out`, `for={{ groups: ["admin"] }}`, `for={{ groups: { includes: [...], excludes: [...] } }}`. Use a static value. Hides in the browser only; not access control.

Document an API:
- **ParamField**: request parameter, adds an API playground. `<ParamField path="id" type="string" required>Description</ParamField>`. Location key: `query`, `path`, `body`, or `header`. Also `default`, `placeholder`, `deprecated`, `pre`, `post`. Arrays: `type="string[]"`.
- **ResponseField**: response value. `<ResponseField name="id" type="string" required>Description</ResponseField>`. `name` and `type` required; `default`, `deprecated`, `pre`, `post`.
- **RequestExample / ResponseExample**: pin code blocks in the right sidebar. Each block needs a title. `dropdown` prop.
````mdx
<RequestExample>
```bash Request
curl https://api.example.com/v1/items
```
</RequestExample>
````

Link to pages:
- **Card**: linked container. `<Card title="Title" icon="rocket" href="/quickstart">Text</Card>`. `horizontal`, `img`, `cta`, `arrow`, `color`, `type` (`info`, `warning`, `note`, `tip`, `check`, `danger`). Group cards with `<Columns cols={2}>`.
- **Tile**: visual preview link. `<Tile href="/x" title="Title" description="Short"><img src="/images/x-light.svg" alt="..." className="block dark:hidden" /></Tile>`. `href` and children required. Grid with `<Columns>`.

Visual context:
- **Icon**: `<Icon icon="flag" size={32} />` or `<Icon src="/images/icon.svg" />` (one of `icon` or `src` required). `color`, `iconType`.
- **Mermaid**: fenced block ` ```mermaid `. Options on the fence: `placement="top-left"` (default `bottom-right`), `actions={false}`. ELK layout: first line `%%{init: {'flowchart': {'defaultRenderer': 'elk'}}}%%`.
- **Color**: swatches. `<Color variant="compact"><Color.Item name="blue-500" value="#3B82F6" /></Color>`. `variant`: `compact` or `table` (use `<Color.Row title="...">`). `value` may be `{{ light: "#fff", dark: "#000" }}`.
- **Tree / FileTree**: file structure (aliases). `<Tree><Tree.Folder name="app" defaultOpen><Tree.File name="page.tsx" highlight /></Tree.Folder></Tree>`. Folder: `name`, `defaultOpen`, `openable`, `highlight`. Or a nested Markdown list inside `<FileTree>` with blank lines after the opening tag and before the closing tag; trailing `/` marks a folder.
- **GitHub.Repo**: repo card with live stars and forks. `<GitHub.Repo repo="owner/name" variant="flat" />`. `variant`: `inset` (default), `flat`.

Custom React components: declare with `export const Name = () => ...` in the page or a `/snippets/` file. Hooks are pre-injected, no npm imports, no default exports. See https://www.mintlify.com/docs/customize/react-components.

## Verify
```bash
mint validate
mint dev --no-open
```
Open the page in the preview and check each component renders.
