Your Mintlify organization holds one or more projects. Each project is either docs or a base. Organization members can work in every project, so the same team can maintain your public docs and your internal knowledge.

## Project types

|  | Docs | Base |
| --- | --- | --- |
| Built for | Your customers and their agents | Your team and its agents |
| Typical content | API references, guides, and help centers | Specs, runbooks, and onboarding guides |
| Where people read it | A docs site at its own address, public or behind [authentication](/deploy/authentication-setup) | Your dashboard and connected AI tools, for members of your organization only |
| Saving changes | Edit on a branch, then publish | Edits to shared pages commit to your repository automatically |
| Get started | [Quickstart](/quickstart) | [Set up a base](/base/setup) |

Both types use the same [editor](/editor/index), [agent](/editor/agent), and [admin MCP](/ai/mintlify-mcp), and both store their pages in a Git repository. For more on how a base works, see [Mintlify Base](/base/index).

## Create a project

When you sign up for Mintlify, you create your first project. To add another project to your organization:

<Steps>
  <Step title="Start a new project">
    In your dashboard, open the project switcher at the top of the sidebar and click **New project**.
  </Step>
  <Step title="Choose a project type">
    Select **Docs** or **Base**, then click **Continue**.
  </Step>
  <Step title="Set up the project">
    Select how you plan to make updates: **Web editor**, **Local development**, or **MCP**. For docs, also enter a **Site address**. Your choice of method only affects setup. You can use every method in the project later.

    Click **Create project**.
  </Step>
</Steps>

If your organization is on an Enterprise plan, [contact sales](https://mintlify.com/enterprise) to add a project.

## Switch projects

Open the project switcher at the top of the dashboard sidebar and select a project. The switcher lists docs projects under **Docs** and bases under **Base**.

## Copy pages between projects

To reuse a page in another project, such as a base page you want to publish in your docs, open its options menu and select **Copy to a project**. The copy is independent of the original. For details, see [Copy a page to another project](/editor/pages#copy-a-page-to-another-project).
