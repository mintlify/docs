<Info>
  Role-based access control (RBAC) is available on [Enterprise plans](https://mintlify.com/pricing?ref=rbac).
</Info>

Mintlify provides three dashboard access levels: viewer, editor, and admin. Without RBAC, every member has full access to your organization's dashboard, and new members join as editors.

To invite members, change their roles, or remove them, see [Members](/dashboard/members).

|                                | Viewer | Editor | Admin |
| ------------------------------ | :----: | :----: | :---: |
| View content in the editor     |   ✅   |   ✅   |  ✅   |
| View dashboard and analytics   |   ✅   |   ✅   |  ✅   |
| Ask the [Slack agent](/agent/slack) questions |   ✅   |   ✅   |  ✅   |
| Make changes with the Slack agent |   ❌   |   ✅   |  ✅   |
| Edit content in the web editor |   ❌   |   ✅   |  ✅   |
| Publish changes                |   ❌   |   ✅   |  ✅   |
| Create, rename, and delete pages |   ❌   |   ✅   |  ✅   |
| Reorder navigation             |   ❌   |   ✅   |  ✅   |
| Upload media                   |   ❌   |   ✅   |  ✅   |
| Trigger deployments            |   ❌   |   ✅   |  ✅   |
| Roll back and promote deployments |   ❌   |   ✅   |  ✅   |
| Create and delete API keys     |   ❌   |   ✅   |  ✅   |
| Configure integrations         |   ❌   |   ✅   |  ✅   |
| Configure assistant            |   ❌   |   ✅   |  ✅   |
| Configure add-ons              |   ❌   |   ✅   |  ✅   |
| Invite editors and viewers     |   ❌   |   ✅   |  ✅   |
| Update user roles              |   ❌   |   ❌   |  ✅   |

<Tip>
  Limit admin access to only the people who need to perform admin tasks.
</Tip>

## Repository contributors and deployments

Anyone with write access to your documentation repository can contribute by pushing changes. Pushes to your deploy branch deploy automatically, whatever the person's dashboard role. Dashboard roles only control what people can do in the Mintlify dashboard.
