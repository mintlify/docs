Bring the assistant to the places your users already work, such as your app, dashboard, marketing site, or support portal. It answers from the same documentation as the assistant on your docs site.

| Option | What you get | What you build |
| :--- | :--- | :--- |
| [Widget](#widget) | A ready-made chat panel and trigger that you add with a script | Nothing beyond the install code |
| [Assistant API](#assistant-api) | Endpoints for answers and search | Your own chat interface |

## Widget

The [widget](/assistant/widget) adds the assistant to any website or web application with a hosted script. You can configure its appearance, starter questions, and trigger, and it uses the same credits as the assistant.

You can no longer set up the widget in the dashboard. If you already use the widget, it keeps working on your authorized sites. To set up the widget on a new site, email [support@mintlify.com](mailto:support@mintlify.com).

## Assistant API

Use the assistant API to build your own interface with full control over how it looks and behaves. Authenticate with an [assistant API key](https://app.mintlify.com/settings/organization/api-keys).

- Follow [Build an in-app assistant](/guides/assistant-embed) for a complete Next.js example.
- See [Create assistant message](/api/assistant/create-assistant-message-v2) and [Search documentation](/api/assistant/search) for the endpoints.
