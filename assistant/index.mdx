## About the assistant

The assistant answers natural language questions on your documentation site, so users find answers even when they don't know where to look. It uses tool calling to:

* **Search and retrieve** relevant documentation content as Markdown.
* **Build context** from the page the user is viewing.
* **Read images** such as screenshots and diagrams on pages it can access. It cannot fetch arbitrary image URLs.
* **Cite sources** with links to referenced pages.
* **Return API details** from your OpenAPI specifications, including methods, parameters, request bodies, and response schemas.
* **Generate copyable code examples.**
* **Accept text, images, and other files** as context.

### How indexing works

The assistant indexes your published documentation and API specifications immediately when you publish. It does not index draft branches, preview deployments, or, by default, hidden pages. To include hidden pages, set `seo.indexing: "all"` in your `docs.json`. See [Hidden pages](/organize/hidden-pages#search-seo-and-ai-indexing).

### How the assistant handles unknown questions

The assistant only answers from your documentation. If it finds nothing relevant, it says it doesn't have enough information. [Set a deflection email](/assistant/configure#set-deflection-emails) to give those users your support contact.

## Make content AI ingestible

Clear structure and context help the assistant give accurate answers.

<Card title="Structure and organization">
  - Use semantic markup and descriptive headings.
  - Create a logical hierarchy with consistent formatting.
  - Include comprehensive frontmatter metadata.
  - Keep paragraphs short.
</Card>

<Card title="Context">
  - Define terms and acronyms on first use.
  - Explain features and procedures with examples and use cases.
  - Cross-reference related topics.
  - Add [hidden pages](/organize/hidden-pages) with context only the assistant needs.
</Card>

<Tip>
  Use the [`Visibility`](/components/visibility) component to tailor content on the same page: wrap UI-oriented content in `<Visibility for="humans">` and agent-only context in `<Visibility for="agents">`.
</Tip>
