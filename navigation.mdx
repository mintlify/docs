The [navigation](settings#param-navigation) property in `docs.json` controls the structure and hierarchy of your documentation.

## Pages

Pages are the fundamental navigation unit and map to MDX files. In `navigation`, `pages` is an array of paths to [page files](pages).

```json
{
  "navigation": {
    "pages": ["settings", "pages", "navigation", "themes", "custom-domain"]
  }
}
```

## Groups

Groups organize your sidebar into sections and can be nested, labeled with tags, and styled with icons. Each entry requires `group` and `pages`; `icon`, `tag`, and `expanded` are optional.

```json
{
  "navigation": {
    "groups": [
      {
        "group": "Getting started",
        "icon": "play",
        "expanded": true,
        "pages": [
          "quickstart",
          {
            "group": "Editing",
            "icon": "pencil",
            "pages": ["installation", "editor"]
          }
        ]
      },
      {
        "group": "Writing content",
        "icon": "notebook-text",
        "tag": "NEW",
        "pages": ["writing-content/page", "writing-content/text"]
      }
    ]
  }
}
```

Set `expanded: true` to expand a group by default.

## Tabs

Tabs create distinct sections with separate URL paths and a horizontal navigation bar. Each entry requires a `tab` field and can contain groups, pages, icons, or external links.

```json
{
  "navigation": {
    "tabs": [
      {
        "tab": "API reference",
        "icon": "square-terminal",
        "pages": ["api-reference/get", "api-reference/post"]
      },
      {
        "tab": "Blog",
        "icon": "newspaper",
        "href": "https://external-link.com/blog"
      }
    ]
  }
}
```

### Menus

Add a `menu` array to a tab for dropdown navigation. Each entry requires an `item` field and can contain groups, pages, icons, or links.

```json
{
  "tab": "Developer tools",
  "menu": [
    {
      "item": "API reference",
      "icon": "rocket",
      "pages": ["api-reference/get", "api-reference/post"]
    },
    {
      "item": "SDKs",
      "icon": "code",
      "pages": ["sdk/fetch", "sdk/create"]
    }
  ]
}
```

## Anchors

Anchors add persistent items to the top of your sidebar. Each entry requires an `anchor` field.

```json
{
  "navigation": {
    "anchors": [
      {
        "anchor": "Documentation",
        "icon": "book-open",
        "pages": ["quickstart", "development"]
      },
      {
        "anchor": "Blog",
        "href": "https://external-link.com/blog"
      }
    ]
  }
}
```

Use `global.anchors` for external-only links (requires `href`, no relative paths).

```json
{
  "navigation": {
    "global": {
      "anchors": [
        { "anchor": "Community", "icon": "house", "href": "https://slack.com" }
      ]
    }
  }
}
```

## Dropdowns

Dropdowns are an expandable menu at the top of your sidebar. Each entry requires a `dropdown` field.

```json
{
  "navigation": {
    "dropdowns": [
      {
        "dropdown": "Documentation",
        "icon": "book-open",
        "pages": ["quickstart", "development"]
      },
      {
        "dropdown": "Blog",
        "href": "https://external-link.com/blog"
      }
    ]
  }
}
```

## OpenAPI

Set a default `openapi` specification at any level of the navigation hierarchy; children inherit it unless overridden.

```json
{
  "group": "API reference",
  "openapi": "/path/to/openapi-v1.json",
  "pages": ["overview", "GET /users", "POST /users"]
}
```

See [OpenAPI setup](/api-playground/openapi-setup) for details.

## Versions and languages

Partition navigation with `versions` or `languages` arrays. Each entry requires a `version` or `language` field and can contain any other navigation fields.

```json
{
  "navigation": {
    "versions": [
      { "version": "1.0.0", "groups": [/*...*/] },
      { "version": "2.0.0", "groups": [/*...*/] }
    ]
  }
}
```

Supported languages: `ar`, `cn`, `zh-Hant`, `en`, `fr`, `de`, `id`, `it`, `jp`, `ko`, `pt-BR`, `ru`, `es`, `tr`. For automated translations, [contact sales](mailto:gtm@mintlify.com).

## Nesting

Anchors, tabs, and dropdowns can be nested interchangeably to build any structure you need.

## Breadcrumbs

Control breadcrumbs via the `styling` property in `docs.json`:

```json
"styling": {
  "eyebrows": "breadcrumbs" // or "section" for parent only
}
```

## Interaction configuration

Use the `interaction.drilldown` property to control group expand behavior:

- `true` — navigate to the first page when a group is expanded
- `false` — only expand or collapse
- unset — theme default

```json
"interaction": {
  "drilldown": true
}
```
