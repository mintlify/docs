Votre organisation Mintlify contient un ou plusieurs projets. Chaque projet est soit une documentation (docs), soit une base. Les membres de l'organisation peuvent travailler dans tous les projets, ce qui permet à une même équipe de gérer votre documentation publique et votre base de connaissances interne.

<div id="project-types">

## Types de projets

</div>

|  | Docs | Base |
| --- | --- | --- |
| Conçu pour | Vos utilisateurs et leurs agents | Votre équipe et ses agents |
| Exemples de contenu | Références d'API, guides et centres d'aide | Spécifications, runbooks et guides d'intégration |
| Où le contenu est lu | Un site de documentation à sa propre URL, accessible publiquement ou protégé par une [authentification](/fr/deploy/authentication-setup) | Votre dashboard et les outils d'IA connectés, réservés aux membres de votre organisation |
| Enregistrement des modifications | Modifiez sur une branch, puis publiez | Les modifications des pages partagées sont automatiquement commitées dans votre dépôt |
| Pour commencer | [Démarrage rapide](/fr/quickstart) | [Configurer une base](/fr/base/setup) |

Les deux types de projets utilisent le même [éditeur](/fr/editor/index), le même [agent](/fr/editor/agent) et le même [MCP d'administration](/fr/ai/mintlify-mcp), si bien que la modification de contenu offre la même expérience dans l'un comme dans l'autre. Et les deux types de projets stockent leurs pages dans un dépôt Git.

<div id="create-a-project">

## Créer un projet

</div>

Lorsque vous vous inscrivez sur Mintlify, vous créez votre premier projet. Vous pouvez ajouter un autre projet à votre organisation depuis votre [dashboard](https://app.mintlify.com/).

<Steps>
  <Step title="Créer un nouveau projet">
    1. Cliquez sur le sélecteur de projet en haut de la barre latérale gauche.
    2. Cliquez sur <Icon icon="plus" /> **New project**.
  </Step>
  <Step title="Choisir un type de projet">
    1. Sélectionnez **Docs** ou **Base**.
    2. Pour une documentation, saisissez une **Site address**.
    3. Cliquez sur **Continue**.
  </Step>
  <Step title="Configurer le projet">
    1. Sélectionnez la façon dont vous prévoyez d'effectuer les mises à jour : **Web editor**, **Local development** ou **MCP**. Ce choix ne concerne que la configuration initiale. Vous pourrez ensuite utiliser toutes les méthodes dans le projet.
    2. Cliquez sur **Create project**.
  </Step>
</Steps>

<div id="switch-projects">

## Changer de projet

</div>

1. Cliquez sur le sélecteur de projet en haut de la barre latérale gauche.
2. Sélectionnez un projet.

<div id="copy-pages-between-projects">

## Copier des pages entre projets

</div>

Pour réutiliser une page dans un autre projet, par exemple une page de base que vous souhaitez publier dans votre documentation, ouvrez son menu d'options et sélectionnez **Copy to a project**. La copie est indépendante de l'original. Pour plus de détails, consultez [Copier une page vers un autre projet](/fr/editor/pages#copy-a-page-to-another-project).
