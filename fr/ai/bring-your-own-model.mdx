<Info>
  L'utilisation de votre propre modèle nécessite un [forfait Enterprise](https://mintlify.com/pricing?ref=bring-your-own-model). La section **AI model** n'apparaît dans votre dashboard que lorsque votre contrat l'inclut.
</Info>

Par défaut, Mintlify sélectionne les modèles qui alimentent l'assistant, l'agent et Autopilot. Pour utiliser un modèle spécifique avec votre propre compte fournisseur, fournissez une clé d'API et choisissez le modèle. Mintlify exécute ensuite l'inférence auprès de votre fournisseur. Si vous utilisez Anthropic, vous pouvez [associer votre organisation Claude](#link-your-claude-organization) au lieu de fournir une clé d'API.

Une seule configuration couvre tous les produits d'IA d'un projet : l'[assistant](/fr/assistant), l'[agent](/fr/agent), les [automatisations](/fr/automations/index) et [Autopilot](/fr/autopilot).

Vous sélectionnez un modèle pour chaque projet individuellement, et non pour l'ensemble de votre organisation. Si votre organisation compte plusieurs projets, configurez chacun séparément. Les projets que vous ne configurez pas utilisent les modèles par défaut de Mintlify.

<div id="supported-providers">
  ## Fournisseurs pris en charge
</div>

- OpenRouter
- Anthropic, avec une clé d'API ou la facturation associée
- OpenAI
- Amazon Bedrock

Quel que soit le fournisseur pris en charge, l'assistant, l'agent, les automatisations et Autopilot utilisent votre compte fournisseur et votre modèle.

Les tâches d'IA annexes s'exécutent également avec votre compte fournisseur plutôt qu'avec celui de Mintlify. Elles incluent les [questions de démarrage](/fr/assistant/configure#add-sample-questions) propres à chaque page, ainsi que les messages de commit et les détails de pull request que Mintlify rédige lorsque vous publiez depuis l'[éditeur](/fr/editor/index). Pour ces tâches, Mintlify utilise un modèle de votre fournisseur adapté à la tâche plutôt que le modèle que vous avez sélectionné. Si votre compte ne peut pas accéder à ce modèle, Mintlify réessaie avec le modèle que vous avez sélectionné.

Chaque fournisseur prend en charge un ensemble fixe de modèles. Les menus de modèles n'affichent que les modèles disponibles pour le fournisseur que vous sélectionnez. Pour Amazon Bedrock, les modèles disponibles dépendent de la région que vous sélectionnez.

<div id="configure-your-model">
  ## Configurer votre modèle
</div>

Les [éditeurs et administrateurs](/fr/dashboard/roles) peuvent configurer le modèle.

1. Sélectionnez le projet que vous souhaitez configurer.
2. Accédez à la page [Clés d'API](https://app.mintlify.com/settings/organization/api-keys) de votre tableau de bord.
3. Dans la section **AI model**, activez **Bring your own model**.
4. Sélectionnez un fournisseur. Pour Amazon Bedrock, sélectionnez également une **Region**.
5. Sélectionnez un **Assistant model**.
6. Facultatif : sélectionnez un **Agent model** pour exécuter l'agent, les automatisations et Autopilot avec un modèle différent. Si vous le laissez vide, ils utilisent le modèle de l'assistant.
7. Saisissez la clé d'API de votre fournisseur. Pour Amazon Bedrock, utilisez une clé d'API Amazon Bedrock. Mintlify ne prend pas en charge les clés d'accès AWS ni les identifiants de rôle IAM. Pour Anthropic, vous pouvez plutôt [associer votre organisation Claude](#link-your-claude-organization).
8. Cliquez sur **Save**.

Mintlify stocke votre clé de manière chiffrée et ne l'affiche plus jamais après l'enregistrement.

<div id="link-your-claude-organization">
  ## Associer votre organisation Claude
</div>

<Note>
  La facturation associée avec Claude Platform est en préversion publique.
</Note>

Si vous utilisez Anthropic, vous pouvez associer votre organisation Claude Platform au lieu de saisir une clé d'API. Anthropic facture l'utilisation de l'API Claude par l'assistant, l'agent, les automatisations et Autopilot directement à votre organisation Claude. Mintlify ne stocke pas de clé d'API Anthropic pour les projets qui utilisent la facturation associée. Mintlify facture votre abonnement séparément.

Associez votre organisation Claude une seule fois pour votre organisation Mintlify. Choisissez ensuite la facturation associée pour les projets qui doivent l'utiliser. Une organisation Claude ne peut être associée qu'à une seule organisation Mintlify.

<Warning>
  La facturation associée modifie uniquement la manière dont vous êtes facturé. Les requêtes s'exécutent toujours dans l'organisation Claude de Mintlify : ce sont donc les paramètres et les accords sur les données de Mintlify avec Anthropic qui s'appliquent, et non les vôtres. Si votre organisation Claude bénéficie de la conservation zéro des données (ZDR), celle-ci ne couvre pas l'utilisation associée. Votre accord de partenariat commercial (BAA), vos clés gérées par le client et vos listes d'adresses IP autorisées ne s'appliquent pas non plus. Si vous avez besoin de HIPAA, FERPA ou CMEK, n'associez pas votre organisation Claude pendant la préversion publique.
</Warning>

Pour associer votre organisation, vous avez besoin de :

- Une organisation Claude Platform facturée directement par Anthropic. Si vous achetez Claude via Amazon Bedrock, Google Cloud Vertex AI, Microsoft Foundry ou une place de marché cloud, utilisez plutôt une clé d'API.
- Le rôle Owner, Admin ou Billing dans votre organisation Claude.
- Le [rôle d'administrateur ou de propriétaire](/fr/dashboard/roles) dans votre organisation Mintlify. Une fois votre organisation associée, les éditeurs peuvent choisir la facturation associée sur un projet.

<Steps>
  <Step title="Choisir la facturation associée">
    1. Sélectionnez le projet que vous souhaitez configurer.
    2. Accédez à la page [Clés d'API](https://app.mintlify.com/settings/organization/api-keys) de votre tableau de bord.
    3. Dans la section **AI model**, activez **Bring your own model**.
    4. Sélectionnez **Anthropic** comme fournisseur.
    5. Sélectionnez **Linked billing** comme **Billing method**.

    Si votre organisation Mintlify est déjà associée, la ligne **Linked billing** affiche **Linked**. Passez directement à l'étape quatre.
  </Step>
  <Step title="Associer votre organisation Claude">
    Cliquez sur **Link your Claude organization**.
  </Step>
  <Step title="Approuver l'association">
    Connectez-vous à Claude, puis examinez et approuvez l'association. Claude vous renvoie vers la page **Clés d'API**.
  </Step>
  <Step title="Choisir vos modèles et enregistrer">
    1. Sélectionnez un **Assistant model**.
    2. Facultatif : sélectionnez un **Agent model**.
    3. Cliquez sur **Save**.
  </Step>
</Steps>

Si vous n'avez pas le rôle Owner, Admin ou Billing dans votre organisation Claude, ou si vous refusez la demande, Claude vous renvoie vers votre dashboard sans effectuer l'association. Demandez à une personne ayant l'un de ces rôles dans votre organisation Claude de l'associer. Cette personne doit également avoir le rôle d'administrateur ou de propriétaire dans votre organisation Mintlify.

Lorsque votre organisation est associée, Anthropic envoie un e-mail aux propriétaires, administrateurs et membres de facturation de votre organisation Claude. Anthropic n'envoie pas ces e-mails à certaines organisations, comme celles soumises à HIPAA.

<div id="linked-usage-billing">
  ### Facturation de l'utilisation associée
</div>

Anthropic facture l'utilisation associée sur le solde prépayé de votre organisation Claude ou, si votre organisation est facturée mensuellement, sur sa facture. Certains crédits ne peuvent pas payer l'utilisation associée, notamment les crédits API mensuels inclus dans les forfaits Max, Ultra et Team, ainsi que les crédits issus des programmes partenaires, capital-risque et startups d'Anthropic.

Si votre compte Claude n'a pas de solde ou ne peut pas être facturé, Anthropic refuse les requêtes et les fonctionnalités d'IA de Mintlify s'arrêtent sur les projets qui utilisent la facturation associée.

<div id="set-a-spend-limit">
  ### Définir une limite de dépenses
</div>

Vous pouvez définir une limite de dépenses mensuelle facultative pour Mintlify lorsque vous approuvez l'association, ou plus tard sur la page [Linked platforms](https://platform.claude.com/linked-platforms) de la Claude Console, où elle s'appelle spend cap. Vous pouvez également définir une limite par défaut pour toutes les plateformes associées. Une limite que vous définissez pour Mintlify remplace la limite par défaut.

- Lorsque l'utilisation atteint la limite, Anthropic refuse les requêtes jusqu'à ce que vous augmentiez la limite ou que celle-ci soit réinitialisée au début du mois suivant. Une requête qui dépasse la limite se termine quand même, de sorte que l'utilisation peut légèrement la dépasser.
- La limite comptabilise l'utilisation au prix catalogue, avant toute remise que vous avez négociée avec Anthropic. Avec une remise, vous pouvez atteindre la limite avant que votre facture n'atteigne ce montant.
- La limite de dépenses mensuelle propre à votre organisation Claude s'applique toujours. La première limite atteinte arrête les requêtes.
- Les administrateurs de votre organisation Claude reçoivent un e-mail lorsque l'utilisation atteint 80 % de la limite, puis un autre à 100 %.

Si Anthropic refuse des requêtes en raison d'une limite de dépenses, d'un crédit insuffisant ou d'un autre problème de facturation, les fonctionnalités d'IA cessent de fonctionner sur les projets qui utilisent la facturation associée. Vérifiez vos limites de dépenses, votre solde et votre compte dans la Claude Console.

<div id="unlink-your-claude-organization">
  ### Dissocier votre organisation Claude
</div>

Vous pouvez dissocier Mintlify à tout moment sur la page [Linked platforms](https://platform.claude.com/linked-platforms) de la Claude Console. Un administrateur ou propriétaire de votre organisation Mintlify peut également cliquer sur **Unlink** dans la section **AI model** de la page [Clés d'API](https://app.mintlify.com/settings/organization/api-keys) de votre tableau de bord.

La dissociation arrête généralement les nouvelles requêtes en moins de 10 secondes. Les requêtes déjà en cours se terminent et sont facturées à votre organisation Claude. Anthropic envoie un e-mail aux propriétaires, administrateurs et membres de facturation de votre organisation Claude lorsque Mintlify la dissocie.

La dissociation affecte tous les projets de votre organisation Mintlify qui utilisent la facturation associée. Les fonctionnalités d'IA de ces projets cessent de fonctionner jusqu'à ce que vous l'associiez de nouveau ou que vous passiez le projet à une clé d'API.

Pour passer un projet à une clé d'API :
1. Sélectionnez le projet que vous souhaitez configurer.
2. Accédez à la page [Clés d'API](https://app.mintlify.com/settings/organization/api-keys) de votre tableau de bord.
4. Sélectionnez **API key** comme **Billing method**.
5. Saisissez votre clé.
6. Cliquez sur **Save**.

Pour toute question concernant Mintlify, contactez le [support](mailto:support@mintlify.com). Pour toute question concernant votre organisation Claude ou sa facturation, contactez Anthropic.

<div id="end-user-identifiers">
  ## Identifiants des utilisateurs finaux
</div>

Mintlify envoie un identifiant haché de l'utilisateur final avec chaque requête vers OpenAI, Anthropic et OpenRouter. Si les systèmes de sécurité de votre fournisseur détectent un trafic abusif, le fournisseur peut bloquer uniquement cet utilisateur plutôt que toute votre clé d'API.

L'identifiant est un hachage HMAC de votre projet et de l'adresse IP, de la conversation ou du compte Mintlify de l'utilisateur. Il ne contient ni l'adresse IP brute, ni l'adresse e-mail, ni d'autres données personnelles. Un même utilisateur reçoit le même identifiant d'une requête à l'autre, ce qui vous permet de rapprocher l'activité signalée dans le tableau de bord de votre fournisseur.

| Fournisseur | Champ de la requête |
| --- | --- |
| OpenAI | `safety_identifier` (Responses API) ou `user` (Chat Completions API) |
| Anthropic | `metadata.user_id` |
| OpenRouter | `user` |

<div id="rotate-or-remove-your-key">
  ## Faire pivoter ou supprimer votre clé
</div>

Mintlify réutilise votre clé enregistrée pour tous les modèles du même fournisseur sur ce projet. Saisissez à nouveau une clé uniquement pour la faire pivoter, lorsque vous changez de fournisseur ou lorsque vous configurez un autre projet.

Pour faire pivoter votre clé, saisissez la nouvelle clé dans le champ **API key**, puis cliquez sur **Save**.

Pour cesser d'utiliser votre propre modèle, désactivez **Bring your own model**. Mintlify supprime la configuration et la clé stockées pour ce projet, et ses produits d'IA reviennent aux modèles par défaut de Mintlify. Les autres projets conservent leurs propres configurations. Désactiver l'utilisation de votre propre modèle sur un projet ne dissocie pas votre organisation Claude.
