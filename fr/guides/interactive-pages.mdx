Ajoutez des pages interactives pour permettre à vos lecteurs de parcourir un flux, d'utiliser des widgets ou de voir votre produit en action. Ce guide présente quatre éléments de base pour ces pages :

1. Des [widgets interactifs](#interactive-widgets) écrits dans la page sous forme de composants React.
2. Des [vidéos](#videos) du produit, ou d'une session d'agent, enregistrées avec un script de navigateur.
3. Des [captures d'écran](#screenshots) dans des cadres, en versions claire et sombre.
4. Des [tableaux](#tables) pour les statuts, les limites et les comparaisons.

<Note>
  Les produits, les chiffres et les étapes des exemples de ce guide sont des données d'exemple.
</Note>

<div id="choose-a-building-block">
  ## Choisir un élément de base
</div>

| Vous voulez montrer | Utilisez | Pourquoi |
| --- | --- | --- |
| Un flux en plusieurs étapes ou états | Widget interactif | Les lecteurs avancent à leur rythme, et chaque état a sa propre explication. |
| Comment un coût, une limite ou un paramètre varie selon les valeurs saisies | Widget interactif | Les lecteurs peuvent calculer leurs propres chiffres au lieu d'un exemple. |
| Le produit qui réalise une tâche de bout en bout | Vidéo | Le mouvement montre le rythme et les transitions que les captures ne peuvent pas montrer. |
| Un écran, un paramètre ou un résultat | Capture d'écran | Se charge rapidement et se parcourt d'un coup d'œil. |
| Des statuts, limites ou options côte à côte | Tableau | Les lecteurs comparent les lignes sans lire de texte. |

<div id="interactive-widgets">
  ## Widgets interactifs
</div>

Un widget est un composant React déclaré dans la page avec `export const`, puis placé avec une balise comme `<RxJourney />`. Placez les définitions des composants à la fin du fichier pour que le contenu se lise de haut en bas. Consultez [Composants React](/fr/customize/react-components) pour savoir ce que prend en charge l'environnement MDX.

<div id="how-the-calculator-works">
  ### Fonctionnement de la calculatrice
</div>

Voici le code source complet de la calculatrice. Les boutons de forfait, les curseurs et le résultat lisent tous l'état, et le total est calculé au rendu.

```mdx usage.mdx [expandable]
<RxCalculator />

export const RxCalculator = () => {
  const plans = { Basic: 0.12, Team: 0.08, Business: 0.05 };
  const [plan, setPlan] = useState("Team");
  const [seats, setSeats] = useState(12);
  const [runs, setRuns] = useState(40);
  const perRun = plans[plan];
  const total = seats * runs * perRun;
  const border = "1px solid rgba(127,127,127,.3)";
  return (
    <div className="not-prose" style={{ border, borderRadius: 14, padding: 16, display: "grid", gap: 14, fontSize: 14 }}>
      <div role="group" aria-label="Plan" style={{ display: "flex", flexWrap: "wrap", gap: 8 }}>
        {Object.keys(plans).map((name) => (
          <button
            key={name}
            type="button"
            aria-pressed={plan === name}
            onClick={() => setPlan(name)}
            style={{
              padding: "6px 12px", borderRadius: 8, font: "inherit", color: "inherit", cursor: "pointer",
              border: plan === name ? "1px solid #26BD6C" : border,
              background: plan === name ? "rgba(38,189,108,.15)" : "transparent",
            }}
          >
            {name}
          </button>
        ))}
      </div>
      <label style={{ display: "grid", gap: 6 }}>
        Seats: {seats}
        <input type="range" min={1} max={50} value={seats} onChange={(e) => setSeats(Number(e.target.value))} />
      </label>
      <label style={{ display: "grid", gap: 6 }}>
        Runs per seat each month: {runs}
        <input type="range" min={5} max={200} step={5} value={runs} onChange={(e) => setRuns(Number(e.target.value))} />
      </label>
      <div style={{ display: "flex", flexWrap: "wrap", justifyContent: "space-between", gap: 8, padding: 12, borderRadius: 10, background: "rgba(127,127,127,.08)" }}>
        <span style={{ opacity: 0.75 }}>{seats} seats × {runs} runs × ${perRun.toFixed(2)}</span>
        <strong>${total.toFixed(2)} per month</strong>
      </div>
    </div>
  );
};
```

<div id="widget-guidelines">
  ### Règles pour les widgets
</div>

- Faites fonctionner chaque couleur en mode clair et en mode sombre. Utilisez `currentColor` ou `inherit` pour le texte et les traits, des gris translucides comme `rgba(127,127,127,.25)` pour les bordures et les remplissages, et une seule couleur d'accent. Évitez le noir ou le blanc fixes.
- Ajoutez `className="not-prose"` à l'élément extérieur pour que les styles typographiques de la page ne modifient pas l'espacement dans le widget.
- Écrivez les données dans le composant sous forme de constantes. Ne récupérez pas de données et n'utilisez pas `localStorage`, `sessionStorage` ni les cookies, car ils échouent ou ne font rien dans l'éditeur.
- Écrivez du JavaScript simple. Une annotation TypeScript casse toute la page sur votre site publié.
- Placez les liens dans le texte autour d'un widget. Les liens à l'intérieur d'un widget ne fonctionnent pas dans l'éditeur.
- Donnez aux composants de chaque page un préfixe court commun, comme `Rx`, pour que leurs noms n'entrent pas en conflit avec les composants intégrés ni entre eux.
- Donnez aux boutons et aux champs des libellés visibles ou un `aria-label`, et indiquez l'option sélectionnée avec `aria-pressed` ou `aria-current`.
- Limitez chaque page à quelques widgets. L'éditeur exécute au maximum 10 widgets à la fois et met les autres en pause jusqu'à ce qu'ils apparaissent à l'écran.
- Pour utiliser un widget sur plusieurs pages, déplacez-le dans un fichier sous `/snippets/` et importez-le. Consultez [Extraits réutilisables](/fr/create/reusable-snippets).

<div id="videos">
  ## Vidéos
</div>

Enregistrez une courte vidéo lorsque les lecteurs doivent voir quelque chose bouger : la visite d'une interface, la fin d'un déploiement ou un agent qui accomplit une tâche. Les vidéos muettes en boucle fonctionnent comme des captures animées. Gardez les clips auto-hébergés courts et légers, et hébergez les vidéos plus longues sur une plateforme comme YouTube. Consultez [Médias](/fr/guides/media) pour savoir quand utiliser la vidéo et comment réduire la taille des fichiers.

```mdx
<Frame caption="Creating a project, from sign in to the first deployment">
  <video
    src="/images/walkthrough.webm"
    controls
    autoPlay
    muted
    loop
    playsInline
    className="w-full rounded-xl"
  />
</Frame>
```

<div id="record-the-product-with-a-script">
  ### Enregistrer le produit avec un script
</div>

Un script de navigateur produit la même vidéo à chaque fois, ce qui vous permet de la réenregistrer après une modification de l'interface. Ce script [Playwright](https://playwright.dev) enregistre un fichier WebM pendant qu'il parcourt un flux :

```js record.mjs
import { chromium } from "playwright";

const browser = await chromium.launch();
const context = await browser.newContext({
  viewport: { width: 1280, height: 720 },
  recordVideo: { dir: "videos", size: { width: 1280, height: 720 } },
});
const page = await context.newPage();

await page.goto("http://localhost:3000");
await page.waitForTimeout(800);
await page.getByRole("link", { name: "New project" }).click();
await page.getByLabel("Name").pressSequentially("Sample project", { delay: 60 });
await page.getByRole("button", { name: "Create" }).click();
await page.waitForTimeout(1500);

await context.close();
await browser.close();
```

Conseils pour des enregistrements lisibles :

- Faites une pause d'environ une seconde après chaque action, pour que les lecteurs puissent suivre le changement.
- Saisissez le texte avec un délai au lieu de remplir les champs instantanément.
- Gardez les vidéos sous 30 secondes. Découpez les flux plus longs en plusieurs vidéos placées à côté des étapes qu'elles montrent.
- Utilisez des comptes et des données d'exemple, jamais des données de production.

<div id="replay-an-agent-session">
  ### Rejouer une session d'agent
</div>

Pour montrer ce qu'a fait un agent, enregistrez sa session et rejouez-la sous forme de vidéo. Claude Code et Codex peuvent écrire la session en lignes JSON, par exemple `claude -p "<task>" --output-format stream-json --verbose > session.jsonl`. Affichez les messages et les appels d'outils dans une page HTML simple de style terminal, puis enregistrez cette page avec le script Playwright. Une rediffusion montre les vraies commandes et l'ordre dans lequel l'agent les a exécutées, sans exposer de terminal en direct.

<div id="screenshots">
  ## Captures d'écran
</div>

Placez les captures d'écran dans un `<Frame>` avec une légende qui indique quoi regarder. Recadrez sur la partie de l'écran qui compte.

```mdx
<Frame caption="The settings page, with the custom domain field highlighted">
  <img className="block dark:hidden" src="/images/settings-light.png" alt="Settings page in light mode" />
  <img className="hidden dark:block" src="/images/settings-dark.png" alt="Settings page in dark mode" />
</Frame>
```

Pour garder les captures à jour, prenez-les avec un script. Utilisez la même configuration Playwright que pour le script vidéo, appelez `page.screenshot({ path: "images/settings-light.png" })` et relancez-le lorsque l'interface change. Pour la version sombre, créez le contexte avec `colorScheme: "dark"`. Consultez [Images et intégrations](/fr/create/image-embeds) pour les options de taille et de zoom.

<div id="tables">
  ## Tableaux
</div>

Les tableaux contiennent les détails que les lecteurs viennent rechercher : statuts, limites, prix et prise en charge selon les options. Commencez par le tableau et gardez le texte autour concis.

| Fonctionnalité | Basic | Team | Business |
| --- | --- | --- | --- |
| Projets | 1 | 10 | Illimités |
| Exécutions mensuelles | 100 | 5 000 | Sur mesure |
| Authentification unique | Non | Non | Oui |
| Support | Communauté | E-mail | Canal dédié |

Pour une page composée principalement de tableaux, définissez `mode: "wide"` dans le frontmatter pour leur donner toute la largeur. Consultez [Mode de page](/fr/organize/pages#page-mode).

<div id="build-these-pages-with-an-agent">
  ## Créer ces pages avec un agent
</div>

Les agents de code écrivent bien les widgets et les scripts d'enregistrement lorsque vous leur donnez le modèle et les données. Indiquez ce guide à l'agent, puis décrivez ce que vous voulez que le lecteur comprenne.

```text Widget
Read https://www.mintlify.com/docs/guides/interactive-pages.md.
Add an interactive widget to docs/billing/usage.mdx that lets readers
pick a plan and a number of monthly runs, and shows the monthly cost with
the formula. Use the prices in the table on that page. Follow the widget
guidelines: export const at the end of the file, not-prose, currentColor,
no fetch. Run mint dev and check it in light and dark mode.
```

```text Video
Write a Playwright script that records the "create a project" flow on
http://localhost:3000 as a 1280x720 WebM: sign in with the sample account
from .env.example, click New project, type "Sample project", and wait
for the deployment to finish. Pause about a second after each action.
Save it to images/create-project.webm and embed it in quickstart.mdx in a
Frame with a caption.
```

Avant de publier :

- Ouvrez la page avec `mint dev` ou dans l'éditeur, en mode clair et en mode sombre.
- Vérifiez que chaque widget s'affiche et réagit aux clics et au clavier.
- Réduisez le navigateur à la largeur d'un téléphone et vérifiez que rien ne déborde.
- Lisez chaque vidéo et ouvrez chaque image.

export const RxTheme = {
  accent: "#26BD6C",
  accentSoft: "rgba(38,189,108,.12)",
  border: "rgba(127,127,127,.25)",
  surface: "rgba(127,127,127,.06)",
};

export const RxFrame = ({ children, title, caption }) => (
  <div className="not-prose" style={{ border: `1px solid ${RxTheme.border}`, borderRadius: 14, padding: 16, display: "grid", gap: 14, width: "100%", fontSize: 14, color: "inherit" }}>
    <div style={{ display: "flex", flexWrap: "wrap", alignItems: "baseline", justifyContent: "space-between", gap: 8 }}>
      <div style={{ fontWeight: 600 }}>{title}</div>
      {caption ? <div style={{ fontSize: 12, opacity: 0.65 }}>{caption}</div> : null}
    </div>
    {children}
  </div>
);

export const RxButton = ({ children, onClick, disabled, pressed }) => (
  <button
    type="button"
    onClick={onClick}
    disabled={disabled}
    aria-pressed={pressed}
    style={{
      padding: "6px 12px", borderRadius: 8, font: "inherit", fontSize: 13, fontWeight: 600, color: "inherit",
      cursor: disabled ? "not-allowed" : "pointer", opacity: disabled ? 0.45 : 1,
      border: `1px solid ${pressed ? RxTheme.accent : "rgba(127,127,127,.35)"}`,
      background: pressed ? RxTheme.accentSoft : "transparent",
    }}
  >
    {children}
  </button>
);

export const RxJourney = () => {
  const steps = [
    { name: "Sign up", who: "Reader", detail: "The reader creates an account with an email address and confirms it from the inbox." },
    { name: "Create project", who: "Reader", detail: "The reader names the project and picks a template. The product creates a repository with starter pages." },
    { name: "First deploy", who: "Product", detail: "The product builds the starter pages and publishes them to a preview URL in about a minute." },
    { name: "Invite team", who: "Reader", detail: "The reader invites teammates by email. Each teammate gets editor access to the project." },
    { name: "Go live", who: "Reader", detail: "The reader adds a custom domain and points DNS at the product. The site is live on the domain." },
  ];
  const [active, setActive] = useState(0);
  return (
    <RxFrame title="Sample onboarding journey" caption={`Step ${active + 1} of ${steps.length}`}>
      <div style={{ display: "grid", gridTemplateColumns: "repeat(auto-fit, minmax(110px, 1fr))", gap: 8 }}>
        {steps.map((step, i) => {
          const isActive = i === active;
          return (
            <button
              key={step.name}
              type="button"
              onClick={() => setActive(i)}
              aria-current={isActive ? "step" : undefined}
              style={{
                textAlign: "left", padding: 10, borderRadius: 10, font: "inherit", color: "inherit", cursor: "pointer", minWidth: 0,
                border: isActive ? `2px solid ${RxTheme.accent}` : `1px solid ${RxTheme.border}`,
                background: isActive ? RxTheme.accentSoft : i < active ? RxTheme.surface : "transparent",
                opacity: i > active ? 0.6 : 1, transition: "background .25s, opacity .25s",
              }}
            >
              <div style={{ fontSize: 11, textTransform: "uppercase", letterSpacing: ".04em", opacity: 0.7 }}>{step.who}</div>
              <div style={{ fontWeight: 600, fontSize: 13 }}>{step.name}</div>
            </button>
          );
        })}
      </div>
      <div style={{ height: 4, borderRadius: 4, background: RxTheme.surface, overflow: "hidden" }}>
        <div style={{ width: `${((active + 1) / steps.length) * 100}%`, height: "100%", background: RxTheme.accent, transition: "width .3s" }} />
      </div>
      <p style={{ margin: 0, lineHeight: 1.55, minHeight: 44 }}>{steps[active].detail}</p>
      <div style={{ display: "flex", gap: 8 }}>
        <RxButton onClick={() => setActive(active - 1)} disabled={active === 0}>Back</RxButton>
        <RxButton onClick={() => setActive(active + 1)} disabled={active === steps.length - 1}>Next</RxButton>
      </div>
    </RxFrame>
  );
};

export const RxChart = () => {
  const weeks = ["W1", "W2", "W3", "W4", "W5", "W6"];
  const series = {
    "Page views": [420, 510, 480, 620, 700, 760],
    "Searches": [130, 150, 170, 160, 210, 240],
    "Feedback": [12, 18, 15, 22, 19, 27],
  };
  const [metric, setMetric] = useState("Page views");
  const values = series[metric];
  const max = Math.max(...values);
  const change = Math.round(((values[values.length - 1] - values[0]) / values[0]) * 100);
  return (
    <RxFrame title="Sample weekly usage" caption={`${metric}: ${change >= 0 ? "+" : ""}${change}% over six weeks`}>
      <div style={{ display: "flex", flexWrap: "wrap", gap: 8 }}>
        {Object.keys(series).map((name) => (
          <RxButton key={name} pressed={metric === name} onClick={() => setMetric(name)}>{name}</RxButton>
        ))}
      </div>
      <div role="img" aria-label={`${metric} by week: ${values.join(", ")}`} style={{ display: "grid", gridTemplateColumns: `repeat(${values.length}, 1fr)`, alignItems: "end", gap: 10, height: 160 }}>
        {values.map((v, i) => (
          <div key={weeks[i]} style={{ display: "grid", gap: 4, alignItems: "end", height: "100%" }}>
            <div style={{ fontSize: 11, textAlign: "center", opacity: 0.7, fontVariantNumeric: "tabular-nums", alignSelf: "end" }}>{v}</div>
            <div style={{ height: `${(v / max) * 120}px`, borderRadius: "6px 6px 2px 2px", background: i === values.length - 1 ? RxTheme.accent : "rgba(127,127,127,.3)", transition: "height .3s" }} />
          </div>
        ))}
      </div>
      <div style={{ display: "grid", gridTemplateColumns: `repeat(${weeks.length}, 1fr)`, gap: 10, fontSize: 11, opacity: 0.6, textAlign: "center" }}>
        {weeks.map((w) => <span key={w}>{w}</span>)}
      </div>
    </RxFrame>
  );
};
