<div id="create-your-knowledge-base">

## Créer votre base de connaissances

</div>

<Tabs>
  <Tab title="Nouveau sur Mintlify">
    <Steps>
      <Step title="S'inscrire sur Mintlify">
        Accédez à [app.mintlify.com/signup?product=base](https://app.mintlify.com/signup?product=base) et créez votre compte. Cliquez ensuite sur **Get started**.
      </Step>
      <Step title="Choisir comment effectuer les mises à jour">
        Sélectionnez la façon dont vous prévoyez d'effectuer les mises à jour : **Code editor**, **Web editor** ou **MCP**. Ce choix ne concerne que la configuration initiale. Vous pourrez ensuite utiliser toutes les méthodes dans votre base de connaissances.
      </Step>
      <Step title="Créer le projet">
        Cliquez sur **Create project**. Votre base de connaissances s'ouvre dans l'éditeur avec une page de démarrage.
      </Step>
    </Steps>
  </Tab>
  <Tab title="Organisation existante">
    <Steps>
      <Step title="Créer une base de connaissances depuis le sélecteur de projet de votre dashboard">
        1. Dans votre [dashboard](https://app.mintlify.com/), cliquez sur le sélecteur de projet en haut de la barre latérale gauche.
        2. Cliquez sur <Icon icon="plus" /> **New project**.
        3. Sélectionnez **Knowledge base**, puis cliquez sur **Continue**.

        Votre base de connaissances fait partie de la même organisation que vos autres projets.
      </Step>
      <Step title="Choisir comment effectuer les mises à jour">
        Sélectionnez la façon dont vous prévoyez d'effectuer les mises à jour : **Code editor**, **Web editor** ou **MCP**. Ce choix ne concerne que la configuration initiale. Vous pourrez ensuite utiliser toutes les méthodes dans votre base de connaissances.
      </Step>
      <Step title="Créer le projet">
        Cliquez sur **Create project**. Votre base de connaissances s'ouvre dans l'éditeur avec une page de démarrage.
      </Step>
    </Steps>
  </Tab>
</Tabs>

<Check>
  Votre base de connaissances apparaît dans le sélecteur de projet de votre dashboard. La barre latérale de l'éditeur affiche une checklist de configuration avec vos prochaines étapes.
</Check>

<div id="add-pages">

## Ajouter des pages

</div>

Créez des pages pour votre équipe dans la section **Navigation** de la barre latérale.

Cliquez sur le bouton <Icon icon="plus" /> plus à côté de l'en-tête **Navigation** et sélectionnez **New page**. Pour importer des fichiers Markdown existants, faites-les glisser depuis votre ordinateur vers la barre latérale.

Lorsque vous modifiez des pages dans **Navigation**, Mintlify commit automatiquement les modifications dans le dépôt de votre base de connaissances. Pour rédiger d'abord en privé, créez une page dans la section **Personal** et déplacez-la vers **Navigation** lorsque vous souhaitez la rendre disponible à votre équipe.

Pour plus d'informations sur la modification des pages, consultez [Créer et modifier des pages](/fr/editor/pages).

<div id="invite-your-team">

## Inviter votre équipe

</div>

Les membres de votre organisation peuvent accéder à votre base de connaissances. Pour ajouter des collègues, invitez-les depuis vos paramètres [Members](https://app.mintlify.com/settings/organization/members).

<div id="connect-your-ai-tools">

## Connecter vos outils d'IA

</div>

Connectez Claude, ChatGPT, Cursor ou un autre outil d'IA à votre base de connaissances afin qu'il puisse rechercher, lire et mettre à jour vos pages.

1. Dans votre dashboard, ouvrez votre base de connaissances et accédez aux paramètres [MCP](https://app.mintlify.com/products/mcp).
2. Sous **Connect**, sélectionnez votre outil d'IA et suivez les instructions pour vous connecter.

Lorsqu'un outil d'IA modifie votre base de connaissances, il commit les modifications de la même manière que l'éditeur. Pour connaître les outils disponibles et des exemples de prompts, consultez [MCP d'administration](/fr/ai/mintlify-mcp).

<div id="optional-create-from-a-local-folder">

## (Facultatif) Créer à partir d'un dossier local

</div>

Si vous disposez d'un dossier existant de fichiers Markdown, vous pouvez le publier dans une nouvelle base de connaissances depuis la ligne de commande avec la CLI Mint.

<Steps>
  <Step title="Provisionner la base de connaissances">
    Exécutez la commande suivante depuis n'importe quel répertoire, en remplaçant `<name>` par le sous-domaine de votre choix :

    ```bash
    mint deploy --knowledge-base --subdomain <name>
    ```

    La sortie inclut une commande de clonage avec un jeton d'écriture de courte durée, ainsi que le lien de l'éditeur de votre nouvelle base de connaissances.
  </Step>

  <Step title="Cloner le dépôt hébergé">
    Copiez et exécutez la commande de clonage indiquée dans la sortie de l'étape précédente. Elle ressemble à ceci :

    ```bash
    git -c http.<REPOSITORY_URL>.extraHeader="Authorization: Bearer <WRITE_TOKEN>" clone <REPOSITORY_URL> <name>
    ```

    Cela crée un répertoire `<name>` contenant le dépôt hébergé. Le jeton d'écriture de la commande de clonage expire ; si nécessaire, exécutez à nouveau `mint deploy --knowledge-base` depuis le même répertoire pour en obtenir un nouveau.
  </Step>

  <Step title="Copier votre contenu et faire un commit">
    Copiez vos fichiers Markdown et MDX dans le répertoire cloné. Placez `docs.json` et vos pages à la racine du dépôt.

    Ensuite, faites un commit de vos modifications :

    ```bash
    cd <name>
    git add .
    git commit -m "Initial content"
    ```
  </Step>

  <Step title="Pousser vers la base de connaissances">
    Exécutez la commande suivante depuis le répertoire où vous avez exécuté `mint deploy` (et non depuis le clone) :

    ```bash
    mint deploy --knowledge-base --push <name>
    ```

    Cette commande rebase vos commits sur la dernière version de la branche main du dépôt hébergé, puis les pousse. N'exécutez pas `git push` directement.

    En cas de conflit de rebase, résolvez-le, exécutez `git rebase --continue` dans le clone, puis relancez cette commande.
  </Step>

  <Step title="Revendiquer la base de connaissances">
    La base de connaissances que vous avez provisionnée n'est pas encore dans votre compte Mintlify. La sortie de `mint deploy` indique quand elle expire. Si personne ne la revendique d'ici là, Mintlify la supprime.

    Une fois votre contenu poussé, exécutez [`mint claim`](/fr/cli/commands#mint-claim) depuis le répertoire où vous avez exécuté `mint deploy` :

    ```bash
    mint claim
    ```

    Ouvrez le lien de revendication affiché, connectez-vous et cliquez sur **Confirm**. La base de connaissances est transférée dans votre compte.
  </Step>
</Steps>

Après la revendication, ouvrez votre base de connaissances via le lien de l'éditeur de la première étape. La CLI ne peut plus y pousser de modifications : modifiez-la donc dans l'éditeur ou [connectez votre propre dépôt](#optional-connect-your-own-repository).

<div id="optional-connect-your-own-repository">

## (Facultatif) Connecter votre propre dépôt

</div>

Votre base de connaissances démarre avec un dépôt hébergé par Mintlify. Pour modifier votre base de connaissances en local ou pour utiliser [Autopilot](/fr/autopilot), connectez un dépôt depuis vos [paramètres Git](https://app.mintlify.com/settings/project/git-settings). Les commits poussés vers le dépôt connecté mettent à jour votre base de connaissances.

<div id="optional-add-a-project-icon">

## (Facultatif) Ajouter une icône de projet

</div>

Ajoutez une icône pour distinguer votre base de connaissances de vos autres projets dans le sélecteur de projets. Pour ajouter une icône, vous avez besoin d'un [rôle](/fr/dashboard/roles) qui peut gérer les paramètres du site et de l'espace de travail.

1. Dans votre dashboard, ouvrez votre base de connaissances et accédez aux paramètres [Project](https://app.mintlify.com/settings/project/site).
2. Dans la ligne **Icon**, cliquez sur **Upload** et sélectionnez un fichier PNG, JPEG, WebP ou SVG de 4 Mo maximum.

Pour changer l'icône plus tard, cliquez sur **Replace**. Pour la supprimer, cliquez sur le bouton de suppression <Icon icon="trash" /> à côté de **Replace**.
