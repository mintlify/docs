<div id="create-your-base">

## Créer votre base

</div>

<Tabs>
  <Tab title="Nouveau sur Mintlify">
    <Steps>
      <Step title="S'inscrire sur Mintlify">
        Accédez à [app.mintlify.com/signup?product=base](https://app.mintlify.com/signup?product=base) et créez votre compte. Cliquez ensuite sur **Get started**.
      </Step>
      <Step title="Choisir comment effectuer les mises à jour">
        Sélectionnez la façon dont vous prévoyez d'effectuer les mises à jour : **Web editor**, **Local development** ou **MCP**. Ce choix ne concerne que la configuration initiale. Vous pourrez ensuite utiliser toutes les méthodes dans votre base.
      </Step>
      <Step title="Créer le projet">
        Cliquez sur **Create project**. Votre base s'ouvre dans l'éditeur avec une page de démarrage.
      </Step>
    </Steps>
  </Tab>
  <Tab title="Organisation existante">
    <Steps>
      <Step title="Créer une base depuis le sélecteur de projet de votre dashboard">
        1. Dans votre [dashboard](https://app.mintlify.com/), cliquez sur le sélecteur de projet en haut de la barre latérale gauche.
        2. Cliquez sur <Icon icon="plus" /> **New project**.
        3. Sélectionnez **Base**, puis cliquez sur **Continue**.

        Votre base fait partie de la même organisation que vos autres projets.
      </Step>
      <Step title="Choisir comment effectuer les mises à jour">
        Sélectionnez la façon dont vous prévoyez d'effectuer les mises à jour : **Web editor**, **Local development** ou **MCP**. Ce choix ne concerne que la configuration initiale. Vous pourrez ensuite utiliser toutes les méthodes dans votre base.
      </Step>
      <Step title="Créer le projet">
        Cliquez sur **Create project**. Votre base s'ouvre dans l'éditeur avec une page de démarrage.
      </Step>
    </Steps>
  </Tab>
</Tabs>

<Check>
  Votre base apparaît sous **Base** dans le sélecteur de projet de votre dashboard. La barre latérale de l'éditeur affiche une checklist de configuration avec vos prochaines étapes.
</Check>

<div id="add-pages">

## Ajouter des pages

</div>

Créez des pages pour votre équipe dans la section **Teamspace** de la barre latérale.

Cliquez sur le bouton <Icon icon="plus" /> plus à côté de l'en-tête **Teamspace** et sélectionnez **New page**. Pour importer des fichiers Markdown existants, faites-les glisser depuis votre ordinateur vers la barre latérale.

Lorsque vous modifiez des pages de votre Teamspace, Mintlify commit automatiquement les modifications dans le dépôt de votre base. Pour rédiger d'abord en privé, créez une page dans la section **Personal** et déplacez-la vers votre **Teamspace** lorsque vous souhaitez la rendre disponible à votre équipe.

Pour plus d'informations sur la modification des pages, consultez [Créer et modifier des pages](/fr/editor/pages).

<div id="invite-your-team">

## Inviter votre équipe

</div>

Les membres de votre organisation peuvent accéder à votre base. Pour ajouter des collègues, invitez-les depuis vos paramètres [Members](https://app.mintlify.com/settings/organization/members).

<div id="connect-your-ai-tools">

## Connecter vos outils d'IA

</div>

Connectez Claude, ChatGPT, Cursor ou un autre outil d'IA à votre base afin qu'il puisse rechercher, lire et mettre à jour vos pages.

1. Dans votre dashboard, ouvrez votre base et accédez aux paramètres [MCP](https://app.mintlify.com/products/mcp).
2. Sous **Connect**, sélectionnez votre outil d'IA et suivez les instructions pour vous connecter.

Lorsqu'un outil d'IA modifie votre base, il commit les modifications de la même manière que l'éditeur. Pour connaître les outils disponibles et des exemples de prompts, consultez [MCP d'administration](/fr/ai/mintlify-mcp).

<div id="optional-connect-your-own-repository">

## (Facultatif) Connecter votre propre dépôt

</div>

Votre base démarre avec un dépôt hébergé par Mintlify. Pour modifier votre base en local, connectez un dépôt depuis vos [paramètres Git](https://app.mintlify.com/settings/project/git-settings). Les commits poussés vers le dépôt connecté mettent à jour votre base.
