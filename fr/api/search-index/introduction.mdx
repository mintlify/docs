Utilisez l’API REST Mintlify Index pour récupérer des connaissances techniques pour vos applications et agents. L’API prend en charge trois modes de récupération :

- [`context`](/fr/api/search-index/context) assemble du contenu avec des sources citées dans une limite de tokens.
- [`search`](/fr/api/search-index/search) renvoie des résultats classés par pertinence issus de la documentation et du web.
- [`contents`](/fr/api/search-index/contents) récupère le contenu correspondant à des ID de résultats Mintlify ou à des URL de résultats sélectionnés.

<Info>
  L’API REST nécessite une clé API pour votre organisation. Le [serveur MCP Index public](/fr/search-index/mcp) ne nécessite pas de clé API.
</Info>

<div id="base-url">
  ## URL de base
</div>

Envoyez les requêtes de l’API REST à l’adresse suivante :

```text
https://leaves.mintlify.com/api/universal-search/v1
```

Ajoutez le chemin d’un endpoint à cette URL de base, par exemple `/context`, `/search` ou `/contents`.

<div id="authentication">
  ## Authentification
</div>

Authentifiez chaque requête avec une clé API Index dans l’en-tête `Authorization` :

```http
Authorization: Bearer mint_us_...
```

Les clés API Index commencent par `mint_us_`.

<Steps>
  <Step title="Créer une clé API Index">
    Ouvrez la [page des clés API](https://app.mintlify.com/settings/organization/api-keys) dans votre tableau de bord et créez une clé API Index.

    Si ce type de clé n’est pas disponible, votre organisation n’a pas accès à l’API REST Index.
  </Step>
  <Step title="Stocker la clé en toute sécurité">
    Enregistrez la clé dans une variable d’environnement côté serveur. Mintlify n’affiche la clé complète qu’au moment de sa création. Stockez-la en toute sécurité.

    ```bash
    export MINTLIFY_INDEX_API_KEY="mint_us_..."
    ```

    <Warning>
      N’exposez pas une clé API Index dans du code côté client et ne l’enregistrez pas dans le contrôle de version.
    </Warning>
  </Step>
  <Step title="Construire le contexte">
    Envoyez votre première requête à l’endpoint `context` :

    ```bash
    curl -X POST "https://leaves.mintlify.com/api/universal-search/v1/context" \
      -H "Authorization: Bearer $MINTLIFY_INDEX_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{
        "query": "Comment dois-je configurer la mise en cache dans Next.js 16 ?",
        "product": "Next.js",
        "format": "txt",
        "tokenBudget": 3000
      }'
    ```

    Une réponse réussie contient le contexte assemblé avec les URL des sources, le nombre de résultats utilisés et le nombre de tokens produits.
  </Step>
</Steps>

<div id="rate-limits">
  ## Limites de débit
</div>

Les limites de l’API REST s’appliquent par organisation Mintlify. Toutes les clés API d’une organisation partagent la même limite :

| Fenêtre | Limite |
| --- | ---: |
| Par seconde | 10 requêtes |
| Par jour | 1 000 requêtes |

Les requêtes qui dépassent l’une ou l’autre limite renvoient `429 Too Many Requests`. Utilisez un délai de reprise exponentiel avant de réessayer.

<div id="errors">
  ## Erreurs
</div>

| Statut | Signification |
| --- | --- |
| `400` | Le corps de la requête n’est pas valide. |
| `401` | La clé API est absente ou invalide, ou l’organisation n’a pas accès à l’API REST Index. |
| `403` | L’adresse IP de la requête n’est pas autorisée par la clé API. |
| `429` | L’organisation a dépassé une limite de débit. |
| `500` | L’Index n’a pas pu traiter la requête. |
