<Note>
  L'exportation statique n'est pas disponible pour les déploiements dont l'authentification est activée. Ce point de terminaison renvoie une réponse `403` si le déploiement cible utilise une authentification partielle ou complète. Contactez [support@mintlify.com](mailto:support@mintlify.com) si vous devez exporter un déploiement authentifié.
</Note>
