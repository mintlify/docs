<Note>
  L'application de bureau est en bêta et peut évoluer.
</Note>

L'application de bureau Mintlify exécute votre [Dashboard](https://app.mintlify.com) et l'[éditeur](/fr/editor/index) sur votre ordinateur. Travaillez dans des onglets ou plusieurs fenêtres avec accès au même contenu et aux mêmes paramètres que dans le navigateur.

L'application de bureau met à jour le contenu de la même manière que l'éditeur. Elle n'ouvre ni ne modifie de fichiers sur votre ordinateur. Pour travailler sur des fichiers locaux, utilisez la [CLI](/fr/cli/index).

<div id="install">
  ## Installation
</div>

<Tabs>
  <Tab title="macOS">
    Nécessite macOS 14 ou une version ultérieure sur Apple silicon.

    1. Téléchargez l'application de bureau depuis [mintlify.com/desktop](https://mintlify.com/desktop).
    2. Ouvrez le fichier.
    3. Faites glisser **Mintlify** dans votre dossier **Applications**.

    Vous pouvez aussi l'installer depuis le terminal.

    ```bash Install the desktop app
    curl -fsSL https://desktop.mintlify.com/install.sh | bash
    ```

    Le script installe l'application dans `/Applications`, ou dans `~/Applications` si vous ne pouvez pas écrire dans `/Applications`.
  </Tab>
  <Tab title="Windows">
    Nécessite Windows 10 ou une version ultérieure, 64 bits.

    1. Téléchargez l'application de bureau depuis [mintlify.com/desktop](https://mintlify.com/desktop).
    2. Exécutez le programme d'installation.

  </Tab>
  <Tab title="Linux">
    Nécessite une machine x86_64. L'application de bureau est disponible sous forme d'AppImage et de paquet `.deb`.

    Téléchargez l'un ou l'autre fichier depuis [mintlify.com/desktop](https://mintlify.com/desktop) ou installez l'AppImage depuis le terminal.

    ```bash Install the desktop app
    curl -fsSL https://desktop.mintlify.com/install.sh | bash
    ```

    Le script installe l'application dans `~/.local/share/mintlify-desktop`, ajoute une commande `mintlify-desktop` dans `~/.local/bin` et ajoute Mintlify au menu des applications.

    Les AppImages nécessitent FUSE 2. Si l'application de bureau ne démarre pas, installez FUSE 2. Sur Ubuntu :

    ```bash Install FUSE 2
    sudo apt install libfuse2
    ```
  </Tab>
</Tabs>

<div id="sign-in">
  ## Connexion
</div>

L'application de bureau vous connecte avec le compte Mintlify que vous utilisez déjà dans votre navigateur par défaut.

1. Ouvrez l'application de bureau. L'application affiche un écran **Log in to Mintlify**.
2. Cliquez sur **Continue in browser**. Votre navigateur par défaut ouvre une page de consentement Mintlify qui affiche votre compte et votre organisation.
3. Cliquez sur **Approve**. Pour vous connecter à une autre organisation, cliquez d'abord sur **Use a different organization**.
4. Revenez à l'application de bureau. L'application vous connecte.

L'application de bureau et votre navigateur partagent la même session. Vous déconnecter de l'un vous déconnecte de l'autre.

<div id="sign-in-without-your-browser">
  ### Se connecter sans le navigateur
</div>

La connexion via le navigateur n'est pas disponible pour certaines organisations, comme celles qui définissent une [durée de session maximale](/fr/dashboard/session-security#maximum-session-lifetime). Si la page de consentement indique que la connexion de bureau n'est pas disponible, connectez-vous dans l'application :

1. Sur l'écran **Log in to Mintlify**, cliquez sur **Log in here instead**.
2. Connectez-vous de la même manière que vous vous connectez à votre Dashboard dans le navigateur.

<div id="tabs-and-windows">
  ## Onglets et fenêtres
</div>

Ouvrez chaque page sur laquelle vous travaillez dans son propre onglet ou sa propre fenêtre. Les onglets et fenêtres se rouvrent là où vous les avez laissés lorsque vous redémarrez l'application.

Faites un clic droit sur un onglet pour le dupliquer, copier son lien ou fermer les autres onglets. Faites un clic du milieu sur un onglet pour le fermer.

Pour afficher les onglets dans une barre latérale plutôt qu'en haut de la fenêtre, modifiez la disposition des onglets dans les [Paramètres](#settings).

<div id="each-tab-has-its-own-session">
  ### Chaque onglet a sa propre session
</div>

Un nouvel onglet s'ouvre connecté au même compte et à la même organisation que l'onglet à partir duquel vous l'avez ouvert. Ensuite, chaque onglet conserve sa propre session :

- Changer d'organisation dans un onglet ne modifie pas vos autres onglets. Vous pouvez donc travailler dans différentes organisations côte à côte.
- Se déconnecter ou se connecter à un autre compte n'affecte que cet onglet.

Pour vous déconnecter partout, utilisez **Clear all data** dans les [Paramètres](#settings).

<div id="links-to-other-sites">
  ### Liens vers d'autres sites
</div>

Les onglets chargent uniquement le Dashboard Mintlify et les services qu'il utilise pour la connexion, l'accès aux crédits des fonctionnalités d'IA et la connexion des fournisseurs Git. Les liens vers tout autre site s'ouvrent dans votre navigateur par défaut.

<div id="keyboard-shortcuts">
  ## Raccourcis clavier
</div>

Sur Windows et Linux, utilisez <kbd>Ctrl</kbd> au lieu de <kbd>Cmd</kbd>.

| Action | Raccourci |
| :--- | :--- |
| Nouvel onglet | <kbd>Cmd</kbd> + <kbd>T</kbd> |
| Nouvelle fenêtre | <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>N</kbd> |
| Fermer l'onglet | <kbd>Cmd</kbd> + <kbd>W</kbd> |
| Fermer la fenêtre | <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>W</kbd> |
| Aller à l'onglet 1-9 | <kbd>Cmd</kbd> + <kbd>1</kbd>-<kbd>9</kbd> |
| Onglet suivant | <kbd>Ctrl</kbd> + <kbd>Tab</kbd> |
| Onglet précédent | <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>Tab</kbd> |
| Précédent | <kbd>Cmd</kbd> + <kbd>[</kbd> |
| Suivant | <kbd>Cmd</kbd> + <kbd>]</kbd> |
| Recharger | <kbd>Cmd</kbd> + <kbd>R</kbd> |
| Rechercher dans la page | <kbd>Cmd</kbd> + <kbd>F</kbd> |
| Rechercher le suivant | <kbd>Cmd</kbd> + <kbd>G</kbd> |
| Rechercher le précédent | <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>G</kbd> |
| Copier l'URL de la page | <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>C</kbd> |
| Ouvrir les paramètres | <kbd>Cmd</kbd> + <kbd>,</kbd> |

Rechercher dans la page ouvre une barre de recherche en haut à droite de la page. Appuyez sur <kbd>Enter</kbd> pour passer au résultat suivant, sur <kbd>Shift</kbd> + <kbd>Enter</kbd> pour revenir au précédent et sur <kbd>Esc</kbd> pour la fermer. Si une page possède sa propre recherche pour <kbd>Cmd</kbd> + <kbd>F</kbd>, c'est cette recherche qui s'ouvre.

Pour les raccourcis dans l'éditeur, consultez [Raccourcis clavier](/fr/editor/keyboard-shortcuts).

<div id="settings">
  ## Paramètres
</div>

Ouvrez les paramètres avec <kbd>Cmd</kbd> + <kbd>,</kbd> sur macOS ou <kbd>Ctrl</kbd> + <kbd>,</kbd> sur Windows et Linux.

- **Tab layout** : Affichez les onglets en haut de la fenêtre (**Horizontal**) ou dans une barre latérale (**Vertical**).
- **Check for updates** : Vérifiez si une nouvelle version de l'application est disponible. Consultez [Mises à jour](#updates).
- **Clear all data** : Déconnectez-vous de tous les onglets, fermez tous les onglets et réinitialisez les paramètres. L'application redémarre.

La fenêtre des paramètres affiche également la version de l'application.

<div id="updates">
  ## Mises à jour
</div>

L'application recherche des mises à jour au démarrage, puis toutes les quatre heures pendant son exécution. Lorsqu'une mise à jour est disponible, un bouton **Update** apparaît dans la barre d'onglets.

Pour rechercher manuellement une mise à jour, cliquez sur **Check for updates** dans les [Paramètres](#settings). Vous pouvez aussi sélectionner **Check for Updates…** dans le menu de l'application. Sur macOS, cette option se trouve sous **About Mintlify** dans le menu **Mintlify**. Sur Windows et Linux, elle se trouve en bas du menu **File**. Une boîte de dialogue indique si une mise à jour est disponible et vous permet de l'installer.

- **macOS** : Cliquez sur **Update** pour télécharger et installer la mise à jour dans l'application.
- **Windows et Linux** : Cliquez sur **Update** pour télécharger la nouvelle version depuis votre navigateur, puis installez-la.

<div id="uninstall">
  ## Désinstallation
</div>

<Tabs>
  <Tab title="macOS">
    1. Quittez l'application de bureau.
    2. Déplacez **Mintlify** de votre dossier **Applications** vers la Corbeille.
    3. Pour supprimer votre connexion et vos paramètres, supprimez `~/Library/Application Support/Mintlify Electron`.
  </Tab>
  <Tab title="Windows">
    1. Ouvrez **Settings** > **Apps** > **Installed apps**.
    2. Recherchez **Mintlify** et sélectionnez **Uninstall**.
    3. Pour supprimer votre connexion et vos paramètres, supprimez `%APPDATA%\Mintlify Electron`.
  </Tab>
  <Tab title="Linux">
    Si vous avez installé l'application de bureau avec le script, supprimez les fichiers qu'il a créés :

    ```bash Remove the desktop app
    rm -rf ~/.local/share/mintlify-desktop \
      ~/.local/bin/mintlify-desktop \
      ~/.local/share/applications/mintlify-desktop.desktop \
      ~/.local/share/icons/hicolor/512x512/apps/mintlify-desktop.png
    ```

    Si vous avez installé le paquet `.deb`, supprimez-le avec votre gestionnaire de paquets.

    Pour supprimer votre connexion et vos paramètres, supprimez `~/.config/Mintlify Electron`.
  </Tab>
</Tabs>
