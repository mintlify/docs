<div id="workspace-and-site">

## Workspace et Site

</div>

La barre latérale de l'éditeur est divisée en deux onglets : **Workspace** et **Site**.

**Workspace** affiche le contenu qui ne fait pas partie de votre site publié. Il contient vos brouillons **Personal** et les pages que d'autres ont partagées dans **Shared with me**.

**Site** affiche les pages que voient vos visiteurs. **Navigation** est la structure ordonnée définie par `docs.json`. **Hidden files** liste les fichiers du dépôt dont les pages ne figurent pas dans votre navigation.

Le changement d'onglet rouvre la dernière page que vous avez consultée dans cet onglet. **Share** n'apparaît dans la barre supérieure que sur **Workspace**. **Preview**, la liste déroulante des branches et **Publish** n'apparaissent que sur **Site**.

Hidden files masque certains fichiers par défaut, notamment `docs.json`, les fichiers et dossiers dont le nom commence par un point, les fichiers sans extension, les fichiers Markdown en majuscules comme `README.md`, ainsi que les fichiers `.css`, `.js`, `.jsx`, `.mjs`, `.cjs` et `.pdf`. Pour afficher tous les fichiers, activez [Show all files](/fr/editor/settings#appearance) ou appuyez sur <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>.</kbd> (macOS) ou <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>.</kbd> (Windows).

<div id="add-and-remove-pages-from-your-navigation">

## Ajouter et retirer des pages de votre navigation

</div>

Faites glisser une page depuis **Hidden files** dans **Navigation** pour l'ajouter à cette position. Faites glisser un dossier pour l'ajouter en tant que group. Vous pouvez faire glisser une sélection multi-lignes et tous les éléments sélectionnés se déplacent dans l'ordre du document.

Faites glisser une page ou un group depuis **Navigation** dans **Hidden files** pour la retirer de votre navigation sans supprimer le fichier. Vous pouvez aussi ouvrir le menu d'options de la page dans l'arborescence de navigation et sélectionner **Move to hidden files**. Une invite d'annulation apparaît après le déplacement.

Pour promouvoir une page privée sur votre site, ouvrez son menu d'options et sélectionnez **Move to site**, ou faites-la glisser depuis **Personal** dans **Navigation**. La barre latérale bascule sur **Site** et met en surbrillance la nouvelle ligne. Promouvoir une page privée est un changement irréversible.

<div id="create-a-page">

## Créer une page

</div>

Pour ajouter une page à votre navigation, cliquez sur le bouton <Icon icon="plus" /> plus sur l'élément de navigation où vous la souhaitez. Saisissez un nom pour votre page. L'éditeur ajoute l'extension `.mdx` à votre place.

<div id="add-media">

## Ajouter des médias

</div>

Saisissez <kbd>/image</kbd> ou <kbd>/video</kbd> pour téléverser un fichier ou en choisir un déjà présent dans votre dépôt. Vous pouvez aussi faire glisser des fichiers depuis votre ordinateur sur la page. Pour réutiliser un média, faites glisser une image ou une vidéo depuis l'arborescence de navigation sur une page.

- Les fichiers téléversés sont enregistrés dans vos dossiers `images/` et `videos/` et sont inclus dans le commit de votre prochaine publication.
- Les formats pris en charge sont PNG, JPG, JPEG, GIF, WebP, SVG, MP4 et WebM.
- Pour afficher des images différentes en mode clair et en mode sombre, survolez une image insérée et utilisez **Light/dark variants**.
- Saisissez <kbd>/embed</kbd> et collez une URL YouTube, Loom ou Vimeo pour générer l'iframe. Pour tout autre cas, activez **Manual embed** afin d'écrire du HTML personnalisé.

Pour la mise en forme des images et l'utilisation du composant Frame, consultez [Images et intégrations](/fr/create/image-embeds).

<div id="organize-navigation">

## Organiser la navigation

</div>

Faites glisser des éléments dans la vue Navigation pour les réordonner ou les imbriquer. L'éditeur écrit vos modifications dans `docs.json` lorsque vous publiez. Pour connaître le rôle de chaque élément de navigation, notamment les groups, tabs, anchors, dropdowns, menus, products, versions et languages, consultez [Navigation](/fr/organize/navigation).

<Note>
  Certains éléments ne peuvent pas être imbriqués dans d'autres. Par exemple, les tabs ne peuvent pas être imbriqués dans des groups. L'éditeur empêche les combinaisons non valides.
</Note>

Pour modifier le titre, le slug, la description ou le layout d'une page, ouvrez ses paramètres depuis l'arborescence de navigation. Consultez [Pages](/fr/organize/pages) pour plus d'informations sur chaque paramètre.

<div id="move-a-page">

## Déplacer une page

</div>

Pour déplacer une page vers un autre dossier, ouvrez son menu d'options et sélectionnez **Move to**. Un sélecteur de dossiers s'ouvre à côté du menu, affichant les dossiers de votre workspace dans le même ordre que l'arborescence de navigation.

Vous pouvez ouvrir le menu d'options depuis :

- <Icon icon="ellipsis" /> **More options** en haut à droite d'une page ouverte.
- Le menu <Icon icon="ellipsis" /> à côté d'une page dans l'arborescence de navigation.
- Un clic droit sur une page dans l'arborescence de navigation.
- <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>P</kbd> (macOS) ou <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>P</kbd> (Windows) avec la page ouverte.

Dans le sélecteur, recherchez pour filtrer les dossiers, développez les dossiers pour voir les destinations imbriquées, puis sélectionnez un dossier pour déplacer la page. Le dossier actuel est atténué et ne peut pas être sélectionné.

Déplacer une page du site met à jour son chemin de fichier et sa position dans la navigation. Déplacer une page privée la réattache dans votre section **Personal**. Les editors et les admins peuvent déplacer les pages du site. Vous pouvez déplacer les pages privées dont vous êtes propriétaire.

<div id="delete-a-page">

## Supprimer une page

</div>

Pour supprimer une page, cliquez sur <Icon icon="ellipsis" /> **More options** en haut à droite de la page, puis sur **Move to trash**. Vous pouvez aussi supprimer une page depuis son menu d'options dans l'arborescence de navigation.

La suppression d'une page supprime à la fois le fichier et son entrée de navigation. Malgré le libellé **Move to trash**, il n'existe pas de vue corbeille permettant de restaurer des pages. Si vous supprimez une page par erreur, utilisez l'invite d'annulation qui apparaît après la suppression. La suppression est commitée dans votre dépôt lorsque vous publiez : après la publication, vous ne pouvez restaurer la page qu'à partir de l'historique de votre dépôt.

Pour retirer une page de votre navigation publiée sans supprimer son fichier, sélectionnez **Move to hidden files** dans le menu d'options de la page.

Les viewers ne peuvent pas supprimer de pages. Pour les pages privées, le menu affiche **Delete page** à la place, et la suppression est immédiate car les pages privées ne sont pas commitées dans votre dépôt.

<div id="version-history">

## Historique des versions

</div>

L'historique des versions vous permet de consulter et de restaurer des versions enregistrées antérieures d'une page. Il n'est pas disponible pour `docs.json`.

Les viewers peuvent consulter et comparer les versions enregistrées des pages privées. Les editors et les admins peuvent les restaurer.

L'éditeur enregistre une nouvelle entrée dès que le contenu diffère de la dernière version enregistrée. L'historique des versions est limité à la branch. Seul l'historique de la branch actuelle est disponible.

Pour consulter l'historique des versions, cliquez sur <Icon icon="ellipsis" /> **More options** en haut à droite de la page, puis sur **Version history**.

Si vous restaurez une version, cela écrase les modifications non enregistrées que vous avez faites sur la page. Lorsque vous restaurez une page publique, elle n'est restaurée que sur votre branch actuelle. Lorsque vous restaurez une page privée, elle est restaurée sur toutes les branches.

<div id="private-pages">

## Pages privées

</div>

Les pages privées sont des brouillons qui se trouvent dans la section **Personal** de l'onglet **Workspace**. Elles vous sont privées, ne sont pas commitées dans votre dépôt et n'apparaissent jamais sur votre site publié.

Pour créer une page ou un dossier privé, cliquez sur le bouton <Icon icon="plus" /> plus sur l'en-tête de la section **Personal**, puis sélectionnez **New page** ou **New folder**. Le bouton **New page** en bas de l'onglet **Workspace** crée également une page privée.

Pour promouvoir une page privée sur votre site, ouvrez son menu d'options et sélectionnez **Move to site**, ou faites-la glisser dans **Navigation** sur l'onglet **Site**.

<Warning>
  Vous ne pouvez pas ramener une page vers la section **Personal** après l'avoir promue. Rendre publique une page privée est un changement irréversible.
</Warning>
