<div id="home-and-publishing">

## Home et Publishing

</div>

L'espace de travail de l'éditeur est divisé en deux onglets : **Home** et **Publishing**.

**Home** est votre espace de travail. Il affiche les fichiers de contenu de votre dépôt, y compris vos pages privées, qu'elles apparaissent ou non sur votre site publié.

**Publishing** est votre site publié. Il affiche la navigation que voient vos visiteurs, ainsi que les paramètres de votre site.

Home masque certains fichiers par défaut, notamment `docs.json`, les fichiers et dossiers dont le nom commence par un point, les fichiers sans extension, les fichiers Markdown en majuscules comme `README.md`, ainsi que les fichiers `.css`, `.js`, `.jsx`, `.mjs`, `.cjs` et `.pdf`. Pour afficher tous les fichiers, activez [Show all files](/fr/editor/settings#appearance) ou appuyez sur <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>.</kbd> (macOS) ou <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>.</kbd> (Windows).

<div id="create-a-page">

## Créer une page

</div>

Pour ajouter une page à votre navigation, cliquez sur le bouton <Icon icon="plus" /> plus sur l'élément de navigation où vous la souhaitez. Saisissez un nom pour votre page. L'éditeur ajoute l'extension `.mdx` à votre place.

<div id="add-media">

## Ajouter des médias

</div>

Saisissez <kbd>/image</kbd> ou <kbd>/video</kbd> pour téléverser un fichier ou en choisir un déjà présent dans votre dépôt. Vous pouvez aussi faire glisser des fichiers depuis votre ordinateur sur la page. Pour réutiliser un média, faites glisser une image ou une vidéo depuis l'arborescence de navigation sur une page.

- Les fichiers téléversés sont enregistrés dans vos dossiers `images/` et `videos/` et sont inclus dans le commit de votre prochaine publication.
- Les formats pris en charge sont PNG, JPG, JPEG, GIF, WebP, SVG, MP4 et WebM.
- Pour afficher des images différentes en mode clair et en mode sombre, survolez une image insérée et utilisez **Light/dark variants**.
- Saisissez <kbd>/embed</kbd> et collez une URL YouTube, Loom ou Vimeo pour générer l'iframe. Pour tout autre cas, activez **Manual embed** afin d'écrire du HTML personnalisé.

Pour la mise en forme des images et l'utilisation du composant Frame, consultez [Images et intégrations](/fr/create/image-embeds).

<div id="organize-navigation">

## Organiser la navigation

</div>

Faites glisser des éléments dans la vue Navigation pour les réordonner ou les imbriquer. L'éditeur écrit vos modifications dans `docs.json` lorsque vous publiez.

- **Groups** : Sections repliables qui regroupent des pages liées. Peuvent être imbriquées dans d'autres groups.
- **Tabs** : Sections de premier niveau avec une navigation horizontale. Utilisez-les pour des espaces distincts, comme une référence d'API et des guides.
- **Anchors** : Éléments persistants en haut de votre barre latérale. Utiles pour des ressources externes. Peuvent être globaux et apparaître sur toutes les pages.
- **Dropdowns** : Menus déroulants en haut de votre barre latérale. Une alternative plus légère aux tabs.
- **Menus** : Éléments déroulants au sein d'un tab qui renvoient directement vers des pages précises.
- **Products** : Un sélecteur pour plusieurs ensembles de documentation produit, chacun avec sa propre navigation.
- **Versions** : Un sélecteur pour plusieurs versions simultanées de la documentation.
- **Languages** : Un sélecteur pour de la documentation en plusieurs langues.

<Note>
  Certains éléments ne peuvent pas être imbriqués dans d'autres. Par exemple, les tabs ne peuvent pas être imbriqués dans des groups. L'éditeur empêche les combinaisons non valides.
</Note>

Pour modifier le titre, le slug, la description ou le layout d'une page, ouvrez ses paramètres depuis l'arborescence de navigation. Consultez [Pages](/fr/organize/pages) pour plus d'informations sur chaque paramètre.

<div id="version-history">

## Historique des versions

</div>

L'historique des versions vous permet de consulter et de restaurer des versions enregistrées antérieures d'une page. Il n'est pas disponible pour `docs.json`.

Les viewers peuvent consulter et comparer les versions enregistrées des pages privées. Les editors et les admins peuvent les restaurer.

L'éditeur enregistre une nouvelle entrée dès que le contenu diffère de la dernière version enregistrée. L'historique des versions est limité à la branch. Seul l'historique de la branch actuelle est disponible.

Pour consulter l'historique des versions, cliquez sur <Icon icon="ellipsis" /> **More options** en haut à droite de la page, puis sur **Version history**.

Si vous restaurez une version, cela écrase les modifications non enregistrées que vous avez faites sur la page. Lorsque vous restaurez une page publique, elle n'est restaurée que sur votre branch actuelle. Lorsque vous restaurez une page privée, elle est restaurée sur toutes les branches.

<div id="private-pages">

## Pages privées

</div>

Les pages privées sont des brouillons qui se trouvent dans la section **Personal** de l'onglet **Home**. Elles vous sont privées, ne sont pas commitées dans votre dépôt et n'apparaissent jamais sur votre site publié.

Pour créer une page ou un dossier privé, cliquez sur le bouton <Icon icon="plus" /> plus sur l'en-tête de la section **Personal**, puis sélectionnez **New page** ou **New folder**.

Faire glisser une page ou un dossier privé dans votre workspace le met immédiatement à la disposition de vos collaborateurs, sans pour autant l'ajouter à la navigation de votre site.

<Warning>
  Vous ne pouvez pas ramener du contenu du workspace vers la section **Personal**. Rendre publique une page privée est un changement irréversible.
</Warning>
