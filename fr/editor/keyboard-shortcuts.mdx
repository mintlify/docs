Utilisez les raccourcis clavier pour naviguer et travailler plus vite dans l'éditeur web. L'éditeur prend en charge les raccourcis courants comme copier, coller, annuler et tout sélectionner, ainsi que les raccourcis listés ci-dessous.

<div id="editor-wide">

## Dans tout l'éditeur

</div>

Ces raccourcis fonctionnent quel que soit le mode dans lequel vous vous trouvez.

| Commande | macOS | Windows |
| :--- | :--- | :--- |
| **Rechercher des fichiers et du contenu** | <kbd>Cmd</kbd> + <kbd>K</kbd> | <kbd>Ctrl</kbd> + <kbd>K</kbd> |
| **Afficher ou masquer l'assistant d'IA** (hors saisie de texte) | <kbd>Cmd</kbd> + <kbd>I</kbd> | <kbd>Ctrl</kbd> + <kbd>I</kbd> |
| **Basculer entre le mode visuel et le mode source** | <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>S</kbd> | <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>S</kbd> |
| **Afficher tous les fichiers** (y compris les dotfiles et les fichiers hors contenu) | <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>.</kbd> | <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>.</kbd> |

<div id="smart-substitutions">

### Substitutions intelligentes

</div>

L'éditeur convertit automatiquement certaines suites de caractères en symboles typographiques pendant que vous écrivez. Il ignore ces substitutions dans les blocs de code et le code en ligne.

| Saisissez | Résultat |
| :--- | :--- |
| `->` | → |
| `<-` | ← |
| `=>` | ⇒ |
| `<=` | ≤ |
| `>=` | ≥ |
| `!=` | ≠ |
