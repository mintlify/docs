Le serveur MCP Mintlify Index donne aux outils d’IA un accès en lecture seule à la documentation technique et au contexte web. Connectez-vous à l’adresse suivante :

```text
https://index.mintlify.com
```

Vous n’avez pas besoin de vous authentifier auprès du serveur public. Consultez [Connexion](/fr/search-index/connect) pour les instructions de configuration de Claude Code et Cursor.

<Note>
  Index recherche dans la documentation des produits couverts et sur le web technique. Pour rechercher uniquement le contenu d’un site spécifique hébergé sur Mintlify, utilisez le [serveur MCP de recherche](/fr/ai/model-context-protocol) de ce site.
</Note>

<div id="context-tool">
  ## Outil `context`
</div>

Utilisez `context` pour étudier une tâche d’implémentation et renvoyer en un appel un contexte concis avec des sources citées. L’outil est en lecture seule et peut accéder au web ouvert.

<ParamField body="query" type="string" required>
  Question d’implémentation à étudier.
</ParamField>

<ParamField body="product" type="string">
  Nom du produit ou de l’entreprise à utiliser comme indication supplémentaire pour la récupération.
</ParamField>

<ParamField body="includeDomains" type="string[]">
  Domaines à inclure dans la récupération. Lorsque ce champ est défini, la récupération limite les résultats à ces domaines.
</ParamField>

<ParamField body="excludeDomains" type="string[]">
  Domaines à exclure de la récupération.
</ParamField>

<ParamField body="tokenBudget" type="integer" default="3000">
  Nombre maximal de tokens à renvoyer. La valeur maximale est `6000`. Utilisez la valeur par défaut pour les questions ciblées et une limite plus élevée pour les tâches complexes comportant plusieurs parties.
</ParamField>

<div id="output">
  ### Sortie
</div>

L’outil renvoie un contexte au format Markdown assemblé à partir de sources classées par pertinence. Chaque section comprend un titre, une URL source et le contenu pertinent de la source.

```text
### Configurer la mise en cache

Source : https://nextjs.org/docs/app/getting-started/caching-and-revalidating

Le contenu pertinent de la source apparaît ici.

--------------------------------
```

Le serveur MCP renvoie les sources que l’agent connecté doit utiliser. L’agent décide comment appliquer ce contexte à votre tâche.

<div id="rate-limits">
  ## Limites de débit
</div>

Index applique les limites suivantes, par adresse IP, au serveur MCP public :

| Fenêtre | Limite |
| --- | ---: |
| Par seconde | 10 requêtes |
| Par jour | 1 000 requêtes |

Les requêtes qui dépassent l’une ou l’autre limite renvoient `429 Too Many Requests`. Attendez avant de réessayer et utilisez un délai de reprise exponentiel pour les clients automatisés.

<div id="protocol-behavior">
  ## Comportement du protocole
</div>

Le MCP Index utilise le protocole Streamable HTTP sans état :

- Envoyez chaque requête JSON-RPC avec une requête HTTP `POST`.
- Envoyez une seule requête JSON-RPC par requête HTTP. Les traitements par lots ne sont pas pris en charge.
- Ne conservez pas et n’envoyez pas d’identifiant de session MCP entre les requêtes.
