Mintlify Index fournit aux agents de programmation une couche de recherche unique pour les connaissances techniques. Il achemine les questions sur les produits indexés vers la documentation gérée par les éditeurs et hébergée sur Mintlify, et utilise la recherche web pour les questions qui ne concernent pas ce corpus.

Utilisez Index via le serveur MCP public ou l’API REST à accès contrôlé.

- **Serveur MCP** : connectez un outil d’IA afin qu’il récupère du contexte avec des sources citées pendant votre travail. Accessible au public. Aucune clé API n’est requise.
- **API REST** : recherchez des sources classées par pertinence, assemblez un contexte dans une limite de tokens ou récupérez le contenu des résultats sélectionnés. Accès contrôlé. Une clé API Index est requise.

<div id="how-index-retrieves-context">
  ## Comment Index récupère le contexte
</div>

<Steps>
  <Step title="Acheminer la question">
    Index détermine si la question concerne un produit de son corpus documentaire ou si elle nécessite des résultats web plus larges.
  </Step>
  <Step title="Récupérer les sources pertinentes">
    Les questions spécifiques à un produit recherchent dans la documentation actuelle de l’éditeur. Les autres questions recherchent sur le web.
  </Step>
  <Step title="Renvoyer un contexte prêt pour l’agent">
    Index classe les résultats et renvoie les URL des sources avec le contenu pertinent. L’outil MCP `context` et l’endpoint REST `context` assemblent ce contenu dans une limite de tokens.
  </Step>
</Steps>

<div id="choose-a-retrieval-operation">
  ## Choisir une opération de récupération
</div>

- **[`context`](/fr/api/search-index/context)** : utilisez cette opération pour la plupart des tâches d’agent. Elle renvoie en une requête un ensemble concis de sources citées.
- **[`search`](/fr/api/search-index/search)** : utilisez cette opération lorsque votre application a besoin de résultats classés par pertinence et contrôle les sources à lire. Disponible via l’API REST.
- **[`contents`](/fr/api/search-index/contents)** : utilisez cette opération après `search` pour récupérer le contenu correspondant à des ID de résultats Mintlify ou à des URL de résultats sélectionnés. Disponible via l’API REST.
