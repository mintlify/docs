<Note>
  Si le propriétaire de votre espace de travail Slack exige l'approbation d'un administrateur pour installer des applications, demandez-lui d'approuver l'application Mintlify avant de la connecter.
</Note>

Utilisez l'agent dans Slack pour mettre à jour votre contenu, poser des questions et capturer les connaissances de l'équipe. Mentionnez `@mintlify` dans un canal pour l'utiliser de manière collaborative, ou envoyez-lui un message dans son onglet **Chat** pour l'utiliser en privé. Dans un canal, l'agent répond dans un fil.

L'agent Slack fonctionne avec [Autopilot](/fr/autopilot). Lorsque Autopilot publie dans un fil Slack, mentionnez `@mintlify` dans ce fil pour poursuivre la même conversation avec lui. Vous pouvez aussi interroger l'agent sur le travail d'Autopilot ou lui demander de modifier ce sur quoi Autopilot travaille, comme dans un [chat avec Autopilot](/fr/autopilot#chat-with-autopilot).

<Tip>
  L'application Slack et les intégrations tierces fonctionnent ensemble. Installez l'application Slack pour discuter avec l'agent et donner à l'agent et aux exécutions d'automatisations accès au contenu Slack autorisé. Connectez ensuite des [intégrations](/fr/automations/integrations) afin que l'agent puisse aussi utiliser le contexte d'applications comme Notion, Jira, Linear ou Google Drive.
</Tip>

<div id="connect-your-slack-workspace">
  ## Connecter votre espace de travail Slack
</div>

<Note>
  Chaque espace de travail Slack ne peut être connecté qu'à une seule organisation Mintlify à la fois. Si vous tentez d'installer l'agent dans un espace de travail déjà connecté à une autre organisation, l'installation échoue avec une erreur « wrong organization ». Désinstallez d'abord l'application de l'autre organisation, ou utilisez un autre espace de travail Slack.

  Vous pouvez installer l'agent Slack même si vous n'avez pas de projet hébergé par Mintlify. L'agent fonctionne toujours pour répondre aux questions et tenir des conversations. Les fonctionnalités qui ouvrent des pull requests nécessitent un dépôt connecté.
</Note>

1. Ouvrez les paramètres [Automatisations](https://app.mintlify.com/settings/project/automations).
2. Cliquez sur **Connect Slack**.
3. Suivez les instructions Slack pour installer l'application `mintlify` dans votre espace de travail et accorder les autorisations demandées.
4. Confirmez dans votre dashboard Mintlify la connexion à votre espace de travail Slack.
5. Vérifiez que l'agent fonctionne et répond lorsque vous :
   - Lui envoyez un message dans son onglet **Chat**.
   - Mentionnez l'agent avec `@mintlify` dans un canal.

<Warning>
  Sur Slack Enterprise Grid, vous devez installer l'application dans l'espace de travail spécifique où vous souhaitez utiliser l'agent. Si vous omettez cette étape, l'agent apparaît comme disponible au niveau de l'organisation, mais ne répond pas dans votre espace de travail.

  Pour ajouter l'application à un espace de travail, ouvrez la page de gestion des applications de votre organisation (une URL telle que `https://app.slack.com/manage/<your-org-id>/integrations/installed`). Trouvez l'application `mintlify` et installez-la dans votre espace de travail.
</Warning>

<Note>
  L'agent Slack n'est pas disponible pour les projets [Bitbucket Cloud](/fr/deploy/bitbucket).

  Si votre fournisseur Git se trouve derrière une liste d'IP autorisées, autorisez l'IP de sortie Mintlify `54.242.90.151` afin que l'agent puisse cloner votre dépôt. Contactez le support pour activer cette option.
</Note>

<div id="disconnect-the-agent">
  ### Déconnecter l'agent
</div>

Pour supprimer l'agent de votre espace de travail Slack :

1. Ouvrez les paramètres [Automatisations](https://app.mintlify.com/settings/project/automations).
2. Cliquez sur **Configure Slack**.
3. Cliquez sur **Disconnect** pour révoquer la connexion entre Mintlify et votre espace de travail.
4. Dans Slack, accédez à **Manage apps**.
5. Cliquez sur **Remove** pour l'application Mintlify.

Lorsque vous déconnectez l'application Slack, l'agent cesse de répondre aux mentions et aux messages directs, et les automatisations qui publient dans Slack cessent de délivrer des notifications.

<div id="reconnect-or-reinstall-the-agent">
  ### Reconnecter ou réinstaller l'agent
</div>

Pour réautoriser l'agent, réinstallez l'application depuis votre dashboard Mintlify. Réautorisez-le lorsque vous devez accorder de nouvelles autorisations après une mise à jour des scopes Slack ou lorsque vous devez récupérer après la révocation d'un jeton.

Lorsque vous réinstallez l'agent dans un espace de travail déjà connecté à votre organisation, Mintlify met à jour sur place le bot token stocké. Vos canaux et fils de discussion existants restent intacts.

<Tip>
Si votre organisation dispose de plusieurs projets, l'agent démarre les nouvelles conversations dans le projet que vous avez utilisé le plus récemment dans Slack. Votre projet préféré est propre à votre compte Slack et n'affecte pas les autres membres de l'équipe.

Si votre demande concerne clairement un autre projet, l'agent bascule automatiquement. Il publie dans le fil un message indiquant le projet vers lequel il bascule, puis relance votre demande dans ce projet.
</Tip>

<div id="use-the-agent-in-slack">
  ## Utiliser l'agent dans Slack
</div>

Une fois connecté, vous pouvez :

- Mentionner `@mintlify` dans un canal pour l'utiliser publiquement et de manière collaborative.
- Envoyer un message à l'agent dans son onglet **Chat** pour l'utiliser en privé.
- Joindre des fichiers et des images directement à vos messages pour que l'agent les traite et les intègre à votre documentation.
- Poursuivre les conversations pour affiner les modifications ou poser des questions de suivi. Dans un fil de canal, mentionnez de nouveau `@mintlify` et l'agent reprend là où il s'était arrêté. Il lit comme contexte les messages publiés par vos coéquipiers dans le fil depuis sa dernière réponse. Dans l'onglet **Chat**, répondez dans la même conversation.
- Partager des liens de pull request avec l'agent pour mettre à jour la documentation associée.

<div id="ask-questions-about-your-docs">
  ## Poser des questions sur votre documentation
</div>

Posez à l'agent des questions sur votre produit ou votre documentation et recevez les réponses dans le fil.

- **Nouvelle question** : Mentionnez `@mintlify` dans un canal avec votre question, ou démarrez une nouvelle conversation dans l'onglet **Chat** de l'agent.
- **Fil existant** : Répondez dans le fil et mentionnez `@mintlify` avec une question de suivi. Dans l'onglet **Chat**, répondez dans la même conversation.

{/* vale Mintlify.FirstPerson = NO */}
Exemples de questions :
- « Quelles pages mentionnent la limite de débit de l'API ? »
- « Comment configurer l'authentification ? »
- « Comment est structurée notre navigation ? »
{/* vale Mintlify.FirstPerson = YES */}

<div id="use-connected-integrations">
  ## Utiliser les intégrations connectées
</div>

<Info>
  Les intégrations nécessitent un [forfait Enterprise](https://mintlify.com/pricing?ref=automations).
</Info>

L'agent Slack peut utiliser les applications tierces connectées comme outils en lecture seule lorsqu'il répond aux questions ou met à jour votre documentation.

- Les **intégrations partagées** sont disponibles pour toute votre organisation.
- Les **intégrations personnelles** utilisent le compte connecté par le coéquipier qui discute avec l'agent. Par exemple, une recherche Google Drive utilise la connexion Drive de ce coéquipier.

Vous n'avez pas à sélectionner les intégrations pour chaque conversation Slack. Demandez naturellement à l'agent d'utiliser une application connectée dans votre requête, par exemple :

- « Compare ce ticket Linear avec le plan de lancement dans le Google Drive connecté. »
- « Mets à jour le guide de migration en fonction du dernier ticket Jira. »
- « Que dit notre brief de lancement Notion sur la disponibilité ? »

Demandez à l'agent de connecter les intégrations que vous souhaitez utiliser. Suivez le lien d'autorisation qu'il renvoie, puis envoyez un autre message dans le même fil afin que l'agent puisse confirmer la connexion.

Consultez [Intégrations](/fr/automations/integrations) pour les applications prises en charge, les portées de connexion et les autorisations.

<div id="update-documentation">
  ## Mettre à jour la documentation
</div>

Utilisez l'agent pour mettre à jour votre documentation au moyen d'une nouvelle demande ou dans un fil existant.

- **Nouvelle demande** : Mentionnez `@mintlify` dans un canal avec des instructions sur ce qu'il faut mettre à jour, ou démarrez une nouvelle conversation dans l'onglet **Chat** de l'agent.
- **Fil existant** : Répondez dans le fil et mentionnez `@mintlify` avec des instructions sur ce qu'il faut mettre à jour. Dans l'onglet **Chat**, répondez dans la même conversation.
- **Avec des pièces jointes** : Téléversez jusqu'à cinq images, PDF, fichiers de code ou autres documents texte avec votre message à l'agent. L'agent les traite automatiquement et les inclut dans votre documentation.

L'agent lit le contexte de la demande ou du fil et met à jour votre dépôt connecté. Selon votre [paramètre de processus de relecture](/fr/agent/index#choose-how-the-agent-publishes-changes), l'agent ouvre une pull request ou effectue des commits directement sur votre branche de déploiement.

Demandez à l'agent de cibler une branche spécifique si vous voulez que les modifications atterrissent ailleurs que sur votre branche de déploiement. Par exemple, « ouvre la PR contre la branche `staging` » ou « pousse ces commits sur `docs-refresh` ». L'agent crée la pull request sur la branche que vous nommez, ou pousse les commits directement dessus lorsque la branche existe déjà.

<div id="continue-an-automation-run">
  ## Poursuivre l'exécution d'une automatisation
</div>

Lorsqu'une [automatisation](/fr/automations) publie une [notification Slack](/fr/automations/manage#slack-notifications) au sujet d'une pull request qu'elle a ouverte, répondez dans ce fil et mentionnez `@mintlify` pour poursuivre le travail. L'agent reprend l'ensemble du contexte de l'exécution, effectue un checkout de la même branche et pousse vos modifications sous forme de commits de suivi sur la même pull request, plutôt que d'en ouvrir une nouvelle.

Vous pouvez également partager un lien vers n'importe quelle pull request Mintlify directement avec l'agent pour la poursuivre depuis un nouveau fil.

Lorsqu'une automatisation de modification de code ouvre une pull request de documentation, elle publie sur la pull request de code déclenchante un commentaire contenant un lien vers la pull request de documentation. Elle attribue ensuite un relecteur en essayant l'auteur puis les committers de la pull request de code, dans l'ordre, jusqu'à ce que l'un d'eux accepte.

<div id="trigger-automations-from-slack-messages">
  ## Déclencher des automatisations depuis des messages Slack
</div>

Vous pouvez configurer une automatisation personnalisée pour qu'elle s'exécute lorsqu'une personne publie un message de premier niveau dans un canal Slack choisi. L'agent lit chaque message, décide s'il justifie une mise à jour de la documentation et ouvre une pull request lorsque c'est le cas. Configurez cela lorsque vous créez ou modifiez l'automatisation dans les paramètres [Automatisations](https://app.mintlify.com/settings/project/automations).

L'application `mintlify` doit être membre du canal choisi. Invitez-la avec `/invite @mintlify` avant d'enregistrer l'automatisation.

<div id="reference-other-repositories">
  ## Référencer d'autres dépôts
</div>

L'agent peut lire le code source de n'importe quel dépôt connecté via la [GitHub App](/fr/deploy/github) ou l'[intégration GitLab](/fr/deploy/gitlab), même s'il ne s'agit pas de votre dépôt de documentation. Cela permet à l'agent de construire un contexte plus approfondi pour guider les mises à jour de la documentation.

Lorsque vous mentionnez un autre dépôt dans votre demande, l'agent le clone à la demande et examine les fichiers pertinents avant de rédiger les modifications.

Exemples de prompts :

- « Mets à jour le guide d'authentification en fonction des changements dans `acme/api-server/src/auth.ts`. »
- « Documente les nouveaux endpoints ajoutés dans `acme/backend#1234`. »
- « À quels dépôts as-tu accès ? »

L'agent traite les dépôts clonés en lecture seule. Il les utilise comme contexte, mais n'écrit des modifications que dans votre dépôt de documentation.

<div id="track-progress-in-real-time">
  ## Suivre la progression en temps réel
</div>

Pendant que l'agent travaille sur votre demande, il fournit un retour dans le fil Slack.

- **Progression** : Un indicateur de progression s'affiche dans le fil pendant que l'agent travaille. L'agent le retire lorsqu'il publie sa réponse.
- **Questions** : Si votre demande est ambiguë, l'agent pose une courte question. Répondez dans le même fil ou la même conversation, en mentionnant `@mintlify` si vous êtes dans un canal.
- **Nouveaux messages** : Si vous envoyez un message à l'agent dans le même fil ou la même conversation pendant qu'il travaille encore, il accuse réception de votre message et l'intègre à la tâche en cours.
- **Occupé** : Si vous mentionnez l'agent dans un fil alors qu'il est occupé par le travail d'un autre fil, il publie un message pour le signaler. Il commence votre demande une fois ce travail terminé.
- **Achèvement** : Lorsque l'agent a terminé, il publie sa réponse dans le fil avec des liens vers les pages, les pull requests ou la documentation en ligne qu'il a modifiées.
- **Erreurs** : En cas de problème, l'agent s'arrête et le signale dans le fil. Envoyez-lui un nouveau message pour réessayer.

<div id="roles-and-permissions">
  ## Rôles et autorisations
</div>

Les capacités de l'agent dans Slack correspondent aux [rôles](/fr/dashboard/roles) des utilisateurs.

- **Administrateurs et éditeurs** : Peuvent poser des questions et apporter des modifications à la documentation. L'agent a accès aux outils d'édition de fichiers et de pull requests.
- **Lecteurs** : Peuvent uniquement poser des questions. L'agent fonctionne toujours en mode lecture seule pour les outils Mintlify, quelle que soit la demande.

Pour modifier les autorisations d'un coéquipier, mettez à jour son rôle sur la page [Members](https://app.mintlify.com/settings/organization/members) de votre dashboard.

<div id="use-the-agent-in-the-slack-side-panel">
  ## Utiliser l'agent dans le panneau latéral Slack
</div>

Ouvrez l'onglet **Chat** de l'agent, que Slack affiche également dans le panneau latéral, pour poser des questions ou demander des mises à jour de la documentation sans publier dans un canal. L'agent dispose des mêmes autorisations, des mêmes outils et du même processus de relecture que dans les canaux.

- Appuyez sur **New chat** pour démarrer une nouvelle conversation.
- Répondez dans une conversation pour la poursuivre.
- Vous n'avez pas besoin de mentionner `@mintlify`. L'agent lit tout ce que vous publiez dans la conversation.

<div id="best-practices">
  ## Bonnes pratiques
</div>

- **Soyez précis** : Indiquez exactement à l'agent ce que vous voulez savoir, ou ce que vous voulez modifier et à quel endroit.
- **Ajoutez du contexte** : Si un fil ne contient pas toutes les informations nécessaires, ajoutez des détails supplémentaires dans votre message à l'agent.
- **Relisez attentivement** : Relisez toujours les pull requests créées par l'agent avant de les fusionner.
