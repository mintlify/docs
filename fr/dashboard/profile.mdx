Gérez vos informations personnelles et vos préférences du tableau de bord dans les paramètres de votre [Profil](https://app.mintlify.com/settings/account). Les paramètres du profil s'appliquent uniquement à votre compte et ne modifient pas ce que voient les autres membres de votre organisation.

<div id="personal-information">
  ## Informations personnelles
</div>

Modifiez votre prénom et votre nom ou téléversez une photo de profil. Les photos de profil peuvent être des fichiers PNG, JPEG, WebP ou SVG.

<div id="starting-page">
  ## Page de démarrage
</div>

Par défaut, lorsque vous accédez à [app.mintlify.com](https://app.mintlify.com), l'éditeur se charge. Pour définir une autre page de démarrage à l'ouverture de Mintlify, sélectionnez-la dans le menu **Starting page** de la section **Preferences**.

Le tableau de bord utilise votre page de démarrage lorsque vous ouvrez le tableau de bord, changez d'organisation ou ouvrez l'URL racine d'un projet, par exemple `https://app.mintlify.com/{organization}/{project}`. Les liens vers une page, un document ou une branche spécifique ouvrent toujours cette destination.

<div id="theme">
  ## Thème
</div>

Choisissez **Light** ou **Dark** dans la section **Appearance**.

<div id="organization">
  ## Organisation
</div>

La section **Organization** indique la date à laquelle vous avez rejoint votre organisation. Si votre organisation utilise des [rôles](/fr/dashboard/roles), elle affiche également votre rôle.

<div id="connect-github">
  ## Connecter GitHub
</div>

Cliquez sur **Authorize** dans la section **Integrations** pour connecter votre compte GitHub. Une fois la connexion établie :

- Mintlify signe les [commits que vous effectuez dans l'éditeur web](/fr/editor/publish#commit-signing) avec votre compte GitHub au lieu de la GitHub App de Mintlify.
- L'agent vous attribue les [pull requests qu'il ouvre](/fr/agent/index#connect-your-github-account) au lieu du bot Mintlify.

Pour supprimer la connexion, cliquez sur **Disconnect**.
