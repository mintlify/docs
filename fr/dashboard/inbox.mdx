La boîte de réception rassemble les commentaires, suggestions et partages de pages qui requièrent votre attention, pour que vous les retrouviez sans fouiller dans vos e-mails. Cliquez sur <Icon icon="inbox" /> **Inbox** dans la barre latérale gauche de votre dashboard pour l'ouvrir. Un point à côté de l'icône signifie que vous avez des éléments non lus.

La boîte de réception affiche l'activité du projet que vous avez ouvert. Pour voir l'activité d'un autre projet, changez de projet.

<div id="what-appears-in-your-inbox">
  ## Ce qui apparaît dans votre boîte de réception
</div>

Vous recevez un élément dans votre boîte de réception lorsque :

- Un collègue ou l'agent Mintlify répond dans un fil de commentaires ou de suggestions que vous avez lancé ou dans lequel vous avez été mentionné.
- Quelqu'un vous mentionne avec `@` dans un commentaire ou dans le [contenu d'une page](/fr/editor/collaborate#mentions-in-page-content). Une nouvelle mention sur une page où vous aviez déjà été mentionné renvoie l'élément existant dans **Unread**.
- Quelqu'un commente ou suggère une modification sur une page dont vous êtes propriétaire, comme une page privée que vous gérez ou une page du site dont vous avez écrit la majeure partie. Vous recevez également les réponses ultérieures dans ces fils.
- Quelqu'un partage une page ou un dossier privé avec vous.

Chaque fil correspond à un seul élément. Une nouvelle activité dans un fil met à jour son élément existant et le place en haut de la liste. Vos propres actions ne créent jamais d'éléments dans votre boîte de réception.

La boîte de réception et les [notifications par e-mail](/fr/dashboard/notifications) sont indépendantes. Vos préférences d'e-mail ne modifient pas ce qui apparaît dans votre boîte de réception.

Pour lire votre boîte de réception depuis un outil d'IA, connectez l'[admin MCP](/fr/ai/mintlify-mcp) et utilisez l'[outil `read_inbox`](/fr/ai/mintlify-mcp#comments).

<div id="sections-and-filters">
  ## Sections et filtres
</div>

Utilisez la barre latérale pour passer d'une section à l'autre :

- **All** : Tout le contenu de votre boîte de réception.
- **Suggestions** : Les modifications suggérées et leurs réponses. Filtrez par **From the agent** ou **From people**.
- **Comments** : Les fils de commentaires. Filtrez par **Mentions** ou **On my pages**.
- **Invitations** : Les pages et dossiers privés que vos collègues ont partagés avec vous.

Chaque section indique combien d'éléments requièrent votre attention. Utilisez le sélecteur de dates pour modifier la période, qui correspond par défaut aux 30 derniers jours.

<div id="work-through-your-inbox">
  ## Traiter votre boîte de réception
</div>

Chaque élément indique qui a agi, ce qu'il a fait et sur quelle page, avec un aperçu du dernier commentaire ou de la dernière suggestion.

- Cliquez sur **View** sur un commentaire pour ouvrir le fil dans l'éditeur.
- Cliquez sur **Review** sur une suggestion pour l'ouvrir dans l'éditeur, où vous pouvez l'accepter ou la rejeter. Consultez [Suggestions](/fr/editor/collaborate#suggestions) pour plus d'informations.
- Cliquez sur **View page** pour ouvrir une page que quelqu'un a partagée avec vous.
- Cliquez sur **Dismiss** sur une suggestion pour la retirer de votre liste. Ignorer une suggestion ne la rejette pas.

Ouvrir un commentaire ou un partage de page le déplace vers **Read**. Une suggestion reste dans **Unread** jusqu'à ce que quelqu'un l'accepte ou la rejette, ou jusqu'à ce que vous l'ignoriez.

Les éléments passent également dans **Read** lorsque le fil est résolu, que la suggestion est acceptée ou rejetée, ou que vous perdez l'accès à la page. Ces éléments affichent une étiquette indiquant leur statut, comme **Resolved**, **Applied**, **Rejected** ou **Access removed**. Si un fil reçoit une nouvelle activité après que son élément est passé dans **Read**, l'élément revient dans **Unread**.

Pour tout effacer dans la vue actuelle, cliquez sur <Icon icon="ellipsis" /> **More inbox actions** et sélectionnez **Mark all as read**.

<div id="find-read-items">
  ## Retrouver les éléments lus
</div>

Dans la section **All**, passez de **Unread** à **Read** pour voir les éléments que vous avez ouverts, ignorés ou marqués comme lus, ainsi que les éléments résolus. Pour remettre dans **Unread** un élément que vous avez effacé, cliquez sur **Restore**.
