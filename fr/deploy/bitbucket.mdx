<Info>
  Bitbucket Cloud nécessite un [plan Enterprise](https://mintlify.com/pricing?ref=bitbucket-cloud).
</Info>

Mintlify se connecte à Bitbucket Cloud via OAuth. Après avoir connecté un dépôt, Mintlify déploie automatiquement les modifications poussées sur votre branche de déploiement et crée des déploiements de prévisualisation pour les pull requests.

Mintlify prend en charge les dépôts Bitbucket Cloud hébergés sur `bitbucket.org`. Bitbucket Data Center, l'agent Slack et les automatisations ne prennent pas en charge les dépôts Bitbucket.

<div id="requirements">
  ## Prérequis
</div>

- Un compte Bitbucket Cloud
- L'autorisation de créer un webhook dans le dépôt que vous souhaitez connecter
- Un accès administrateur à votre organisation Mintlify
- Un fichier `docs.json` dans votre dépôt

<div id="set-up-a-new-bitbucket-connection">
  ## Configurer une nouvelle connexion Bitbucket
</div>

Lorsque vous ouvrez [Git Settings](https://app.mintlify.com/settings/deployment/git-settings) pour la première fois, un assistant de configuration vous guide pour connecter votre dépôt Bitbucket.

<Steps>
  <Step title="Sélectionner Bitbucket comme fournisseur">
    1. Sur la page [Git Settings](https://app.mintlify.com/settings/deployment/git-settings), sélectionnez **Connect to Bitbucket**.
    2. Cliquez sur **Continue**.
  </Step>
  <Step title="Déplacer le contenu hébergé par Mintlify">
    Si vous hébergez actuellement votre contenu dans un dépôt géré par Mintlify, téléchargez-le sous forme de fichier zip. Extrayez le contenu du zip et poussez les fichiers vers votre dépôt Bitbucket.

    Si votre contenu est déjà dans Bitbucket, cliquez sur **Continue setup**.
  </Step>
  <Step title="Autoriser Bitbucket">
    1. Cliquez sur **Connect Bitbucket**.
    2. Bitbucket ouvre une nouvelle page pour autoriser Mintlify à accéder à votre compte Bitbucket. Autorisez Mintlify à accéder au dépôt que vous souhaitez connecter.

    Après autorisation, Bitbucket vous redirige vers vos paramètres Git Mintlify.
  </Step>
  <Step title="Configurer le dépôt">
    Saisissez les valeurs suivantes :

    - **Workspace** : Le slug du workspace Bitbucket qui possède le dépôt. Par exemple, dans `https://bitbucket.org/acme/docs`, `acme` est le slug du workspace.
    - **Repository** : Le slug du dépôt. Par exemple, dans `https://bitbucket.org/acme/docs`, `docs` est le slug du dépôt.
    - **Deploy branch** : La branche qui publie sur votre site de documentation en production, comme `main`.

  </Step>
  <Step title="Configurer un répertoire de contenu (facultatif)">
    1. Si votre fichier `docs.json` se trouve dans un sous-répertoire, activez **Docs are in a subdirectory** sur votre page de paramètres Git.
    2. Saisissez le chemin du répertoire qui contient votre fichier `docs.json`. Par exemple, si votre `docs.json` se trouve dans le répertoire `apps/docs/`, saisissez `apps/docs`.
  </Step>
  <Step title="Connecter le dépôt">
    1. Cliquez sur **Connect**.
    2. Confirmez le changement. Mintlify vérifie que le compte Bitbucket autorisé peut accéder à votre dépôt et enregistre le webhook qui déclenche les déploiements et les prévisualisations de pull requests.
  </Step>
</Steps>

<div id="update-an-existing-connection">
  ## Mettre à jour une connexion existante
</div>

1. Accédez à la page [Git Settings](https://app.mintlify.com/settings/deployment/git-settings) de votre tableau de bord Mintlify.
2. Développez la section **Bitbucket OAuth**.
3. Activez ou désactivez chaque dépôt individuellement. La désactivation d'un dépôt supprime son webhook Mintlify.

La révocation d'une connexion supprime les webhooks Mintlify pour tous les dépôts connectés via ce compte.

<div id="configure-multiple-repositories">
  ## Configurer plusieurs dépôts
</div>

Vous pouvez combiner du contenu provenant de plusieurs dépôts Bitbucket dans un seul site. Chaque source du déploiement doit utiliser Bitbucket, et vous devez activer chaque dépôt sous **Bitbucket OAuth** avant de l'ajouter comme source.

Consultez [Déploiements multi-dépôts](/fr/deploy/multi-repo) pour les instructions de configuration et des informations sur les chemins d'URL, les sources de base et la navigation.

<div id="troubleshooting">
  ## Dépannage
</div>

<AccordionGroup>
<Accordion title="Dépôt non autorisé">

Si Mintlify signale qu'aucune installation connectée ne peut accéder à votre dépôt, vérifiez les points suivants :

- Les valeurs de workspace et de dépôt utilisent les bons slugs, et non les noms d'affichage.
- Le compte Bitbucket connecté dispose des autorisations nécessaires pour accéder au dépôt.
- Vous avez activé le dépôt dans la section **Bitbucket OAuth** de vos paramètres Git Mintlify.

Si le dépôt n'apparaît pas, reconnectez votre compte Bitbucket avec un compte ayant accès au dépôt.

</Accordion>
<Accordion title="Les déploiements ne se déclenchent pas automatiquement">

Dans Bitbucket, ouvrez **Repository settings** > **Webhooks** et vérifiez qu'un webhook actif nommé **Mintlify** existe. S'il est manquant, revenez à vos paramètres Git Mintlify, désactivez le dépôt sous **Bitbucket OAuth**, puis réactivez-le.

Vérifiez que la branche dans vos paramètres Git Mintlify correspond à la branche Bitbucket sur laquelle vous poussez les modifications.

</Accordion>
<Accordion title="Les prévisualisations de pull requests n'apparaissent pas">

Vérifiez que le webhook Mintlify est actif et inclut les événements de pull request. Si vos autorisations Bitbucket ont changé après avoir connecté le dépôt, reconnectez votre compte Bitbucket et réactivez le dépôt.
</Accordion>
</AccordionGroup>
