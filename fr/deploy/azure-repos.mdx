<Info>
  Azure Repos nécessite un [forfait Enterprise](https://mintlify.com/pricing?ref=azure-repos).
</Info>

Mintlify se connecte à Azure Repos via Microsoft Entra ID. Vous vous connectez avec votre compte Microsoft afin que Mintlify puisse vérifier les organisations, projets et dépôts auxquels vous avez accès. Mintlify utilise ensuite l'application Mintlify dans votre tenant Entra pour lire votre dépôt, créer des service hooks, déployer chaque modification poussée sur votre branche de déploiement et créer des déploiements de prévisualisation pour les pull requests.

Mintlify prend en charge les organisations Azure DevOps Services sur `dev.azure.com` connectées à Microsoft Entra ID, y compris les organisations qui utilisent encore des URL `*.visualstudio.com`. Mintlify ne prend pas en charge Azure DevOps Server.

<div id="requirements">
  ## Prérequis
</div>

- Une organisation Azure DevOps connectée à Microsoft Entra ID.
- Un administrateur Entra qui accorde son consentement à l'application Mintlify dans votre tenant.
- L'application Mintlify ajoutée à votre organisation Azure DevOps avec un accès **Basic**, ainsi qu'au projet qui contient votre dépôt.
- L'application Mintlify dans le groupe **Project Administrators** du projet. Azure DevOps n'autorise que les administrateurs de projet à créer des service hooks.
- Un compte Microsoft administrateur du projet ou disposant de **Manage permissions** sur le dépôt que vous souhaitez connecter.
- Un accès administrateur à votre organisation Mintlify.
- Un fichier `docs.json` dans votre dépôt.

<div id="set-up-a-new-azure-repos-connection">
  ## Configurer une nouvelle connexion Azure Repos
</div>

Lorsque vous ouvrez [Git Settings](https://app.mintlify.com/settings/project/git-settings) pour la première fois, un assistant de configuration vous guide pour connecter votre dépôt.

<Steps>
  <Step title="Sélectionner Azure Repos comme fournisseur">
    1. Sur la page [Git Settings](https://app.mintlify.com/settings/project/git-settings), cliquez sur **Connect to Azure Repos**.
    2. Cliquez sur **Continue**.
  </Step>
  <Step title="Déplacer le contenu hébergé par Mintlify">
    Si vous hébergez actuellement votre contenu dans un dépôt géré par Mintlify, téléchargez-le sous forme de fichier zip. Extrayez le contenu du zip et poussez les fichiers vers votre dépôt Azure Repos.

    Si votre contenu se trouve déjà dans Azure Repos, cliquez sur **Continue setup**.
  </Step>
  <Step title="Connecter Microsoft">
    1. Cliquez sur **Connect Microsoft**.
    2. Connectez-vous avec un compte Microsoft administrateur du projet ou disposant de **Manage permissions** sur le dépôt que vous souhaitez connecter.

    Une fois connecté, Microsoft vous redirige vers vos paramètres Git Mintlify.
  </Step>
  <Step title="Sélectionner le dépôt">
    Sélectionnez les valeurs suivantes. Chaque liste affiche les ressources auxquelles votre compte Microsoft a accès.

    - **Organization** : l'organisation Azure DevOps. Par exemple, dans `https://dev.azure.com/acme/docs-project/_git/docs`, `acme` est l'organisation.
    - **Project** : le projet qui contient le dépôt, par exemple `docs-project`.
    - **Repository** : le nom du dépôt, par exemple `docs`.
    - **Deploy branch** : la branche qui publie sur votre site de documentation de production, par exemple `main`.
  </Step>
  <Step title="Configurer un répertoire de contenu (facultatif)">
    1. Si votre fichier `docs.json` se trouve dans un sous-répertoire, activez **docs.json is in a subdirectory**.
    2. Saisissez le chemin du répertoire qui contient votre fichier `docs.json`. Par exemple, si votre `docs.json` se trouve dans le répertoire `apps/docs/`, saisissez `apps/docs`.
  </Step>
  <Step title="Connecter le dépôt">
    1. Cliquez sur **Connect**.
    2. Confirmez la modification.

    Mintlify vérifie que votre compte Microsoft peut gérer le dépôt et que la branche de déploiement existe. Mintlify enregistre ensuite les service hooks qui maintiennent votre site et l'éditeur synchronisés, puis lance votre premier déploiement.
  </Step>
</Steps>

Pour vérifier les service hooks, ouvrez votre projet Azure DevOps et accédez à **Project settings** > **Service hooks**. Mintlify crée trois abonnements **Web Hooks** pour le dépôt : **Code pushed**, **Pull request created** et **Pull request updated**.

<div id="switch-an-existing-deployment-to-azure-repos">
  ## Basculer un déploiement existant vers Azure Repos
</div>

1. Sur la page [Git Settings](https://app.mintlify.com/settings/project/git-settings), sélectionnez **Azure Repos** comme fournisseur Git.
2. Si vous n'avez pas connecté de compte Microsoft, cliquez sur **Connect Microsoft** et connectez-vous.
3. Sélectionnez l'organisation, le projet, le dépôt et la branche de déploiement, puis saisissez un répertoire de contenu si nécessaire.
4. Cliquez sur **Switch to Azure Repos**.

<div id="change-the-connected-microsoft-account">
  ## Changer le compte Microsoft connecté
</div>

Toute votre organisation Mintlify partage le compte Microsoft défini dans Git Settings, et seuls les administrateurs peuvent le modifier. Mintlify actualise automatiquement les identifiants Microsoft, vous n'avez donc pas besoin de renouveler les jetons.

Pour utiliser un autre compte, ouvrez la section **Microsoft connection** sur la page [Git Settings](https://app.mintlify.com/settings/project/git-settings) et cliquez sur **Change account**. Le nouveau compte doit être administrateur du projet ou disposer de **Manage permissions** sur le dépôt.

<div id="edit-in-the-web-editor">
  ## Modifier dans l'éditeur web
</div>

Vous pouvez modifier le contenu Azure Repos dans l'[éditeur](/fr/editor). Lorsque vous publiez, Mintlify pousse une branche vers Azure Repos et ouvre une pull request vers votre branche de déploiement.

- Les branches que vous poussez vers Azure Repos sont synchronisées dans l'éditeur.
- Les modifications apportées aux pull requests dans Azure Repos sont synchronisées dans la branche correspondante de l'éditeur.
- Lorsque vous supprimez une branche dans Azure Repos, Mintlify la retire de l'éditeur.
- Si votre branche de déploiement est soumise à des stratégies de branche bloquantes, comme des relecteurs obligatoires, publiez via une pull request.

<div id="preview-deployments">
  ## Déploiements de prévisualisation
</div>

Lorsque vous ouvrez une pull request vers votre branche de déploiement, Mintlify génère un [déploiement de prévisualisation](/fr/deploy/preview-deployments) et y renvoie depuis un statut **Mintlify preview ready** sur la pull request. Mintlify régénère la prévisualisation lorsque vous poussez sur la branche de la pull request, et la supprime lorsque vous terminez ou abandonnez la pull request ou supprimez la branche.

<div id="use-autopilot">
  ## Utiliser Autopilot
</div>

[Autopilot](/fr/autopilot) fonctionne avec Azure Repos. Il s'exécute lorsque du code est fusionné dans les dépôts connectés et ouvre des pull requests dans votre dépôt Azure Repos. Acceptez ou fermez ses pull requests sur la page Autopilot, ou fusionnez-les dans Azure Repos.

Pour donner plus de contexte à Autopilot, connectez vos dépôts de code source dans Git Settings, puis sélectionnez-les dans la ligne **Azure Repos** de la page Autopilot. Consultez [Dépôts Azure Repos](/fr/autopilot#azure-repos-repositories).

Sur Azure Repos, Autopilot n'assigne pas les pull requests, ne demande pas de relectures et ne répond pas aux commentaires des pull requests. Pour demander des modifications, envoyez un message dans la suggestion sur la page Autopilot.

<div id="use-the-agent-in-slack">
  ## Utiliser l'agent dans Slack
</div>

L'[agent dans Slack](/fr/agent/slack) fonctionne avec Azure Repos. Lorsque vous lui demandez de mettre à jour votre contenu, il ouvre une pull request dans votre dépôt Azure Repos.

<div id="troubleshooting">
  ## Dépannage
</div>

<AccordionGroup>
  <Accordion title="Mintlify n'a pas pu se connecter à votre tenant Microsoft Entra">
    Demandez à un administrateur Entra de votre tenant d'accorder son consentement à l'application Mintlify, puis connectez à nouveau le dépôt.
  </Accordion>
  <Accordion title="L'organisation n'est pas connectée à Microsoft Entra ID">
    Mintlify ne prend en charge que les organisations Azure DevOps adossées à Microsoft Entra ID. Connectez votre organisation à votre tenant Entra dans Azure DevOps sous **Organization settings** > **Microsoft Entra**, puis réessayez.
  </Accordion>
  <Accordion title="Ajouter l'application Mintlify à l'organisation ou au projet">
    L'application Mintlify ne peut pas lire le dépôt. Ajoutez l'application Mintlify à votre organisation Azure DevOps avec un accès **Basic**, puis ajoutez-la au projet qui contient le dépôt.
  </Accordion>
  <Accordion title="Ajouter l'application Mintlify au groupe Project Administrators">
    Mintlify doit créer des service hooks pour déployer automatiquement vos modifications. Ajoutez l'application Mintlify au groupe **Project Administrators** du projet, puis connectez à nouveau le dépôt.
  </Accordion>
  <Accordion title="Votre compte Microsoft ne peut pas accéder au dépôt">
    Le compte Microsoft connecté dans Git Settings ne peut pas lire le dépôt. Cliquez sur **Change account** et connectez-vous avec un compte qui y a accès. Les utilisateurs disposant d'un accès **Stakeholder** ne peuvent pas lire les dépôts des projets privés.
  </Accordion>
  <Accordion title="Seul un administrateur du projet peut connecter le dépôt">
    Le compte Microsoft connecté dans Git Settings peut lire le dépôt, mais pas le gérer. Cliquez sur **Change account** et connectez-vous avec un compte membre du groupe **Project Administrators** du projet ou disposant de **Manage permissions** sur le dépôt.
  </Accordion>
  <Accordion title="La branche de déploiement est introuvable">
    Vérifiez que la branche existe dans le dépôt et que son nom correspond exactement.
  </Accordion>
  <Accordion title="Les push ne déclenchent pas de déploiement">
    Dans Azure DevOps, accédez à **Project settings** > **Service hooks** et ouvrez les abonnements Mintlify pour consulter leur historique de livraison. Vérifiez que vous avez poussé sur la branche de déploiement configurée dans Mintlify.

    Si un abonnement est désactivé ou manquant, cliquez sur **Save** dans [Git Settings](https://app.mintlify.com/settings/project/git-settings). Mintlify remplace tout abonnement qui n'est pas en bon état.
  </Accordion>
</AccordionGroup>

<Note>
  Mintlify ne supprime pas les service hooks lorsque vous passez à un autre fournisseur Git. Supprimez-les dans **Project settings** > **Service hooks**.
</Note>
