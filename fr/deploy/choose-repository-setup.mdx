Votre site est déployé à partir d'un dépôt Git. Par défaut, il est déployé à partir de la racine d'un seul dépôt. Si vous stockez votre documentation avec votre code, ou dans plusieurs dépôts, choisissez l'une de ces configurations.

| | [Configuration monorepo](/fr/deploy/monorepo) | [Projet multi-référentiels](/fr/deploy/multi-repo) | [GitHub Action multi-repo](/fr/deploy/multirepo-action) |
| --- | --- | --- | --- |
| **Forfait** | Tous | Enterprise | Tous |
| **Idéal pour** | Une documentation livrée dans les mêmes pull requests que le code qu'elle décrit | Des équipes qui gardent chacune leur documentation dans leur propre dépôt, avec leurs propres branches et relectures | Combiner des dépôts GitHub sans forfait Enterprise, ou gérer les sources dans un fichier de configuration |
| **Où vous stockez le contenu** | Un sous-répertoire d'un seul dépôt | Plusieurs dépôts, chacun avec son propre `docs.json` à la racine ou dans un sous-répertoire, combinés au moment du déploiement | Plusieurs dépôts enfants, copiés dans un dépôt parent |
| **Paramètres du site** | Le `docs.json` de votre répertoire de documentation | Le `docs.json` de la source de base | Le `docs.base.json` du dépôt parent |
| **Fournisseurs Git** | Tout fournisseur pris en charge par Mintlify | GitHub, GitLab, Bitbucket ou Azure Repos, avec toutes les sources chez le même fournisseur | GitHub |
| **Se configure dans** | Les paramètres Git du dashboard | Les paramètres Git du dashboard | Un fichier de configuration et un workflow dans le dépôt parent |
| **Modification dans l'éditeur** | Oui | Oui, passez d'une source à l'autre depuis la barre latérale | Uniquement le contenu que l'action ne synchronise pas, car elle remplace les fichiers synchronisés et `docs.json` à chaque exécution |

Par exemple, dans un projet multi-référentiels, une équipe produit peut gérer les guides, une équipe plateforme la référence d'API et une équipe SDK la documentation des SDK. Les pages de chaque dépôt apparaissent sous leur propre chemin d'URL, comme `/api` ou `/sdks`.
