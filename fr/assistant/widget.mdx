<Info>
  L'API de l'assistant nécessite une [offre Pro ou Enterprise](https://mintlify.com/pricing?ref=assistant). Les réponses via l'API utilisent les mêmes [crédits](/fr/credits) que l'assistant de votre site de documentation.
</Info>

<Warning>
  Le widget hébergé de Mintlify est obsolète. Pour ajouter l'assistant à un autre site ou à une autre application, créez votre propre interface sur l'API de l'assistant.
</Warning>

L'[assistant](/fr/assistant) répond aux questions sur votre site Mintlify. Pour proposer les mêmes réponses dans votre tableau de bord, votre site marketing, votre portail d'assistance ou ailleurs, créez un widget qui appelle l'API de l'assistant. Vous contrôlez l'apparence et le comportement du widget, et l'assistant répond à partir du même contenu que votre site de documentation.

Un widget comporte trois parties :

- **Votre interface** : une interface de chat dans votre site ou votre application, comme un bouton flottant qui ouvre un panneau.
- **Une route serveur** : une route sur votre backend qui ajoute votre clé d'API de l'assistant à chaque requête et la transmet à Mintlify.
- **L'API de l'assistant** : l'endpoint [créer un message de l'assistant](/fr/api/assistant/create-assistant-message-v2), qui diffuse les réponses au format de messages UI de l'[AI SDK](https://ai-sdk.dev).

Pour un exemple complet avec Next.js, voir [Créer un assistant intégré à l'application](/fr/guides/assistant-embed).

<div id="get-an-assistant-api-key">
  ## Obtenir une clé d'API de l'assistant
</div>

1. Accédez à la page [API keys](https://app.mintlify.com/settings/organization/api-keys) de votre Dashboard.
2. Cliquez sur **Create Assistant API Key**.
3. Copiez la clé, qui commence par `mint_dsc_`, et enregistrez-la comme variable d'environnement côté serveur.

<Warning>
  Conservez votre clé d'API de l'assistant sur votre serveur. Toute personne qui copie la clé depuis votre code client peut utiliser vos crédits de l'assistant et lire les pages protégées de votre projet.
</Warning>

Vous avez également besoin de votre nom de domaine, qui apparaît à la fin de l'URL de votre Dashboard. Par exemple, si l'URL de votre Dashboard est `https://app.mintlify.com/org-name/domain-name`, votre nom de domaine est `domain-name`.

<div id="add-a-server-route">
  ## Ajouter une route serveur
</div>

Créez une route qui ajoute votre clé d'API à chaque requête et la transmet à l'API de l'assistant. Renvoyez la réponse en streaming sans la modifier et transmettez les en-têtes du fil.

```js
const DOMAIN = "your-domain";

export async function POST(request) {
  const upstream = await fetch(
    `https://api.mintlify.com/discovery/v2/assistant/${DOMAIN}/message`,
    {
      method: "POST",
      headers: {
        "Content-Type": "application/json",
        Authorization: `Bearer ${process.env.MINTLIFY_ASSISTANT_KEY}`,
      },
      body: await request.text(),
    }
  );

  const headers = new Headers();
  for (const name of ["content-type", "x-thread-id", "x-thread-key", "x-message-id"]) {
    const value = upstream.headers.get(name);
    if (value) headers.set(name, value);
  }

  return new Response(upstream.body, { status: upstream.status, headers });
}
```

Remplacez `your-domain` par votre nom de domaine. Cet exemple utilise les API standard `Request` et `Response`, qui fonctionnent dans les route handlers Next.js et dans la plupart des environnements d'exécution JavaScript côté serveur. Adaptez-le à votre framework backend si nécessaire.

Comme c'est votre serveur qui appelle Mintlify, la Content Security Policy de votre site doit seulement autoriser les requêtes vers votre propre route.

<div id="connect-your-interface">
  ## Connecter votre interface
</div>

L'API de l'assistant est compatible avec AI SDK v5 et versions ultérieures. Dans React, utilisez le hook `useChat` et faites pointer son transport vers votre route serveur :

```jsx
import { useChat } from "@ai-sdk/react";
import { DefaultChatTransport } from "ai";

const { messages, sendMessage, status } = useChat({
  transport: new DefaultChatTransport({
    api: "/api/assistant",
    body: { fp: "anonymous" },
  }),
});
```

Appelez `sendMessage({ text: question })` pour poser une question, puis affichez les parties texte de chaque message de `messages`. Le champ `fp` identifie l'utilisateur. Utilisez `anonymous` ou votre propre identifiant d'utilisateur.

Si vous n'utilisez pas React, toute intégration UI de l'AI SDK ou tout client HTTP capable de lire une réponse en streaming fonctionne. Voir [créer un message de l'assistant](/fr/api/assistant/create-assistant-message-v2) pour le format complet de la requête et de la réponse.

<div id="customize-the-widget">
  ## Personnaliser le widget
</div>

Votre interface contrôle tout ce que voient les visiteurs, comme le déclencheur, le thème, les libellés, les questions de démarrage et les liens d'assistance. Utilisez les champs de la requête et les données de la réponse pour contrôler les réponses de l'assistant.

<div id="scope-retrieval-by-language-or-version">
  ### Limiter la recherche par langue ou par version
</div>

Passez `filter` dans le corps de la requête pour restreindre ce que l'assistant récupère lorsque vous organisez votre contenu par langue ou par [versions](/fr/organize/navigation#versions). Omettez un champ pour rechercher dans toutes ses valeurs.

```js
body: {
  fp: "anonymous",
  filter: {
    language: "en",
    version: "v2",
  },
},
```

`language` doit être un [code de langue pris en charge](/fr/organize/settings-reference#navigation-global-languages), comme `en`, `es`, `fr` ou `zh-Hans`. `version` correspond au nom de version configuré dans votre Dashboard.

`filter` accepte aussi `groups` pour restreindre la récupération de [contenu protégé](/fr/deploy/authentication-setup). Mintlify ne vérifie pas l'appartenance aux groupes : votre serveur doit donc choisir les groupes de chaque utilisateur.

<div id="add-page-context">
  ### Ajouter le contexte de la page
</div>

Passez `currentPath` avec le chemin de la page consultée par le visiteur pour que l'assistant donne des réponses plus pertinentes. Passez `context` pour inclure des extraits de code ou du texte sélectionné avec une question.

<div id="show-sources">
  ### Afficher les sources
</div>

L'assistant effectue une recherche dans votre contenu avant de répondre. Chaque recherche apparaît dans le message sous forme de partie `tool-search`, et son tableau `output.results` liste les pages trouvées. Utilisez ces résultats pour afficher des liens vers les sources sous chaque réponse. Voir [citations des sources](/fr/guides/assistant-embed#source-citations) pour un exemple.

<div id="continue-conversations">
  ### Poursuivre les conversations
</div>

La première réponse d'une nouvelle conversation renvoie les en-têtes `X-Thread-Id` et `X-Thread-Key`. Enregistrez les deux, puis incluez `threadId` et `threadKey` dans le corps de chaque requête suivante pour poursuivre la même conversation. Le serveur ne renvoie la clé du fil qu'une seule fois : enregistrez-la immédiatement. Voir [suivre les fils de conversation](/fr/guides/assistant-embed#track-conversation-thread-ids) pour un exemple.

<div id="add-search">
  ### Ajouter la recherche
</div>

Pour afficher les pages correspondantes pendant la saisie, appelez l'endpoint [rechercher dans la documentation](/fr/api/assistant/search) depuis votre route serveur avec la même clé d'API. Les requêtes de recherche n'utilisent pas de crédits.
