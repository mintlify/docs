Mintlify lit ces extensions et ces champs dans votre spécification OpenAPI. Il ne lit pas `x-tagGroups`. Pour afficher tout autre champ de votre spécification comme étiquette sur les paramètres, utilisez les [pastilles de paramètres](/fr/api-playground/customize-endpoint-pages#add-parameter-pills).

Pour ajouter des extensions à une spécification que vous ne modifiez pas directement, utilisez un [overlay](/fr/api-playground/overlays).

<div id="operation-extensions">
  ## Extensions d'opération
</div>

Ajoutez-les à une opération, comme `paths./users.get`.

| Extension | Effet |
| --- | --- |
| `x-mint.metadata` | Remplace le frontmatter de la page, comme `title`, `sidebarTitle`, `description`, `playground` ou `tag`. Consultez [Remplacer les métadonnées de la page](/fr/api-playground/customize-endpoint-pages#override-page-metadata). |
| `x-mint.content` | Ajoute du contenu MDX à la page. Consultez [Ajouter du contenu à une page](/fr/api-playground/customize-endpoint-pages#add-content-to-a-page). |
| `x-mint.href` | Définit l'URL de la page. Consultez [Définir l'URL d'un endpoint](/fr/api-playground/endpoint-urls#set-a-url-for-one-endpoint). |
| `x-mint.playground.expand` | Définissez-le sur `false` pour que les champs d'objets imbriqués soient réduits par défaut. Consultez [Réduire les champs du playground](/fr/api-playground/customize-endpoint-pages#collapse-playground-fields). |
| `x-mint.groups` | N'affiche l'endpoint qu'aux lecteurs des groupes d'utilisateurs listés. Fonctionne aussi sur un chemin. Consultez [Filtrer les endpoints](/fr/create/personalization#filter-endpoints). |
| `x-hidden` | Crée la page mais l'exclut de la navigation. Consultez [Masquer ou exclure des endpoints](/fr/api-playground/organize-endpoints#hide-or-exclude-endpoints). |
| `x-excluded` | Ne crée pas de page. Consultez [Masquer ou exclure des endpoints](/fr/api-playground/organize-endpoints#hide-or-exclude-endpoints). |
| `x-codeSamples` | Ajoute vos propres exemples de requête. `x-code-samples` fonctionne aussi. Consultez [Écrire vos propres exemples](/fr/api-playground/code-examples#write-your-own-examples). |

`x-hidden` et `x-excluded` fonctionnent aussi sur les webhooks.

<div id="schema-extensions">
  ## Extensions de schéma
</div>

Ajoutez-les à un schéma ou à une propriété.

| Extension | Effet |
| --- | --- |
| `x-mint.pre`, `x-mint.post` | Ajoute des pastilles avant ou après le nom d'un paramètre. Consultez [Ajouter des pastilles de paramètres](/fr/api-playground/customize-endpoint-pages#add-parameter-pills). |
| `x-mint.groups` | N'affiche une propriété ou une variante `oneOf` qu'aux lecteurs des groupes d'utilisateurs listés. Consultez [Filtrer les propriétés de schéma](/fr/create/personalization#filter-schema-properties). |
| `x-mint-enum` | N'affiche certaines valeurs d'enum qu'aux lecteurs des groupes d'utilisateurs listés. Consultez [Filtrer les valeurs d'enum](/fr/create/personalization#filter-enum-values). |
| `x-default` | Préremplit le playground avec une valeur sans modifier l'exemple documenté ni le `default`. Sur les paramètres, a priorité sur les exemples, que `api.examples.prefill` soit activé ou non. Sur les champs du corps de la requête, ne s'applique que lorsque `api.examples.prefill` est désactivé. Consultez [Préremplir des valeurs d'exemple](/fr/api-playground/configure-playground#prefill-example-values). |

<div id="security-scheme-extensions">
  ## Extensions de schéma de sécurité
</div>

| Extension | Effet |
| --- | --- |
| `x-default` | Préremplit le champ d'identifiants dans le playground. Fonctionne sur les schémas `apiKey` et `http` bearer. Consultez [Préremplir les identifiants](/fr/api-playground/configure-playground#prefill-credentials). |

<div id="tag-extensions-and-fields">
  ## Extensions et champs de tags
</div>

| Champ | Effet |
| --- | --- |
| `x-group` | Définit le libellé du groupe de navigation pour le tag. Consultez [Renommer les groupes de tags](/fr/api-playground/organize-endpoints#rename-tag-groups). |
| `x-displayName` | Définit le libellé du groupe si le tag n'a pas de `x-group`. |
| `parent`, `kind`, `summary` | OpenAPI 3.2 uniquement. Imbriquent des groupes, affichent des pastilles de badge et définissent des libellés. Consultez [Imbriquer des groupes avec des hiérarchies de tags](/fr/api-playground/organize-endpoints#nest-groups-with-tag-hierarchies). |

Aucun d'eux ne modifie les URL des pages. Les URL utilisent le `name` du tag.

<div id="frontmatter-fields">
  ## Champs de frontmatter
</div>

Utilisez-les dans les pages MDX qui référencent votre spécification.

| Champ | Effet |
| --- | --- |
| `openapi` | Génère la page à partir d'une opération ou d'un webhook, comme `openapi: "openapi.json GET /users"`. Consultez [Créer des pages MDX pour les endpoints](/fr/api-playground/customize-endpoint-pages#create-mdx-pages-for-endpoints). |
| `openapi-schema` | Génère la page à partir d'un schéma de `components.schemas`. Consultez [Créer des pages pour les modèles de données](/fr/api-playground/customize-endpoint-pages#create-pages-for-data-models). |
| `playground` | Définit le mode d'affichage du playground pour la page. Consultez [Choisir un mode d'affichage](/fr/api-playground/configure-playground#choose-a-display-mode). |
