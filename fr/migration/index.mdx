Transférez votre documentation existante vers Mintlify avec un scraper automatisé, un export depuis votre plateforme actuelle ou une migration manuelle. Le meilleur parcours dépend du fait que votre site soit public ou non, que vous puissiez accéder à ses fichiers sources et des fonctionnalités spécifiques à la plateforme que vous utilisez.

<Card title="Docusaurus" href="/fr/migration/docusaurus">
  Scrapez un site public, ou migrez depuis les sources pour préserver les pages privées, les documents versionnés, le contenu localisé et les composants React personnalisés.
</Card>
<Card title="ReadMe" href="/fr/migration/readme">
  Exportez les fichiers du projet pour préserver le contenu privé et les fichiers OpenAPI, ou scrapez un site public pour un point de départ plus rapide.
</Card>
<Card title="GitBook" href="/fr/migration/gitbook">
  Exportez chaque section avec Git Sync pour la migration la plus complète, ou scrapez un site public.
</Card>
<Card title="Fern" href="/fr/migration/fern">
  Migrez le MDX, les ressources, les spécifications d'API et la configuration `docs.yml` depuis le référentiel source.
</Card>
<Card title="Document360" href="/fr/migration/document360">
  Exportez chaque espace de travail et chaque langue en tant que ZIP de projet, y compris les articles, les catégories et les fichiers médias.
</Card>
<Card title="Autres plateformes" href="/fr/migration/manual">
  Suivez le workflow manuel pour une autre plateforme ou un projet avec des sources de contenu mixtes.
</Card>

<div id="scrape-individual-pages">
  ## Scraper des pages individuelles
</div>

Les guides Docusaurus, ReadMe et GitBook utilisent la commande `section` du scraper, qui convertit chaque page accessible depuis l'URL que vous lui fournissez. Pour convertir une seule page à la place, utilisez la commande `page` depuis votre répertoire de migration.

```bash
npx @mintlify/scraping@latest page https://docs.example.com/getting-started
```

Utilisez `page` pour vérifier comment le scraper convertit votre contenu avant une exécution complète, ou pour compléter des pages individuelles qu'une exécution `section` aurait manquées. Pour un site volumineux, affinez une exécution `section` avec `--filter` plutôt que de tout scraper d'un coup.

<div id="generate-a-site-from-a-repository">
  ## Générer un site à partir d'un référentiel
</div>

Mintlify peut générer un site de documentation complet pour n'importe quel référentiel GitHub, qu'il contienne déjà de la documentation ou seulement du code.

Remplacez `github` par `mintlify` dans l'URL de votre référentiel.

```text
https://github.com/org/repo -> https://mintlify.com/org/repo
```

Parcourez les [sites de documentation générés](https://www.mintlify.com/wiki) pour voir plus d'exemples.
