La skill `mintlify` aide votre agent de codage à rédiger de la documentation, à configurer votre site et à personnaliser son apparence et son comportement dans le navigateur. Elle comprend des références sur les sélecteurs, les parties de composants, les variables CSS, les API du navigateur, le cycle de vie des scripts, les thèmes et les snippets React. Votre agent ne charge que les références nécessaires à chaque tâche.

<div id="install-the-skill">
  ## Installer la skill
</div>

Vous avez besoin de Node.js et d'un agent de codage qui prend en charge les skills.

```bash
npx skills@latest add \
  https://github.com/mintlify/docs/tree/main/agent-context/context/skills/mintlify \
  --skill mintlify
```

Sélectionnez votre agent et la portée lorsque vous y êtes invité. Ajoutez `--global` pour l'installer dans tous vos projets.

Pour la mettre à jour, relancez la même commande avec les mêmes options, puis démarrez une nouvelle session de l'agent. Si vous obtenez la skill via un plugin, mettez plutôt à jour le plugin.

<div id="ask-your-agent-to-customize-your-site">
  ## Demander à votre agent de personnaliser votre site
</div>

Décrivez le résultat souhaité, votre thème et les pages ou composants concernés. Par exemple :

```text
Use mintlify to make the left sidebar 320px wide on desktop in the mint theme.
Keep the content and footer aligned, and check at 1024px and 1440px.
```

```text
Use mintlify to set body text to 17px with a 1.6 line height and widen
the content column to 768px on large screens.
```

```text
Use mintlify to review my styles.css and replace selectors that depend on
generated class names with stable IDs or data attributes.
```

```text
Use mintlify to hide breadcrumbs in search results.
```

La skill privilégie la [configuration](/fr/organize/settings), les [props de composants](/fr/components/index) et les [composants React](/fr/customize/react-components) plutôt que le CSS ou le JavaScript globaux.
