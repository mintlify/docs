<Info>
  Les analytics d'économies nécessitent un [plan Enterprise](https://mintlify.com/pricing?ref=analytics).
</Info>

La vue **Économies** de la page [analytics](https://app.mintlify.com/analytics) estime la quantité de travail que Mintlify fait économiser à votre équipe. Elle affiche les heures économisées grâce à l'agent et aux automatisations, ainsi que les coûts de support évités lorsque l'assistant répond aux questions des utilisateurs.

Utilisez la vue Économies pour :

- **Rendre compte du retour sur investissement** : Partagez les heures et les montants économisés estimés avec les parties prenantes.
- **Comparer la valeur des automatisations** : Identifiez les types de travail automatisé qui contribuent le plus aux gains de temps.

<div id="time-saved">
  ## Temps économisé
</div>

Le graphique **Temps économisé (heures)** répartit les heures économisées estimées en quatre catégories.

- **Agent Slack** : Pull requests que l'[agent ouvre depuis Slack](/fr/agent/slack).
- **Automatisations de contenu auto-mis à jour** : Pull requests issues des [automatisations de contenu auto-mis à jour](/fr/automations/reference#self-updating-content-automations), comme Mettre à jour à partir des modifications de code et Brouillon de changelog.
- **Automatisations de maintenance** : Pull requests issues des [automatisations de maintenance](/fr/automations/reference#maintenance-automations), comme Traduire le contenu et Corriger les liens cassés.
- **Automatisations personnalisées** : Pull requests issues des [automatisations personnalisées](/fr/automations/create).

Mintlify ne comptabilise que les pull requests fusionnées qui ont été ouvertes pour la première fois pendant la plage de temps sélectionnée. Chaque pull request ajoute des heures en fonction du nombre de lignes modifiées.

| Lignes modifiées | Heures économisées |
| :--------------- | :----------------- |
| Moins de 20      | 0.5                |
| De 20 à 99       | 2                  |
| 100 ou plus      | 5                  |

Lorsque le nombre de lignes d'une pull request n'est pas disponible, Mintlify utilise une estimation par défaut.

<div id="money-saved">
  ## Argent économisé
</div>

La carte **Argent économisé** affiche deux métriques.

- **Argent économisé** : Coût de support évité estimé, calculé à 12 $ pour chaque question à laquelle l'assistant répond, sur la base du coût moyen des tickets de support tous secteurs confondus.
- **Questions répondues par l'assistant** : Nombre de conversations avec l'[assistant](/fr/analytics/assistant) pendant la plage de temps sélectionnée auxquelles l'assistant a répondu sans rediriger l'utilisateur vers l'équipe commerciale ou le support.
