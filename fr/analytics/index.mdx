<Info>
  Les analytics nécessitent un [plan Pro ou Enterprise](https://mintlify.com/pricing?ref=analytics).
</Info>

La page [analytics](https://app.mintlify.com/analytics) de votre dashboard montre comment les visiteurs trouvent et utilisent votre documentation. Utilisez ces signaux pour identifier les pages précieuses, découvrir les lacunes de contenu et suivre les évolutions dans le temps.

Les données analytics apparaissent généralement quelques minutes après une interaction. Les événements très récents peuvent ne pas apparaître immédiatement.
