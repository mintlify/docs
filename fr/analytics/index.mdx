<Info>
  Les analytics nécessitent un [plan Pro ou Enterprise](https://mintlify.com/pricing?ref=analytics).
</Info>

La page [analytics](https://app.mintlify.com/analytics) de votre dashboard montre comment les visiteurs et les agents trouvent et utilisent votre documentation. Utilisez ces signaux pour identifier les pages précieuses, découvrir les lacunes de contenu et suivre les évolutions dans le temps.

<Tip>
  Posez des questions à l'[agent](/fr/editor/agent#ask-about-your-analytics) sur vos données analytics directement dans le panneau de chat. L'agent peut répondre à vos questions sur les données et fournir des recommandations pour améliorer votre documentation.
</Tip>

Les données analytics apparaissent généralement quelques minutes après une interaction. Les événements très récents peuvent ne pas apparaître immédiatement.

<div id="filter-by-time-period">
  ## Filtrer par période
</div>

Utilisez le sélecteur de plage dans une vue analytics pour ajuster la période des données affichées. Choisissez une plage prédéfinie, comme **Last 7 days** ou **All time**, ou sélectionnez une plage personnalisée dans le calendrier. Les exports utilisent également la plage de temps sélectionnée.

<div id="filter-by-page-or-path">
  ## Filtrer par page ou par chemin
</div>

Utilisez le menu **Filter** pour restreindre le tableau de bord à une seule page ou à un chemin. Lorsque vous sélectionnez un chemin, la page analytics affiche les données de chaque page située sous ce chemin. Par exemple, si vous filtrez sur `docs/authentication`, la page analytics affiche les données de toutes les pages du chemin `docs/authentication/*`. Les vues Assistant et Search affichent toujours les données de l'ensemble du site.

Dans la vue Traffic, filtrer par page modifie le classement des pages populaires pour qu'il commence à la page sélectionnée et se poursuive vers le bas du classement, plutôt que d'afficher uniquement cette page.
