<Info>
  Les analytics nécessitent un [plan Pro ou Enterprise](https://mintlify.com/pricing?ref=analytics).
</Info>

Exportez les catégories d'analytics au format CSV pour une analyse plus approfondie, du reporting ou de l'archivage. Les exports utilisent la plage de temps sélectionnée sur la page [analytics](https://app.mintlify.com/analytics).

1. Sélectionnez **Export to CSV**.
2. Sélectionnez une catégorie à exporter : trafic, référents, conversations avec l'assistant, recherches ou retours.
3. Attendez que Mintlify vous envoie un lien de téléchargement par e-mail.

<div id="interpret-traffic-exports">
  ## Interpréter les exports de trafic
</div>

Les exports de trafic ventilent les pages vues par catégorie de visiteur, afin que vous puissiez comparer le trafic des humains, des agents, des crawlers de recherche et des autres bots.

| Colonne | Description |
| --- | --- |
| `humanViews` | Pages vues HTML provenant d'un trafic non-bot. |
| `aiViews` | Vues provenant d'agents IA tels que ChatGPT, Claude et Cursor, ainsi que les récupérations de pages Markdown par des clients qui ne sont pas des crawlers reconnus. |
| `searchIndexViews` | Vues provenant des crawlers de recherche et d'indexation, tels que Googlebot, Bingbot et OAI-SearchBot. |
| `trainingViews` | Vues provenant de crawlers qui collectent du contenu pour l'entraînement de modèles IA, tels que GPTBot, ClaudeBot et CCBot. |
| `otherAiViews` | Vues provenant d'autres bots liés à l'IA qui n'entrent pas dans les catégories précédentes. |
| `totalViews` | La somme de `humanViews` et de `aiViews`. |

Mintlify classe chaque vue à l'aide de schémas connus de user-agents pour les crawlers de recherche, les crawlers d'entraînement et les assistants IA. Les catégories sont mutuellement exclusives, donc chaque vue compte pour exactement une colonne.

<Note>
  `searchIndexViews`, `trainingViews` et `otherAiViews` ne comptent pas dans `totalViews`.
</Note>

<div id="interpret-assistant-exports">
  ## Interpréter les exports de l'assistant
</div>

Les exports de l'assistant incluent les requêtes, les réponses, les sources et une colonne `resolutionStatus`. Cette colonne indique si l'assistant a répondu avec succès à chaque question avec la valeur `answered` ou `unanswered`. Utilisez-la pour identifier les lacunes de la documentation révélées par les questions que l'assistant n'a pas pu résoudre.

<Tip>
  Exemples de prompts d'analyse pour les exports de l'assistant :

  - Lister toutes les requêtes pour lesquelles aucune source n'a été citée.
  - Trouver des schémas dans les interactions infructueuses.
  - Regrouper les requêtes sans réponse par sujet afin de prioriser les mises à jour de contenu.
</Tip>
