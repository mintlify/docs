Vous avez besoin d'une write key provenant d'une source d'événements Hightouch avant de pouvoir connecter Hightouch. Créez une source d'événements dans votre espace de travail Hightouch et copiez sa write key. Consultez la [documentation des sources d'événements de Hightouch](https://hightouch.com/docs/events/sources/overview) pour les étapes de configuration.

Ajoutez la write key à votre fichier `docs.json` pour envoyer des Analytics à Hightouch.

<Info>

  N'incluez pas `https://` pour `apiHost`.

</Info>

<CodeGroup>

```json Options d'Analytics dans docs.json
"integrations": {
    "hightouch": {
        "writeKey": "required",
        "apiHost": "optional"
    }
}
```

```json Exemple
"integrations": {
    "hightouch": {
        "writeKey": "9132c81do371p76sr11da0075469b54f77649c9a067dp0303p56q0q64n072336",
        "apiHost": "us-east-1.hightouch-events.com"
    }
}
```

</CodeGroup>

<div id="configuration-options">
  ## Options de configuration
</div>

<ParamField path="writeKey" type="string" required>
  La write key de votre source d'événements Hightouch.
</ParamField>

<ParamField path="apiHost" type="string">
  L'hôte de l'API d'événements Hightouch, sans `https://`. La valeur par défaut est `us-east-1.hightouch-events.com`.
</ParamField>

<div id="verify-the-integration">
  ## Vérifier l'intégration
</div>

Après le déploiement de vos modifications, Mintlify envoie à Hightouch des événements d'engagement, comme les vues de page et les requêtes de recherche. Pour confirmer que les événements arrivent, inspectez les événements en direct dans le [débogueur d'événements de Hightouch](https://hightouch.com/docs/events/sources/overview#debugger).

Pour un aperçu des événements suivis par Mintlify, consultez [Intégrations d'Analytics](/fr/integrations/analytics/overview).
