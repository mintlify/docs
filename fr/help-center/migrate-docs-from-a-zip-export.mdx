Mintlify n'a pas de fonctionnalité directe d'« import ZIP ». Mintlify construit votre site à partir des fichiers d'un dépôt Git, donc migrer depuis un export ZIP consiste à convertir les fichiers exportés en pages Markdown ou MDX dans votre dépôt de documentation. Le bon chemin dépend de la plateforme qui a produit le ZIP.

<div id="if-the-zip-came-from-document360">
## Si le ZIP provient de Document360
</div>

Suivez le [guide de migration Document360](/fr/migration/document360) dédié. Il explique comment exporter chaque espace de travail et chaque langue sous forme de ZIP de projet, puis convertir les articles, catégories, médias et contenus réutilisables.

<div id="if-the-zip-came-from-readme">
## Si le ZIP provient de ReadMe
</div>

Suivez le [guide de migration ReadMe](/fr/migration/readme) dédié. Il couvre la structure d'un export ZIP ReadMe, y compris les guides, recettes, pages personnalisées et fichiers OpenAPI. Notez que les exports ZIP de ReadMe référencent les images hébergées par URL au lieu d'inclure les fichiers d'images, donc téléchargez ces ressources séparément.

<div id="if-the-zip-came-from-another-platform">
## Si le ZIP provient d'une autre plateforme
</div>

Utilisez le [flux de migration manuelle](/fr/migration/manual) :

1. Décompressez l'export et conservez le ZIP d'origine inchangé comme instantané source. Effectuez le travail de conversion dans une copie.
2. Créez un inventaire des pages avec la source, le chemin de destination et le statut de migration de chaque page.
3. Convertissez le contenu exporté en Markdown, HTML ou JSON en pages MDX.
4. Recréez votre navigation dans `docs.json` et vérifiez les pages pour repérer la syntaxe résiduelle de la plateforme source.

Si le site source est aussi accessible publiquement, le scraping peut être plus rapide que la conversion des fichiers exportés. Consultez [Convertir des pages individuelles](/fr/migration/index#scrape-individual-pages).

<div id="exporting-your-mintlify-docs-as-a-zip">
## Exporter votre documentation Mintlify en ZIP
</div>

Si vous cherchez la direction inverse, une archive ZIP de votre documentation Mintlify publiée pour une consultation hors ligne ou une diffusion privée, utilisez `mint export`. Consultez [Export hors ligne](/fr/deploy/export).
