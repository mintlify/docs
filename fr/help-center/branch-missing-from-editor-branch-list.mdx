Si une branche qui existe dans votre dépôt n'apparaît pas dans la liste déroulante des branches de l'éditeur web, la branche n'est pas supprimée. La liste déroulante ne répertorie volontairement que :

- Les branches créées dans l'éditeur web qui n'ont pas de pull request fusionnée ou fermée.
- Les branches ayant une pull request ou merge request ouverte ciblant votre branche de déploiement.

Ces branches n'apparaissent pas dans la liste déroulante :

- Les branches poussées directement vers GitHub, GitLab ou Bitbucket sans pull request ouverte.
- Les branches dont la pull request a été fusionnée ou fermée, y compris les branches créées dans l'éditeur web. Une branche quitte la liste déroulante lorsque sa pull request est fusionnée, même si la branche existe toujours dans votre dépôt.
- Les branches dont la pull request cible une branche autre que votre branche de déploiement.
- Les branches dont la pull request a été ouverte depuis un fork. Consultez [Déploiement de prévisualisation non créé pour une branche de fork](/fr/help-center/preview-deployment-not-created-for-fork-branch) pour les limitations liées aux forks.

Votre travail sur ces branches est en sécurité dans votre dépôt. Vous pouvez le vérifier en affichant la branche chez votre fournisseur Git.

<div id="open-a-branch-that-isnt-listed">
  ## Ouvrir une branche qui n'est pas listée
</div>

Ouvrez une pull request ou une merge request pour la branche vers votre branche de déploiement, depuis une branche du même dépôt plutôt que depuis un fork. La branche apparaît alors dans la liste déroulante des branches de l'éditeur avec une prise en charge complète de l'éditeur.

Si vous devez consulter ou modifier la branche avant d'ouvrir une pull request, ouvrez n'importe quelle branche dans l'éditeur, puis remplacez le nom de la branche dans l'URL de votre navigateur par le nom de la branche souhaitée. L'éditeur charge cette branche, mais les fonctionnalités propres aux branches restent indisponibles tant qu'une pull request n'existe pas : les commits automatiques sont ignorés, la vue de relecture ne peut pas charger de diff, et vous ne pouvez pas renommer ni supprimer la branche depuis l'éditeur.

Pour en savoir plus sur la création et le changement de branches, consultez [Travailler avec des branches](/fr/guides/branches).
