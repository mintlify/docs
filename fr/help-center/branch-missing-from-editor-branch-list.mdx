Si une branche qui existe dans votre référentiel n’apparaît pas dans la liste déroulante des branches de l’éditeur web, la branche n’a pas été supprimée. La liste déroulante n’affiche intentionnellement que :

- Les branches créées dans l’éditeur web.
- Les branches ayant une pull request ou une merge request ouverte ciblant votre branche de déploiement.

Les branches poussées directement vers GitHub, GitLab ou Bitbucket sans pull request ouverte n’apparaissent pas dans la liste. Votre travail sur ces branches est en sécurité dans votre référentiel. Vous pouvez le vérifier en consultant la branche chez votre fournisseur Git.

<div id="open-a-branch-that-isnt-listed">
  ## Ouvrir une branche qui n’est pas listée
</div>

Utilisez l’une de ces approches :

- **Ouvrez une pull request ou une merge request** pour la branche vers votre branche de déploiement chez votre fournisseur Git. La branche apparaît alors dans la liste déroulante des branches de l’éditeur.
- **Modifiez l’URL de l’éditeur.** Ouvrez n’importe quelle branche dans l’éditeur, puis remplacez le nom de la branche dans l’URL de votre navigateur par le nom de la branche souhaitée. L’éditeur charge directement cette branche.

Pour en savoir plus sur la création et le changement de branches, consultez [Travailler avec les branches](/fr/guides/branches).
