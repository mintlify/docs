Si vous ne voyez pas du tout la liste déroulante des branches dans la barre d'outils de l'éditeur, elle est peut-être masquée par une préférence personnelle. Consultez [Afficher le sélecteur de branche](/fr/editor/publish#show-the-branch-selector).

Si une branche qui existe dans votre dépôt n'apparaît pas dans la liste déroulante des branches de l'éditeur web, la branche n'est pas supprimée. Avant que vous saisissiez une recherche, la liste déroulante ne répertorie volontairement que :

- Les branches créées dans l'éditeur web qui n'ont pas de pull request fusionnée ou fermée.
- Les branches ayant une pull request ou merge request ouverte ciblant votre branche de déploiement.

<div id="find-a-branch-with-search">
  ## Trouver une branche avec la recherche
</div>

Saisissez du texte dans le champ de recherche de la liste déroulante pour trouver les branches absentes de la liste par défaut :

- Les branches poussées directement vers GitHub, GitLab ou Bitbucket sans pull request apparaissent lorsque votre recherche correspond à une partie du nom de la branche. Ces lignes affichent uniquement le nom de la branche, sans état de pull request ni contributeurs.
- Les branches dont la pull request a été fusionnée ou fermée apparaissent lorsque votre recherche correspond au nom de la branche ou au titre de la pull request.

Les branches ayant une pull request ouverte depuis un fork n'apparaissent toujours pas, car la branche se trouve dans le fork et non dans votre dépôt. Consultez [Déploiement de prévisualisation non créé pour une branche de fork](/fr/help-center/preview-deployment-not-created-for-fork-branch) pour les limitations liées aux forks.

<div id="work-with-a-branch-that-has-no-pull-request">
  ## Travailler avec une branche sans pull request
</div>

Vous pouvez ouvrir une branche sans pull request en la recherchant dans la liste déroulante puis en la sélectionnant. Tant qu'aucune pull request ciblant votre branche de déploiement n'existe, les fonctionnalités de l'éditeur propres aux branches sont indisponibles : les commits automatiques sont ignorés, la vue de révision ne peut pas charger de diff et vous ne pouvez ni renommer ni supprimer la branche depuis l'éditeur.

Ouvrez une pull request ou merge request pour la branche contre votre branche de déploiement, depuis une branche du même dépôt et non depuis un fork. La branche apparaît alors dans la liste déroulante des branches de l'éditeur avec la prise en charge complète de l'éditeur.

Pour en savoir plus sur la création et le changement de branches, consultez [Travailler avec les branches](/fr/guides/branches).
