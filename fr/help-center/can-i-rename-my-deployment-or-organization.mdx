Certains noms dans Mintlify peuvent être modifiés à tout moment, tandis que d'autres sont fixés à la création :

- **Modifiables** : le nom de votre organisation, le nom de votre projet, le nom de votre site de documentation dans `docs.json` et votre domaine personnalisé.
- **Fixes** : le sous-domaine de votre projet et le slug de votre organisation. Modifier l'un ou l'autre nécessite de supprimer puis de recréer.

<div id="rename-your-project">
## Renommer votre projet
</div>

Le nom du projet est le nom d'affichage de votre projet dans le tableau de bord. Pour le modifier :

1. Accédez à la page des [paramètres généraux](https://app.mintlify.com/settings/project/general) de votre tableau de bord.
2. Dans le champ **Project name**, saisissez le nouveau nom. Les noms doivent comporter de 3 à 100 caractères et ne contenir que des lettres, des chiffres, des tirets et des tirets bas.
3. Enregistrez vos modifications.

Renommer le projet nécessite l'autorisation de mettre à jour le projet. Si le champ est désactivé, contactez un admin de votre organisation. Consultez [Rôles et autorisations](/fr/dashboard/roles).

<div id="change-your-projects-subdomain">
## Changer le sous-domaine de votre projet
</div>

Votre sous-domaine identifie votre projet. Il apparaît dans votre URL `<subdomain>.mintlify.app` et dans l'URL de votre tableau de bord, `app.mintlify.com/<org>/<subdomain>`. Le sous-domaine ne peut pas être modifié après la création du projet.

Pour utiliser un autre sous-domaine, créez un nouveau projet avec le nom souhaité, puis supprimez l'ancien :

1. Créez un nouveau projet connecté au même dépôt.
2. Si vous utilisez un domaine personnalisé, retirez-le de l'ancien projet, puis ajoutez-le au nouveau. Consultez [Domaine personnalisé](/fr/customize/custom-domain).
3. Supprimez l'ancien projet depuis la section **Zone de danger** de la page de paramètres [Organisation](https://app.mintlify.com/settings/organization/general). Consultez [Supprimer un projet](/fr/deploy/deployments#delete-a-project).

<Warning>
  La suppression d'un projet est définitive et efface toutes les données du projet, y compris l'historique des analytics et les déploiements de prévisualisation associés. Les paramètres du tableau de bord ne sont pas transférés vers le nouveau projet ; reconfigurez-les après sa création.
</Warning>

<div id="rename-your-organization">
## Renommer votre organisation
</div>

Le nom de l'organisation est le nom d'affichage du workspace visible dans le tableau de bord. Pour le modifier :

1. Accédez à la page des [paramètres généraux de l'organisation](https://app.mintlify.com/settings/organization/general) de votre tableau de bord.
2. Dans le champ **Name** sous **Workspace**, saisissez le nouveau nom.
3. Sélectionnez **Save**.

Renommer l'organisation nécessite l'autorisation de mettre à jour l'organisation. Si le champ est désactivé, contactez un admin de votre organisation. Consultez [Rôles et autorisations](/fr/dashboard/roles).

<div id="change-your-organizations-slug">
## Changer le slug de votre organisation
</div>

Le slug de votre organisation est l'identifiant unique qui apparaît dans l'URL de votre tableau de bord, `app.mintlify.com/<org>/<subdomain>`. Le slug ne peut pas être modifié après la création de l'organisation. Pour utiliser un autre slug, créez une nouvelle organisation, recréez-y vos projets, puis supprimez l'ancienne organisation depuis la section **Zone de danger** de la page de paramètres [Organisation](https://app.mintlify.com/settings/organization/general). La suppression d'une organisation est irréversible et nécessite le [rôle admin](/fr/dashboard/roles).

<div id="what-your-readers-see">
## Ce que voient vos lecteurs
</div>

Votre sous-domaine et le nom de votre organisation sont rarement visibles par les lecteurs, il se peut donc que vous n'ayez rien à renommer :

- Le nom du site affiché sur votre documentation provient du [champ `name`](/fr/organize/settings-reference#name) dans `docs.json`. Vous pouvez le modifier à tout moment.
- L'URL visitée par les lecteurs peut être un [domaine personnalisé](/fr/customize/custom-domain) comme `docs.example.com`, que vous pouvez ajouter ou modifier à tout moment.
