La prop `title` des composants [Accordion](/fr/components/accordions), [Card](/fr/components/cards), [Step](/fr/components/steps), [Tab](/fr/components/tabs), [Tile](/fr/components/tiles) et [Color.Row](/fr/components/color) prend en charge un ensemble limité de Markdown en ligne. Écrivez la syntaxe Markdown directement dans la chaîne `title` et Mintlify la rend sous forme de texte mis en forme.

<div id="supported-formatting">
  ## Mise en forme prise en charge
</div>

- Gras : `**text**`
- Italique : `*text*` ou `_text_`
- Barré : `~~text~~`
- Code en ligne : `` `text` ``
- Liens : `[text](https://example.com)`

```mdx Example
<AccordionGroup>
  <Accordion title="Edit the `docs.json` file">
    Inline code renders in the accordion title.
  </Accordion>
  <Accordion title="**Required:** set your API key">
    Bold text renders in the accordion title.
  </Accordion>
</AccordionGroup>
```

<div id="limitations">
  ## Limitations
</div>

- Les liens dans les titres sont rendus comme du texte de libellé stylisé, et non comme des liens cliquables. Cela évite d'imbriquer un lien dans un titre déjà interactif.
- Le Markdown de niveau bloc, les images, le HTML brut et les composants MDX dans les titres sont rendus comme du texte littéral.
- Le soulignement n'est pas pris en charge.

<div id="how-formatted-titles-affect-ids-and-navigation">
  ## Effet des titres mis en forme sur les ID et la navigation
</div>

Les ID d'ancrage, les entrées de la table des matières et la synchronisation des onglets utilisent le texte brut du titre, sans les caractères de mise en forme. Par exemple, un onglet intitulé `**npm**` se synchronise avec un onglet intitulé `npm`, car les deux se résolvent en le même texte brut.
