Lorsque vous créez un second déploiement Mintlify depuis le même dépôt GitHub privé qui héberge déjà un déploiement existant, le sélecteur de dépôts de l'onboarding peut ne pas afficher ce dépôt privé. Cela vient du fait que votre autorisation GitHub initiale n'a accordé que le scope `public_repo`, et qu'en revenant à l'onboarding l'autorisation existante est réutilisée au lieu de redemander l'accès aux dépôts privés.

Vous pouvez créer des déploiements distincts depuis un même dépôt. Mintlify n'exige pas un nouveau dépôt par déploiement. Pour regrouper plusieurs dépôts dans un même site, consultez [Configuration multi-repo](/fr/deploy/multi-repo).

## Réautoriser avec l'accès aux dépôts privés

Ouvrez cette URL pendant que vous êtes connecté au dashboard Mintlify :

```
https://app.mintlify.com/api/onboarding/github/authorize?private=true
```

Le paramètre de requête `?private=true` demande le scope `repo` de GitHub, qui accorde l'accès aux dépôts privés. GitHub vous demande d'autoriser le scope supplémentaire, puis vous renvoie vers le dashboard.

Après avoir réautorisé :

1. Revenez au flux d'onboarding de votre nouveau déploiement.
2. Rouvrez le sélecteur de dépôts. Votre dépôt privé est désormais sélectionnable.
3. Poursuivez l'onboarding pour terminer la création du second déploiement.

## Si le dépôt n'apparaît toujours pas

Si le sélecteur ne liste toujours pas le dépôt après la réautorisation, l'installation de la GitHub App Mintlify sur l'organisation de ce dépôt peut nécessiter une mise à jour pour l'inclure :

1. Ouvrez les [paramètres de la GitHub App](https://github.com/apps/mintlify/installations/new) et sélectionnez l'organisation propriétaire du dépôt.
2. Sous **Repository access**, sélectionnez **All repositories** ou ajoutez le dépôt spécifique sous **Only select repositories**.
3. Enregistrez la modification et rouvrez le sélecteur de dépôts.

Pour une réinitialisation complète de la connexion à la GitHub App, consultez [Problèmes de connexion à la GitHub App](/fr/deploy/github#github-app-connection-issues).
