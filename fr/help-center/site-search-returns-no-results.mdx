Si la recherche intégrée de votre site de documentation Mintlify ne renvoie aucun résultat, quelle que soit la requête, y compris les titres exacts de pages, vos pages sont probablement exclues de l'index de recherche par un paramètre `hidden` dans votre `docs.json`.

<div id="check-for-hidden-true-on-a-version-or-other-top-level-navigation-element">
## Vérifier la présence de `hidden: true` sur une version ou un autre élément de navigation de premier niveau
</div>

Définir `hidden: true` sur une version, une ancre, un menu déroulant, une langue ou un produit dans votre `docs.json` exclut chaque page qu'il contient de l'index de recherche. Si cet élément contient toutes vos pages, par exemple votre seule version, l'index de recherche devient vide et chaque recherche ne renvoie rien. Le site lui-même continue de fonctionner, car les pages masquées restent accessibles par URL directe.

```json Example: this hides every page from search
"navigation": {
  "versions": [
    {
      "version": "v1",
      "hidden": true,
      "groups": [...]
    }
  ]
}
```

Pour corriger le problème, choisissez l'une des options suivantes :

- Retirez `hidden: true` de la version ou de l'autre élément.
- Gardez l'élément masqué dans la navigation, mais réintégrez ses pages dans la recherche et l'indexation en définissant `seo.indexing: "all"` dans votre `docs.json` :

  ```json
  "seo": {
    "indexing": "all"
  }
  ```

Contrairement aux onglets et aux groupes, les versions et les autres éléments de navigation de premier niveau ne prennent pas en charge l'option `searchable: true`. Consultez [Pages masquées](/fr/organize/hidden-pages#search-seo-and-ai-indexing) pour le comportement complet de visibilité et d'indexation de chaque emplacement de `hidden`.

La recherche se réindexe lorsque votre site est reconstruit ; poussez donc la modification de `docs.json` et attendez la fin du déploiement avant de tester à nouveau.

<div id="other-causes">
## Autres causes
</div>

- **Onglets ou groupes masqués** : `hidden: true` sur un onglet ou un groupe exclut également ses pages de la recherche. Pour les onglets et les groupes, vous pouvez ajouter `searchable: true` en plus de `hidden: true` pour garder les pages descendantes accessibles à la recherche. Consultez [Inclure les pages situées sous des onglets ou groupes masqués spécifiques](/fr/organize/hidden-pages#include-pages-under-specific-hidden-tabs-or-groups).
- **Pages absentes de la navigation** : les pages qui ne figurent pas dans la navigation de votre `docs.json` sont exclues de la recherche par défaut.
- **Frontmatter de la page** : `hidden: true`, `noindex: true` ou `searchable: false` dans le frontmatter d'une page excluent chacun cette page de la recherche du site.
