Par défaut, le tableau de bord Mintlify s'ouvre sur **Home**, qui correspond à l'éditeur web. Vous pouvez choisir une autre page de démarrage pour que le tableau de bord s'ouvre là où vous travaillez le plus souvent, par exemple **Analytics** ou **Activity**.

Votre page de démarrage est une préférence personnelle. Elle s'applique à chaque projet que vous ouvrez et ne modifie pas ce que voient les autres membres de votre organisation.

<div id="set-your-starting-page">
## Définir votre page de démarrage
</div>

1. Accédez à la page [My profile](https://app.mintlify.com/settings/account) du tableau de bord.
2. Dans la section **Preferences**, sélectionnez une page dans le menu **Starting page** :
   - **Home**
   - **Activity**
   - **Analytics**
   - **Automations**

Mintlify enregistre votre choix immédiatement. Si l'enregistrement échoue, le tableau de bord affiche une erreur et conserve votre choix précédent.

<div id="when-your-starting-page-applies">
## Quand votre page de démarrage s'applique
</div>

Mintlify utilise votre page de démarrage lorsque vous ouvrez le tableau de bord ou la racine d'un projet, comme `https://app.mintlify.com/{organization}/{project}`. Ouvrir la racine d'un projet vous amène à la page de démarrage de ce projet.

Les liens vers une page, un document ou une branche spécifique ouvrent toujours cette destination. Sélectionner **Home** dans la barre latérale ouvre toujours l'éditeur.

Si votre page de démarrage n'est pas disponible pour un projet, le tableau de bord ouvre **Home** à la place. Si l'éditeur n'est pas disponible non plus, le tableau de bord ouvre **Activity**.
