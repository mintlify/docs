Si votre organisation a configuré le [SSO](/fr/dashboard/sso) ou le [SCIM](/fr/dashboard/scim) avant que le portail d'administration ne soit disponible, un admin doit reconnecter votre fournisseur d'identité via le portail d'administration. Votre configuration SSO actuelle continue de fonctionner jusqu'à la bascule de votre organisation. Le SCIM configuré avant le portail d'administration n'ajoute ni ne supprime plus de membres : reconnectez donc le SCIM dès que possible pour que les membres restent synchronisés avec votre fournisseur d'identité.

<div id="reconnect-your-identity-provider">
## Reconnecter votre fournisseur d'identité
</div>

1. Dans le portail d'administration, suivez les étapes correspondant à votre fournisseur d'identité.
2. Ajoutez la nouvelle connexion en tant que nouvelle application dans votre fournisseur d'identité. Conservez votre application Mintlify existante afin que les membres puissent continuer à se connecter jusqu'à la bascule de votre organisation.

<div id="when-your-organization-switches-over">
## Lors de la bascule de votre organisation
</div>

Lors de la bascule de votre organisation, Mintlify déconnecte tous les membres du tableau de bord. Les membres se reconnectent via votre fournisseur d'identité.

Après la bascule, supprimez l'ancienne application Mintlify de votre fournisseur d'identité.
