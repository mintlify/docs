Si votre organisation a configuré le [SSO](/fr/dashboard/sso) ou le [SCIM](/fr/dashboard/scim) avant que le portail d'administration ne soit disponible, un admin doit reconnecter votre fournisseur d'identité avant le 20 novembre 2026. Votre configuration actuelle continue de fonctionner d'ici là.

Lorsque votre organisation doit se reconnecter, le tableau de bord affiche une bannière qui indique ce qu'il faut reconnecter : le SSO, le SCIM ou les deux.

<div id="reconnect-your-identity-provider">
## Reconnecter votre fournisseur d'identité
</div>

1. Dans la bannière, cliquez sur **Set up now**. Seuls les membres autorisés à gérer le SSO voient ce bouton.
2. Dans le portail d'administration, suivez les étapes correspondant à votre fournisseur d'identité.
3. Ajoutez la nouvelle connexion en tant que nouvelle application dans votre fournisseur d'identité. Conservez votre application Mintlify existante afin que les membres puissent continuer à se connecter jusqu'à la bascule de votre organisation.

**Set up now** ouvre une étape du portail d'administration à la fois. Si vous reconnectez le SSO et que votre organisation n'a pas de domaine vérifié, la première étape est la vérification du domaine. Viennent ensuite le SSO, puis le SCIM. Une fois une étape terminée, cliquez à nouveau sur **Set up now** pour lancer la suivante.

Si le SSO et le SCIM sont déjà reconnectés, Mintlify affiche **SSO and SCIM are already set up.** au lieu d'ouvrir le portail d'administration.

<div id="when-your-organization-switches-over">
## Lors de la bascule de votre organisation
</div>

Lors de la bascule de votre organisation, Mintlify déconnecte tous les membres du tableau de bord. Les membres se reconnectent via votre fournisseur d'identité.

Après la bascule, supprimez l'ancienne application Mintlify de votre fournisseur d'identité.
