---
title: "Corriger l'erreur \"Must be a valid url\" pour logo.href ou navbar.primary.href"
description: "Résolvez les erreurs de validation de docs.json lorsque vous utilisez un chemin relatif comme /contact dans logo.href, navbar.links ou navbar.primary.href."
keywords: ["Must be a valid url", "Invalid docs.json", "logo.href", "navbar.primary.href", "navbar.links", "relative path", "mint dev error"]
---

Vous pouvez utiliser un chemin relatif comme `/contact` dans les champs `logo.href`, `navbar.links[].href` ou `navbar.primary.href` de `docs.json`. Si vous exécutez `mint dev` ou `mint validate` avec une version obsolète de la CLI, elle signale des erreurs comme celles-ci :

```text
🚨 Invalid docs.json:
#.logo.href: Must be a valid url
#.navbar.primary.href: Must be a valid url
```

Les versions actuelles de la CLI Mintlify acceptent à la fois les URL absolues et les chemins relatifs commençant par `/` dans ces champs. Les chemins relatifs permettent aux liens de fonctionner sur les déploiements de prévisualisation, les domaines personnalisés et les prévisualisations locales, sans coder en dur votre domaine de production.

<div id="update-the-cli">
  ## Mettre à jour la CLI
</div>

Mettez à jour la CLI vers la dernière version :

```bash
mint update
```

Si `mint update` n'est pas disponible dans votre version, réinstallez la CLI. Consultez [Installer la CLI](/fr/cli/install#update) pour les commandes de réinstallation.

Ensuite, vérifiez votre version et relancez la validation :

```bash
mint version
mint validate
```

<div id="example-configuration">
  ## Exemple de configuration
</div>

```json docs.json
"logo": {
  "light": "/logo/light.svg",
  "dark": "/logo/dark.svg",
  "href": "/quickstart"
},
"navbar": {
  "links": [
    { "label": "Changelog", "href": "/changelog" }
  ],
  "primary": {
    "type": "button",
    "label": "Contact us",
    "href": "/contact"
  }
}
```

Les chemins relatifs doivent commencer par `/`. Une valeur comme `contact` sans barre oblique initiale échoue toujours à la validation. Les types de bouton `github` et `discord` nécessitent toujours une URL de dépôt GitHub ou une URL d'invitation Discord.

Pour la référence complète des champs, consultez [`logo`](/fr/organize/settings-appearance#logo) et [`navbar`](/fr/organize/settings-structure#navbar).
