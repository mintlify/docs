Si un composant React que vous avez écrit vous-même apparaît un instant après le chargement du reste d'une page Mintlify, ou si son contenu est absent lorsque vous affichez le code source de la page, il s'agit du comportement attendu. Mintlify affiche les composants personnalisés uniquement dans le navigateur.

<div id="why-custom-components-are-not-in-the-initial-html">
  ## Pourquoi les composants personnalisés ne figurent pas dans le HTML initial
</div>

Les composants personnalisés s'exécutent uniquement dans le navigateur. Le HTML rendu côté serveur omet les composants que vous définissez avec `export` dans un fichier MDX et les composants que vous importez par leur nom depuis un snippet, comme `import { MyComponent } from "/snippets/my-component.jsx"`. Après le chargement de la page, le navigateur affiche ces composants à leur emplacement.

Les snippets MDX que vous importez en tant que contenu, comme `import MySnippet from "/snippets/my-snippet.mdx"`, sont rendus côté serveur comme le reste de la page.

Par conséquent :

- Le code source de la page et le HTML initial n'incluent pas le contenu du composant.
- Les visiteurs peuvent voir le composant apparaître soudainement ou décaler la mise en page après l'affichage du reste de la page.
- Les moteurs de recherche peuvent ne pas indexer complètement le contenu du composant.

<div id="use-built-in-components-for-content-that-must-render-on-the-server">
  ## Utiliser des composants intégrés pour le contenu qui doit être rendu côté serveur
</div>

La plupart des [composants intégrés](/fr/components), y compris ceux ci-dessous, sont rendus côté serveur et apparaissent dans le HTML initial. Si vous utilisez un composant personnalisé pour la mise en page ou du contenu statique, remplacez-le par un composant intégré ou un [snippet MDX](/fr/create/reusable-snippets). Par exemple :

- Utilisez des [cartes](/fr/components/cards) et des [colonnes](/fr/components/columns) pour des grilles de liens ou de fonctionnalités.
- Utilisez des [onglets](/fr/components/tabs), des [accordéons](/fr/components/accordions) et des [étapes](/fr/components/steps) pour organiser le contenu.
- Utilisez des [encadrés](/fr/components/callouts) pour mettre en évidence des informations.

Réservez les composants personnalisés aux éléments interactifs qui ont besoin d'un état ou des API du navigateur. Consultez [Composants React](/fr/customize/react-components) pour savoir comment les créer et connaître les autres points à prendre en compte.
