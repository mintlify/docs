title: "Erreur 'keytar is required for credential storage' lors de mint login"
description: "Résolvez l'échec de mint login qui signale que keytar est manquant en mettant à jour la CLI Mintlify vers une version qui stocke les identifiants dans un fichier de configuration."
keywords: ["keytar", "mint login", "stockage des identifiants", "npm install keytar", "erreur d'authentification CLI", "mint login échoue"]
---

Si vous collez le code d'autorisation de `mint login` et que la CLI se termine avec :

> keytar is required for credential storage but is not installed. Install it with: npm install keytar

la version installée de la CLI Mintlify essaie d'utiliser `keytar`, un module Node natif pour accéder au trousseau du système d'exploitation. Les versions actuelles de la CLI ne dépendent pas de `keytar`. Elles enregistrent les identifiants dans `~/.config/mintlify/config.json`. Consultez [`mint login`](/fr/cli/commands#mint-login).

<div id="fix-the-error">
  ## Corriger l'erreur
</div>

Mettez la CLI à jour vers la dernière version :

<CodeGroup>
  ```bash npm
  npm i -g mint@latest
  ```

  ```bash pnpm
  pnpm add -g mint@latest
  ```
</CodeGroup>

Puis exécutez à nouveau `mint login`.

Si l'erreur persiste, vous avez probablement à la fois le package hérité `mintlify` et le package actuel `mint` installés. Supprimez `mintlify` et réinstallez `mint` :

```bash
npm uninstall -g mintlify
npm cache clean --force
npm i -g mint
```

Consultez [Installer la CLI](/fr/cli/install) pour la référence complète d'installation et de dépannage.
