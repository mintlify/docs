Si vous faites passer votre dépôt de documentation de privé à public, ou de public à privé, certaines fonctionnalités qui dépendent de Git peuvent cesser de fonctionner :

- **Edit suggestions** ou **Raise issues** n'apparaissent pas sur votre site publié.
- Les déploiements de prévisualisation ne sont pas générés pour les nouvelles pull requests.
- Les options de branche dans votre Dashboard ou dans l'éditeur semblent obsolètes.

Mintlify met en cache la visibilité et les autorisations de votre dépôt. Après un changement de visibilité, cet état en cache reste obsolète jusqu'à ce que vous revalidiez la connexion Git.

<div id="check-which-direction-the-visibility-changed">
  ## Vérifiez dans quel sens la visibilité a changé
</div>

- **De privé à public** : la revalidation rétablit les fonctionnalités concernées, y compris les suggestions de modification et la création d'issues.
- **De public à privé** : les suggestions de modification et la création d'issues ne sont disponibles que pour les dépôts publics. Elles disparaissent donc normalement. La revalidation ne les rétablit pas. Elle corrige toutefois les autres symptômes d'une connexion obsolète, comme des déploiements de prévisualisation manquants ou des options de branche périmées.

Pour en savoir plus sur les fonctionnalités de retours et leurs exigences en matière de dépôt, consultez [Retours](/fr/optimize/feedback#enable-feedback).

<div id="revalidate-your-git-connection">
  ## Revalidez votre connexion Git
</div>

1. Accédez à la page [Paramètres Git](https://app.mintlify.com/settings/project/git-settings) de votre Dashboard.
2. Appuyez sur <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>Enter</kbd> (macOS) ou <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>Enter</kbd> (Windows).

Mintlify vérifie à nouveau la visibilité et les autorisations de votre dépôt. Patientez environ une minute, puis actualisez votre site de documentation.

Si votre déploiement utilise GitLab, vous pouvez aussi cliquer sur le badge vert **Active** dans l'encadré des paramètres GitLab. Consultez [Revalider les paramètres Git](/fr/deploy/gitlab#revalidate-git-settings).

Si les fonctionnalités ne fonctionnent toujours pas après la revalidation, contactez le [support Mintlify](/fr/contact-support).
