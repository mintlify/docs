Mintlify héberge automatiquement un fichier [`llms.txt`](/fr/ai/llmstxt) à la racine de chaque site de documentation. Si `https://yourdocs.com/llms.txt` renvoie `404` alors que `https://yourdocs.com/llms-full.txt` se charge normalement, la cause la plus probable est le paramètre **Don't index project**.

<div id="check-the-dont-index-project-setting">
## Vérifier le paramètre Don't index project
</div>

Lorsque vous activez **Don't index project** sur la page [Add-ons](https://app.mintlify.com/settings/deployment/addons) de votre tableau de bord, Mintlify renvoie `404` pour `llms.txt` et `/.well-known/llms.txt`. Ce paramètre ne bloque pas `llms-full.txt`, qui reste disponible. Cette différence donne l'impression que l'absence de `llms.txt` est un bug de déploiement, alors qu'il s'agit d'un comportement configuré.

L'export Markdown de chaque page (l'URL `.md`) conserve également son pointeur vers `/llms.txt` tant que le paramètre est activé, même si cette URL renvoie `404`.

Pour rétablir `llms.txt` :

1. Ouvrez la page [Add-ons](https://app.mintlify.com/settings/deployment/addons) de votre tableau de bord.
2. Désactivez **Don't index project**.
3. Attendez la fin du redéploiement. Activer ou désactiver l'indexation redéploie votre site, et le changement prend effet une fois le redéploiement terminé.

Consultez [Désactiver l'indexation pour l'ensemble du projet](/fr/optimize/seo#disable-indexing-for-the-entire-project) pour découvrir tout ce que ce paramètre contrôle par ailleurs.

<div id="other-causes">
## Autres causes
</div>

Si **Don't index project** est désactivé et que `llms.txt` renvoie toujours `404` :

- **Authentification** : sur les sites entièrement authentifiés, `llms.txt` et `llms-full.txt` nécessitent tous deux une authentification. Les requêtes non authentifiées échouent pour les deux fichiers, pas seulement pour `llms.txt`. Consultez [llms.txt](/fr/ai/llmstxt) pour savoir comment l'authentification affecte chaque fichier.
- **Routage du reverse proxy** : si vous servez votre documentation via un reverse proxy avec une liste d'autorisation de chemins, vérifiez que le proxy transfère `/llms.txt` et `/.well-known/llms.txt`. Consultez [Reverse proxy](/fr/deploy/reverse-proxy#routing-configuration).
