<Info>
  El assistant requiere un [plan Pro o Enterprise](https://mintlify.com/pricing?ref=assistant).
</Info>

El assistant es un chat con IA en tu sitio de documentación. Los usuarios hacen preguntas en lenguaje natural y obtienen respuestas a partir de tu contenido, para que puedan tener éxito con tu producto incluso cuando no saben dónde buscar.

<div id="what-your-users-can-do-with-the-assistant">
  ## Qué pueden hacer tus usuarios con el assistant
</div>

- Obtener respuestas que citan las páginas de las que provienen, con enlaces a cada página.
- Preguntar sobre tu API y obtener métodos, parámetros, cuerpos de solicitud y esquemas de respuesta de tus especificaciones OpenAPI.
- Copiar ejemplos de código que el assistant escribe a partir de tu documentación.
- Preguntar sobre capturas de pantalla y diagramas de tus páginas.
- Añadir contexto resaltando texto, enviando un bloque de código o adjuntando archivos. El assistant también sabe en qué página está el usuario. Consulta [Añadir contexto a una pregunta](/es/assistant/use#add-context-to-a-question).
- Contactar con tu equipo por correo, tu centro de ayuda o un ticket de soporte cuando el assistant no puede responder.

<div id="how-the-assistant-answers">
  ## Cómo responde el assistant
</div>

El assistant responde solo a partir de tu documentación publicada y tus especificaciones de API, además de los [dominios de búsqueda](/es/assistant/sources#search-domains) que añadas. Si no encuentra información relevante, lo indica en lugar de adivinar. Consulta [Gestionar lo que sabe el assistant](/es/assistant/sources) para controlar qué contenido usa.
