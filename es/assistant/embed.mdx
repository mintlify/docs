<Info>
  El assistant requiere un [plan Pro o Enterprise](https://mintlify.com/pricing?ref=assistant).
</Info>

Lleva el assistant a los lugares donde tus usuarios ya trabajan, como tu aplicación, tu dashboard, tu sitio de marketing o tu portal de soporte. Responde a partir de la misma documentación que el assistant de tu sitio de documentación.

Usa la API del assistant para crear tu propia interfaz con control total sobre su apariencia y comportamiento. Autentícate con una [clave de API del assistant](https://app.mintlify.com/settings/organization/api-keys).

- Sigue [Crear un assistant en la aplicación](/es/guides/assistant-embed) para ver un ejemplo completo con Next.js.
- Consulta [Crear mensaje del assistant](/es/api/assistant/create-assistant-message) y [Buscar en la documentación](/es/api/assistant/search) para ver los endpoints.
