<Info>
  La API del asistente requiere un [plan Pro o Enterprise](https://mintlify.com/pricing?ref=assistant). Las respuestas a través de la API usan los mismos [créditos](/es/credits) que el asistente de tu sitio de documentación.
</Info>

<Warning>
  El widget alojado de Mintlify está obsoleto. Para añadir el asistente a otro sitio o aplicación, crea tu propia interfaz sobre la API del asistente.
</Warning>

El [asistente](/es/assistant) responde preguntas en tu sitio de Mintlify. Para llevar las mismas respuestas a tu panel, sitio de marketing, portal de soporte o cualquier otro lugar, crea un widget que llame a la API del asistente. Tú controlas el aspecto y el comportamiento del widget, y el asistente responde con el mismo contenido que tu sitio de documentación.

Un widget tiene tres partes:

- **Tu interfaz**: Una interfaz de chat en tu sitio o aplicación, como un botón flotante que abre un panel.
- **Una ruta de servidor**: Una ruta en tu backend que añade tu clave de la API del asistente a cada solicitud y la reenvía a Mintlify.
- **La API del asistente**: El endpoint [crear mensaje del asistente](/es/api/assistant/create-assistant-message-v2), que transmite las respuestas en el formato de mensajes de UI del [AI SDK](https://ai-sdk.dev).

Para ver un ejemplo completo con Next.js, consulta [Crea un asistente en la aplicación](/es/guides/assistant-embed).

<div id="get-an-assistant-api-key">
  ## Obtén una clave de la API del asistente
</div>

1. Ve a la página [API keys](https://app.mintlify.com/settings/organization/api-keys) de tu dashboard.
2. Haz clic en **Create Assistant API Key**.
3. Copia la clave, que empieza por `mint_dsc_`, y guárdala como variable de entorno del servidor.

<Warning>
  Mantén tu clave de la API del asistente en tu servidor. Cualquier persona que copie la clave de tu código de cliente puede usar tus créditos del asistente y leer las páginas protegidas de tu proyecto.
</Warning>

También necesitas tu nombre de dominio, que aparece al final de la URL de tu dashboard. Por ejemplo, si la URL de tu dashboard es `https://app.mintlify.com/org-name/domain-name`, tu nombre de dominio es `domain-name`.

<div id="add-a-server-route">
  ## Añade una ruta de servidor
</div>

Crea una ruta que añada tu clave de API a cada solicitud y la reenvíe a la API del asistente. Transmite la respuesta sin cambios y pasa los encabezados del hilo.

```js
const DOMAIN = "your-domain";

export async function POST(request) {
  const upstream = await fetch(
    `https://api.mintlify.com/discovery/v2/assistant/${DOMAIN}/message`,
    {
      method: "POST",
      headers: {
        "Content-Type": "application/json",
        Authorization: `Bearer ${process.env.MINTLIFY_ASSISTANT_KEY}`,
      },
      body: await request.text(),
    }
  );

  const headers = new Headers();
  for (const name of ["content-type", "x-thread-id", "x-thread-key", "x-message-id"]) {
    const value = upstream.headers.get(name);
    if (value) headers.set(name, value);
  }

  return new Response(upstream.body, { status: upstream.status, headers });
}
```

Reemplaza `your-domain` por tu nombre de dominio. Este ejemplo usa las API estándar `Request` y `Response`, que funcionan en los route handlers de Next.js y en la mayoría de los entornos de ejecución de JavaScript en servidor. Adáptalo a tu framework de backend según sea necesario.

Como tu servidor es quien llama a Mintlify, la Content Security Policy de tu sitio solo necesita permitir solicitudes a tu propia ruta.

<div id="connect-your-interface">
  ## Conecta tu interfaz
</div>

La API del asistente es compatible con AI SDK v5 y versiones posteriores. En React, usa el hook `useChat` y apunta su transporte a tu ruta de servidor:

```jsx
import { useChat } from "@ai-sdk/react";
import { DefaultChatTransport } from "ai";

const { messages, sendMessage, status } = useChat({
  transport: new DefaultChatTransport({
    api: "/api/assistant",
    body: { fp: "anonymous" },
  }),
});
```

Llama a `sendMessage({ text: question })` para hacer una pregunta y muestra las partes de texto de cada mensaje en `messages`. El campo `fp` identifica al usuario. Usa `anonymous` o tu propio ID de usuario.

Si no usas React, funciona cualquier integración de UI del AI SDK o cliente HTTP que lea una respuesta transmitida. Consulta [crear mensaje del asistente](/es/api/assistant/create-assistant-message-v2) para ver el formato completo de la solicitud y la respuesta.

<div id="customize-the-widget">
  ## Personaliza el widget
</div>

Tu interfaz controla todo lo que ven los visitantes, como el activador, el tema, las etiquetas, las preguntas iniciales y los enlaces de soporte. Usa los campos de la solicitud y los datos de la respuesta para controlar con qué responde el asistente.

<div id="scope-retrieval-by-language-or-version">
  ### Limita la búsqueda por idioma o versión
</div>

Pasa `filter` en el cuerpo de la solicitud para restringir lo que recupera el asistente cuando organizas tu contenido por idioma o [versiones](/es/organize/navigation#versions). Omite un campo para buscar en todos sus valores.

```js
body: {
  fp: "anonymous",
  filter: {
    language: "en",
    version: "v2",
  },
},
```

`language` debe ser un [código de idioma compatible](/es/organize/settings-reference#navigation-global-languages), como `en`, `es`, `fr` o `zh-Hans`. `version` coincide con el nombre de versión configurado en tu dashboard.

`filter` también acepta `groups` para restringir la recuperación de [contenido protegido](/es/deploy/authentication-setup). Mintlify no verifica la pertenencia a grupos, así que tu servidor debe elegir los grupos de cada usuario.

<div id="add-page-context">
  ### Añade contexto de la página
</div>

Pasa `currentPath` con la ruta de la página que está viendo el visitante para que el asistente dé respuestas más relevantes. Pasa `context` para incluir fragmentos de código o texto seleccionado con una pregunta.

<div id="show-sources">
  ### Muestra las fuentes
</div>

El asistente busca en tu contenido antes de responder. Cada búsqueda aparece en el mensaje como una parte `tool-search`, y su arreglo `output.results` enumera las páginas que encontró. Usa estos resultados para enlazar las fuentes debajo de cada respuesta. Consulta [citas de fuentes](/es/guides/assistant-embed#source-citations) para ver un ejemplo.

<div id="continue-conversations">
  ### Continúa las conversaciones
</div>

La primera respuesta de una conversación nueva devuelve los encabezados `X-Thread-Id` y `X-Thread-Key`. Guarda ambos y luego incluye `threadId` y `threadKey` en el cuerpo de cada solicitud de seguimiento para continuar la misma conversación. El servidor solo devuelve la clave del hilo una vez, así que guárdala de inmediato. Consulta [seguimiento de hilos de conversación](/es/guides/assistant-embed#track-conversation-thread-ids) para ver un ejemplo.

<div id="add-search">
  ### Añade búsqueda
</div>

Para mostrar páginas coincidentes mientras los visitantes escriben, llama al endpoint [buscar en la documentación](/es/api/assistant/search) desde tu ruta de servidor con la misma clave de API. Las solicitudes de búsqueda no usan créditos.
