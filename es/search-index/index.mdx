Mintlify Index proporciona a los agentes de programación una única capa de búsqueda para obtener conocimientos técnicos. Enruta las preguntas sobre productos indexados a documentación mantenida por sus autores y alojada en Mintlify, y utiliza la búsqueda web para las preguntas que quedan fuera de ese corpus.

Puedes usar Index mediante el servidor MCP público o la API REST con control de acceso.

- **Servidor MCP**: Conecta una herramienta de IA y permite que recupere contexto con citas de fuentes mientras trabajas. Disponible públicamente. No requiere una clave de API.
- **API REST**: Busca fuentes clasificadas por relevancia, recopila contexto dentro de un presupuesto de tokens o recupera el contenido de resultados seleccionados. Tiene control de acceso. Requiere una clave de API de Index.

<div id="how-index-retrieves-context">
  ## Cómo recupera Index el contexto
</div>

<Steps>
  <Step title="Enrutar la pregunta">
    Index identifica si la pregunta trata sobre un producto incluido en su corpus de documentación o si requiere resultados web más amplios.
  </Step>
  <Step title="Recuperar fuentes relevantes">
    Las preguntas específicas de un producto se buscan en la documentación actual del autor. Las demás preguntas buscan en la web.
  </Step>
  <Step title="Devolver contexto listo para el agente">
    Index clasifica los resultados y devuelve las URL de las fuentes junto con el contenido relevante. La herramienta MCP `context` y el endpoint REST `context` recopilan ese contenido dentro de un presupuesto de tokens.
  </Step>
</Steps>

<div id="choose-a-retrieval-operation">
  ## Elegir una operación de recuperación
</div>

- **[`context`](/es/api/search-index/context)**: Úsalo para la mayoría de las tareas de los agentes. Devuelve un conjunto compacto de material de fuentes con citas en una sola solicitud.
- **[`search`](/es/api/search-index/search)**: Úsalo cuando tu aplicación necesite resultados clasificados y controle qué fuentes leer. Está disponible mediante la API REST.
- **[`contents`](/es/api/search-index/contents)**: Úsalo después de `search` para recuperar contenido a partir de los ID o las URL de resultados de Mintlify seleccionados. Está disponible mediante la API REST.
