Conecta tu agente de programación a Mintlify Index para que pueda recuperar documentación técnica actual y contexto web mientras planifica y escribe código. Index es compatible con Claude Code, Cursor, VS Code, Codex, OpenCode, Windsurf y Zed.

<Info>
  No necesitas una cuenta de Mintlify ni una clave de API para conectarte al servidor MCP público de Index.
</Info>

<div id="set-up-with-the-cli">
  ## Configurar mediante la CLI
</div>

Ejecuta el comando de configuración de Index para configurar uno o varios agentes de programación en un solo paso:

```bash
npx mint index
```

El comando detecta los agentes de programación compatibles que tienes instalados y te pide que elijas cuáles configurar. Para cada agente seleccionado, añade el servidor MCP de Index a su configuración e instala una regla que indica al agente cuándo debe usar la herramienta `context`.

Para omitir el selector, pasa uno o varios indicadores de agente:

```bash
npx mint index --claude --cursor
```

| Indicador | Agente de programación |
| --- | --- |
| `--claude` | Claude Code |
| `--cursor` | Cursor |
| `--vscode` | VS Code |
| `--codex` | Codex |
| `--opencode` | OpenCode |
| `--windsurf` | Windsurf |
| `--zed` | Zed |

<Tip>
  Añade `--yes` para configurar todos los agentes detectados sin solicitar confirmación, o `--project` para escribir la configuración en el proyecto actual en lugar de hacerlo en la configuración global del agente. No todos los agentes admiten configuración a nivel de proyecto. Esos agentes siempre reciben la configuración global.
</Tip>

Vuelve a ejecutar el comando para actualizar una configuración existente o añadir otro agente.

<div id="set-up-manually">
  ## Configurar manualmente
</div>

Para configurar Claude Code o Cursor manualmente, o para verificar qué cambió la CLI, sigue los pasos correspondientes a tu agente.

<Tabs>
  <Tab title="Claude Code" icon="terminal">
    <Steps>
      <Step title="Añadir el servidor">
        Ejecuta el siguiente comando:

        ```bash
        claude mcp add --transport http mintlify-index https://index.mintlify.com
        ```
      </Step>
      <Step title="Verificar la conexión">
        Enumera tus servidores MCP configurados:

        ```bash
        claude mcp list
        ```

        La salida debe indicar que `mintlify-index` está conectado.
      </Step>
    </Steps>
  </Tab>
  <Tab title="Cursor" icon="mouse-pointer-2">
    Selecciona **Instalar en Cursor**, revisa la configuración de MCP y aprueba la instalación.

    <PreviewButton href="cursor://anysphere.cursor-deeplink/mcp/install?name=mintlify-index&config=eyJ1cmwiOiJodHRwczovL2luZGV4Lm1pbnRsaWZ5LmNvbSJ9">Instalar en Cursor</PreviewButton>

    Para configurar Cursor manualmente:

    <Steps>
      <Step title="Abrir la configuración de MCP">
        1. Abre la paleta de comandos con <kbd>Command</kbd> + <kbd>Shift</kbd> + <kbd>P</kbd> (<kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>P</kbd> en Windows).
        2. Busca **Abrir la configuración de MCP**.
        3. Selecciona **Añadir MCP personalizado** para abrir `mcp.json`.
      </Step>
      <Step title="Añadir Mintlify Index">
        Añade el siguiente servidor:

        ```json
        {
          "mcpServers": {
            "mintlify-index": {
              "url": "https://index.mintlify.com"
            }
          }
        }
        ```
      </Step>
      <Step title="Verificar la conexión">
        Vuelve a cargar Cursor y abre **Configuración → Herramientas y MCP**. El servidor `mintlify-index` debe aparecer como conectado y con la herramienta `context` disponible.
      </Step>
    </Steps>
  </Tab>
</Tabs>

<div id="use-index-in-a-session">
  ## Usar Index en una sesión
</div>

Haz una pregunta de implementación e indica a tu agente que use Index cuando quieras asegurarte de que recupera fuentes actuales. Por ejemplo:

```text
Usa Mintlify Index para encontrar la forma recomendada actualmente de configurar la caché en Next.js 16. Cita las fuentes que uses.
```

El agente llama a la herramienta `context` de Index cuando necesita contexto técnico e incluye en su trabajo los enlaces a las fuentes devueltas.

<div id="remove-the-connection">
  ## Eliminar la conexión
</div>

<Tabs>
  <Tab title="Claude Code" icon="terminal">
    Ejecuta el siguiente comando:

    ```bash
    claude mcp remove mintlify-index
    ```
  </Tab>
  <Tab title="Cursor" icon="mouse-pointer-2">
    Abre **Configuración → Herramientas y MCP** y elimina la entrada `mintlify-index` de `mcp.json`.
  </Tab>
</Tabs>

Para VS Code, Codex, OpenCode, Windsurf o Zed, elimina la entrada `mintlify-index` de la configuración del servidor MCP de ese agente.

Consulta la [referencia de MCP de Index](/es/search-index/mcp) para conocer las entradas de la herramienta y los límites de velocidad.
