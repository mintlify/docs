Mintlify lee estas extensiones y campos de tu especificación OpenAPI. No lee `x-tagGroups`. Para mostrar cualquier otro campo de tu especificación como etiqueta en los parámetros, usa [píldoras de parámetros](/es/api-playground/customize-endpoint-pages#add-parameter-pills).

Para agregar extensiones a una especificación que no editas directamente, usa un [overlay](/es/api-playground/overlays).

<div id="operation-extensions">
  ## Extensiones de operación
</div>

Agrégalas a una operación, como `paths./users.get`.

| Extensión | Qué hace |
| --- | --- |
| `x-mint.metadata` | Sobrescribe el frontmatter de la página, como `title`, `sidebarTitle`, `description`, `playground` o `tag`. Consulta [Sobrescribir los metadatos de la página](/es/api-playground/customize-endpoint-pages#override-page-metadata). |
| `x-mint.content` | Agrega contenido MDX a la página. Consulta [Agregar contenido a una página](/es/api-playground/customize-endpoint-pages#add-content-to-a-page). |
| `x-mint.href` | Define la URL de la página. Consulta [Definir la URL de un endpoint](/es/api-playground/endpoint-urls#set-a-url-for-one-endpoint). |
| `x-mint.playground.expand` | Configúralo como `false` para que los campos de objetos anidados aparezcan contraídos. Consulta [Contraer los campos del playground](/es/api-playground/customize-endpoint-pages#collapse-playground-fields). |
| `x-mint.groups` | Muestra el endpoint solo a los lectores de los grupos de usuarios indicados. También funciona en una ruta. Consulta [Filtrar endpoints](/es/create/personalization#filter-endpoints). |
| `x-hidden` | Crea la página, pero la deja fuera de la navegación. Consulta [Ocultar o excluir endpoints](/es/api-playground/organize-endpoints#hide-or-exclude-endpoints). |
| `x-excluded` | No crea una página. Consulta [Ocultar o excluir endpoints](/es/api-playground/organize-endpoints#hide-or-exclude-endpoints). |
| `x-codeSamples` | Agrega tus propios ejemplos de solicitud. `x-code-samples` también funciona. Consulta [Escribir tus propios ejemplos](/es/api-playground/code-examples#write-your-own-examples). |

`x-hidden` y `x-excluded` también funcionan en webhooks.

<div id="schema-extensions">
  ## Extensiones de esquema
</div>

Agrégalas a un esquema o a una propiedad.

| Extensión | Qué hace |
| --- | --- |
| `x-mint.pre`, `x-mint.post` | Agrega píldoras antes o después del nombre de un parámetro. Consulta [Agregar píldoras de parámetros](/es/api-playground/customize-endpoint-pages#add-parameter-pills). |
| `x-mint.groups` | Muestra una propiedad o una variante de `oneOf` solo a los lectores de los grupos de usuarios indicados. Consulta [Filtrar propiedades de esquema](/es/create/personalization#filter-schema-properties). |
| `x-mint-enum` | Muestra valores de enum individuales solo a los lectores de los grupos de usuarios indicados. Consulta [Filtrar valores de enum](/es/create/personalization#filter-enum-values). |
| `x-default` | Rellena previamente el playground con un valor sin cambiar el ejemplo documentado ni el `default`. En los parámetros, tiene prioridad sobre los ejemplos, esté o no activado `api.examples.prefill`. En los campos del cuerpo de la solicitud, solo se aplica cuando `api.examples.prefill` está desactivado. Consulta [Rellenar previamente valores de ejemplo](/es/api-playground/configure-playground#prefill-example-values). |

<div id="security-scheme-extensions">
  ## Extensiones de esquemas de seguridad
</div>

| Extensión | Qué hace |
| --- | --- |
| `x-default` | Rellena previamente el campo de credenciales en el playground. Funciona en esquemas `apiKey` y `http` bearer. Consulta [Rellenar previamente las credenciales](/es/api-playground/configure-playground#prefill-credentials). |

<div id="tag-extensions-and-fields">
  ## Extensiones y campos de tags
</div>

| Campo | Qué hace |
| --- | --- |
| `x-group` | Define la etiqueta del grupo de navegación para el tag. Consulta [Renombrar los grupos de tags](/es/api-playground/organize-endpoints#rename-tag-groups). |
| `x-displayName` | Define la etiqueta del grupo si el tag no tiene `x-group`. |
| `parent`, `kind`, `summary` | Solo en OpenAPI 3.2. Anidan grupos, muestran píldoras de badge y definen etiquetas. Consulta [Anidar grupos con jerarquías de tags](/es/api-playground/organize-endpoints#nest-groups-with-tag-hierarchies). |

Ninguno de ellos cambia las URLs de las páginas. Las URLs usan el `name` del tag.

<div id="frontmatter-fields">
  ## Campos de frontmatter
</div>

Úsalos en páginas MDX que hacen referencia a tu especificación.

| Campo | Qué hace |
| --- | --- |
| `openapi` | Genera la página a partir de una operación o un webhook, como `openapi: "openapi.json GET /users"`. Consulta [Crear páginas MDX para endpoints](/es/api-playground/customize-endpoint-pages#create-mdx-pages-for-endpoints). |
| `openapi-schema` | Genera la página a partir de un esquema de `components.schemas`. Consulta [Crear páginas para modelos de datos](/es/api-playground/customize-endpoint-pages#create-pages-for-data-models). |
| `playground` | Define el modo de visualización del playground para la página. Consulta [Elegir un modo de visualización](/es/api-playground/configure-playground#choose-a-display-mode). |
