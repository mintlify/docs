<Info>
  Las bibliotecas de terceros requieren un [plan Enterprise](https://mintlify.com/pricing?ref=third-party-libraries). Contacta a tu gestor de cuenta para activarlas en tu sitio.
</Info>

Usa componentes de paquetes npm, como gráficos o tu propio sistema de diseño, en tus páginas MDX. Cuando despliegas, Mintlify instala los paquetes de tu lockfile, renderiza cada componente a HTML y carga su JavaScript en el navegador.

<Warning>
  Instala solo paquetes en los que confíes. El código de los paquetes se ejecuta con el mismo acceso que la página, incluido el contenido de la página y todo lo que el navegador del lector almacena para tu sitio. Puede realizar solicitudes de red a cualquier servidor. Eliminar un paquete o revertir un despliegue no detiene el código que ya se cargó en el navegador de un lector.
</Warning>

Las bibliotecas de terceros no están disponibles en sitios que usan [autenticación](/es/deploy/authentication-setup) o [personalización](/es/create/personalization). Los despliegues que incluyen `packages` en `docs.json` fallan en esos sitios. Esto también se aplica a las [implementaciones de vista previa](/es/deploy/preview-deployments#restrict-access-to-preview-deployments) que requieren autenticación de la organización o una contraseña.

Mientras tu sitio use bibliotecas de terceros, no puedes activar la autenticación, la personalización ni las restricciones de acceso para las implementaciones de vista previa.

<div id="interactive-charts">
  ### Gráficos interactivos
</div>

Pasa el cursor sobre cualquiera de los gráficos y ambos tooltips siguen la misma fecha. Arrastra los controles bajo el gráfico de latencia para acotar el rango de fechas de ambos gráficos. Creado con [`recharts`](https://www.npmjs.com/package/recharts).

<Accordion title="Código del gráfico">
  ```jsx snippets/recharts-example.jsx
  import { useId } from "react";
  import {
    Area,
    AreaChart,
    Brush,
    CartesianGrid,
    Line,
    LineChart,
    ResponsiveContainer,
    Tooltip,
    XAxis,
    YAxis,
  } from "recharts";

  const data = [
    { day: "Oct 1", requests: 16600, latency: 142 },
    { day: "Oct 2", requests: 21900, latency: 154 },
    { day: "Oct 3", requests: 18800, latency: 148 },
    { day: "Oct 4", requests: 25800, latency: 182 },
    { day: "Oct 5", requests: 28200, latency: 176 },
    { day: "Oct 6", requests: 19700, latency: 136 },
    { day: "Oct 7", requests: 22900, latency: 151 },
    { day: "Oct 8", requests: 24100, latency: 158 },
    { day: "Oct 9", requests: 26400, latency: 171 },
    { day: "Oct 10", requests: 21300, latency: 149 },
  ];

  const tick = { fill: "currentColor", fillOpacity: 0.6, fontSize: 12 };
  const grid = { stroke: "currentColor", strokeOpacity: 0.15 };
  const tooltip = {
    contentStyle: {
      backgroundColor: "rgba(17, 24, 39, 0.92)",
      border: "none",
      borderRadius: 8,
      color: "#fff",
      fontSize: 12,
    },
    itemStyle: { color: "#fff" },
    isAnimationActive: false,
  };

  export const SynchronizedCharts = () => {
    const syncId = useId();

    return (
      <div style={{ width: "100%" }}>
        <div style={{ width: "100%", height: 180 }}>
          <ResponsiveContainer width="100%" height="100%" minWidth={0}>
            <AreaChart data={data} syncId={syncId} accessibilityLayer>
              <CartesianGrid vertical={false} {...grid} />
              <XAxis dataKey="day" tick={tick} stroke="currentColor" strokeOpacity={0.3} />
              <YAxis width={72} tick={tick} stroke="currentColor" strokeOpacity={0.3} />
              <Tooltip {...tooltip} />
              <Area
                dataKey="requests"
                name="Requests"
                type="monotone"
                stroke="#166E3F"
                fill="#26BD6C"
                fillOpacity={0.25}
                isAnimationActive={false}
              />
            </AreaChart>
          </ResponsiveContainer>
        </div>
        <div style={{ width: "100%", height: 230 }}>
          <ResponsiveContainer width="100%" height="100%" minWidth={0}>
            <LineChart data={data} syncId={syncId} accessibilityLayer>
              <CartesianGrid vertical={false} {...grid} />
              <XAxis dataKey="day" tick={tick} stroke="currentColor" strokeOpacity={0.3} />
              <YAxis
                width={72}
                domain={[0, 240]}
                tick={tick}
                stroke="currentColor"
                strokeOpacity={0.3}
                tickFormatter={(value) => `${value} ms`}
              />
              <Tooltip {...tooltip} />
              <Line
                dataKey="latency"
                name="Latency (ms)"
                type="monotone"
                stroke="#E0803A"
                strokeWidth={2}
                dot={false}
                isAnimationActive={false}
              />
              <Brush
                dataKey="day"
                height={28}
                travellerWidth={10}
                stroke="#26BD6C"
                fill="transparent"
                ariaLabel="Visible date range for both charts"
              />
            </LineChart>
          </ResponsiveContainer>
        </div>
      </div>
    );
  };
  ```
</Accordion>

<DitheringExample />

<Accordion title="Código del shader">
  ```jsx snippets/dithering-example.jsx
  import { useEffect, useId, useState } from "react";
  import { Dithering } from "@paper-design/shaders-react";

  const palettes = [
    { name: "Mint", back: "#0b1f14", front: "#26BD6C" },
    { name: "Violet", back: "#10091f", front: "#d9c6ff" },
    { name: "Ember", back: "#1f0d06", front: "#ffb37a" },
  ];

  const shapes = ["sphere", "warp", "ripple", "swirl"];

  const control = {
    font: "inherit",
    fontSize: 13,
    padding: "4px 10px",
    borderRadius: 6,
    border: "1px solid rgba(127, 127, 127, 0.4)",
    background: "transparent",
    color: "inherit",
    cursor: "pointer",
  };

  export const DitheringExample = () => {
    const shapeId = useId();
    const [palette, setPalette] = useState(palettes[0]);
    const [shape, setShape] = useState("sphere");
    const [size, setSize] = useState(3);
    const [paused, setPaused] = useState(false);
    // Hold the shader still until the reduced-motion check runs after mount.
    const [motionChecked, setMotionChecked] = useState(false);

    useEffect(() => {
      if (window.matchMedia("(prefers-reduced-motion: reduce)").matches) {
        setPaused(true);
      }
      setMotionChecked(true);
    }, []);

    return (
      <div style={{ width: "100%" }}>
        <Dithering
          width="100%"
          height={320}
          speed={paused || !motionChecked ? 0 : 0.4}
          scale={0.6}
          maxPixelCount={2000000}
          colorBack={palette.back}
          colorFront={palette.front}
          shape={shape}
          type="4x4"
          size={size}
          style={{ borderRadius: 12, overflow: "hidden", backgroundColor: palette.back }}
        />
        <div
          style={{
            display: "flex",
            flexWrap: "wrap",
            alignItems: "center",
            gap: 8,
            marginTop: 12,
            marginBottom: 16,
            fontSize: 13,
          }}
        >
          {palettes.map((p) => (
            <button
              key={p.name}
              type="button"
              aria-pressed={palette.name === p.name}
              onClick={() => setPalette(p)}
              style={{
                ...control,
                borderColor: palette.name === p.name ? p.front : "rgba(127, 127, 127, 0.4)",
              }}
            >
              {p.name}
            </button>
          ))}
          <label htmlFor={shapeId} style={{ marginLeft: 8 }}>
            Shape
          </label>
          <select
            id={shapeId}
            value={shape}
            onChange={(e) => setShape(e.target.value)}
            style={control}
          >
            {shapes.map((s) => (
              <option key={s} value={s}>
                {s}
              </option>
            ))}
          </select>
          <label style={{ display: "flex", alignItems: "center", gap: 6, marginLeft: 8 }}>
            Pixel size
            <input
              type="range"
              min={1}
              max={8}
              value={size}
              style={{ accentColor: palette.front }}
              onChange={(e) => setSize(Number(e.target.value))}
            />
          </label>
          <button
            type="button"
            onClick={() => setPaused(!paused)}
            style={{ ...control, marginLeft: "auto" }}
          >
            {paused ? "Play" : "Pause"}
          </button>
        </div>
      </div>
    );
  };
  ```
</Accordion>

<div id="add-a-package">
  ## Agregar un paquete
</div>

<Steps>
  <Step title="Enumera tus dependencias">
    Crea un archivo `package.json` en la misma carpeta que tu archivo `docs.json`. Enumera cada paquete que importes en `dependencies`, incluidos `react` y `react-dom`.

    ```json package.json
    {
      "private": true,
      "dependencies": {
        "@acme/charts": "^2.0.0",
        "react": "^18.3.1",
        "react-dom": "^18.3.1"
      }
    }
    ```

    Mintlify instala solo `dependencies`. Los paquetes que solo aparecen en `devDependencies` o `peerDependencies` no están disponibles para tus páginas.
  </Step>
  <Step title="Confirma un lockfile">
    Instala tus dependencias y confirma el lockfile junto a `package.json`.

    <CodeGroup>
      ```bash pnpm
      pnpm install
      ```

      ```bash npm
      npm install
      ```
    </CodeGroup>

    Mintlify instala las versiones exactas de tu lockfile. Admite `pnpm-lock.yaml` versión 9 de pnpm y `package-lock.json` de npm. Los lockfiles de Yarn y Bun no son compatibles.
  </Step>
  <Step title="Activa los paquetes">
    Agrega la clave `packages` a tu `docs.json`. Un objeto vacío activa los paquetes con la configuración predeterminada.

    ```json docs.json
    {
      "packages": {}
    }
    ```
  </Step>
  <Step title="Importa un componente">
    Crea un componente en tu carpeta `snippets` que importe desde el paquete.

    ```jsx snippets/requests-chart.jsx
    import { LineChart } from "@acme/charts";

    const data = [
      { day: "Mon", requests: 120 },
      { day: "Tue", requests: 180 },
      { day: "Wed", requests: 150 },
    ];

    export const RequestsChart = () => (
      <LineChart data={data} x="day" y="requests" height={240} />
    );
    ```

    Luego impórtalo en una página:

    ```mdx
    import { RequestsChart } from "/snippets/requests-chart.jsx";

    <RequestsChart />
    ```
  </Step>
  <Step title="Despliega">
    Sube tus cambios. Si un paquete no se puede instalar o compilar, el despliegue falla con un error que indica el paquete y el problema.
  </Step>
</Steps>

Para obtener una vista previa local, instala tus dependencias y luego ejecuta [`mint dev`](/es/cli/preview) desde la carpeta que contiene tu archivo `docs.json`.

<div id="use-package-components">
  ## Usar componentes de paquetes
</div>

También puedes importar componentes directamente desde un paquete en una página MDX:

```mdx
import { Tooltip } from "@acme/ui";

<Tooltip content="Requests per day">Usage</Tooltip>
```

- Coloca los componentes de paquetes en sus propias líneas. No funcionan dentro de un párrafo, una celda de tabla o texto en línea.
- Pasa cadenas, números y booleanos directamente como props. Para funciones, arrays, objetos o props JSX, escribe un componente contenedor en tu carpeta `snippets`, como el gráfico de [Agregar un paquete](#add-a-package), y pasa los valores allí.
- El Markdown dentro de un componente de paquete se renderiza como HTML sin formato. Los componentes de Mintlify, como los callouts y las tarjetas, no se renderizan dentro de un componente de paquete.

<div id="load-package-styles">
  ## Cargar estilos de paquetes
</div>

Los componentes pueden importar su propio CSS. Para cargar una hoja de estilos que un paquete distribuye por separado, agrega su ruta dentro del paquete instalado a `packages.css`:

```json docs.json
{
  "packages": {
    "css": ["@acme/ui/dist/styles.css"]
  }
}
```

Los paquetes deben distribuir CSS compilado. Mintlify no ejecuta herramientas de compilación ni plugins de CSS sobre el código de los paquetes, y no admite módulos CSS. Las hojas de estilos de los paquetes no pueden cargar fuentes ni imágenes desde URL remotas. En su lugar, carga las fuentes con la [configuración de fuentes](/es/customize/fonts) de tu sitio.

<div id="wrap-components-in-a-provider">
  ## Envolver componentes en un proveedor
</div>

Si tus componentes necesitan un proveedor de tema o de contexto, exporta un componente `Provider` desde un snippet y establece `packages.provider` con su ruta:

```json docs.json
{
  "packages": {
    "provider": "/snippets/provider.jsx"
  }
}
```

```jsx snippets/provider.jsx
import { ThemeProvider } from "@acme/ui";

export const Provider = ({ children }) => <ThemeProvider>{children}</ThemeProvider>;
```

El proveedor envuelve cada componente de paquete por separado. Los componentes no comparten estado a través de él.

<div id="install-from-another-registry">
  ## Instalar desde otro registro
</div>

Los paquetes sin scope se instalan desde el registro público de npm. Para instalar un scope desde un registro diferente, asigna el scope a la URL del registro en `packages.registries`:

```json docs.json
{
  "packages": {
    "registries": {
      "@acme": "https://npm.acme.com/"
    }
  }
}
```

El registro debe usar HTTPS en el puerto predeterminado y ser accesible desde la internet pública sin credenciales.

<div id="limitations">
  ## Limitaciones
</div>

- **Orígenes de dependencias**: Las dependencias deben ser versiones del registro, rangos de versiones o etiquetas. Las URL de Git, las rutas locales y los alias `file:`, `link:`, `workspace:` y `npm:` no son compatibles.
- **Scripts de instalación**: Los paquetes se instalan sin ejecutar scripts de instalación como `postinstall`. Los paquetes que los necesitan, o que necesitan binarios nativos, no funcionan.
- **Tamaño**: La salida de paquetes de un despliegue puede incluir hasta 1000 archivos, 8 MB por archivo, 40 MB en total y 5 MB comprimidos con gzip. Los paquetes que cargan grandes conjuntos de módulos en tiempo de ejecución, como los mapas de iconos dinámicos, pueden superar el límite de archivos.
- **Renderizado en el servidor**: Cada componente debe renderizarse en menos de tres segundos en el servidor. Un componente que falla o agota el tiempo de espera solo se renderiza en el navegador, por lo que no aparece en el HTML de la página.
- **Búsqueda e IA**: La búsqueda, el asistente y las exportaciones de Markdown usan tu código fuente MDX, no el contenido que renderiza un componente. Mantén el contenido de referencia importante en el texto de tu MDX.
- **Editor web**: La vista previa del editor web no renderiza componentes de paquetes.

Para dejar de usar paquetes, elimina `packages` de tu archivo `docs.json` y vuelve a desplegar.
