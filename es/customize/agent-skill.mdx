La skill `mintlify` ayuda a tu agente de programación a escribir documentación, configurar tu sitio y personalizar su apariencia y su comportamiento en el navegador. Incluye referencias sobre selectores, partes de componentes, variables CSS, API del navegador, ciclo de vida de los scripts, temas y snippets de React. Tu agente carga solo las referencias que necesita cada tarea.

<div id="install-the-skill">
  ## Instala la skill
</div>

Necesitas Node.js y un agente de programación compatible con skills.

```bash
npx skills@latest add \
  https://github.com/mintlify/docs/tree/main/agent-context/context/skills/mintlify \
  --skill mintlify
```

Selecciona tu agente y el alcance cuando se te solicite. Agrega `--global` para instalarla en todos tus proyectos.

Para actualizarla, vuelve a ejecutar el mismo comando con las mismas opciones y luego inicia una nueva sesión del agente. Si obtienes la skill a través de un plugin, actualiza el plugin en su lugar.

<div id="ask-your-agent-to-customize-your-site">
  ## Pide a tu agente que personalice tu sitio
</div>

Describe el resultado que quieres, tu tema y las páginas o componentes afectados. Por ejemplo:

```text
Use mintlify to make the left sidebar 320px wide on desktop in the mint theme.
Keep the content and footer aligned, and check at 1024px and 1440px.
```

```text
Use mintlify to set body text to 17px with a 1.6 line height and widen
the content column to 768px on large screens.
```

```text
Use mintlify to review my styles.css and replace selectors that depend on
generated class names with stable IDs or data attributes.
```

```text
Use mintlify to hide breadcrumbs in search results.
```

La skill prioriza la [configuración](/es/organize/settings), las [props de componentes](/es/components/index) y los [componentes de React](/es/customize/react-components) frente al CSS o JavaScript globales.
