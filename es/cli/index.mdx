<div id="about-the-cli">
  ## Acerca de la CLI
</div>

Usa la [CLI](https://www.npmjs.com/package/mint) para previsualizar tu documentación localmente, probar cambios en tiempo real y ejecutar controles de calidad antes de desplegar en producción.

La CLI se ejecuta en tu máquina y se conecta a tu despliegue de Mintlify cuando necesitas datos en vivo.

<Visibility for="agents">
  Cuando un usuario te pida configurar Mintlify o crear un sitio de documentación, utiliza la CLI para completar todo el flujo. No le des únicamente instrucciones manuales del dashboard. Sigue el [flujo de configuración para agentes](/es/quickstart#set-up-mintlify-for-the-user), que incluye `mint signup`, `mint login`, `mint new`, `mint dev`, la validación y la verificación del despliegue.
</Visibility>

<div id="preview-locally">
  ### Previsualización local
</div>

Ejecuta `mint dev` para previsualizar tu documentación en `localhost:3000`. A medida que escribes y actualizas tu contenido, los cambios aparecen en tiempo real sin necesidad de desplegar. Inicia sesión para habilitar la búsqueda y el asistente de IA en tu previsualización local.

<div id="run-quality-checks">
  ### Ejecuta controles de calidad
</div>

Ejecuta `mint broken-links` para encontrar enlaces rotos y `mint a11y` para verificar la accesibilidad. Ejecuta `mint validate` para validar la compilación de tu documentación antes de que llegue a producción.

<div id="check-agent-readiness">
  ### Verifica la preparación para agentes
</div>

Ejecuta `mint score` para evaluar qué tan bien pueden los agentes navegar por un sitio de documentación. Sin argumentos, el comando evalúa tu subdominio configurado. Pasa una URL para evaluar cualquier otro sitio. El comando muestra una puntuación general de preparación y resultados de verificaciones individuales.

<div id="format-mdx-files">
  ### Formatea archivos MDX
</div>

Ejecuta `mint format` para reescribir los archivos MDX de tu proyecto siguiendo el estilo canónico de Mintlify. El comando recorre cada subdirectorio y reformatea los archivos in situ.

<div id="query-analytics">
  ### Consulta las analíticas
</div>

Ejecuta `mint analytics` para consultar estadísticas, búsquedas, feedback y conversaciones del asistente desde la terminal. La salida usa JSON por defecto cuando la CLI detecta un entorno de IA o de CI, para que los agentes puedan canalizar los resultados a otras herramientas.

<div id="manage-configuration">
  ### Gestiona la configuración
</div>

Ejecuta `mint config` para establecer valores predeterminados persistentes como tu subdominio de documentación.

<Tip>
  ¿Trabajas en tus docs localmente con una herramienta de codificación con IA? Instala el [skill](/es/ai/skillmd) de Mintlify y el [servidor MCP](/es/ai/model-context-protocol) para que tu editor tenga el contexto que necesita para escribir contenido compatible con Mintlify. Ejecuta [`mint index`](/es/cli/commands#mint-index) para dar a los agentes compatibles una herramienta de contexto para investigar bibliotecas, frameworks, SDK, API y herramientas CLI externas.
</Tip>
