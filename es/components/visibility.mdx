Usa el componente `Visibility` para mostrar contenido diferente a distintas audiencias en la misma página. Puedes dirigirte a los humanos que visitan tu sitio, a los agentes de IA que procesan la salida Markdown o a los lectores según su estado de inicio de sesión y sus grupos de usuarios. Esto te permite personalizar la información para cada audiencia sin mantener páginas separadas.

En tu sitio publicado, el contenido marcado con `for="humans"` se renderiza normalmente y el contenido marcado con `for="agents"` se oculta. En las [vistas de página en Markdown](/es/ai/markdown-export) (URLs `.md`), ocurre lo contrario: el contenido para agentes se renderiza en la salida Markdown y el contenido exclusivo para humanos no. Las mismas reglas se aplican al archivo [`llms-full.txt`](/es/ai/llmstxt).

<div id="example">
  ## Ejemplo
</div>

```mdx
<Visibility for="humans">
  <Note>
    Estás viendo este contenido **en la web**.

    Este contenido se muestra normalmente en las páginas estándar de tu sitio.

    Úsalo para un paso como: Haz clic en el botón **Get started** en la esquina superior derecha para crear tu cuenta.

    En este ejemplo, las instrucciones orientadas a la interfaz aparecen en la página estándar. Consulta la [versión Markdown de esta página](https://mintlify.com/docs/components/visibility.md) para ver las instrucciones orientadas a la API para agentes.
  </Note>
</Visibility>

<Visibility for="agents">
  > Estás viendo este contenido **en Markdown**.
  >
  > Este contenido solo aparece en la versión Markdown de las páginas.
  >
  > Úsalo para información que solo usan los agentes, como: Para crear una cuenta, llama a `POST /v1/accounts` con una dirección de correo electrónico válida.
  >
  > En este ejemplo, las instrucciones orientadas a la API aparecen en la versión Markdown de la página. Consulta la [página estándar](https://mintlify.com/docs/components/visibility) para ver las instrucciones orientadas a la interfaz para humanos.
</Visibility>
```

<div id="show-content-by-sign-in-state-or-group">
  ## Mostrar contenido según el estado de inicio de sesión o el grupo
</div>

Si tu sitio usa [autenticación](/es/deploy/authentication-setup), puedes mostrar contenido en función de si un lector ha iniciado sesión o de los [grupos](/es/deploy/authentication-setup#control-access-with-groups) a los que pertenece.

```mdx
<Visibility for="signed-in">
  Bienvenido de nuevo. Ve a la [configuración de tu cuenta](/account) para gestionar tus claves de API.
</Visibility>

<Visibility for="signed-out">
  [Inicia sesión](/login) para ver las claves de API de tu cuenta.
</Visibility>

<Visibility for={{ groups: ["admin", "enterprise"] }}>
  Los administradores y los clientes enterprise pueden configurar SSO desde la pestaña **Security**.
</Visibility>
```

- El contenido `signed-in` se renderiza solo para lectores con una sesión activa.
- El contenido `signed-out` se renderiza solo para lectores que no han iniciado sesión.
- El contenido `groups` se renderiza solo para lectores con sesión iniciada que pertenecen al menos a uno de los grupos indicados.

Las vistas de página en Markdown y `llms-full.txt` son iguales para todos los lectores, por lo que los agentes siempre obtienen la vista sin sesión iniciada. Mintlify elimina el contenido `signed-in` y `groups` de la salida Markdown e incluye el contenido `signed-out`.

Para comprobar estas reglas localmente, ejecuta [`mint dev --signed-in` o `mint dev --groups`](/es/cli/preview#preview-as-a-specific-group). Sin ninguno de los dos flags, la previsualización local muestra la vista sin sesión iniciada.

<Warning>
  Las reglas de inicio de sesión y de grupo solo ocultan el contenido en el navegador. El contenido oculto se sigue enviando al navegador de cada lector. Para restringir el acceso a contenido sensible, colócalo en una página independiente y usa la [propiedad de frontmatter `groups`](/es/deploy/authentication-setup#control-access-with-groups).
</Warning>

<div id="properties">
  ## Propiedades
</div>

<ResponseField name="for" type="string | object" required>
  La audiencia del contenido envuelto. Debe ser uno de los siguientes:

  - `humans`: Contenido visible en la web y excluido de la salida Markdown.
  - `agents`: Contenido oculto en la web e incluido en la salida Markdown.
  - `signed-in`: Contenido visible en la web para lectores con sesión iniciada y excluido de la salida Markdown.
  - `signed-out`: Contenido visible en la web para lectores sin sesión iniciada e incluido en la salida Markdown.
  - `{ groups: [...] }`: Contenido visible en la web para lectores con sesión iniciada que pertenecen al menos a uno de los grupos indicados y excluido de la salida Markdown.

  Usa un valor estático. Mintlify excluye de la salida Markdown el contenido con un valor `for` calculado, como una variable o una expresión condicional.
</ResponseField>
