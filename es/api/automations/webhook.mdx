Usa este endpoint para ejecutar una automatización personalizada configurada con un activador de **Webhook**. Cada solicitud pone en cola una ejecución que usa el prompt guardado de la automatización y lee el historial completo del repositorio. Los cuerpos de solicitud se ignoran.

Este endpoint solo admite [automatizaciones personalizadas](/es/automations/create) con un activador de webhook. Las automatizaciones predefinidas y las automatizaciones con cualquier otro activador devuelven una respuesta `404`. Para activar bajo demanda una automatización personalizada programada, usa [Activar automatización](/es/api/automations/trigger).

<div id="use-cases">
## Casos de uso
</div>

- **Pipelines CI/CD**: Ejecuta una automatización personalizada en cada fusión a `main` o después de una publicación, sin esperar a una ejecución programada.
- **Eventos de publicación**: Ejecuta una automatización personalizada desde un script de publicación cuando creas una etiqueta o publicas una nueva versión de un SDK.
- **Herramientas internas**: Activa automatizaciones desde dashboards internos, comandos de Slack o tareas programadas que ya ejecutas.

<div id="get-the-webhook-url-and-auth-header">
## Obtén la URL del webhook y el encabezado de autenticación
</div>

Abre la página de [Automatizaciones](https://app.mintlify.com/products/automations) en tu dashboard y haz clic en el botón de ajustes <Icon icon="settings-2" /> de una automatización personalizada con un activador de webhook. La tarjeta del activador muestra la URL completa del webhook y una acción **Copy auth header** para la plantilla del encabezado `Authorization: Bearer <api-key>`.

Sustituye `<api-key>` por una clave de API de organización sin caducar con acceso de escritura. Crea o gestiona claves en la página [API keys](https://app.mintlify.com/settings/organization/api-keys). Las automatizaciones no crean, almacenan ni rotan claves por ti.

<div id="example">
## Ejemplo
</div>

Activa una automatización de webhook desde una GitHub Action cada vez que se fusiona código a `main`:

```yaml .github/workflows/trigger-docs.yml
on:
  push:
    branches: [main]

jobs:
  trigger:
    runs-on: ubuntu-latest
    steps:
      - run: |
          curl -fsS -X POST \
            "https://api.mintlify.com/v2/workflow/$PROJECT_ID/$WORKFLOW_ID/webhook" \
            -H "Authorization: Bearer ${{ secrets.MINTLIFY_API_KEY }}"
        env:
          PROJECT_ID: ${{ vars.MINTLIFY_PROJECT_ID }}
          WORKFLOW_ID: ${{ vars.MINTLIFY_WORKFLOW_ID }}
```

<div id="rate-limits">
## Límites de tasa
</div>

Este endpoint comparte un límite de tasa con [Trigger update](/es/api/update/trigger) y [Activar automatización](/es/api/automations/trigger): hasta 10 solicitudes cada 10 segundos por organización. Cada ejecución en cola consume créditos al mismo ritmo que cualquier otra ejecución de una automatización personalizada. Consulta [Precios de créditos](/es/credits).
