<Info>
  Este endpoint está en beta privada y requiere un acuerdo empresarial. Contacta con [sales@mintlify.com](mailto:sales@mintlify.com) para más información.
</Info>

<Note>
  La exportación estática no está disponible para deployments con autenticación habilitada. Este endpoint devuelve una respuesta `403` si el deployment de destino usa autenticación parcial o completa. Contacta con [support@mintlify.com](mailto:support@mintlify.com) si necesitas exportar un deployment autenticado.
</Note>
