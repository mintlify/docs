---
title: "Activar implementación de vista previa"
openapi: "/es/openapi.json POST /project/preview/{projectId}"
keywords: ["preview", "preview deployment", "branch preview", "staging"]
---

Usa este endpoint para crear o actualizar de forma programática una implementación de vista previa para una rama de Git. Si ya existe una vista previa para la rama especificada, el endpoint activa una reimplementación en lugar de crear un duplicado.

La respuesta incluye un `statusId` que puedes pasar a [Get deployment status](/es/api/update/status) para rastrear el progreso de la implementación.

<div id="branch-requirements">
  ## Requisitos de la rama
</div>

La `branch` debe existir en el repositorio conectado a tu proyecto de Mintlify y debes tener instalada la aplicación de GitHub de Mintlify. Este endpoint no admite ramas de forks. Consulta [Solicitudes de extracción de forks](/es/deploy/preview-deployments#fork-pull-requests) para saber cómo previsualizar cambios de un fork.

<div id="use-cases">
  ## Casos de uso
</div>

- **Pipelines CI/CD**: Crea automáticamente implementaciones de vista previa cuando los usuarios abren o actualizan solicitudes de extracción.
- **Vistas previas programadas**: Genera vistas previas de ramas de funcionalidades de larga duración de forma programada.
- **Herramientas personalizadas**: Integra la creación de vistas previas en flujos de trabajo internos o bots de Slack.

<div id="access-to-previews">
  ## Acceso a las vistas previas
</div>

De forma predeterminada, las vistas previas creadas con este endpoint son accesibles públicamente a menos que habilites la autenticación para tus vistas previas. Consulta [Restringir el acceso a las implementaciones de vista previa](/es/deploy/preview-deployments#restrict-access-to-preview-deployments).

Para restringir el acceso a una vista previa específica, pasa un objeto `auth` en el cuerpo de la solicitud. Mintlify aplica la configuración de acceso a la vista previa antes de poner en cola la implementación. Si omites `auth`, la vista previa conserva su configuración de acceso actual.

- `{ "type": "password", "password": "..." }`: Cualquier persona con la contraseña puede ver la vista previa. Las contraseñas deben tener al menos 8 caracteres. Establecer una contraseña reemplaza cualquier contraseña existente en la vista previa.
- `{ "type": "mintlify" }`: Solo los miembros de tu organización que hayan iniciado sesión en Mintlify pueden ver la vista previa.

```bash
curl --request POST \
  --url https://api.mintlify.com/v1/project/preview/{projectId} \
  --header 'Authorization: Bearer <token>' \
  --header 'Content-Type: application/json' \
  --data '{
    "branch": "feature/new-guide",
    "auth": { "type": "password", "password": "review-pass-123" }
  }'
```

Establecer `auth` tiene estos requisitos:

- Tu plan debe incluir la autenticación de implementaciones de vista previa. De lo contrario, el endpoint devuelve un `403`.
- Tu sitio debe tener habilitada la [autenticación](/es/deploy/authentication-setup) o la autenticación de vistas previas. De lo contrario, el endpoint devuelve un `409`.
- La autenticación debe estar habilitada en la propia vista previa. De lo contrario, el endpoint devuelve un `409`.

<div id="rate-limits">
  ## Límites de tasa
</div>

Este endpoint permite hasta 5 solicitudes por minuto por organización.
