<Note>
  El endpoint de mensaje de assistant v1 está descontinuado. Las solicitudes a este endpoint devuelven `410 Gone`.

  Migra cualquier integración que llame al endpoint v1 a este endpoint v2. Consulta [Migrar desde v1](#migrate-from-v1).
</Note>

<div id="compatibility">
  ## Compatibilidad
</div>

El endpoint de mensaje de assistant es compatible con **AI SDK v5 o superior**. Si tu integración usa AI SDK v4, actualiza a AI SDK v5 o posterior para usar este endpoint.

<div id="integration-with-usechat">
  ## Integración con `useChat`
</div>

El hook `useChat` del AI SDK de Vercel es la forma recomendada de integrar la assistant API en tu aplicación.

<Steps>
  <Step title="Instalar AI SDK">
    ```bash
    npm i ai@^6 @ai-sdk/react
    ```
  </Step>

  <Step title="Agregar una ruta proxy">
    Crea una ruta del lado del servidor que agregue tu clave de API del assistant a cada solicitud y la reenvíe a `https://api.mintlify.com/discovery/v2/assistant/{domain}/message`. Guarda la clave en una variable de entorno del lado del servidor.

    No llames al endpoint directamente desde el navegador. Cualquiera que extraiga la clave de tu código del cliente puede usar tus créditos del assistant y leer contenido protegido por autenticación. Consulta [Clave de la API del Assistant](/es/api/introduction#assistant-api-key).

    Para ver una ruta proxy completa en Next.js, consulta [Crea un assistant dentro de tu aplicación](/es/guides/assistant-embed).
  </Step>

  <Step title="Usar el hook">
    Apunta `useChat` a tu ruta proxy.

    ```tsx
    import { useState } from "react";
    import { useChat } from "@ai-sdk/react";
    import { DefaultChatTransport } from "ai";

    function MyComponent() {
      const [input, setInput] = useState("");

      const { messages, sendMessage } = useChat({
        transport: new DefaultChatTransport({
          api: "/api/assistant",
          body: {
            fp: "anonymous",
            retrievalPageSize: 5,
            context: [
              {
                type: "code",
                value: 'const example = "code snippet";',
                elementId: "code-block-1",
              },
            ],
          },
        }),
      });

      return (
        <div>
          {messages.map((message) => (
            <div key={message.id}>
              {message.role === "user" ? "User: " : "Assistant: "}
              {message.parts
                .filter((part) => part.type === "text")
                .map((part) => part.text)
                .join("")}
            </div>
          ))}
          <form
            onSubmit={(e) => {
              e.preventDefault();
              if (input.trim()) {
                sendMessage({ text: input });
                setInput("");
              }
            }}
          >
            <input value={input} onChange={(e) => setInput(e.target.value)} />
            <button type="submit">Send</button>
          </form>
        </div>
      );
    }
    ```

    **Configuración obligatoria:**

    * `transport` - Usa `DefaultChatTransport` con `api` configurado en tu ruta proxy.
    * `body.fp` - Identificador de huella digital (usa `'anonymous'` o un identificador único de usuario).
    * `body.retrievalPageSize` - Número de resultados de búsqueda que se usarán (recomendado: 5).

    **Configuración opcional:**

    * `body.context` - Array de información contextual que se le proporciona al assistant. Cada objeto de contexto contiene:
      * `type` - Puede ser `'code'` o `'textSelection'`.
      * `value` - El fragmento de código o el contenido de texto seleccionado.
      * `path` (opcional) - Ruta al archivo o a la página de origen.
      * `elementId` (opcional) - Identificador del elemento de la interfaz de usuario que contiene el contexto.
    * `body.currentPath` - La ruta de la página que el usuario está viendo en ese momento. Cuando se proporciona, el assistant utiliza este contexto para ofrecer respuestas más relevantes. Longitud máxima: 200 caracteres.
  </Step>
</Steps>

Consulta [useChat](https://ai-sdk.dev/docs/reference/ai-sdk-ui/use-chat) y [Transport](https://ai-sdk.dev/docs/ai-sdk-ui/transport) en la documentación del AI SDK para más detalles.

<div id="migrate-from-v1">
  ## Migrar desde v1
</div>

El endpoint v1 está descontinuado y devuelve `410 Gone`. Para migrar, cambia la URL de `/discovery/v1/assistant/{domain}/message` a `/discovery/v2/assistant/{domain}/message` y actualiza tus mensajes y el manejo del stream.

Tu clave de API y estos campos del cuerpo no cambian: `fp`, `threadId`, `threadKey`, `regenerate`, `retrievalPageSize`, `filter`, `context` y `currentPath`.

<div id="if-you-use-usechat">
  ### Si usas `useChat`
</div>

Actualiza a AI SDK v5 o posterior y usa `DefaultChatTransport` como se muestra en [Integración con `useChat`](#integration-with-usechat). Elimina `streamProtocol` y `sendExtraMessageFields`. No son necesarios en v2. Renderiza los mensajes a partir de `message.parts` en lugar de `message.content`.

<div id="if-you-call-the-api-directly">
  ### Si llamas a la API directamente
</div>

**Los mensajes usan `parts` en lugar de `content`.** Elimina la cadena `content` y envía el texto como una parte de texto. El rol `data` ya no se acepta.

<CodeGroup>

```json v1
{
  "id": "msg_1",
  "role": "user",
  "content": "How do I get started?",
  "parts": [{ "type": "text", "text": "How do I get started?" }]
}
```

```json v2
{
  "id": "msg_1",
  "role": "user",
  "parts": [{ "type": "text", "text": "How do I get started?" }]
}
```

</CodeGroup>

**Los archivos adjuntos son partes `file`.** Reemplaza `experimental_attachments` por entradas en `parts`.

<CodeGroup>

```json v1
{
  "experimental_attachments": [
    { "name": "screenshot.png", "contentType": "image/png", "url": "data:image/png;base64,..." }
  ]
}
```

```json v2
{
  "parts": [
    { "type": "file", "filename": "screenshot.png", "mediaType": "image/png", "url": "data:image/png;base64,..." }
  ]
}
```

</CodeGroup>

**Las respuestas se transmiten como server-sent events.** v1 devuelve el data stream de AI SDK v4, compuesto por líneas `0:"..."`. v2 devuelve el [UI message stream](https://ai-sdk.dev/docs/ai-sdk-ui/stream-protocol#ui-message-stream) de AI SDK. Cada evento es una línea JSON `data: {...}`, el texto llega en eventos `text-delta` y el stream termina con `data: [DONE]`. Los encabezados de respuesta `X-Thread-Id`, `X-Thread-Key` y `X-Message-Id` no cambian.

<div id="rate-limits">
  ## Límites de uso
</div>

La API del assistant tiene el siguiente límite:

* 10.000 solicitudes por organización de Mintlify por hora
