<Info>
  La API REST de la plataforma requiere un [plan Pro o Enterprise](https://mintlify.com/pricing?ref=api).

  La [API REST de Mintlify Index](/es/api/search-index/introduction) usa una clave de API y una URL base independientes.
</Info>

La API REST (Representational State Transfer) de Mintlify te permite interactuar de forma programática con tu documentación, activar actualizaciones, integrar experiencias de chat basadas en IA y exportar datos de Analytics.

<div id="endpoints">
  ## Puntos de conexión
</div>

* [Activar actualización](/es/api/update/trigger): Activa una actualización de tu sitio cuando quieras.
* [Obtener estado de actualización](/es/api/update/status): Obtén el estado de una actualización y otros detalles de tu documentación.
* [Activar implementación de vista previa](/es/api/preview/trigger): Crea o actualiza una implementación de vista previa para una rama específica.
* [Activar automatización](/es/api/automations/trigger): Ejecuta una automatización programada bajo demanda.
* [Detectar prosa con apariencia de IA](/es/api/admin/deslop): Analiza una página en busca de prosa generada por IA y obtén sugerencias de reescritura humana.
* [Crear tarea de agente](/es/api/agent/v2/create-agent-job): Crea una tarea de agente para editar tu documentación automáticamente.
* [Obtener tarea de agente](/es/api/agent/v2/get-agent-job): Obtén los detalles y el estado de una tarea de agente específica.
* [Enviar mensaje de seguimiento](/es/api/agent/v2/send-message): Envía un mensaje de seguimiento a una tarea de agente existente.
* [Crear mensaje del asistente](/es/api/assistant/create-assistant-message-v2): Integra el asistente, entrenado con tu documentación, en cualquier aplicación que elijas.
* [Buscar documentación](/es/api/assistant/search): Busca en tu documentación.
* [Obtener contenido de página](/es/api/assistant/get-page-content): Recupera el contenido de texto completo de una página de documentación.
* [Obtener comentarios de usuarios](/es/api/analytics/feedback): Exporta los comentarios de los usuarios de tu documentación.
* [Obtener comentarios por página](/es/api/analytics/feedback-by-page): Exporta los recuentos de comentarios agregados por página.
* [Obtener conversaciones del asistente](/es/api/analytics/assistant-conversations): Exporta el historial de conversaciones del asistente.
* [Obtener estadísticas de llamadas del asistente](/es/api/analytics/assistant-caller-stats): Obtén un desglose de los recuentos de consultas del asistente por tipo de origen.
* [Obtener consultas de búsqueda](/es/api/analytics/searches): Exporta los términos de búsqueda de la documentación y los datos de Analytics.
* [Obtener visualizaciones de páginas](/es/api/analytics/views): Exporta el número de visualizaciones del contenido por página y de todo el sitio.
* [Obtener visitantes únicos](/es/api/analytics/visitors): Exporta el número de visitantes únicos por página y de todo el sitio.

<div id="common-use-cases">
  ### Casos de uso comunes
</div>

* **Implementaciones automatizadas**: Activa actualizaciones del sitio a intervalos establecidos o cuando se produzcan eventos con [Activar actualización](/es/api/update/trigger) y [Obtener estado de actualización](/es/api/update/status).
* **Integración CI/CD**: Actualiza la documentación como parte de tu pipeline de implementación cuando el código cambie con [Activar actualización](/es/api/update/trigger).
* **Implementaciones de vista previa**: Crea o actualiza implementaciones de vista previa de forma programática en tu pipeline CI/CD con [Activar implementación de vista previa](/es/api/preview/trigger).
* **Automatizaciones bajo demanda**: Activa automatizaciones programadas desde tu pipeline CI/CD o tus herramientas de lanzamiento con [Activar automatización](/es/api/automations/trigger).
* **Integraciones del asistente**: Integra el asistente de IA en tu producto, portal de soporte o herramientas internas con [Crear mensaje del asistente](/es/api/assistant/create-assistant-message-v2).
* **Recuperación de documentación**: Busca y recupera documentación para experiencias de búsqueda personalizadas con [Buscar documentación](/es/api/assistant/search) y [Obtener contenido de página](/es/api/assistant/get-page-content).
* **Edición automatizada**: Usa tareas de agente para actualizar la documentación programáticamente y a escala con [Crear tarea de agente](/es/api/agent/v2/create-agent-job), [Obtener tarea de agente](/es/api/agent/v2/get-agent-job) y [Enviar mensaje de seguimiento](/es/api/agent/v2/send-message).
* **Exportación de Analytics**: Exporta comentarios, conversaciones del asistente, datos de búsqueda, visualizaciones de páginas y datos de visitantes para análisis externo con [Obtener comentarios de usuarios](/es/api/analytics/feedback), [Obtener comentarios por página](/es/api/analytics/feedback-by-page), [Obtener conversaciones del asistente](/es/api/analytics/assistant-conversations), [Obtener estadísticas de llamadas del asistente](/es/api/analytics/assistant-caller-stats), [Obtener consultas de búsqueda](/es/api/analytics/searches), [Obtener visualizaciones de páginas](/es/api/analytics/views) y [Obtener visitantes únicos](/es/api/analytics/visitors).

<div id="authentication">
  ## Autenticación
</div>

Genera claves de API en la [página de claves de API](https://app.mintlify.com/settings/organization/api-keys) de tu dashboard. Las claves de API de administrador y de Index pertenecen a una organización; puedes usar las mismas claves en varias implementaciones dentro de la misma organización. Las claves de API del asistente pertenecen a la implementación donde las creas.

Puedes crear hasta 10 claves de API por hora y por organización.

Al crear una clave, puedes configurarla para que caduque en 7, 30, 60 o 90 días, o seleccionar **Sin caducidad**. Las nuevas claves caducan en 90 días de forma predeterminada. La página de claves de API muestra una insignia **Caduca en …** para las claves que caducan en los próximos 7 días y una insignia **Caducada** para las que ya han caducado. Las claves caducadas dejan de funcionar, por lo que debes rotarlas o reemplazarlas antes de la fecha de caducidad.

Mintlify usa tres tipos de claves de API, cada una con un conjunto diferente de puntos de conexión:

| Tipo de clave | Prefijo | Uso |
| --- | --- | --- |
| Clave de API de administrador | `mint_` | Actualizaciones, tareas de agente y exportaciones de Analytics. Solo del lado del servidor. |
| Clave de API del asistente | `mint_dsc_` | Mensajes del asistente, búsqueda de documentación y contenido de páginas. Usa un proxy en producción. |
| Clave de API de Index | `mint_us_` | Búsqueda de Index, ensamblado de contexto y recuperación de contenido. Solo del lado del servidor. |

<div id="assistant-api-key">
  ### Clave de la API del asistente
</div>

<Warning>
  No integres directamente la clave de API del asistente en código del lado del cliente. Cualquier visitante que extraiga la clave puede llamar al punto de conexión de mensajes del asistente en tu nombre, consumir créditos y provocar potencialmente cargos por exceso de uso.

  En implementaciones de producción, usa tu propio backend como proxy para las solicitudes que utilicen una clave de API del asistente y almacena la clave como una variable de entorno del lado del servidor. Enrutar las solicitudes a través de un proxy también te permite añadir límites de uso, autenticación y protección contra bots para evitar abusos.
</Warning>

Usa la clave de API del asistente para autenticar solicitudes a los puntos de conexión del asistente, de búsqueda y de contenido de páginas.

* [Crear mensaje del asistente](/es/api/assistant/create-assistant-message-v2)
* [Buscar documentación](/es/api/assistant/search)
* [Obtener contenido de página](/es/api/assistant/get-page-content)

Las claves de API del asistente comienzan con el prefijo `mint_dsc_`.

<Note>
  Las solicitudes de búsqueda de documentación y de contenido de páginas no consumen créditos. Las solicitudes de mensajes del asistente usan créditos y pueden generar cargos por exceso de uso.
</Note>

<div id="index-api-key">
  ### Clave de la API de Index
</div>

Usa una clave de API de Index para autenticar solicitudes a la API REST de [Mintlify Index](/es/search-index). Las claves de API de Index comienzan con el prefijo `mint_us_`.

La clave de API de Index es un secreto del lado del servidor. No la expongas en código del lado del cliente.

<div id="restrict-keys-by-ip-address">
  ### Restringir claves por dirección IP
</div>

Puedes restringir opcionalmente una clave de API a una lista de direcciones IP o rangos CIDR permitidos. Cuando una clave tiene una lista de permitidos, las solicitudes desde cualquier otra dirección IP se rechazan con una respuesta `403`. Las claves de API de administrador, del asistente y de Index admiten listas de permitidos.

Configura la lista de permitidos al crear una clave en la [página de claves de API](https://app.mintlify.com/settings/organization/api-keys) de tu dashboard. La lista de permitidos es fija durante la vida de la clave; para cambiarla, debes crear una clave nueva. Si no configuras una lista de permitidos, la clave acepta solicitudes desde cualquier dirección IP.

Las entradas admiten:

* Direcciones IPv4 e IPv6, por ejemplo `203.0.113.5` o `2001:db8::1`.
* Rangos CIDR, por ejemplo `198.51.100.0/24` o `2001:db8::/48`.

No puedes usar entradas generales como `0.0.0.0/0` y `::/0`.

Usa listas de IP permitidas cuando un conjunto estable de IP de salida llame a tu clave de API, por ejemplo, un runner de CI/CD, una puerta de enlace NAT estática o tu servidor backend. Evita las listas de permitidos para claves usadas desde portátiles de personas desarrolladoras u otros entornos con IP cambiantes.

<div id="restrict-admin-keys-by-scope">
  ### Restringir claves de administrador por ámbito
</div>

Puedes restringir opcionalmente una clave de API de administrador a los ámbitos `read` o `write`. Los ámbitos se aplican solo a las claves de API de administrador.

Configura los ámbitos al crear una clave en la [página de claves de API](https://app.mintlify.com/settings/organization/api-keys) de tu dashboard. Los ámbitos son fijos durante la vida de la clave; para cambiarlos, debes crear una clave nueva. Si no configuras ningún ámbito, la clave puede llamar a todos los puntos de conexión de administrador.

Mintlify deriva el ámbito requerido a partir del método HTTP de la solicitud.

| Método HTTP | Ámbito requerido |
| --- | --- |
| `GET`, `HEAD` | `read` |
| Todos los demás | `write` |

Una clave con `write` también satisface `read`, por lo que `["read", "write"]` y `["write"]` permiten todos los puntos de conexión. Las solicitudes que requieren un ámbito que la clave no tiene se rechazan con una respuesta `403`.

El ámbito solo acepta `read` y `write`. Cualquier otro valor devuelve una respuesta `400` al crear la clave.

<div id="set-an-expiration-date">
  ### Establecer una fecha de expiración
</div>

Puedes establecer opcionalmente una fecha de expiración para cualquier clave de API al crearla. Cuando pasa la marca de tiempo de expiración, las solicitudes que usan la clave devuelven una respuesta `401`. Todas las claves de API admiten la expiración.

Configura la expiración en la [página de claves de API](https://app.mintlify.com/settings/organization/api-keys) de tu dashboard. La expiración es fija durante la vida de la clave. Para cambiarla, debes crear una clave nueva. Si no configuras una expiración, la clave nunca caduca.

La expiración debe ser una marca de tiempo ISO 8601 futura. Las marcas de tiempo pasadas o no válidas devuelven una respuesta `400` al crear la clave. La expiración se devuelve como `expiresAt` al listar las claves, o como `null` para las claves sin expiración.

Usa expiraciones para credenciales de corta duración, como tokens de CI/CD, colaboradores externos o scripts puntuales. Rota las claves de larga duración creando una de reemplazo, actualizando tus integraciones y eliminando la clave anterior.
