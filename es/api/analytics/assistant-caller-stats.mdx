<div id="usage">
  ## Uso
</div>

Utiliza este endpoint para ver cuántas conversaciones del assistant provienen de cada tipo de origen. Cada conversación cuenta una sola vez, sin importar cuántas preguntas contenga. La respuesta desglosa el total de conversaciones en:

- `web`: Conversaciones desde el sitio de documentación
- `api`: Conversaciones desde llamadas directas a la API
- `other`: Conversaciones desde otras fuentes (por ejemplo, integraciones, SDKs)
- **total**: Suma de todos los tipos de origen

<div id="filtering">
  ## Filtrado
</div>

Filtra por rango de fechas usando los parámetros `dateFrom` y `dateTo`. Cada conversación cuenta para el rango en el que se inició.

## Límites de uso

Este endpoint permite 100 solicitudes por organización por hora. Todos los endpoints de analytics comparten este límite.
