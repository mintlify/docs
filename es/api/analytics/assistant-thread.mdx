<div id="usage">
  ## Uso
</div>

Usa este endpoint para obtener la transcripción completa de mensajes de una única conversación del assistant en formato JSON. La respuesta incluye la lista ordenada de mensajes del usuario y del assistant, cada uno con un ID, rol, contenido y marca de tiempo.

Usos comunes:

- Adjuntar la transcripción de la conversación a un ticket de soporte cuando un usuario contacta desde el assistant.
- Reconstruir una conversación específica para revisión, control de calidad o análisis fuera de línea.

<div id="getting-a-thread-id">
  ## Obtener un thread ID
</div>

Puedes obtener un `threadId` desde cualquiera de las siguientes fuentes:

- El campo `id` de cualquier fila devuelta por [Obtener conversaciones del assistant](/es/api/analytics/assistant-conversations).
- El parámetro de consulta `threadId` que Mintlify añade a la URL de soporte cuando el assistant deriva a tu plataforma de soporte usando la [derivación por enlace](/es/assistant/configure#deflect-to-a-support-link).

## Límites de uso

Este endpoint permite 100 solicitudes por organización por hora. Todos los endpoints de analytics comparten este límite.
