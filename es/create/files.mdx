Mintlify sirve automáticamente activos estáticos desde tu repositorio de documentación en la ruta correspondiente de tu domain. Por ejemplo, si tienes `/images/logo.png` en tu repositorio, el archivo de imagen estará disponible en `https://docs.your-project.com/images/logo.png`.

Puedes poner a disposición de tus usuarios cualquier tipo de archivo compatible, incluidas especificaciones OpenAPI, imágenes, vídeos y más.

Los archivos deben ser menores de 20 MB. Para servir archivos más grandes, almacénalos con [Git LFS](#large-files-with-git-lfs).

<Note>
  La entrega de archivos no es compatible para sitios de documentación con la autenticación habilitada. Si tu sitio requiere autenticación, los archivos estáticos no son accesibles en sus URL directas.
</Note>

<div id="supported-file-types">
  ## Tipos de archivo compatibles
</div>

Tipos de archivo compatibles para todos los planes:

- **Imágenes**: `.png`, `.jpg`, `.jpeg`, `.gif`, `.webp`, `.svg`, `.ico`
- **Vídeo**: `.mp4`, `.webm`
- **Audio**: `.mp3`, `.wav`
- **Datos**: `.json`, `.yaml`
- **Hojas de estilo**: `.css`
- **Scripts**: `.js`
- **Fuentes**: `.woff`, `.woff2`, `.ttf`, `.eot`

Tipos de archivo compatibles para los planes Enterprise:

- **Documentos**: `.pdf`, `.txt`
- **Datos**: `.xml`, `.csv`
- **Archivos comprimidos**: `.zip`

<div id="file-organization">
  ## Organización de archivos
</div>

Organiza tus archivos en carpetas para que tu repositorio sea fácil de navegar:

```text
/your-project
  |- docs.json
  |- images/
    |- logo.png
    |- screenshots/
      |- dashboard.png
  |- assets/
    |- whitepaper.pdf
    |- demo-video.mp4
```

Mintlify sirve los archivos desde la raíz de tu domain, por lo que la estructura de tu repositorio se corresponde directamente con la estructura de la URL. En el ejemplo anterior, `assets/whitepaper.pdf` estaría disponible en `https://docs.your-project.com/assets/whitepaper.pdf`.

<div id="large-files-with-git-lfs">
  ## Archivos grandes con Git LFS
</div>

<Info>
  La compatibilidad con Git LFS requiere un [plan Enterprise](https://mintlify.com/pricing?ref=git-lfs). Contacta a tu gestor de cuenta para habilitarla.
</Info>

Si tu repositorio almacena archivos con [Git Large File Storage (LFS)](https://git-lfs.com), Mintlify descarga cada archivo desde GitHub cuando despliegas y lo sirve en su ruta como cualquier otro archivo estático. Los archivos almacenados con Git LFS pueden superar los 20 MB, pero deben seguir siendo de un [tipo de archivo compatible](#supported-file-types).

Para almacenar un archivo con Git LFS, rastréalo y envíalo a la rama desde la que despliega Mintlify.

```bash
git lfs track "videos/*.mp4"
git add .gitattributes videos/product-tour.mp4
git commit -m "Store videos with Git LFS"
git push
```

Mintlify solo vuelve a descargar un archivo cuando cambia, por lo que los archivos sin cambios no consumen tu ancho de banda de GitHub LFS en despliegues posteriores.

Si Mintlify no puede descargar un archivo, por ejemplo porque se agotó tu cuota de ancho de banda de GitHub LFS, el despliegue se completa igualmente. La versión anterior del archivo sigue publicada y el registro del despliegue muestra una advertencia con la ruta del archivo y el motivo.

La compatibilidad con Git LFS funciona con repositorios en GitHub.com. No es compatible con repositorios de GitHub Enterprise Server, GitLab o Bitbucket, ni con sitios que tengan la autenticación habilitada. Sin compatibilidad con Git LFS, Mintlify sirve el pequeño archivo puntero de LFS en la ruta del archivo en lugar del propio archivo, y el registro del despliegue muestra una advertencia.
