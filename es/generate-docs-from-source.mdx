Mintlify puede usar un repositorio de GitHub existente como contexto de solo lectura al generar tu documentación. Usa este flujo de trabajo cuando tu producto o código vivan en un repositorio y tu documentación deba vivir en otro.

Mintlify lee tu repositorio de código fuente, pero no escribe en él. Mintlify escribe las páginas generadas en tu espacio de trabajo de documentación, donde puedes revisarlas y publicarlas desde el editor web.

<div id="before-you-begin">
  ## Antes de comenzar
</div>

- Asegúrate de poder acceder al repositorio de GitHub que contiene el producto o el código que quieres documentar.
- Conecta un repositorio de documentación durante la configuración inicial o permite que Mintlify cree uno por ti.
- Si el repositorio de código fuente es privado, prepárate para autorizar la aplicación de GitHub de Mintlify cuando la configuración inicial solicite acceso.

<div id="generate-documentation-from-a-repository">
  ## Genera documentación desde un repositorio
</div>

1. Abre [la configuración inicial de Mintlify](https://mintlify.com/start).
1. Añade la URL del repositorio de GitHub que contiene tu material de origen. Puedes añadir más de un repositorio de código fuente.
1. Si Mintlify no puede acceder a un repositorio privado, haz clic en **Autorizar** y completa el flujo de autorización de GitHub. Los repositorios públicos se pueden usar como fuentes de solo lectura sin acceso de escritura.
1. Haz clic en **Implementar** para iniciar la generación.

El paso de importación también acepta un sitio web existente como material de origen. Añade una URL de sitio web en lugar de una URL de repositorio cuando quieras que Mintlify use contenido publicado como contexto.

El flujo de configuración inicial también intenta encontrar el contexto de marca del sitio generado. Mintlify comprueba el dominio de la primera URL de origen, después la página de inicio del repositorio de GitHub conectado y, por último, el nombre de la empresa. Cuando hay datos de marca disponibles, el agente de generación usa sus colores para los colores primario, claro y oscuro de `docs.json`, y selecciona URL adecuadas para el logotipo y el favicon. La búsqueda de marca no bloquea la generación. Si no encuentra datos de marca, la generación continúa sin estos recursos.

<div id="review-generated-pages">
  ## Revisa las páginas generadas
</div>

La documentación generada utiliza el siguiente flujo de trabajo:

1. Mintlify lee los repositorios de código fuente como contexto de investigación.
1. Mintlify escribe las páginas de documentación en el espacio de trabajo de documentación con permisos de escritura.
1. Las páginas nuevas aparecen en la navegación del editor a medida que se escriben. Mintlify crea grupos de la barra lateral a partir de la ruta de la página cuando no existe un grupo coincidente.
1. Mintlify completa la configuración de navegación una vez escritas las páginas. El `docs.json` final controla el orden de las páginas y la estructura de la barra lateral.

Cada página generada necesita un frontmatter YAML completo. Durante la generación, los valores `title`, `sidebarTitle` y `description` del frontmatter se sincronizan con los metadatos de navegación de la página cuando el agente de generación escribe o edita la página.

```mdx
---
title: "Authenticate API requests"
sidebarTitle: "Authentication"
description: "Learn how to authenticate requests to the API."
---

Explain how readers authenticate their requests.
```

Usa `title` para el título de la página, `sidebarTitle` para una etiqueta de navegación más corta y `description` para la descripción de la página. Si se omite un campo, Mintlify conserva el valor de navegación existente. Si una página no tiene un título de navegación útil, Mintlify lo deriva de la ruta de la página.

<div id="publish-your-documentation">
  ## Publica tu documentación
</div>

Abre el sitio generado en el [editor web](/es/editor/index) para revisar las páginas, la navegación y el frontmatter. Cuando tus cambios estén listos, haz clic en **Publicar**. Después, puedes seguir editando con el [editor web](/es/editor/pages) o tu repositorio de Git conectado.

Para una configuración manual sin generar documentación desde un repositorio de código fuente, consulta la [guía de inicio rápido](/es/quickstart).
