Agrega tu write key de Segment a tu archivo `docs.json` para enviar Analytics a Segment.

<CodeGroup>

```json Opciones de Analytics en docs.json
"integrations": {
    "segment": {
        "key": "required",
        "cdnUrl": "optional"
    }
}
```

```json Ejemplo
"integrations": {
    "segment": {
        "key": "nqJxiRG15Y6M594P8Sb8ESEciU3VC2"
    }
}
```

</CodeGroup>

## URL de CDN personalizada

Usa `cdnUrl` para cargar Segment a través de tu propio subdominio en lugar del predeterminado `https://cdn.segment.com`. Esta es la solución estándar para los bloqueadores de anuncios que bloquean el CDN predeterminado de Segment y requiere configurar la [función de dominio personalizado de Segment](https://segment.com/docs/connections/sources/custom-domain/).

`cdnUrl` debe ser una URL HTTPS válida y no puede contener parámetros de consulta ni fragmentos. Cuando se omite, Segment se carga desde `https://cdn.segment.com`.

```json Ejemplo con CDN personalizada
"integrations": {
    "segment": {
        "key": "nqJxiRG15Y6M594P8Sb8ESEciU3VC2",
        "cdnUrl": "https://analytics.example.com"
    }
}
```
