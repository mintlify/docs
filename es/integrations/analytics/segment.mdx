Agrega tu write key de Segment a tu archivo `docs.json` para enviar Analytics a Segment.

<CodeGroup>

```json Opciones de Analytics en docs.json
"integrations": {
    "segment": {
        "key": "required",
        "cdnUrl": "optional"
    }
}
```

```json Ejemplo
"integrations": {
    "segment": {
        "key": "nqJxiRG15Y6M594P8Sb8ESEciU3VC2",
        "cdnUrl": "https://cdn.mydomain.com"
    }
}
```

</CodeGroup>

<div id="custom-cdn-url">

## URL de CDN personalizada

</div>

Si usas la [función de dominio personalizado de Segment](https://segment.com/docs/connections/sources/custom-domains/), configura `cdnUrl` para cargar el script de Segment desde tu dominio personalizado en lugar del predeterminado `cdn.segment.com`. Cargar desde tu propio dominio ayuda a evitar que los bloqueadores de anuncios bloqueen tus análisis.

El valor de `cdnUrl` debe ser una URL HTTPS sin parámetros de consulta ni fragmentos.
