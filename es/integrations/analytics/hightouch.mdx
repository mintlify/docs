Necesitas una write key de una fuente de eventos de Hightouch antes de poder conectar Hightouch. Crea una fuente de eventos en tu espacio de trabajo de Hightouch y copia su write key. Consulta la [documentación de fuentes de eventos de Hightouch](https://hightouch.com/docs/events/sources/overview) para conocer los pasos de configuración.

Agrega la write key a tu archivo `docs.json` para enviar Analytics a Hightouch.

<Info>

  No incluyas `https://` en el `apiHost`.

</Info>

<CodeGroup>

```json Opciones de Analytics en docs.json
"integrations": {
    "hightouch": {
        "writeKey": "required",
        "apiHost": "optional"
    }
}
```

```json Ejemplo
"integrations": {
    "hightouch": {
        "writeKey": "9132c81do371p76sr11da0075469b54f77649c9a067dp0303p56q0q64n072336",
        "apiHost": "us-east-1.hightouch-events.com"
    }
}
```

</CodeGroup>

<div id="configuration-options">
  ## Opciones de configuración
</div>

<ParamField path="writeKey" type="string" required>
  La write key de tu fuente de eventos de Hightouch.
</ParamField>

<ParamField path="apiHost" type="string">
  El host de la API de eventos de Hightouch, sin `https://`. De forma predeterminada es `us-east-1.hightouch-events.com`.
</ParamField>

<div id="verify-the-integration">
  ## Verifica la integración
</div>

Después de desplegar tus cambios, Mintlify envía eventos de interacción, como vistas de página y consultas de búsqueda, a Hightouch. Para confirmar que los eventos llegan, inspecciona los eventos en vivo en el [depurador de eventos de Hightouch](https://hightouch.com/docs/events/sources/overview#debugger).

Para obtener una descripción general de los eventos que Mintlify registra, consulta [Integraciones de Analytics](/es/integrations/analytics/overview).
