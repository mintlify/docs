<div id="cookie-consent-banner">
  ## Banner de consentimiento de cookies
</div>

Mintlify incluye un banner de consentimiento de cookies integrado que pide permiso a los visitantes antes de que tu sitio rastree cookies de analítica o marketing. Úsalo si necesitas una forma sencilla de cumplir con el RGPD y normativas similares sin configurar una plataforma de terceros.

Para activar o desactivar el banner:

1. En tu dashboard, ve a **Settings** > **Privacy**.
2. Activa **Consent banner** para mostrar el banner a los visitantes, o desactívalo para ocultarlo.

Cuando el banner está activado, las integraciones de analítica solo envían eventos para los visitantes que otorgan su consentimiento. Revocar el consentimiento recarga la página para descargar los scripts de analítica ya cargados.

<div id="cookie-consent-and-disabling-telemetry">
  ## Consentimiento de cookies y desactivación de la telemetría
</div>

Si necesitas verificar si un usuario ya ha dado su consentimiento para las cookies para cumplir con el RGPD, puedes especificar una key de almacenamiento local y un value en `cookies`:

```json
  "integrations": {
    "cookies": {
      "key": "LOCAL STORAGE KEY",
      "value": "LOCAL STORAGE VALUE"
    }
  }
```

Si estableces estos valores, tu sitio comprobará el almacenamiento local en busca de la key y el value especificados para determinar si un usuario ha dado su consentimiento para las cookies. Si un usuario no ha dado su consentimiento para las cookies, tu sitio desactivará la telemetría para ese usuario.

Si quieres desactivar la telemetría para todos los usuarios, añade lo siguiente a tu archivo `docs.json`:

```json
  "integrations": {
    "telemetry": {
      "enabled": false
    }
  }
```

<Note>
  Si desactivas la telemetría, no podrás recopilar comentarios en tus páginas de documentación, incluso si habilitas los comentarios en tu dashboard.
</Note>
