<Info>
  Las analytics de ahorros requieren un [plan Enterprise](https://mintlify.com/pricing?ref=analytics).
</Info>

La vista **Ahorros** de la página de [analytics](https://app.mintlify.com/analytics) estima cuánto trabajo le ahorra Mintlify a tu equipo. Muestra las horas ahorradas por el agente y las automatizaciones, y los costos de soporte evitados cuando el assistant responde las preguntas de los usuarios.

Usa la vista Ahorros para:

- **Informar sobre el retorno de la inversión**: Comparte con las partes interesadas las horas y el dinero ahorrados estimados.
- **Comparar el valor de las automatizaciones**: Consulta qué tipos de trabajo automatizado aportan más ahorro de tiempo.

<div id="time-saved">
  ## Tiempo ahorrado
</div>

El gráfico **Tiempo ahorrado (horas)** desglosa las horas ahorradas estimadas en cuatro categorías.

- **Agente de Slack**: Pull requests que el [agente abre desde Slack](/es/agent/slack).
- **Automatizaciones de contenido autoactualizable**: Pull requests de [automatizaciones de contenido autoactualizable](/es/automations/reference#self-updating-content-automations), como Actualizar a partir de cambios de código y Redactar el registro de cambios.
- **Automatizaciones de mantenimiento**: Pull requests de [automatizaciones de mantenimiento](/es/automations/reference#maintenance-automations), como Traducir contenido y Corregir enlaces rotos.
- **Automatizaciones personalizadas**: Pull requests de [automatizaciones personalizadas](/es/automations/create).

Mintlify solo cuenta las pull requests fusionadas que se abrieron por primera vez durante el intervalo de tiempo seleccionado. Cada pull request suma horas según el número de líneas modificadas.

| Líneas modificadas | Horas ahorradas |
| :----------------- | :-------------- |
| Menos de 20        | 0.5             |
| De 20 a 99         | 2               |
| 100 o más          | 5               |

Cuando el número de líneas de una pull request no está disponible, Mintlify usa una estimación predeterminada.

<div id="money-saved">
  ## Dinero ahorrado
</div>

La tarjeta **Dinero ahorrado** muestra dos métricas.

- **Dinero ahorrado**: Costo de soporte evitado estimado, calculado en 12 $ por cada pregunta que responde el assistant, según el costo promedio de los tickets de soporte en distintas industrias.
- **Preguntas respondidas por el assistant**: Número de conversaciones con el [assistant](/es/analytics/assistant) en el intervalo de tiempo seleccionado que el assistant respondió sin derivar al usuario a ventas o soporte.
