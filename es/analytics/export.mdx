<Info>
  Las analíticas requieren un [plan Pro o Enterprise](https://mintlify.com/pricing?ref=analytics).
</Info>

Exporta categorías de analíticas a CSV para análisis más profundos, informes o archivo. Las exportaciones usan el rango de tiempo seleccionado en la página de [analíticas](https://app.mintlify.com/analytics).

1. Selecciona **Export to CSV**.
2. Selecciona una categoría para exportar: tráfico, referencias, conversaciones del assistant, búsquedas o comentarios.
3. Espera a que Mintlify te envíe por correo un enlace de descarga.

<div id="interpret-traffic-exports">
  ## Interpretar las exportaciones de tráfico
</div>

Las exportaciones de tráfico desglosan las vistas de página por categoría de visitante para que puedas comparar el tráfico de humanos, agentes, crawlers de búsqueda y otros bots.

| Columna | Descripción |
| --- | --- |
| `humanViews` | Vistas de página HTML de tráfico no proveniente de bots. |
| `aiViews` | Vistas de agentes de IA como ChatGPT, Claude y Cursor, además de solicitudes de páginas Markdown desde clientes que no son crawlers reconocidos. |
| `searchIndexViews` | Vistas de crawlers de búsqueda e indexación, como Googlebot, Bingbot y OAI-SearchBot. |
| `trainingViews` | Vistas de crawlers que recopilan contenido para el entrenamiento de modelos de IA, como GPTBot, ClaudeBot y CCBot. |
| `otherAiViews` | Vistas de otros bots relacionados con IA que no encajan en las categorías anteriores. |
| `totalViews` | La suma de `humanViews` y `aiViews`. |

Mintlify clasifica cada vista utilizando patrones conocidos de user-agent para crawlers de búsqueda, crawlers de entrenamiento y assistants de IA. Las categorías son mutuamente excluyentes, por lo que cada vista se cuenta en exactamente una columna.

<Note>
  `searchIndexViews`, `trainingViews` y `otherAiViews` no se cuentan en `totalViews`.
</Note>

<div id="interpret-assistant-exports">
  ## Interpretar las exportaciones del assistant
</div>

Las exportaciones del assistant incluyen las consultas, las respuestas, las fuentes y una columna `resolutionStatus`. La columna indica si el assistant respondió con éxito a cada pregunta con un valor de `answered` o `unanswered`. Úsala para identificar brechas en la documentación reveladas por preguntas que el assistant no pudo resolver.

<Tip>
  Prompts de análisis de ejemplo para las exportaciones del assistant:

  - Enumera cualquier consulta que no tenga fuentes citadas.
  - Encuentra patrones en las interacciones no exitosas.
  - Agrupa las consultas sin respuesta por tema para priorizar las actualizaciones de contenido.
</Tip>
