Agrega páginas interactivas para que tus lectores recorran un flujo, usen widgets o vean tu producto en funcionamiento. Esta guía cubre cuatro elementos para esas páginas:

1. [Widgets interactivos](#interactive-widgets) escritos en la página como componentes de React.
2. [Videos](#videos) del producto, o de una sesión de un agente, grabados con un script de navegador.
3. [Capturas de pantalla](#screenshots) en marcos, con versiones clara y oscura.
4. [Tablas](#tables) para estados, límites y comparaciones.

<Note>
  Los productos, las cifras y los pasos de los ejemplos de esta guía son datos de muestra.
</Note>

<div id="choose-a-building-block">
  ## Elige un elemento
</div>

| Quieres mostrar | Usa | Por qué |
| --- | --- | --- |
| Un flujo con varios pasos o estados | Widget interactivo | Los lectores avanzan a su propio ritmo y cada estado tiene su propia explicación. |
| Cómo cambia un costo, un límite o un ajuste según la entrada | Widget interactivo | Los lectores pueden calcular sus propias cifras en lugar de un ejemplo. |
| El producto haciendo algo de principio a fin | Video | El movimiento muestra tiempos y transiciones que las capturas no pueden mostrar. |
| Una pantalla, un ajuste o un resultado | Captura de pantalla | Carga rápido y los lectores pueden recorrerla con la vista. |
| Estados, límites u opciones lado a lado | Tabla | Los lectores comparan filas sin leer prosa. |

<div id="interactive-widgets">
  ## Widgets interactivos
</div>

Un widget es un componente de React declarado en la página con `export const` y colocado luego con una etiqueta como `<RxJourney />`. Pon las definiciones de los componentes al final del archivo para que el contenido se lea de arriba abajo. Consulta [Componentes de React](/es/customize/react-components) para ver lo que admite el entorno MDX.

<div id="how-the-calculator-works">
  ### Cómo funciona la calculadora
</div>

Este es el código fuente completo de la calculadora. Los botones de plan, los controles deslizantes y el resultado leen del estado, y el total se calcula durante el renderizado.

```mdx usage.mdx [expandable]
<RxCalculator />

export const RxCalculator = () => {
  const plans = { Basic: 0.12, Team: 0.08, Business: 0.05 };
  const [plan, setPlan] = useState("Team");
  const [seats, setSeats] = useState(12);
  const [runs, setRuns] = useState(40);
  const perRun = plans[plan];
  const total = seats * runs * perRun;
  const border = "1px solid rgba(127,127,127,.3)";
  return (
    <div className="not-prose" style={{ border, borderRadius: 14, padding: 16, display: "grid", gap: 14, fontSize: 14 }}>
      <div role="group" aria-label="Plan" style={{ display: "flex", flexWrap: "wrap", gap: 8 }}>
        {Object.keys(plans).map((name) => (
          <button
            key={name}
            type="button"
            aria-pressed={plan === name}
            onClick={() => setPlan(name)}
            style={{
              padding: "6px 12px", borderRadius: 8, font: "inherit", color: "inherit", cursor: "pointer",
              border: plan === name ? "1px solid #26BD6C" : border,
              background: plan === name ? "rgba(38,189,108,.15)" : "transparent",
            }}
          >
            {name}
          </button>
        ))}
      </div>
      <label style={{ display: "grid", gap: 6 }}>
        Seats: {seats}
        <input type="range" min={1} max={50} value={seats} onChange={(e) => setSeats(Number(e.target.value))} />
      </label>
      <label style={{ display: "grid", gap: 6 }}>
        Runs per seat each month: {runs}
        <input type="range" min={5} max={200} step={5} value={runs} onChange={(e) => setRuns(Number(e.target.value))} />
      </label>
      <div style={{ display: "flex", flexWrap: "wrap", justifyContent: "space-between", gap: 8, padding: 12, borderRadius: 10, background: "rgba(127,127,127,.08)" }}>
        <span style={{ opacity: 0.75 }}>{seats} seats × {runs} runs × ${perRun.toFixed(2)}</span>
        <strong>${total.toFixed(2)} per month</strong>
      </div>
    </div>
  );
};
```

<div id="widget-guidelines">
  ### Pautas para widgets
</div>

- Haz que cada color funcione en modo claro y oscuro. Usa `currentColor` o `inherit` para el texto y las líneas, grises translúcidos como `rgba(127,127,127,.25)` para bordes y rellenos, y un único color de acento. Evita el negro o el blanco fijos.
- Agrega `className="not-prose"` al elemento externo para que los estilos tipográficos de la página no cambien el espaciado dentro del widget.
- Escribe los datos en el componente como constantes. No obtengas datos ni uses `localStorage`, `sessionStorage` o cookies, porque fallan o no hacen nada en el editor.
- Escribe JavaScript simple. Una anotación de TypeScript rompe toda la página en tu sitio publicado.
- Pon los enlaces en la prosa alrededor del widget. Los enlaces dentro de un widget no navegan en el editor.
- Da a los componentes de cada página un prefijo corto compartido, como `Rx`, para que sus nombres no choquen con los componentes integrados ni entre sí.
- Da a los botones y campos etiquetas visibles o un `aria-label`, y marca la opción seleccionada con `aria-pressed` o `aria-current`.
- Limita cada página a unos pocos widgets. El editor ejecuta como máximo 10 widgets a la vez y pausa el resto hasta que aparecen al desplazarse.
- Para usar un widget en más de una página, muévelo a un archivo en `/snippets/` e impórtalo. Consulta [Fragmentos reutilizables](/es/create/reusable-snippets).

<div id="videos">
  ## Videos
</div>

Graba un video corto cuando los lectores necesitan ver algo en movimiento: un recorrido por una interfaz, un despliegue que termina o un agente trabajando en una tarea. Los videos silenciados que se repiten funcionan como capturas animadas. Mantén los clips autoalojados cortos y ligeros, y aloja los videos más largos en una plataforma como YouTube. Consulta [Medios](/es/guides/media) para saber cuándo usar video y cómo reducir el tamaño de los archivos.

```mdx
<Frame caption="Creating a project, from sign in to the first deployment">
  <video
    src="/images/walkthrough.webm"
    controls
    autoPlay
    muted
    loop
    playsInline
    className="w-full rounded-xl"
  />
</Frame>
```

<div id="record-the-product-with-a-script">
  ### Graba el producto con un script
</div>

Un script de navegador te da el mismo video cada vez, así que puedes volver a grabarlo cuando cambie la interfaz. Este script de [Playwright](https://playwright.dev) graba un archivo WebM mientras recorre un flujo:

```js record.mjs
import { chromium } from "playwright";

const browser = await chromium.launch();
const context = await browser.newContext({
  viewport: { width: 1280, height: 720 },
  recordVideo: { dir: "videos", size: { width: 1280, height: 720 } },
});
const page = await context.newPage();

await page.goto("http://localhost:3000");
await page.waitForTimeout(800);
await page.getByRole("link", { name: "New project" }).click();
await page.getByLabel("Name").pressSequentially("Sample project", { delay: 60 });
await page.getByRole("button", { name: "Create" }).click();
await page.waitForTimeout(1500);

await context.close();
await browser.close();
```

Consejos para grabaciones legibles:

- Haz una pausa de aproximadamente un segundo después de cada acción para que los lectores puedan seguir el cambio.
- Escribe con retraso en lugar de rellenar los campos al instante.
- Mantén los videos por debajo de 30 segundos. Divide los flujos más largos en varios videos junto a los pasos que muestran.
- Usa cuentas y datos de muestra, nunca datos de producción.

<div id="replay-an-agent-session">
  ### Reproduce una sesión de un agente
</div>

Para mostrar lo que hizo un agente, graba su sesión y reprodúcela como video. Claude Code y Codex pueden escribir la sesión como líneas JSON, por ejemplo `claude -p "<task>" --output-format stream-json --verbose > session.jsonl`. Renderiza los mensajes y las llamadas a herramientas en una página HTML sencilla con estilo de terminal y graba esa página con el script de Playwright. Una reproducción muestra los comandos reales y el orden en que el agente los ejecutó, sin exponer una terminal en vivo.

<div id="screenshots">
  ## Capturas de pantalla
</div>

Pon las capturas en un `<Frame>` con un pie que indique qué mirar. Recorta la parte de la pantalla que importa.

```mdx
<Frame caption="The settings page, with the custom domain field highlighted">
  <img className="block dark:hidden" src="/images/settings-light.png" alt="Settings page in light mode" />
  <img className="hidden dark:block" src="/images/settings-dark.png" alt="Settings page in dark mode" />
</Frame>
```

Para mantener las capturas actualizadas, tómalas con un script. Usa la misma configuración de Playwright que el script de video, llama a `page.screenshot({ path: "images/settings-light.png" })` y vuelve a ejecutarlo cuando cambie la interfaz. Para la versión oscura, crea el contexto con `colorScheme: "dark"`. Consulta [Imágenes e insertos](/es/create/image-embeds) para ver las opciones de tamaño y zoom.

<div id="tables">
  ## Tablas
</div>

Las tablas contienen los detalles a los que los lectores vuelven: estados, límites, precios y compatibilidad entre opciones. Empieza con la tabla y mantén breve la prosa a su alrededor.

| Función | Basic | Team | Business |
| --- | --- | --- | --- |
| Proyectos | 1 | 10 | Ilimitados |
| Ejecuciones mensuales | 100 | 5,000 | Personalizado |
| Inicio de sesión único | No | No | Sí |
| Soporte | Comunidad | Correo electrónico | Canal dedicado |

Para una página compuesta principalmente por tablas, establece `mode: "wide"` en el frontmatter para darles todo el ancho. Consulta [Modo de página](/es/organize/pages#page-mode).

<div id="build-these-pages-with-an-agent">
  ## Crea estas páginas con un agente
</div>

Los agentes de programación escriben bien widgets y scripts de grabación cuando les das el patrón y los datos. Indica al agente esta guía y luego describe lo que quieres que entienda el lector.

```text Widget
Read https://www.mintlify.com/docs/guides/interactive-pages.md.
Add an interactive widget to docs/billing/usage.mdx that lets readers
pick a plan and a number of monthly runs, and shows the monthly cost with
the formula. Use the prices in the table on that page. Follow the widget
guidelines: export const at the end of the file, not-prose, currentColor,
no fetch. Run mint dev and check it in light and dark mode.
```

```text Video
Write a Playwright script that records the "create a project" flow on
http://localhost:3000 as a 1280x720 WebM: sign in with the sample account
from .env.example, click New project, type "Sample project", and wait
for the deployment to finish. Pause about a second after each action.
Save it to images/create-project.webm and embed it in quickstart.mdx in a
Frame with a caption.
```

Antes de publicar:

- Abre la página con `mint dev` o en el editor, en modo claro y oscuro.
- Comprueba que cada widget se renderiza y responde a los clics y al teclado.
- Reduce el navegador al ancho de un teléfono y comprueba que nada se desborda.
- Reproduce cada video y abre cada imagen.

export const RxTheme = {
  accent: "#26BD6C",
  accentSoft: "rgba(38,189,108,.12)",
  border: "rgba(127,127,127,.25)",
  surface: "rgba(127,127,127,.06)",
};

export const RxFrame = ({ children, title, caption }) => (
  <div className="not-prose" style={{ border: `1px solid ${RxTheme.border}`, borderRadius: 14, padding: 16, display: "grid", gap: 14, width: "100%", fontSize: 14, color: "inherit" }}>
    <div style={{ display: "flex", flexWrap: "wrap", alignItems: "baseline", justifyContent: "space-between", gap: 8 }}>
      <div style={{ fontWeight: 600 }}>{title}</div>
      {caption ? <div style={{ fontSize: 12, opacity: 0.65 }}>{caption}</div> : null}
    </div>
    {children}
  </div>
);

export const RxButton = ({ children, onClick, disabled, pressed }) => (
  <button
    type="button"
    onClick={onClick}
    disabled={disabled}
    aria-pressed={pressed}
    style={{
      padding: "6px 12px", borderRadius: 8, font: "inherit", fontSize: 13, fontWeight: 600, color: "inherit",
      cursor: disabled ? "not-allowed" : "pointer", opacity: disabled ? 0.45 : 1,
      border: `1px solid ${pressed ? RxTheme.accent : "rgba(127,127,127,.35)"}`,
      background: pressed ? RxTheme.accentSoft : "transparent",
    }}
  >
    {children}
  </button>
);

export const RxJourney = () => {
  const steps = [
    { name: "Sign up", who: "Reader", detail: "The reader creates an account with an email address and confirms it from the inbox." },
    { name: "Create project", who: "Reader", detail: "The reader names the project and picks a template. The product creates a repository with starter pages." },
    { name: "First deploy", who: "Product", detail: "The product builds the starter pages and publishes them to a preview URL in about a minute." },
    { name: "Invite team", who: "Reader", detail: "The reader invites teammates by email. Each teammate gets editor access to the project." },
    { name: "Go live", who: "Reader", detail: "The reader adds a custom domain and points DNS at the product. The site is live on the domain." },
  ];
  const [active, setActive] = useState(0);
  return (
    <RxFrame title="Sample onboarding journey" caption={`Step ${active + 1} of ${steps.length}`}>
      <div style={{ display: "grid", gridTemplateColumns: "repeat(auto-fit, minmax(110px, 1fr))", gap: 8 }}>
        {steps.map((step, i) => {
          const isActive = i === active;
          return (
            <button
              key={step.name}
              type="button"
              onClick={() => setActive(i)}
              aria-current={isActive ? "step" : undefined}
              style={{
                textAlign: "left", padding: 10, borderRadius: 10, font: "inherit", color: "inherit", cursor: "pointer", minWidth: 0,
                border: isActive ? `2px solid ${RxTheme.accent}` : `1px solid ${RxTheme.border}`,
                background: isActive ? RxTheme.accentSoft : i < active ? RxTheme.surface : "transparent",
                opacity: i > active ? 0.6 : 1, transition: "background .25s, opacity .25s",
              }}
            >
              <div style={{ fontSize: 11, textTransform: "uppercase", letterSpacing: ".04em", opacity: 0.7 }}>{step.who}</div>
              <div style={{ fontWeight: 600, fontSize: 13 }}>{step.name}</div>
            </button>
          );
        })}
      </div>
      <div style={{ height: 4, borderRadius: 4, background: RxTheme.surface, overflow: "hidden" }}>
        <div style={{ width: `${((active + 1) / steps.length) * 100}%`, height: "100%", background: RxTheme.accent, transition: "width .3s" }} />
      </div>
      <p style={{ margin: 0, lineHeight: 1.55, minHeight: 44 }}>{steps[active].detail}</p>
      <div style={{ display: "flex", gap: 8 }}>
        <RxButton onClick={() => setActive(active - 1)} disabled={active === 0}>Back</RxButton>
        <RxButton onClick={() => setActive(active + 1)} disabled={active === steps.length - 1}>Next</RxButton>
      </div>
    </RxFrame>
  );
};

export const RxChart = () => {
  const weeks = ["W1", "W2", "W3", "W4", "W5", "W6"];
  const series = {
    "Page views": [420, 510, 480, 620, 700, 760],
    "Searches": [130, 150, 170, 160, 210, 240],
    "Feedback": [12, 18, 15, 22, 19, 27],
  };
  const [metric, setMetric] = useState("Page views");
  const values = series[metric];
  const max = Math.max(...values);
  const change = Math.round(((values[values.length - 1] - values[0]) / values[0]) * 100);
  return (
    <RxFrame title="Sample weekly usage" caption={`${metric}: ${change >= 0 ? "+" : ""}${change}% over six weeks`}>
      <div style={{ display: "flex", flexWrap: "wrap", gap: 8 }}>
        {Object.keys(series).map((name) => (
          <RxButton key={name} pressed={metric === name} onClick={() => setMetric(name)}>{name}</RxButton>
        ))}
      </div>
      <div role="img" aria-label={`${metric} by week: ${values.join(", ")}`} style={{ display: "grid", gridTemplateColumns: `repeat(${values.length}, 1fr)`, alignItems: "end", gap: 10, height: 160 }}>
        {values.map((v, i) => (
          <div key={weeks[i]} style={{ display: "grid", gap: 4, alignItems: "end", height: "100%" }}>
            <div style={{ fontSize: 11, textAlign: "center", opacity: 0.7, fontVariantNumeric: "tabular-nums", alignSelf: "end" }}>{v}</div>
            <div style={{ height: `${(v / max) * 120}px`, borderRadius: "6px 6px 2px 2px", background: i === values.length - 1 ? RxTheme.accent : "rgba(127,127,127,.3)", transition: "height .3s" }} />
          </div>
        ))}
      </div>
      <div style={{ display: "grid", gridTemplateColumns: `repeat(${weeks.length}, 1fr)`, gap: 10, fontSize: 11, opacity: 0.6, textAlign: "center" }}>
        {weeks.map((w) => <span key={w}>{w}</span>)}
      </div>
    </RxFrame>
  );
};
