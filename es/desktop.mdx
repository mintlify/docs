<Note>
  La aplicación de escritorio está en beta y puede cambiar.
</Note>

La aplicación de escritorio de Mintlify ejecuta tu [dashboard](https://app.mintlify.com) y el [editor](/es/editor/index) en tu computadora. Trabaja en pestañas o en varias ventanas con acceso al mismo contenido y a la misma configuración que usas en el navegador.

La aplicación de escritorio actualiza el contenido igual que cuando trabajas en el editor. No abre ni edita archivos en tu computadora. Para trabajar con archivos locales, usa la [CLI](/es/cli/index).

<div id="install">
  ## Instalar
</div>

<Tabs>
  <Tab title="macOS">
    Requiere macOS 14 o posterior en Apple silicon.

    1. Descarga la aplicación de escritorio desde [mintlify.com/desktop](https://mintlify.com/desktop).
    2. Abre el archivo.
    3. Arrastra **Mintlify** a tu carpeta **Applications**.

    También puedes instalarla desde la terminal.

    ```bash Install the desktop app
    curl -fsSL https://desktop.mintlify.com/install.sh | bash
    ```

    El script instala la aplicación en `/Applications`, o en `~/Applications` si no puedes escribir en `/Applications`.
  </Tab>
  <Tab title="Windows">
    Requiere Windows 10 o posterior, de 64 bits.

    1. Descarga la aplicación de escritorio desde [mintlify.com/desktop](https://mintlify.com/desktop).
    2. Ejecuta el instalador.

  </Tab>
  <Tab title="Linux">
    Requiere una máquina x86_64. La aplicación de escritorio está disponible como AppImage y como paquete `.deb`.

    Descarga cualquiera de los dos archivos desde [mintlify.com/desktop](https://mintlify.com/desktop) o instala la AppImage desde la terminal.

    ```bash Install the desktop app
    curl -fsSL https://desktop.mintlify.com/install.sh | bash
    ```

    El script instala la aplicación en `~/.local/share/mintlify-desktop`, añade un comando `mintlify-desktop` a `~/.local/bin` y añade Mintlify al menú de aplicaciones.

    Las AppImages requieren FUSE 2. Si la aplicación de escritorio no se inicia, instala FUSE 2. En Ubuntu:

    ```bash Install FUSE 2
    sudo apt install libfuse2
    ```
  </Tab>
</Tabs>

<div id="sign-in">
  ## Iniciar sesión
</div>

1. Abre la aplicación de escritorio. La aplicación muestra una pantalla **Log in to Mintlify**.
2. Haz clic en **Log in here instead**.
3. Inicia sesión de la misma forma en que inicias sesión en tu dashboard en el navegador.

<Note>
  El inicio de sesión desde el navegador no está disponible durante el acceso beta. No puedes usar el botón **Continue in browser** para iniciar sesión.
</Note>

<div id="tabs-and-windows">
  ## Pestañas y ventanas
</div>

Abre cada página en la que estés trabajando en su propia pestaña o ventana. Las pestañas y ventanas se vuelven a abrir donde las dejaste cuando reinicias la aplicación.

Haz clic derecho en una pestaña para duplicarla, copiar su enlace o cerrar las demás pestañas. Haz clic con el botón central en una pestaña para cerrarla.

Para mostrar las pestañas en una barra lateral en lugar de en la parte superior de la ventana, cambia la disposición de las pestañas en [Configuración](#settings).

<div id="each-tab-has-its-own-session">
  ### Cada pestaña tiene su propia sesión
</div>

Una pestaña nueva se abre con la sesión iniciada en la misma cuenta y organización que la pestaña desde la que la abriste. A partir de ahí, cada pestaña mantiene su propia sesión:

- Cambiar de organización en una pestaña no cambia tus otras pestañas, así que puedes trabajar en diferentes organizaciones en paralelo.
- Cerrar sesión o iniciar sesión con otra cuenta solo afecta a esa pestaña.

Para cerrar sesión en todas partes, usa **Clear all data** en [Configuración](#settings).

<div id="links-to-other-sites">
  ### Enlaces a otros sitios
</div>

Las pestañas solo cargan el dashboard de Mintlify y los servicios que usa para iniciar sesión, acceder a créditos para funciones de IA y conectar proveedores de Git. Los enlaces a cualquier otro sitio se abren en tu navegador predeterminado.

<div id="keyboard-shortcuts">
  ## Atajos de teclado
</div>

En Windows y Linux, usa <kbd>Ctrl</kbd> en lugar de <kbd>Cmd</kbd>.

| Acción | Atajo |
| :--- | :--- |
| Nueva pestaña | <kbd>Cmd</kbd> + <kbd>T</kbd> |
| Nueva ventana | <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>N</kbd> |
| Cerrar pestaña | <kbd>Cmd</kbd> + <kbd>W</kbd> |
| Cerrar ventana | <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>W</kbd> |
| Ir a la pestaña 1-9 | <kbd>Cmd</kbd> + <kbd>1</kbd>-<kbd>9</kbd> |
| Pestaña siguiente | <kbd>Ctrl</kbd> + <kbd>Tab</kbd> |
| Pestaña anterior | <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>Tab</kbd> |
| Atrás | <kbd>Cmd</kbd> + <kbd>[</kbd> |
| Adelante | <kbd>Cmd</kbd> + <kbd>]</kbd> |
| Recargar | <kbd>Cmd</kbd> + <kbd>R</kbd> |
| Copiar la URL de la página | <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>C</kbd> |
| Abrir la configuración | <kbd>Cmd</kbd> + <kbd>,</kbd> |

Para ver los atajos dentro del editor, consulta [Atajos de teclado](/es/editor/keyboard-shortcuts).

<div id="settings">
  ## Configuración
</div>

Abre la configuración con <kbd>Cmd</kbd> + <kbd>,</kbd> en macOS o <kbd>Ctrl</kbd> + <kbd>,</kbd> en Windows y Linux.

- **Tab layout**: Muestra las pestañas en la parte superior de la ventana (**Horizontal**) o en una barra lateral (**Vertical**).
- **Clear all data**: Cierra la sesión en todas las pestañas, cierra todas las pestañas y restablece la configuración. La aplicación se reinicia.

La ventana de configuración también muestra la versión de la aplicación.

<div id="updates">
  ## Actualizaciones
</div>

La aplicación busca actualizaciones al iniciarse y cada cuatro horas mientras se ejecuta. Cuando hay una actualización disponible, aparece un botón **Update** en la barra de pestañas.

Para buscar actualizaciones ahora, haz clic en **Check for updates** junto a la versión en [Configuración](#settings). Si hay una actualización disponible, el botón cambia a **Update to** seguido del número de la nueva versión. Haz clic en él para instalar la actualización igual que con el botón de la barra de pestañas.

- **macOS**: Haz clic en **Update** para descargar e instalar la actualización en la aplicación.
- **Windows y Linux**: Haz clic en **Update** para descargar la nueva versión desde tu navegador y luego instálala.

<div id="uninstall">
  ## Desinstalar
</div>

<Tabs>
  <Tab title="macOS">
    1. Cierra la aplicación de escritorio.
    2. Mueve **Mintlify** de tu carpeta **Applications** a la Papelera.
    3. Para eliminar tu inicio de sesión y tu configuración, elimina `~/Library/Application Support/Mintlify Electron`.
  </Tab>
  <Tab title="Windows">
    1. Abre **Settings** > **Apps** > **Installed apps**.
    2. Busca **Mintlify** y selecciona **Uninstall**.
    3. Para eliminar tu inicio de sesión y tu configuración, elimina `%APPDATA%\Mintlify Electron`.
  </Tab>
  <Tab title="Linux">
    Si instalaste la aplicación de escritorio con el script, elimina los archivos que creó:

    ```bash Remove the desktop app
    rm -rf ~/.local/share/mintlify-desktop \
      ~/.local/bin/mintlify-desktop \
      ~/.local/share/applications/mintlify-desktop.desktop \
      ~/.local/share/icons/hicolor/512x512/apps/mintlify-desktop.png
    ```

    Si instalaste el paquete `.deb`, elimínalo con tu gestor de paquetes.

    Para eliminar tu inicio de sesión y tu configuración, elimina `~/.config/Mintlify Electron`.
  </Tab>
</Tabs>
