Traslada tu documentación existente a Mintlify con un agente de programación, el scraper de Mintlify, archivos fuente exportados o una migración manual. Puedes combinar métodos, por ejemplo, hacer scraping de un sitio público para obtener un primer borrador y luego completar las páginas privadas a partir de una exportación.

<div id="choose-a-migration-method">
  ## Elige un método de migración
</div>

| Método | Cómo funciona | Ideal para |
| --- | --- | --- |
| [Agente de programación](#migrate-with-a-coding-agent) | Pide a tu agente que ejecute `mint migrate` para que siga las instrucciones de migración de Mintlify. Tu agente hace un inventario de tus páginas, las convierte a MDX, crea una estructura de navegación y comprueba los resultados. | Cualquier plataforma compatible con `mint migrate`, incluidas Docusaurus, MkDocs, GitBook, ReadMe, Confluence y PDF. Consulta [`mint migrate`](/es/cli/commands#mint-migrate) para ver todas las plataformas compatibles. |
| Scraper | Ejecuta el paquete `@mintlify/scraping` sobre un sitio público para convertir sus páginas a MDX. | Sitios públicos de Docusaurus, ReadMe y GitBook. |
| [Archivos exportados o fuente](#platform-guides) | Convierte los archivos que exportas desde tu plataforma actual o migra desde el repositorio que genera tu sitio. | Páginas privadas, documentación con versiones, contenido localizado, archivos OpenAPI y componentes personalizados a los que un scraper no puede acceder. |
| [Migración manual](/es/migration/manual) | Recopila, convierte y organiza tu contenido por tu cuenta. | Plataformas sin una ruta automatizada o proyectos que combinan contenido de varias fuentes. |

<div id="platform-guides">
  ## Guías por plataforma
</div>

La forma más sencilla de migrar es con un [agente de programación](#migrate-with-a-coding-agent). Ejecuta `mint migrate --from <platform>` para darle a tu agente instrucciones para tu plataforma. Para migrar sin un agente, sigue una guía con instrucciones para hacer scraping, exportar o migrar archivos fuente.

<div id="migrate-with-a-coding-agent">
  ## Migrar con un agente de programación
</div>

La [CLI](/es/cli/install) muestra instrucciones de migración escritas para agentes de programación con IA. Ejecuta `mint migrate` para ver el flujo de trabajo y las plataformas de origen compatibles, o inicia un agente que siga las instrucciones en el directorio actual.

```bash Example migration command
mint migrate --agent claude --from docusaurus
```

Consulta [`mint migrate`](/es/cli/commands#mint-migrate) para ver los agentes, las plataformas y los flags compatibles.

<div id="scrape-individual-pages">
  ## Hacer scraping de páginas individuales
</div>

Las guías de Docusaurus, ReadMe y GitBook utilizan el comando `section` del scraper, que convierte todas las páginas alcanzables desde la URL que le proporciones. Para convertir una sola página en su lugar, usa el comando `page` desde tu directorio de migración.

```bash
npx @mintlify/scraping@latest page https://docs.example.com/getting-started
```

Usa `page` para comprobar cómo el scraper convierte tu contenido antes de una ejecución completa, o para completar páginas individuales que una ejecución de `section` haya omitido. Para un sitio grande, acota una ejecución de `section` con `--filter` en lugar de hacer scraping de todo a la vez.
