Traslada tu documentación existente a Mintlify con un scraper automatizado, una exportación desde tu plataforma actual o una migración manual. La mejor ruta depende de si tu sitio es público, si puedes acceder a sus archivos fuente y qué funcionalidades específicas de cada plataforma utilizas.

<Card title="Docusaurus" href="/es/migration/docusaurus">
  Realiza scraping de un sitio público o migra desde el código fuente para conservar páginas privadas, documentación con versiones, contenido localizado y componentes personalizados de React.
</Card>
<Card title="ReadMe" href="/es/migration/readme">
  Exporta los archivos del proyecto para conservar contenido privado y archivos OpenAPI, o haz scraping de un sitio público para partir más rápido.
</Card>
<Card title="GitBook" href="/es/migration/gitbook">
  Exporta cada sección con Git Sync para la migración más completa, o haz scraping de un sitio público.
</Card>
<Card title="Fern" href="/es/migration/fern">
  Migra MDX, recursos, especificaciones de API y la configuración de `docs.yml` desde el repositorio fuente.
</Card>
<Card title="Document360" href="/es/migration/document360">
  Exporta cada workspace e idioma como un ZIP de proyecto, incluidos artículos, categorías y archivos multimedia.
</Card>

  Sigue el flujo manual para otra plataforma o un proyecto con fuentes de contenido mixtas.
</Card>

<div id="scrape-individual-pages">
  ## Hacer scraping de páginas individuales
</div>

Las guías de Docusaurus, ReadMe y GitBook utilizan el comando `section` del scraper, que convierte todas las páginas alcanzables desde la URL que le proporciones. Para convertir una sola página en su lugar, usa el comando `page` desde tu directorio de migración.

```bash
npx @mintlify/scraping@latest page https://docs.example.com/getting-started
```

Usa `page` para comprobar cómo el scraper convierte tu contenido antes de una ejecución completa, o para completar páginas individuales que una ejecución de `section` haya omitido. Para un sitio grande, acota una ejecución de `section` con `--filter` en lugar de hacer scraping de todo a la vez.

<div id="generate-a-site-from-a-repository">
  ## Generar un sitio a partir de un repositorio
</div>

Mintlify puede generar un sitio de documentación completo para cualquier repositorio de GitHub, tanto si ya contiene documentación como si solo tiene código.

Sustituye `github` por `mintlify` en la URL de tu repositorio.

```text
https://github.com/org/repo -> https://mintlify.com/org/repo
```

Explora [sitios de documentación generados](https://www.mintlify.com/wiki) para ver más ejemplos.
