description: "Resuelve el fallo de mint login que indica que falta keytar actualizando la CLI de Mintlify a una versión que guarda las credenciales en un archivo de configuración."

---

Si pegas el código de autorización de `mint login` y la CLI termina con:

> keytar is required for credential storage but is not installed. Install it with: npm install keytar

la versión instalada de la CLI de Mintlify está intentando usar `keytar`, un módulo nativo de Node para acceder al llavero del sistema operativo. Las versiones actuales de la CLI no dependen de `keytar`. En su lugar, guardan las credenciales en `~/.config/mintlify/config.json`. Consulta [`mint login`](/es/cli/commands#mint-login).

<div id="fix-the-error">
  ## Corregir el error
</div>

Actualiza la CLI a la última versión:

<CodeGroup>
  ```bash npm
  npm i -g mint@latest
  ```

  ```bash pnpm
  pnpm add -g mint@latest
  ```
</CodeGroup>

Después, vuelve a ejecutar `mint login`.

Si el error persiste, es probable que tengas instalados tanto el paquete heredado `mintlify` como el paquete actual `mint`. Elimina `mintlify` y reinstala `mint`:

```bash
npm uninstall -g mintlify
npm cache clean --force
npm i -g mint
```

Consulta [Instalar la CLI](/es/cli/install) para ver la referencia completa de instalación y solución de problemas.
