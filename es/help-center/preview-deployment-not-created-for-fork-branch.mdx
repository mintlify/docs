Si una solicitud de extracción abierta desde un fork no muestra ningún enlace de implementación de vista previa, este es el comportamiento esperado. Lo mismo ocurre si falla una llamada al endpoint [Trigger preview deployment](/es/api/preview/trigger) con una rama de un fork. Mintlify no genera implementaciones de vista previa a partir de ramas de forks.

La aplicación de GitHub de Mintlify debe estar instalada en un repositorio para generar una vista previa. La aplicación está instalada en tu repositorio principal, no en los forks de los colaboradores, por lo que no puede leer un fork ni generar una vista previa a partir de él. Esto se aplica tanto a las vistas previas automáticas de solicitudes de extracción como a las vistas previas activadas a través de la API. El valor de `branch` en una solicitud de API debe existir en el repositorio conectado a tu proyecto de Mintlify.

<div id="preview-changes-from-a-fork">
  ## Previsualizar cambios de un fork
</div>

Un mantenedor con acceso de escritura al repositorio principal puede enviar la rama del fork al repositorio principal y, a continuación, abrir una solicitud de extracción desde esa rama o pasar ese nombre de rama a la API. Consulta [Solicitudes de extracción de forks](/es/deploy/preview-deployments#fork-pull-requests) para obtener más detalles.
