De forma predeterminada, el dashboard de Mintlify se abre en **Home**, que es el editor web. Puedes elegir otra página de inicio para que el dashboard se abra donde trabajas con más frecuencia, como **Analytics** o **Activity**.

Tu página de inicio es una preferencia personal. Se aplica a todos los proyectos que abres y no cambia lo que ven otros miembros de tu organización.

<div id="set-your-starting-page">
## Configura tu página de inicio
</div>

1. Ve a la página [My profile](https://app.mintlify.com/settings/account) del dashboard.
2. En la sección **Preferences**, selecciona una página en el menú **Starting page**:
   - **Home**
   - **Activity**
   - **Analytics**
   - **Automations**

Mintlify guarda tu elección de inmediato. Si no se puede guardar, el dashboard muestra un error y conserva tu elección anterior.

<div id="when-your-starting-page-applies">
## Cuándo se aplica tu página de inicio
</div>

Mintlify usa tu página de inicio cuando abres el dashboard o la raíz de un proyecto, como `https://app.mintlify.com/{organization}/{project}`. Al abrir la raíz de un proyecto, accedes a la página de inicio de ese proyecto.

Los enlaces a una página, un documento o una rama específicos siguen abriendo ese destino. Al seleccionar **Home** en la barra lateral, siempre se abre el editor.

Si tu página de inicio no está disponible para un proyecto, el dashboard abre **Home** en su lugar. Si el editor tampoco está disponible, el dashboard abre **Activity**.
