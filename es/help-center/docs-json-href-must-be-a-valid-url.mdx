---
title: "Corregir el error \"Must be a valid url\" en logo.href o navbar.primary.href"
description: "Resuelve los errores de validación de docs.json cuando usas una ruta relativa como /contact en logo.href, navbar.links o navbar.primary.href."
keywords: ["Must be a valid url", "Invalid docs.json", "logo.href", "navbar.primary.href", "navbar.links", "relative path", "mint dev error"]
---

Puedes usar una ruta relativa como `/contact` en los campos `logo.href`, `navbar.links[].href` o `navbar.primary.href` de `docs.json`. Si ejecutas `mint dev` o `mint validate` con una versión desactualizada de la CLI, verás errores como estos:

```text
🚨 Invalid docs.json:
#.logo.href: Must be a valid url
#.navbar.primary.href: Must be a valid url
```

Las versiones actuales de la CLI de Mintlify aceptan tanto URL absolutas como rutas relativas que empiezan por `/` en estos campos. Las rutas relativas mantienen los enlaces funcionando en despliegues de vista previa, dominios personalizados y vistas previas locales sin tener que codificar tu dominio de producción.

<div id="update-the-cli">
  ## Actualizar la CLI
</div>

Actualiza la CLI a la última versión:

```bash
mint update
```

Si `mint update` no está disponible en tu versión, reinstala la CLI. Consulta [Instalar la CLI](/es/cli/install#update) para ver los comandos de reinstalación.

Después, comprueba tu versión y vuelve a ejecutar la validación:

```bash
mint version
mint validate
```

<div id="example-configuration">
  ## Configuración de ejemplo
</div>

```json docs.json
"logo": {
  "light": "/logo/light.svg",
  "dark": "/logo/dark.svg",
  "href": "/quickstart"
},
"navbar": {
  "links": [
    { "label": "Changelog", "href": "/changelog" }
  ],
  "primary": {
    "type": "button",
    "label": "Contact us",
    "href": "/contact"
  }
}
```

Las rutas relativas deben empezar por `/`. Un valor como `contact` sin la barra inicial sigue sin superar la validación. Los tipos de botón `github` y `discord` siguen requiriendo una URL de repositorio de GitHub o una URL de invitación de Discord.

Para ver la referencia completa de los campos, consulta [`logo`](/es/organize/settings-appearance#logo) y [`navbar`](/es/organize/settings-structure#navbar).
