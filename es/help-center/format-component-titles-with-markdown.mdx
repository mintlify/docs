La prop `title` de los componentes [Accordion](/es/components/accordions), [Card](/es/components/cards), [Step](/es/components/steps), [Tab](/es/components/tabs), [Tile](/es/components/tiles) y [Color.Row](/es/components/color) admite un conjunto acotado de Markdown en línea. Escribe la sintaxis de Markdown directamente en la cadena de `title` y Mintlify la renderiza como texto con formato.

<div id="supported-formatting">
  ## Formato admitido
</div>

- Negrita: `**text**`
- Cursiva: `*text*` o `_text_`
- Tachado: `~~text~~`
- Código en línea: `` `text` ``
- Enlaces: `[text](https://example.com)`

```mdx Example
<AccordionGroup>
  <Accordion title="Edit the `docs.json` file">
    Inline code renders in the accordion title.
  </Accordion>
  <Accordion title="**Required:** set your API key">
    Bold text renders in the accordion title.
  </Accordion>
</AccordionGroup>
```

<div id="limitations">
  ## Limitaciones
</div>

- Los enlaces en los títulos se renderizan como texto de etiqueta con estilo, no como enlaces en los que se puede hacer clic. Esto evita anidar un enlace dentro de un título que ya es interactivo.
- El Markdown de nivel de bloque, las imágenes, el HTML sin procesar y los componentes MDX en los títulos se renderizan como texto literal.
- El subrayado no es compatible.

<div id="how-formatted-titles-affect-ids-and-navigation">
  ## Cómo afectan los títulos con formato a los ID y a la navegación
</div>

Los ID de anclaje, las entradas de la tabla de contenido y la sincronización de pestañas usan el texto sin formato del título, con los caracteres de formato eliminados. Por ejemplo, una pestaña titulada `**npm**` se sincroniza con una pestaña titulada `npm` porque ambas se resuelven al mismo texto sin formato.
