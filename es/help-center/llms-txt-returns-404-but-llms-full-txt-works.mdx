---
title: "llms.txt devuelve 404 pero llms-full.txt funciona"
description: "Diagnostica por qué el llms.txt de tu sitio devuelve un error 404 mientras llms-full.txt carga, normalmente por la opción Don't index project."
keywords: ["llms.txt 404", "llms.txt not found", "llms-full.txt works", "no llms.txt", "don't index project", "noindex"]
---

Mintlify aloja automáticamente un archivo [`llms.txt`](/es/ai/llmstxt) en la raíz de cada sitio de documentación. Si `https://yourdocs.com/llms.txt` devuelve `404` mientras `https://yourdocs.com/llms-full.txt` carga con normalidad, la causa más probable es la opción **Don't index project**.

<div id="check-the-dont-index-project-setting">
## Comprueba la opción Don't index project
</div>

Cuando activas **Don't index project** en la página [Add-ons](https://app.mintlify.com/settings/deployment/addons) de tu panel, Mintlify devuelve `404` para `llms.txt` y `/.well-known/llms.txt`. La opción no bloquea `llms-full.txt`, que sigue disponible. Esta discrepancia hace que la ausencia de `llms.txt` parezca un error del despliegue cuando en realidad es un comportamiento configurado.

La exportación en Markdown de cada página (la URL `.md`) también conserva su referencia a `/llms.txt` mientras la opción está activada, aunque esa URL devuelva `404`.

Para restaurar `llms.txt`:

1. Abre la página [Add-ons](https://app.mintlify.com/settings/deployment/addons) de tu panel.
2. Desactiva **Don't index project**.
3. Espera a que se complete el redespliegue. Activar o desactivar la indexación redespliega tu sitio, y el cambio surte efecto una vez finalizado el redespliegue.

Consulta [Desactivar la indexación de todo el proyecto](/es/optimize/seo#disable-indexing-for-the-entire-project) para conocer todo lo demás que controla esta opción.

<div id="other-causes">
## Otras causas
</div>

Si **Don't index project** está desactivada y `llms.txt` sigue devolviendo `404`:

- **Autenticación**: en los sitios totalmente autenticados, tanto `llms.txt` como `llms-full.txt` requieren autenticación. Las solicitudes no autenticadas fallan para ambos archivos, no solo para `llms.txt`. Consulta [llms.txt](/es/ai/llmstxt) para ver cómo la autenticación afecta a cada archivo.
- **Enrutamiento del proxy inverso**: si sirves tu documentación a través de un proxy inverso con una lista de rutas permitidas, confirma que el proxy reenvía `/llms.txt` y `/.well-known/llms.txt`. Consulta [Proxy inverso](/es/deploy/reverse-proxy#routing-configuration).
