Cuando creas una segunda implementación de Mintlify desde el mismo repositorio privado de GitHub que ya respalda una implementación existente, el selector de repositorios del onboarding puede no mostrar ese repositorio privado. Esto ocurre porque tu autorización inicial de GitHub solo concedió el ámbito `public_repo`, y al volver al onboarding se reutiliza la autorización existente en lugar de solicitar de nuevo acceso a repositorios privados.

Puedes crear implementaciones separadas desde el mismo repositorio. Mintlify no requiere un repositorio distinto por cada implementación. Para combinar varios repositorios en un mismo sitio, consulta [Configuración multi-repo](/es/deploy/multi-repo).

## Vuelve a autorizar con acceso a repositorios privados

Visita esta URL mientras estás con sesión iniciada en el panel de Mintlify:

```
https://app.mintlify.com/api/onboarding/github/authorize?private=true
```

El parámetro de consulta `?private=true` solicita el ámbito `repo` de GitHub, que otorga acceso a repositorios privados. GitHub te pedirá autorizar el ámbito adicional y después te devolverá al panel.

Tras volver a autorizar:

1. Regresa al flujo de onboarding de tu nueva implementación.
2. Vuelve a abrir el selector de repositorios. Ahora podrás seleccionar tu repositorio privado.
3. Continúa el onboarding para terminar de crear la segunda implementación.

## Si el repositorio sigue sin aparecer

Si el selector sigue sin mostrar el repositorio después de volver a autorizar, es posible que la instalación de la GitHub App de Mintlify en la organización de ese repositorio deba actualizarse para incluirlo:

1. Abre la [configuración de la GitHub App](https://github.com/apps/mintlify/installations/new) y selecciona la organización propietaria del repositorio.
2. En **Repository access**, selecciona **All repositories** o añade el repositorio específico en **Only select repositories**.
3. Guarda el cambio y vuelve a abrir el selector de repositorios.

Para restablecer por completo la conexión con la GitHub App, consulta [Problemas de conexión con la GitHub App](/es/deploy/github#github-app-connection-issues).
