Si no puedes hacer clic en el botón **Publish** del editor y al pasar el cursor por encima aparece el tooltip de error **Fix invalid MDX before publishing**, al menos una página de tu branch tiene MDX que no se puede parsear. El editor bloquea la publicación hasta que todas las páginas de la branch se parseen correctamente. Esto evita que la sintaxis rota llegue a tu sitio en producción.

El tooltip te indica cuántas páginas tienen errores. El mismo error bloquea **Request review** en las feature branches. Entre las causas habituales están:

- Una etiqueta de componente sin cerrar, como un `<Note>` sin su `</Note>` correspondiente.
- JSX mal formado en el cuerpo de la página, como una llave sin cerrar en una expresión.
- Frontmatter que no es YAML válido, como una sangría inconsistente o unas comillas sin cerrar.

Mientras una página tiene MDX no válido o YAML de frontmatter no válido, esas ediciones permanecen locales para ti. Los compañeros que editen la misma página solo reciben contenido válido, así que un error de sintaxis que introduzcas no sobrescribe su trabajo. Consulta [Colaborar en el editor](/es/editor/collaborate) para ver cómo gestiona la edición en tiempo real el contenido no válido.

<div id="fix-the-error-manually">
  ## Corregir el error manualmente
</div>

1. Abre la página afectada en el editor.
2. Cambia al modo source con <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>S</kbd> (macOS) o <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>S</kbd> (Windows). El modo source resalta el MDX no válido y muestra el error de parseo.
3. Corrige la sintaxis. Una vez que la página se parsea, el error desaparece y el botón **Publish** vuelve a estar disponible.

<div id="fix-the-error-with-the-agent">
  ### Corregir el error con el agente
</div>

1. Abre el panel del editor.
2. Pide al agente que corrija cualquier MDX o YAML de frontmatter no válido.
