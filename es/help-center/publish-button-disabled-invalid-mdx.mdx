Si el botón **Publish** del editor web está deshabilitado y al pasar el cursor sobre él aparece **Fix invalid MDX before publishing**, al menos una página de tu rama tiene MDX que no se puede analizar. El editor bloquea la publicación hasta que todas las páginas de la rama se analizan correctamente. Esto evita que la sintaxis rota llegue a tu sitio publicado.

El tooltip te indica cuántas páginas tienen errores. Las causas comunes incluyen:

- Una etiqueta de componente sin cerrar, como un `<Note>` sin su `</Note>` correspondiente.
- JSX mal formado en el cuerpo de la página, como una llave sin cerrar en una expresión.
- Frontmatter que no es YAML válido, como una sangría inconsistente o una comilla sin cerrar.

<div id="fix-the-error">
  ## Corregir el error
</div>

1. Abre la página afectada en el editor.
2. Cambia al modo source con <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>S</kbd> (macOS) o <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>S</kbd> (Windows). El modo source resalta el MDX no válido y muestra el error de análisis.
3. Corrige la sintaxis. Cuando la página se analiza correctamente, el error desaparece y el botón **Publish** vuelve a estar disponible.

Mientras una página tiene MDX no válido o YAML de frontmatter no válido, esas ediciones se mantienen locales para ti. Los compañeros que editan la misma página solo reciben contenido válido, de modo que un error de sintaxis que introduzcas no sobrescribe su trabajo. Consulta [Colaborar en el editor](/es/editor/collaborate) para saber cómo la edición en tiempo real gestiona el contenido no válido.

Para saber qué ocurre cuando publicas, consulta [Publicar cambios](/es/editor/publish).
