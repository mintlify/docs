Si un branch que existe en tu repositorio no aparece en el menú desplegable de branches del editor web, el branch no se ha eliminado. El menú desplegable muestra intencionadamente solo:

- Branches creados en el editor web.
- Branches con un pull request o merge request abierto dirigido a tu rama de implementación.

Los branches enviados directamente a GitHub, GitLab o Bitbucket sin un pull request abierto no aparecen en la lista. Tu trabajo en esos branches está a salvo en tu repositorio. Puedes confirmarlo viendo el branch en tu proveedor de Git.

<div id="open-a-branch-that-isnt-listed">
  ## Abrir un branch que no aparece en la lista
</div>

Usa cualquiera de estos enfoques:

- **Abre un pull request o merge request** para el branch dirigido a tu rama de implementación en tu proveedor de Git. El branch aparecerá entonces en el menú desplegable de branches del editor.
- **Edita la URL del editor.** Abre cualquier branch en el editor y, a continuación, reemplaza el nombre del branch en la URL de tu navegador por el nombre del branch que quieras. El editor carga ese branch directamente.

Para obtener más información sobre cómo crear y cambiar de branch, consulta [Trabajar con branches](/es/guides/branches).
