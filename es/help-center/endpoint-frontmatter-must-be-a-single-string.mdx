description: "Resuelve despliegues fallidos causados por frontmatter de páginas openapi, api o asyncapi que enumera varios endpoints o usa un valor que no es una cadena."
keywords: ["must be a single endpoint string", "Deployment not updated", "openapi frontmatter", "api frontmatter", "asyncapi frontmatter", "multiple endpoints", "YAML array"]
---

Cada página de endpoint MDX en Mintlify documenta exactamente un endpoint. Los campos de frontmatter `openapi`, `api` y `asyncapi` deben ser cada uno una sola cadena. Si alguna página configura uno de estos campos como una lista, un número u otro valor que no sea una cadena, Mintlify hace fallar el despliegue con este mensaje:

```text
Page api, openapi, or asyncapi frontmatter must be a single endpoint string. Deployment not updated
```

Mintlify no publica ningún cambio de un despliegue fallido. Tu sitio en producción sigue sirviendo el último despliegue correcto hasta que corrijas la página.

El error de la página individual comienza con `Invalid "<field>" frontmatter at path`. Indica la ruta de la página y el tipo de valor que recibió Mintlify, como `received an array`.

<div id="common-causes">
  ## Causas comunes
</div>

- Enumerar varios endpoints en un solo campo, como `openapi: [GET /users, POST /users]`.
- Escribir el valor como una lista YAML en líneas separadas que comienzan con `-`.
- Usar un valor que YAML interpreta como un número o un booleano en lugar de una cadena.

<div id="fix-the-frontmatter">
  ## Corregir el frontmatter
</div>

Configura el campo con una sola cadena de endpoint. Encierra el valor entre comillas para que YAML siempre lo interprete como una cadena.

```mdx Incorrect
---
title: "Users"
openapi: [GET /users, POST /users]
---
```

```mdx Correct
---
title: "List users"
openapi: "GET /users"
---
```

Para documentar más de un endpoint, crea una página independiente para cada endpoint. También puedes dejar que Mintlify genere una página por operación a partir de tu especificación. Consulta [Generar automáticamente páginas de API](/es/api-playground/openapi-setup#auto-populate-api-pages).

Para ver el formato completo del frontmatter `openapi`, consulta [Documentar endpoints](/es/api-playground/openapi-setup#document-endpoints).
