Mintlify no tiene una función directa de "importar ZIP". Mintlify construye tu sitio a partir de archivos en un repositorio de Git, así que migrar desde una exportación ZIP implica convertir los archivos exportados en páginas Markdown o MDX en tu repositorio de documentación. El camino correcto depende de qué plataforma generó el ZIP.

<div id="if-the-zip-came-from-document360">
## Si el ZIP proviene de Document360
</div>

Sigue la [guía de migración de Document360](/es/migration/document360) dedicada. Explica cómo exportar cada espacio de trabajo e idioma como un ZIP del proyecto y convertir los artículos, categorías, medios y contenido reutilizable.

<div id="if-the-zip-came-from-readme">
## Si el ZIP proviene de ReadMe
</div>

Sigue la [guía de migración de ReadMe](/es/migration/readme) dedicada. Cubre la estructura de una exportación ZIP de ReadMe, incluidas guías, recetas, páginas personalizadas y archivos de OpenAPI. Ten en cuenta que las exportaciones ZIP de ReadMe referencian las imágenes alojadas por URL en lugar de incluir los archivos de imagen, así que descarga esos recursos por separado.

<div id="if-the-zip-came-from-another-platform">
## Si el ZIP proviene de otra plataforma
</div>

Usa el [flujo de trabajo de migración manual](/es/migration/manual):

1. Descomprime la exportación y conserva el ZIP original sin cambios como instantánea de origen. Haz el trabajo de conversión en una copia.
2. Crea un inventario de páginas con el origen, la ruta de destino y el estado de migración de cada página.
3. Convierte el contenido exportado en Markdown, HTML o JSON en páginas MDX.
4. Recrea tu navegación en `docs.json` y revisa las páginas en busca de sintaxis residual de la plataforma de origen.

Si el sitio de origen también está disponible públicamente, hacer scraping puede ser más rápido que convertir los archivos exportados. Consulta [Convertir páginas individuales](/es/migration/index#scrape-individual-pages).

<div id="exporting-your-mintlify-docs-as-a-zip">
## Exportar tu documentación de Mintlify como ZIP
</div>

Si buscas la dirección opuesta, un archivo ZIP de tu documentación de Mintlify publicada para verla sin conexión o distribuirla de forma privada, usa `mint export`. Consulta [Exportación sin conexión](/es/deploy/export).
