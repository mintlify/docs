El editor web muestra un aviso de **Repository unavailable** cuando Mintlify no puede acceder al repositorio o a la rama de implementación a partir de los cuales se compila tu documentación. Actualizar la página no lo soluciona. Debes restaurar el acceso o actualizar tu configuración de Git.

<div id="common-causes">
  ## Causas comunes
</div>

- El repositorio se eliminó, se renombró o se transfirió a otro propietario.
- El repositorio se quitó de los repositorios seleccionados de la GitHub App de Mintlify.
- La rama de implementación, como `main`, se eliminó o se renombró.

<div id="restore-access">
  ## Restaurar el acceso
</div>

1. Selecciona **Open Git settings** en el aviso para abrir la página de [configuración de Git](https://app.mintlify.com/settings/project/git-settings) de tu dashboard.
2. Confirma que la organización, el repositorio y la rama coinciden con la ubicación actual de tu documentación. Actualízalos si el repositorio o la rama cambiaron.
3. Si usas GitHub, confirma que la GitHub App de Mintlify todavía tiene acceso al repositorio. Consulta [Administrar el acceso al repositorio](/es/deploy/github#manage-repository-access).
4. Vuelve al editor y selecciona **Reload editor**.

Para más información sobre cómo conectar tu repositorio, consulta [GitHub](/es/deploy/github) o [GitLab](/es/deploy/gitlab).
