Si tu proveedor de Git está detrás de una lista de IPs permitidas o de un firewall, tienes que permitir las conexiones que Mintlify hace hacia él. La plataforma de Mintlify se conecta a los proveedores de Git por HTTPS (puerto 443) desde una única dirección IP estática de egreso:

```text
54.242.90.151
```

Añade esta dirección IP a tu lista de permitidas cuando:

- Tu organización de GitHub Enterprise Cloud tenga habilitada una lista de IPs permitidas. Consulta [GitHub Enterprise con listas de IPs permitidas](/es/deploy/github#github-enterprise-with-ip-allowlists).
- Un firewall o una lista de IPs permitidas restrinja el acceso entrante a tu instancia de GitHub Enterprise Server. Consulta los [requisitos de red de GHES](/es/deploy/ghes#network-requirements).
- Un firewall o una lista de IPs permitidas restrinja el acceso entrante a tu instancia de GitLab autoalojada. Consulta los [requisitos de red de GitLab autoalojado](/es/deploy/gitlab-self-hosted#network-requirements).

## Ejecuciones del agente y de automatizaciones

Las ejecuciones del [agente](/es/agent) clonan y hacen push desde una infraestructura sandbox independiente. Ese tráfico usa direcciones IP dinámicas por defecto, por lo que permitir `54.242.90.151` no lo cubre. El soporte de Mintlify puede enrutar el tráfico Git del agente de una implementación a través de la IP estática si se solicita. Consulta [Solucionar ejecuciones del agente bloqueadas por una lista de IPs permitidas](/es/help-center/agent-blocked-by-git-provider-ip-allow-list).

## Tráfico desde tu servidor Git hacia Mintlify

El tráfico en el otro sentido funciona de manera diferente. Tu instancia envía eventos de webhook a nombres de host de Mintlify como `leaves.mintlify.com` y `app.mintlify.com`. Autoriza ese tráfico saliente por nombre de host. Mintlify no publica una lista estática de direcciones IP para esos endpoints, y sus direcciones IP subyacentes pueden cambiar.
