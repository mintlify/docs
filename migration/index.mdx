Move your existing documentation to Mintlify with a coding agent, the Mintlify scraper, export or source files, or a manual migration. You can combine methods, for example scraping a public site for a first draft and then filling in private pages from an export.

## Choose a migration method

| Method | How it works | Best for |
| --- | --- | --- |
| [Coding agent](#migrate-with-a-coding-agent) | Run `mint migrate` to have Claude Code, Codex, Cursor, or Gemini convert your pages to MDX and build navigation and redirects. | Any platform that `mint migrate` supports, including Docusaurus, MkDocs, GitBook, ReadMe, Confluence, Notion, and PDF. |
| Scraper | Run the `@mintlify/scraping` package against a public site to convert its pages to MDX. | Public Docusaurus, ReadMe, and GitBook sites when you want a fast starting point. |
| [Export or source files](#platform-guides) | Convert files you export from your current platform, or migrate from the repository that builds your site. | Private pages, versioned docs, localized content, OpenAPI files, and custom components that a scraper can't reach. |
| [Manual migration](/migration/manual) | Collect, convert, and organize your content yourself. | Platforms without an automated path, or projects that mix content from several sources. |

## Migrate with a coding agent

The [CLI](/cli/install) prints migration instructions written for AI coding agents. Run `mint migrate` to see the workflow and the supported source platforms, or start an agent that follows the instructions in the current directory.

```bash Example migration command
mint migrate --agent claude --from docusaurus
```

See [`mint migrate`](/cli/commands#mint-migrate) for the supported agents, platforms, and flags.

## Scrape individual pages

The Docusaurus, ReadMe, and GitBook guides use the scraper's `section` command, which converts every page it can reach from the URL you give it. To convert a single page instead, use the `page` command from your migration directory.

```bash
npx @mintlify/scraping@latest page https://docs.example.com/getting-started
```

Use `page` to check how the scraper converts your content before a full run, or to fill in individual pages that a `section` run missed. For a large site, narrow a `section` run with `--filter` rather than scraping everything at once.
