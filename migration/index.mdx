`mint migrate` prints migration instructions written for coding agents. Your agent follows them to inventory your pages, convert them to MDX, build `docs.json` navigation and redirects, and check the result.

## Run a migration

[Install the CLI](/cli/install), then run one of these from an empty directory:

```bash
# Print the instructions for your agent to follow
mint migrate --from docusaurus

# Or start an agent that runs the migration
mint migrate --agent claude --from docusaurus
```

`--agent` accepts `claude`, `codex`, `cursor`, or `gemini`. The agent's CLI must already be installed. Run `mint migrate` without flags to see the full workflow.

## Workflow topics

Each step of the migration has its own instructions. Print one with `mint migrate --topic <name>`:

- `discovery`: find the source and list every page.
- `conversion`: convert pages to MDX.
- `navigation`: build `docs.json` navigation and redirects.
- `api`: migrate an API reference.
- `changelog`: migrate a changelog.
- `verify`: check the finished migration.

## When it's done

The migration is complete when `mint validate` and `mint broken-links` both pass and every source URL resolves on the new site. The agent ends with a report of anything it couldn't carry over.

See [`mint migrate`](/cli/commands#mint-migrate) for the full flag reference.
