## What is Mintlify

Mintlify is a documentation platform. You write pages in MDX, keep them in a Git repository, and Mintlify builds and hosts the site. Edit locally with the [CLI](/cli/index) or in the browser with the [web editor](/editor/index).

Every site is built for AI as well as people:

- **[Assistant](/assistant)** answers reader questions from your docs.
- **[Agent](/agent)** and **[automations](/automations/index)** draft updates as pull requests.
- **`llms.txt`, `skill.md`, and an [MCP server](/ai/model-context-protocol)** let AI tools read your docs. Any page is available as Markdown by adding `.md` to its URL.

## Deploy your site

Go to [mintlify.com/start](https://mintlify.com/start) and finish onboarding. Connect GitHub to deploy on every push, or skip it and Mintlify hosts the repository for you.

Your site goes live at `https://<your-project>.mintlify.site`. Find the URL on the [Publishes](https://app.mintlify.com/publishes) page.

Moving from another platform? See [Migrate to Mintlify](/migration).

## Make your first change

<Tabs>
  <Tab title="CLI">
    1. Install the CLI. It needs Node.js v20.17.0 or newer and doesn't run on Node.js 25.

       ```bash
       npm i -g mint
       ```

    2. Clone your repository and edit the `description` in `index.mdx`.
    3. Run `mint dev` and open `http://localhost:3000`.
    4. Commit and push. Mintlify deploys the change.
  </Tab>
  <Tab title="Web editor">
    1. Open the [web editor](https://app.mintlify.com/editor).
    2. Edit the description on the **Introduction** page.
    3. Click **Publish**.
  </Tab>
</Tabs>

## Plans and credits

AI features such as the assistant, agent, and automations use credits. Each Pro plan includes 10,000 credits per month, shared across your organization. See [Credit pricing](/credits) for what each action costs and [mintlify.com/pricing](https://mintlify.com/pricing) for plans.
