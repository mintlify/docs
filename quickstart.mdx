## Deploy your site

<Visibility for="humans">
  Go to [mintlify.com/start](https://mintlify.com/start) and complete onboarding. Name your project, optionally connect GitHub for automatic deployments, then describe the docs you want to build. Add links, files, or repositories as sources and the Mintlify agent generates a starting point with a live preview. To start from placeholder content, select **Skip, start from a blank template**.

  <Accordion title="Skip connecting a Git provider">
    Mintlify creates a private repository for you so you can use the web editor immediately. To move to your own repository later, use the wizard in [Git Settings](https://app.mintlify.com/settings/project/git-settings). See [Clone to your own repository](/deploy/github#clone-to-your-own-repository).
  </Accordion>
</Visibility>

<Visibility for="agents">
  Use the preceding CLI setup workflow. Initiate the corresponding `mint signup` or `mint login` command. Account verification and GitHub authorization open browser pages; have the user approve them. Continue the setup when they finish. Do not consider setup complete until `mint status` reports a subdomain and the deployed `.mintlify.site` URL loads.
</Visibility>

Your site is live at `https://<your-project-name>.mintlify.site`. Find the exact URL on the **Overview** page of your [dashboard](https://app.mintlify.com/). Add a [custom domain](/customize/custom-domain) before sharing with users.

## Make your first change

Every page on your site is a file in your documentation <Tooltip tip="Your documentation's source code where all files and their history are stored.">repository</Tooltip>. Edit locally or in the web editor, and Mintlify deploys when changes reach your repository.

<Tabs>
  <Tab title="CLI">
    <Steps>
      <Step title="Install the CLI">
        Requires [Node.js](https://nodejs.org/en) v20.17.0 or higher.

        <CodeGroup>

        ```bash npm
        npm i -g mint
        ```

        ```bash pnpm
        pnpm add -g mint
        ```

        </CodeGroup>

        See [Install the CLI](/cli/install) for troubleshooting.
      </Step>
      <Step title="Clone and edit">
        Clone your repository, then update the `description` in the frontmatter of `index.mdx`.

        ```bash
        git clone <your-repository-url>
        ```

        If your repository is in Mintlify's private organization, [clone it to your own account](/deploy/github#clone-to-your-own-repository) first.
      </Step>
      <Step title="Preview locally">
        Run `mint dev` from your docs directory and open `http://localhost:3000`.
      </Step>
      <Step title="Push to deploy">
        ```bash
        git add . && git commit -m "Update description" && git push
        ```

        Track deployment status on the [Overview](https://app.mintlify.com/) page of your dashboard.
      </Step>
    </Steps>
  </Tab>
  <Tab title="Web editor">
    <Steps>
      <Step title="Edit a page">
        Open the [web editor](https://app.mintlify.com/editor), select the **Introduction** page, and update the description.

        <Frame>
          <img
            alt="Introduction page open in the web editor with the description edited to say Hello world!."
            className="block dark:hidden"
            src="/images/quickstart/hello-world-light.png"
          />
          <img
            alt="Introduction page open in the web editor with the description edited to say Hello world!."
            className="hidden dark:block"
            src="/images/quickstart/hello-world-dark.png"
          />
        </Frame>
      </Step>
      <Step title="Publish">
        Click **Publish** in the toolbar. When the deployment finishes on your dashboard's [Overview](https://app.mintlify.com/) page, refresh your site to see the change.
      </Step>
    </Steps>
  </Tab>
</Tabs>
