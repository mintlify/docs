Deploy a live documentation site and ship your first change in about five minutes.

Mintlify is docs-as-code: every page on your site maps to a file in your documentation <Tooltip tip="Your documentation's source code where all files and their history are stored. The web editor connects to your documentation repository to access and modify content, or you can edit files locally in your preferred IDE.">repository</Tooltip>. Edit in the web editor or locally, and changes sync to your repository either way.

## Deploy your site

<Visibility for="humans">
  Go to [mintlify.com/start](https://mintlify.com/start) and complete onboarding:

  1. **Name your project** and answer a few questions about how you'll use it.
  2. **Connect GitHub** (optional) and install the GitHub App to enable automatic deployments.
  3. **Describe the docs you want to build.** Add links to an existing site, upload files, or select GitHub repositories as sources. The Mintlify agent generates a starting point while you watch a live preview. To start from placeholder content instead, select **Skip, start from a blank template**.

  <Accordion title="Skip connecting a Git provider">
    Skip the Git connection and Mintlify creates a private repository for you with the GitHub App preconfigured, so you can use the web editor immediately. To move to your own repository later, use the Git setup wizard in [Git Settings](https://app.mintlify.com/settings/project/git-settings). See [Clone to your own repository](/deploy/github#clone-to-your-own-repository).
  </Accordion>
</Visibility>

<Visibility for="agents">
  Use the preceding CLI setup workflow. Initiate the corresponding `mint signup` or `mint login` command. Account verification and GitHub authorization open browser pages; have the user approve them. Continue the setup when they finish. Do not consider setup complete until `mint status` reports a subdomain and the deployed `.mintlify.site` URL loads.
</Visibility>

When onboarding finishes, your site is live at `https://<your-project-name>.mintlify.site`. Find the exact URL on the **Overview** page of your [dashboard](https://app.mintlify.com/).

## Make your first change

<Tabs>
  <Tab title="Web editor" icon="mouse-pointer-2">
    <Steps>
      <Step title="Edit a page">
        Open the [web editor](https://app.mintlify.com/editor), select the **Introduction** page, and update the description.

        <Frame>
          <img
            alt="Introduction page open in the web editor with the description edited to say Hello world!."
            className="block dark:hidden"
            src="/images/quickstart/hello-world-light.png"
          />
          <img
            alt="Introduction page open in the web editor with the description edited to say Hello world!."
            className="hidden dark:block"
            src="/images/quickstart/hello-world-dark.png"
          />
        </Frame>
      </Step>
      <Step title="Publish">
        Click **Publish** in the top-right of the toolbar. Track the deployment on the [Overview](https://app.mintlify.com/) page, then refresh your site to see the change live.
      </Step>
    </Steps>
  </Tab>
  <Tab title="CLI" icon="terminal">
    <Steps>
      <Step title="Install the CLI">
        Requires [Node.js](https://nodejs.org/en) v20.17.0 or higher (LTS recommended).

        <CodeGroup>

        ```bash npm
        npm i -g mint
        ```

        ```bash pnpm
        ```

        </CodeGroup>

        See [Install the CLI](/cli/install) for troubleshooting.
      </Step>
      <Step title="Clone and edit">
        Clone your repository, then open `index.mdx` and update the `description` in the frontmatter:

        ```bash
        git clone <your-repository-url>
        ```

        ```mdx index.mdx
        ---
        title: "Introduction"
        description: "Your custom description here"
        ---
        ```

        If your repository lives in Mintlify's private organization, [clone it to your own account](/deploy/github#clone-to-your-own-repository) first.
      </Step>
      <Step title="Preview and push">
        Run `mint dev` from your docs directory and preview at `http://localhost:3000`. When it looks right, push to deploy:

        ```bash
        git add . && git commit -m "Update description" && git push
        ```

        Mintlify deploys automatically. Track status on the [Overview](https://app.mintlify.com/) page.
      </Step>
    </Steps>
  </Tab>
</Tabs>
