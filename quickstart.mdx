## Before you begin

Mintlify uses a docs-as-code approach. Every page on your site is a file in your documentation <Tooltip tip="Your documentation's source code where all files and their history are stored. The web editor connects to your documentation repository to access and modify content, or you can edit files locally in your preferred IDE.">repository</Tooltip>, and you can edit locally or in the web editor and sync changes to your remote repository.

## Deploy your documentation site

<Visibility for="humans">
  Go to [mintlify.com/start](https://mintlify.com/start) and complete onboarding: name your project, answer a few questions, and optionally connect GitHub to enable automatic deployments.

  In the final step, describe the docs you want and add sources like existing site links, files, or GitHub repositories. The Mintlify agent generates a starting point while you watch a live preview. To use placeholder content instead, select **Skip, start from a blank template**.

  Your site then deploys to your `.mintlify.site` URL.

  <Accordion title="Optional: Skip connecting a Git provider during onboarding">
    If you skip the Git connection, Mintlify creates a private repository in a private organization and configures the GitHub App for you, so you can use the web editor immediately. To move to your own repository later, use the Git setup wizard in [Git Settings](https://app.mintlify.com/settings/project/git-settings). See [Clone to your own repository](/deploy/github#clone-to-your-own-repository).
  </Accordion>
</Visibility>

<Visibility for="agents">
  Use the preceding CLI setup workflow. Initiate the corresponding `mint signup` or `mint login` command. Account verification and GitHub authorization open browser pages; have the user approve them. Continue the setup when they finish. Do not consider setup complete until `mint status` reports a subdomain and the deployed `.mintlify.site` URL loads.
</Visibility>

## Make your first change

<Tabs>
  <Tab title="CLI">
    <Steps>
      <Step title="Install the CLI">
        Requires [Node.js](https://nodejs.org/en) v20.17.0 or higher (LTS recommended).

        <CodeGroup>

        ```bash npm
        npm i -g mint
        ```

        ```bash pnpm
        pnpm add -g mint
        ```

        </CodeGroup>

        See [Install the CLI](/cli/install) for troubleshooting.
      </Step>
      <Step title="Clone your repository">
        ```bash
        git clone <your-repository-url>
        ```

        If your repository is in Mintlify's private organization, first [clone it to your own repository](/deploy/github#clone-to-your-own-repository).
      </Step>
      <Step title="Edit a page">
        In `index.mdx`, update the frontmatter description:

        ```mdx
        ---
        title: "Introduction"
        description: "Your custom description here"
        ---
        ```
      </Step>
      <Step title="Preview locally">
        From your documentation directory, run:

        ```bash
        mint dev
        ```

        Your preview runs at `http://localhost:3000`.
      </Step>
      <Step title="Push your changes">
        Commit and push to deploy:

        ```bash
        git add .
        git commit -m "Update description"
        git push
        ```

        Track deployment status on your dashboard's [Overview](https://app.mintlify.com/) page.
      </Step>
    </Steps>
  </Tab>
  <Tab title="Web editor">
    <Steps>
      <Step title="Open the web editor">
        Go to the [web editor](https://app.mintlify.com/editor).
      </Step>
      <Step title="Edit a page">
        Open the **Introduction** page and update the description.

        <Frame>
          <img
            alt="Introduction page open in the web editor with the description edited to say Hello world!."
            className="block dark:hidden"
            src="/images/quickstart/hello-world-light.png"
          />
          <img
            alt="Introduction page open in the web editor with the description edited to say Hello world!."
            className="hidden dark:block"
            src="/images/quickstart/hello-world-dark.png"
          />
        </Frame>
      </Step>
      <Step title="Publish">
        Click **Publish** in the top-right of the toolbar.
      </Step>
      <Step title="View live">
        When deployment finishes on your dashboard's [Overview](https://app.mintlify.com/) page, refresh your site to see the changes.
      </Step>
    </Steps>
  </Tab>
</Tabs>
