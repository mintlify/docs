### Commands

- `mint dev`: Preview docs at `localhost:3000` with live reload. Log in for search and AI assistant.
- `mint broken-links`, `mint a11y`, `mint validate`: Check links, accessibility, and build validity.
- `mint score`: Score agent readiness for your subdomain or any URL.
- `mint format`: Rewrite MDX files to Mintlify's canonical style.
- `mint config`: Set persistent defaults like your subdomain.

<Tip>
  Working locally with an AI coding tool? Install the Mintlify [skill](/ai/skillmd) and [MCP server](/ai/model-context-protocol), and run [`mint index`](/cli/commands#mint-index) to give agents a context tool for external libraries and APIs.
</Tip>
