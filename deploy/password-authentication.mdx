<Info>
  Password authentication requires a [Pro or Enterprise plan](https://mintlify.com/pricing?ref=authentication).
</Info>

Password authentication puts your whole site behind one shared password. Use it when you need to keep content out of public view and don't need to know who each reader is.

Because every reader uses the same password, password authentication doesn't support [groups](/deploy/groups), [personalization](/create/personalization), or API playground prefilling. If you need any of those, use [OAuth](/deploy/oauth-authentication), [JWT](/deploy/jwt-authentication), or [emails](/deploy/emails-authentication) authentication.

## Prerequisites

- Your security requirements allow sharing one password among readers.

## Set up password authentication

<Steps>
  <Step title="Create a password.">
    1. In your dashboard, go to [Access](https://app.mintlify.com/settings/project/authentication).
    2. Set **Visibility** to **Private**.
    3. Set **Method** to **Password**.
    4. Enter a secure password.
    5. Click **Save**.

    After you save, your site redeploys. When it finishes deploying, anyone who visits your site must enter the password to read your content.
  </Step>
  <Step title="Share access.">
    Securely share the password and your documentation URL with the people who need access.
  </Step>
</Steps>

To keep some pages readable without the password, [make them public](/deploy/authentication-setup#make-pages-public).
